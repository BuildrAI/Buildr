# Buildr 文档导航

当前产品与技术的解释统一从 [当前知识](../knowledge/README.md) 阅读；本目录保留导航、历史审计、历史资料、规划和对外文章。它们的用途不同，不作为并列的当前说明维护位置。

| 内容 | 入口 | 如何使用 |
|---|---|---|
| 当前解释 | [具体文档目录](../knowledge/docs/README.md) | 产品概览、概念与术语、架构、流程、服务和使用开发指南 |
| 实现定位 | [代码地图](../knowledge/code-map/README.md) | 从功能、对象和调用定位当前实现 |
| 技术关系 | [技术图](../knowledge/archify/index.md) | 阅读图表并回查图源和依据 |
| 规范承诺 | [OpenSpec 规范](../openspec/specs/) | 判断应有行为；与代码冲突时处理真实差异 |
| 进行中与历史变更 | [变更目录](../openspec/changes/) | 理解一次变更的目标、决定与结果，不当作当前行为全集 |
| 未来方向 | [规划索引](roadmap/README.md)、[产品方向汇总](roadmap/product-directions.md) | 规划或当时设想；采用前核对当前实现和授权 |
| 历史审计 | [验证证据审计](verification-evidence-audit.md)、[指令审计](astra-instruction-audit.md)、[命名兼容记录](buildr-web-naming-compatibility.md) | 保存当时观察，不随当前代码自动重写 |
| 历史资料 | [历史目录](archive/) | 原始方案、记录和模板，仅供历史参考 |
| 对外文章 | [文章索引](publications/README.md) | 保留发表语境，按文章维护目标更新 |
| 旧路径去向 | [目录迁移导航](../knowledge/migration.md) | 找回历史材料中引用的已迁移当前说明 |

服务内随包分发的参考文档保留唯一正文，包括 [命令参考](../services/buildr/docs/cli-reference.md)、[运行时支持](../services/buildr/docs/agent-runtime-adapters.md)、[接入指南](../services/buildr/docs/agent-runtime-adapter-contribution.md)和[已知限制](../services/buildr/docs/known-limitations.md)。统一知识入口引用它们，不再复制一份当前说明。
