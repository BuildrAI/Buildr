# 文章与工作空间设置交互预览

本轮按用户要求展示完整页面及可操作流程。现有页面与前端源码已核对；预览沿用 Buildr 的顶部双入口、侧栏、主内容宽度、页面页签、表单和抽屉视觉。

## 打开方式

打开同目录 `article-workspace.html`，也可以用静态文件服务器访问。文件包含全部样式、图标、示例内容与交互脚本，不依赖真实后端。

入口片段：

- `#list`：文章目录。
- `#article/more-and-better`：文章阅读。
- `#edit/more-and-better`：文章编辑。
- `#project/product`：项目主页，只保留项目关注。
- `#workbench`：关注的项目和收藏的具体资料。
- `#catalog`：工作空间选择卡片。
- `#settings/buildr`：工作空间设置抽屉。

## 本次设计

1. 文章以项目归属组织，工作空间聚合；列表支持搜索、项目和稿件状态筛选、排序、收藏及刷新。阅读页提供目录、正文、原文、发布记录及相关资料。
2. 新建、编辑、删除确认与 Markdown 导出可以在预览中直接操作。起草、润色、审校和平台改写提供目标与材料输入，只准备可复制的智能体（Agent）工作请求；不表示已有专项技能或任务已经执行。
3. 项目显示关注，文章和资料显示收藏；两类入口分别在工作台呈现。界面调整不应删除既有偏好记录，也不暗示通知订阅。
4. 设置移出侧栏。顶部工作空间选择菜单提供当前工作空间设置，卡片齿轮提供该卡片的设置，统一打开右侧抽屉。保留名称、说明和辅助辨认的本地目录，不展示编号、数据格式版本和修订值。
5. 正式实施仍须保留工作空间身份、当前版本校验、冲突时的输入和异常提示；卡片操作必须显式读取和保存对应工作空间，不能借用全局当前对象。

- referenceBoundary: 非正式设计、非生产原型、非像素级验收。当前文章只读及设置展示等正式规范仍有效，实施时需同步更新相关设计与规范。
