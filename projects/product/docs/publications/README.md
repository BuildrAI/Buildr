# Buildr 对外发布材料

本目录维护 Buildr 准备对外发布的文章和其他公开材料。

项目文件是内容源。文章可以发布到墨问、微信公众号、Local App 或其他平台；平台只记录为发布目标，不在平台目录中维护第二份内容。

## 维护约定

- 先在本目录完成写作、审校和版本修改，再发布到外部平台。
- 同一篇文章可以对应多个发布目标，不按平台拆分目录。
- `status` 表示文章源的状态，`targets` 表示各平台的发布状态。
- 已发布文章保留原始平台链接；后续修改应在项目文件中完成，再决定是否同步更新平台内容。
- 本目录暂不承载产品规范、当前实现事实或内部研发过程文档。
