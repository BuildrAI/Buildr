# 代码库列表顶部布局修复说明

本文覆盖 Buildr Web 代码库目录头的窄栏布局问题，并解释共享目录的适配方式、验证范围与交付遗留。对应任务为 `repository-header-layout`；代码修复提交为 `b48b3557e870781eccc85e492215ccbc9892afcd`。本文是在用户指出交付缺少独立文档后补写，不是开发前已完成的方案，也不替代任务记录（Task Record）或验证报告（Task Verification Report）。

## 目标与现象

用户提供的画面中，代码库列表与右侧详情同时显示。左侧目录头把“工作空间”“代码库”和说明挤成逐字竖排，顶部占据大量高度，搜索和列表被推到下方。

修复目标是让标题、说明和操作在分栏后的可用宽度内保持可读、可操作；不改变新增、规范化、刷新、编辑、移除等操作的业务行为。

## 原因与来源

[共享目录组件（Component）](../../../services/buildr-web/src/components/ResourceDirectory.tsx#L33-L38)把标题说明与操作区放在同一个横向排列的目录头内。[代码库页面](../../../services/buildr-web/src/features/repository/pages/RepositoriesPage.tsx)额外提供“规范化旧登记”和“新增代码库”按钮，连同刷新按钮占用较大的固定宽度。

原样式不允许操作区收缩，标题说明则被压缩。窄屏规则依据整个浏览器窗口的宽度触发，不能反映宽窗口中左侧分栏已经很窄的事实。因此，宽窗口仍可能出现逐字竖排。

## 修复方式与边界

修改集中在[共享目录样式](../../../services/buildr-web/src/styles.css#L2019-L2026)及其[容器宽度适配规则](../../../services/buildr-web/src/styles.css#L2115-L2124)：

- 标题说明区可使用剩余空间，避免由内容的最小宽度造成溢出。
- 操作区允许自然换行，并限制在目录可用宽度内。
- 目录内容宽度不超过 680 像素时，上下排列标题说明与操作区；标题说明使用完整栏宽，操作区取消原来的顶部偏移。
- 宽栏仍保持标题说明与操作区左右排列。

容器查询（Container Query）判断的是目录自身宽度，不是整个窗口宽度。这一规则由共享目录组件（Component）复用，影响项目、服务、代码库与技能目录头；未重画应用外围，也未修改详情页面或数据写入逻辑。
