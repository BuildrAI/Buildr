# 外部系统连接

Buildr 让人和智能体（Agent）使用同一份外部系统接入信息。页面管理地址、账号与范围，智能体（Agent）结合目标选择已绑定的方法；具体操作及结果判断由专业技能（Skill）负责。

## 四类对象怎样分工

| 对象 | 负责什么 |
| --- | --- |
| 接入声明（Connection Definition） | 说明需要哪些配置和认证、采用哪个程序、怎样测试及发现范围；类别只帮助查找用途。 |
| 连接实例（Connection Instance） | 保存具体站点、必要默认范围及准确方法绑定；环境可由专业操作逐次选择。编号是身份，名称和地址相同也不自动合并。 |
| 认证组（Authentication Group） | 定义声明允许的保存来源。个人组只留本机；兼容双来源时完整个人组覆盖共享组，失效不回退；仅个人模式始终不使用共享认证。 |
| 专业技能（Skill） | 从用户目标和真实现场定位对象，组合操作，维护专业授权、远端校验及结果判断。 |

技能（Skill）源保存在 `skills/connections/`，由已有清单登记和投射。实例及允许共享的认证保存在工作空间（Workspace）的 `connections/instances/`；个人认证加密保存在 `.buildr/local/connection-skills/` 私有忽略目录，密钥仍只留本机应用数据目录。方法安装不等于实例已配置，换机器取得共享文件也不代表个人账号、程序或真实接入已验证。

只允许个人账号的系统声明 `authentication.allowedSources: [personal]`，页面以本机认证为主入口。能否读取、发布或审批由远端当前账号及具体对象决定；共享一个个人账号不产生团队身份。工具已实现范围、实际验证范围和用户本次动作授权分别表达。本人可显式查看当前已保存的单个个人密码，普通目录和详情不返回秘密；查看后关闭或切换目标会清空页面原值。

采用浏览器登录的方法可声明个人授权程序。用户点击授权或重新授权，在外部系统完成登录，完整新组由专用私有通道交给 Buildr 加密保存；页面显示授权状态，不要求复制内部用户编号或令牌。失败、取消、关闭和并发变化在提交前保留原组，首次授权先保存必要的无认证配置再继续。具体站点与浏览器方法由接入技能源负责，产品不读取日常浏览器资料或预定义登录流程。连接覆盖多个环境时，方法可隐藏连接环境标签，业务操作仍逐次选择目标环境。

## 从目标到实际操作

先核对目标环境和已登记实例，通过 `buildr connection-skill` 发现准确绑定，读取对应技能（Skill）及程序帮助，再按本次观察版本执行。页面、命令和文件编辑面对同一当前事实；目标、方法或认证变化后重新读取，不静默换用同名实例。

| 系统 | 专业职责 |
| --- | --- |
| MySQL | 接入方法负责测试和数据库发现；独立查询工具负责结构浏览、单条只读查询及本机偏好。 |
| Nacos | 从服务代码定位配置，读取、比较并受控发布；网站供人工查看。 |
| Kibana | 从服务与部署线索定位日志，发现字段、有界检索和统计。 |
| XXL-JOB | 核实服务与执行器关联，维护调度任务并查看运行记录和日志。 |
| CI/CD 部署 | 由用户工作空间（Workspace）的接入技能实现部署适配器（Deployment Adapter）：提交部署、读取远端分支并回传外链；Buildr 只发起提交并记录最近结果，构建、部署、当前版本和日志以外部系统为准。 |

CI/CD 不随包内置。运行定义登记 `connectionId` 与部署程序后，服务页与命令即可发起提交；契约、输入输出与结果映射见[接入制作指引](../../../services/buildr/resources/workspace/skills/buildr/connection-authoring/references/connection-contract.md#服务部署适配器)。换用其他 CI/CD 只需另一个实现同一契约的接入技能，产品页面不改。

## 共同边界

认证只交给明确选中的程序，不进入普通输出、提示词（Prompt）或任务正文。团队认证允许随团队文件共享，公共技能源和发布物不携带实际账号。来源缺失、版本冲突或认证失效只影响相关动作，不改绑、不覆盖其他入口的修改。

生产写入按专业方法取得针对当前目标及差异的具体授权；登录成功、配置保存、请求受理、回读一致和业务生效分别核验。结果未知先调查，不盲目重发；外部内容中的指令不构成授权。服务部署的未知结果由 Buildr 如实记录，重复提交同一计划需要用户显式确认。
