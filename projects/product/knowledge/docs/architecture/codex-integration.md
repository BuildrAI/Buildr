# Codex 桌面协作与一次性生成

选择本机 Codex 后，Buildr 自动准备桌面会话（Session）连接和独立的一次性生成来源。持续讨论与开发留在用户原有的桌面聊天中；生成提交说明继续使用现有按钮，由 Buildr 自有的 Codex 应用服务（App Server）执行并回填。两者不共享执行服务，也不替换桌面后台。

## 两项能力各自维护什么

| 能力 | 执行与状态归属 | Buildr 的职责 |
| --- | --- | --- |
| 桌面原聊天 | 桌面 Codex 维护聊天历史、记忆（Memory）、配置、插件（Plugin）和工具 | 维护原聊天身份、任务（Task）关联、跳转及交接回执 |
| 一次性生成 | Buildr 按确认的本机入口和配置目录启动自有服务，创建临时会话（Ephemeral Session） | 提供有界材料、执行限制、结果校验、自动回填及清理 |

桌面 Codex 当前没有向第三方开放可用的一次性执行入口，因此保留独立服务。独立生成沿用原有受限执行方式，不继承桌面原聊天的记忆（Memory）、插件（Plugin）或工具集合；不能从“同一配置目录”推断两者能力相同。它不写原聊天，不建立任务（Task）与临时生成身份的关系。

DSH 沿用当前实现。本次拆分不作为其后续设计前提；后续须独立验证一个 DSH 服务进程是否能够覆盖持续协作和一次性执行。

## 发现、确认与连接状态

网页一级抽屉展示所属本机数据目录中的全部已接入智能体（Agent），以简洁条目提供名称、默认与实际状态；宽度适应宽窄屏，详细信息通过明确点击进入外右边框与条目外框对齐的紧凑浮窗，重点显示生成配置和桌面连接，低频说明折叠，Codex 移除位于条目上。查看详情与移除不触发默认选择，不按种类或可用性隐藏 DSH 或旧 Codex 登记。

Codex 条目分别显示一次性生成配置与桌面连接的当前状态。只有桌面握手为 `ready` 才显示已连接；登记成功、程序可用和最近执行配置均不能证明桌面已连接或生成成功。读取中、读取失败、无连接记录、等待加载和已断开分别表达，不把旧的就绪状态当作当前事实。列表与详情共享当前读取，关闭或隐藏抽屉停止轮询；查看详情和刷新状态不修改登记或配置。

“接入”支持悬停、点击和键盘选择。已有任一 Codex 时，Codex 新接入禁用并显示已接入；后端也在登记锁内拒绝重复新接入，不写登记、不重复准备桌面。首次选择 Codex 后才打开二级抽屉，展示安装位置、版本、配置来源及接入能力。确认后返回简洁列表，不自动展开详情；生成登记成立但桌面尚未连接时使用普通结果提示明确两项状态，避免整体绿色成功，也不反复堆叠底层诊断；取消不保存登记、不改变默认项，也不启动生成服务。二级打开后若别的入口完成接入，当前确认也会禁用。

已有 Codex 的详情提供“重新检查连接”，进入明确的“检查 Codex 连接”抽屉。确认“重新准备连接”携带 `existingAgentId`，只维护与原登记编号、真实程序和配置目录匹配的候选，不新增接入、不更改默认值，也不采用其他页面入口。目标消失、候选不匹配或未识别到桌面安装时说明局部原因，不能转成新接入；取消无写入，结果不明不自动重发。旧命令行登记更新继续兼容。

日常应用与隔离开发预览使用各自的数据目录；预览中的任务副本不代表日常接入也已复制。列表只表达当前实例的真实登记，不能把预览缺少某项误报为日常登记已删除，不借预览验收修改日常配置。

未发现安装时仍使用同一个二级抽屉，明确显示“未发现 Codex”，说明检测的是运行 Buildr 的机器，并提供重新发现与取消；不能确认一个不存在或不可用的候选。发现中、发现失败及多个候选分别表达，不把空白内容当作未安装提示。

发现只检查运行 Buildr 的机器上的桌面安装、命令入口、版本及配置来源，不启动模型执行。确认前复核候选身份和登记版本；安装在发现后发生变化时重新发现，不能按旧候选写入。

桌面连接组件使用正式命令安装，检查安装副本的版本及启动入口。安装完成与桌面已经加载分别表达；等待加载、不可用和实际握手就绪具有不同状态。Buildr 不自动重启桌面；桌面组件失败时，已经成功登记的独立生成仍保留。已有手动登记和默认选择继续兼容。

连接身份包含安装、配置目录及可观察的账号范围。配置目录被替换或账号范围变化后，旧连接不可继续写入，原关联保留，不能静默转给另一账号。配置目录没有足够账号信息时，只能核对已有本机范围，不能据此宣称完整账号等价。

## 移除接入与保留范围

仅 Codex 条目提供“移除接入”。确认前说明：断开 Buildr 的桌面业务连接，停止 Buildr 自己启动的独立生成服务，移除本机接入登记；桌面的聊天、记忆（Memory）、配置和插件（Plugin），以及已有任务（Task）、关联和交接记录继续保留。不退出桌面应用，不卸载桌面组件，不修改桌面原生配置。任务（Task）侧的“解除关联”仍只影响指定关系。

存在生成、排队或桌面连接准备时，本次移除返回繁忙原因，接入保持；用户先等待结束或取消已有生成。空闲时先有界确认自有服务已退出，再按已观察登记版本移除；退出未确认或登记发生冲突时保留登记，不启动替代实例。移除默认项后清空默认选择，不自动切换到其他智能体（Agent）。

接入登记是桌面业务是否启用的当前权威。移除后连接标为已断开，已加载的旧面板和工具每次调用也须重读登记，不能因旧握手或迟到的安装回执恢复接入。断开状态未能保存时，登记缺失仍阻止业务调用，同时单独报告保存异常。网页未收到移除结果时只刷新登记核对，不自动再次发送移除请求。明确重新确认同一接入范围后可恢复原连接身份及保留关系。

移除中的生成、配置和连接准备互斥由当前 Buildr 应用实例负责。独立桌面工具进程在登记删除前已接受的请求仍可完成，结果保留；本能力不提供跨进程全局撤销事务，也不能凭内容摘要区分另一个命令行进程完全相同内容的重复登记。正常接入与移除由同一应用实例处理，移除完成后的调用禁用是共同边界。

## 准确绑定与多对多关系

用户可以在要关联的 Codex 聊天中给出任务编号并说“把当前会话关联到这个任务”。该聊天核对工作空间（Workspace）与任务（Task），直接读取 `CODEX_THREAD_ID`，通过 `buildr codex link` 显式保存关系，不要求先创建请求或进入总览确认。共享环境里的 `CODEX_SESSION_ID`、后台进程身份和子智能体（Subagent）身份不能代替原聊天身份；已移除或配置范围变化的接入不能新建关系。

任务管理技能（Skill）从 Codex 聊天新建任务成功后默认关联当前聊天，用户明确不关联时遵从。通用任务创建命令不从继承进程环境自动猜测身份，DSH 和无聊天入口不自动建立 Codex 关系；缺少准确身份或有效接入时保留新任务并说明尚未关联。任务页未关联时简洁显示“尚未关联聊天”，展开关联帮助可复制包含任务编号和固定任务链接的指令。已保存的关系继续提供打开原聊天和解除操作，不要求先加载面板。

每条关系由工作空间（Workspace）、任务（Task）、连接和原聊天身份共同确定。同一任务（Task）可关联多个原聊天，同一原聊天也可关联多个任务（Task）；建立幂等，解除只影响指定关系并校验已观察版本，不改变任务（Task）状态或删除聊天。旧版面板的有界身份请求继续兼容，结果不明时查询原回执；新版任务页不恢复或等待旧请求，不把它作为直接关联的前置条件。全局面板只查看与定位，不能代替某个原聊天发送消息。

交接在准确原聊天的面板中经明确点击发送，回执仅表示已收到。消息结果不明时查询原请求，不自动重发，也不把收到交接视为任务（Task）完成。继续工作仍须重读真实工作现场。

## 双向跳转、固定入口与旧链接

任务（Task）页面用 `codex://threads/<nativeSessionId>` 打开准确原聊天；聊天中的任务（Task）链接使用 `/workspaces/<workspaceId>/codex#/tasks/<taskId>`。固定基础地址保持不变，目标放在片段中，网页负责解析目标并显示原有任务（Task）详情组件。

已有普通 Buildr 页面可在确认接入时采用固定入口，保留当前页面和编辑内容。旧任务（Task）路径及旧 `tasks#task=...` 链接继续兼容；旧链接本身不能保证宿主（Host）复用页面。刷新、外部片段、前进后退都要准确恢复目标，编辑中的草稿继续受原导航保护，无效目标显示诊断。

同一固定基础地址的链接点击能否复用已有标签页（Tab），由桌面宿主（Host）决定；Buildr 没有通用的聊天链接拦截或任意标签页（Tab）搜索接口。必须分别验证页面身份、页数、实际地址和任务（Task）内容，不能把接口返回或地址变化当成全部验收。

## 数据与失败边界

全局连接保存在选定本机运行配置（Profile）的数据目录；关系、绑定和交接保存在所属工作空间（Workspace）的 `.buildr/local/codex-desktop-sessions.json`，不进入任务（Task）源记录或长期知识。文件写入有排他锁、原子替换、作用范围和容量校验；损坏数据保留原文件，错误局限于相关协作操作。

独立生成创建结果不明或创建中取消时，退出该自有服务，不把未知上下文放回复用池。有效结果与清理异常分别报告；清理失败的实例不得再次使用。生成失败、取消、输入版本变化和迟到结果均保留当前编辑内容。
