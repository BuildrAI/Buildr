# Codex 原聊天关联与一次性生成

选择并确认本机 Codex 后，Buildr 保存原聊天关联的配置范围与独立生成来源，不安装 Buildr 插件（Plugin）、不显示聊天卡片、不要求桌面加载扩展或重启。持续讨论和开发留在用户原聊天中，提交说明继续通过现有按钮生成并自动回填。

## 两条路径

| 路径 | 谁负责执行与保存 | Buildr 的职责 |
| --- | --- | --- |
| 原聊天协作 | 桌面 Codex 维护历史、记忆（Memory）、配置和工具 | 确认关联范围，维护任务（Task）与具体聊天的多对多关系和双向链接 |
| 一次性生成 | Buildr 按确认的本机程序及配置来源启动独立应用服务（App Server），创建临时会话（Ephemeral Session） | 提供有界材料、限制权限、校验结果、回填和清理 |

两者不共享执行后台。独立生成不继承原聊天的记忆（Memory）、插件（Plugin）或工具集合，不写原聊天，也不把临时生成身份保存为任务关系。DSH 沿用当前实现；其后续服务设计须独立探索。

## 发现、确认与状态

一级抽屉列出当前本机数据目录的全部已接入智能体（Agent），保留 Codex 与 DSH、默认选择、按需详情及 Codex 移除。详情保持与条目对齐的紧凑浮窗；接入菜单支持鼠标、键盘和窄屏。

选择 Codex 后打开二级抽屉，展示安装、版本和配置来源。发现不启动模型或聊天，确认重新核对候选和登记版本。取消无写入；未发现时说明检测机器并允许重新检测或取消，确认不可用。已有 Codex 时禁用重复新接入，显式重新检查只维护同一程序及配置范围，保留编号和默认项。

关联的 `configured` 表示安装和配置范围已确认，`unavailable` 表示范围当前需检查，`disconnected` 表示接入已移除；都不表示桌面在线或模型已执行。界面不再显示插件版本、等待加载或重启要求，也不周期轮询扩展存活。旧登记的握手字段只兼容读取，不作为关联的前提；读取失败必须明确展示，不能沿用旧成功冒充当前事实。

日常应用与隔离预览使用各自的数据目录。预览缺少登记不能解释为日常登记已删除；发现的是运行 Buildr 的机器，不自动复制账号、凭据或聊天库。

## 准确关联与多对多

用户在目标 Codex 聊天中给出任务编号并说“把当前会话关联到这个任务”。该聊天核对工作空间（Workspace）与任务（Task），直接读取 `CODEX_THREAD_ID`，调用 `buildr codex link` 幂等保存关系。共享 `CODEX_SESSION_ID`、工具服务环境和子智能体（Subagent）身份不能代替原聊天。

任务管理技能（Skill）从 Codex 原聊天新建任务后默认关联当前聊天；用户明确不关联时遵从。无准确身份或有效接入时保留任务并说明未关联，不猜测、不重建任务，也不影响 DSH。

一个任务（Task）可关联多个聊天，一个聊天可关联多个任务（Task）。`buildr codex sessions` 可按任务或具体聊天身份正反查询；解除只校验并改变指定关系，不改任务正文或状态。空态简洁显示尚未关联；已保存关系提供准确打开与管理入口，不要求插件或卡片。

## 双向链接与页面复用

任务页使用 `codex://threads/<nativeSessionId>` 打开准确聊天；聊天返回 `/workspaces/<workspaceId>/codex#/tasks/<taskId>` 固定任务链接。打开不代表已发消息或完成工作。继续开发仍在准确原聊天中进行，并重新读取当前工作事实。

固定基址把具体目标放在网址片段（URL Fragment）中，利用桌面宿主（Host）对同一入口的页面复用。Buildr 处理首次加载、片段变化、刷新、前进和后退，保留原草稿保护与无效目标诊断。旧任务路径和 `tasks#task=...` 继续正确到达，但任意旧路径、跨窗口和多个页面精确选择仍取决于宿主（Host）；不能从接口接受或网址变化推断全部复用成功。

## 移除接入与扩展退役

“移除接入”停止 Buildr 自有独立生成服务、删除本项登记并禁用新关联；保留桌面聊天、其他配置、任务（Task）及长期关系，不结束桌面后台，也不自动改选其他智能体（Agent）。忙碌、关闭结果不明或登记并发变化时保留登记并明确说明；结果不明先查询，不重放移除。重新确认同一范围可恢复稳定身份及保留关系。

卸载退役的 Buildr 插件（Plugin）是另一项动作，不能用“移除接入”代替。仅处理准确的 Buildr 扩展及所属工具服务，保留生成登记、配置范围、关联和其他扩展。新版本不再随接入安装扩展。旧 `serve`、绑定及交接专用入口返回明确退役，不创建新请求或发送消息；旧请求和回执数据保留，历史聊天已渲染的卡片不承诺被抹除。

## 数据与生成失败边界

关联登记保存在选定本机运行配置（Profile）的数据目录；长期关系和旧请求保存在所属工作空间（Workspace）的 `.buildr/local/codex-desktop-sessions.json`。它们不进入任务正文或知识源。旧格式兼容读取，写入继续使用锁、原子替换、范围及容量校验，损坏文件原样保留。

独立生成的创建结果不明或创建中取消时，关闭自己拥有的服务，不复用未知上下文，不自动重发请求。有效结果与清理异常分别报告；失败、取消、输入变化或迟到结果均保留当前编辑内容。
