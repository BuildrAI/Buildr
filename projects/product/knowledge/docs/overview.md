# 了解 Buildr

Buildr 把项目事实和工作方法组织成可持续使用的共同依据，帮助智能体（Agent）少重复了解背景、从中断处继续工作，并复用已经验证的方法。你表达目标、作出判断并验收；智能体（Agent）结合当前资料和实际环境推进；Buildr Web 用于查看、维护资料和工作成果。

你不必先学完内部概念或命令。把现有项目和想做的事交给智能体（Agent），让它协助准备环境，再开始第一项真实工作。具体入口见[开始使用](guides/getting-started.md)。

## 它在什么情况下有用

| 你遇到的问题 | Buildr 帮助留下什么 |
| --- | --- |
| 每次对话都重新介绍项目 | 当前目标、业务资料和代码位置，让智能体（Agent）有依据可查 |
| 好方法只留在聊天或个人记忆里 | 可复用的方法与适用边界，供下次工作采用 |
| 换人、换工具或中断后难以接续 | 任务（Task）的目标、进展、结果与成果位置 |
| 不想通读所有执行对话 | 可直接查看的资料、待判断事项和工作结果 |

例如，修改一项同时涉及页面和后端的业务：先更新需求与约束，智能体（Agent）据此找到相关实现，完成修改和检查，再交付可查看的成果。后续参与者重新读取这些共同来源，就能核对已经做了什么、还缺什么；不必只靠上一段对话猜测。

个人可以从一个项目开始。团队也可以用同一批资料协作，将经过确认、值得复用的经验留下来。资料更新后仍需要重新读取；Buildr 不保证自动发现所有依赖，也不会自动同步所有人的副本。

## 工作范围与资料怎样组织

工作空间（Workspace）是你与智能体（Agent）共同工作的目录和资料入口。项目（Project）说明业务目标，服务（Service）说明实现职责，代码库（Repository）登记实际使用的代码来源与位置。这些关系帮助从“要做什么”找到“在哪里做”，详见[工作对象与代码关系](architecture/project-service-repositories.md)。

值得长期维护的内容主要有两类：**工作事实**，例如业务约束和项目组成；**工作方法**，例如可复用的检查、开发或交付方式。规则（Rule）表达边界，技能（Skill）保存方法。普通文件、临时记录和一次查询结果不会因为位于目录中就自动成为受管资产。

Buildr 组织这些来源和发现入口，智能体（Agent）按当前目标选择相关内容，并结合代码、数据库、外部系统和实际工具结果判断。登记了资料不等于当前工具已经加载，也不表示一次调用会装入全部资料。需要深入时，查阅[术语表](glossary.md)和[技能体系](architecture/buildr-skill-system.md)。

## 怎样判断工作完成

先看实际成果是否满足约定目标，再看必要检查与交付是否成立。代码、文件和业务数据仍保存在各自所属位置；Buildr 中的记录帮助查找和接续，不能代替真实结果。

例如，“修改已完成”还需要说清改了什么、检查了什么、还有哪些未覆盖；“已推送”与“应用已生效”也应分别确认。你负责业务取舍、授权和验收，智能体（Agent）负责执行并提供依据。需要持续记录的工作可以使用任务（Task），相关说明见[从讨论到交付](architecture/task-system.md)。

## 当前边界

Buildr 当前以本机工作为主。长期资料可以通过 Git 共享，本机工作记录不会自动跨机器同步；目前没有完整企业权限或云端协作能力。网页提供资料和成果入口，实际智能体（Agent）工作仍在你选择的工具中进行，Buildr 不托管对话或自动调度执行。

安装的 Buildr 同时包含命令行接口（CLI）和网页部分，启动器（Launcher）打开同一安装。更新、工作空间（Workspace）采用更新及数据保护见[开始使用](guides/getting-started.md#更新与数据保护)。工具接入范围见[适配参考](../../services/buildr/docs/agent-runtime-adapters.md)，其他限制见[已知限制](../../services/buildr/docs/known-limitations.md)。

## 后续方向

近期先改善开始工作、找到成果、判断完成和中断接续的体验。跨工作空间（Workspace）协作、外部系统连接、更多智能体（Agent）入口及工作资产（Work Asset）独立分发，都是按真实需求评估的方向，尚不代表已提供能力或版本排期。

每项建设应从一个具体问题出发，证明它能减少重复解释、搬运、核对或人工介入，并说明完成标准与失败影响。已有工具能够可靠承担的执行与调度继续交给它们；Buildr 聚焦共同依据和必要边界。具体实现以正式规范和当次确认范围为准。
