# 职责图的事实依据

覆盖知识建设与维护关系，不表达函数调用顺序或后台自动执行。

| 节点 | 依据 |
| --- | --- |
| guidance | OpenSpec 与 code-architecture 技能（Skill） |
| facts | 当前规范和实现文件 |
| methods | Archify、code-map 与术语治理方法 |
| maintenance | current-knowledge-maintenance |
| artifacts | knowledge/index.yml、解释文档、图源和地图 |
| web | KnowledgePage、knowledge-query 与 KnowledgeDiagram |

关系 guidance-facts 表达建设指导，facts-maintenance 表达维护依据，methods-maintenance 表达按需采用的制作方法，maintenance-artifacts 表达智能体（Agent）执行更新，artifacts-web 表达知识成果的只读呈现。最近访问记录与收藏属于独立的工作台个人偏好，不改写知识成果，未在本图展开。具体文件见[代码地图](../../code-map/knowledge-maintenance.md)。

图源与展示由 Archify deliver 同次生成，9 项检查通过，组合错误和警告均为 0。交付摘要见本次验证记录；未将文件完整性当作语义自动证明。
