# Buildr Web 前端规则

本服务维护 Buildr Web 的前端源码与正式构建；共用约束见[产品规则](../../AGENTS.md)，托管与资源边界见[前端规范](../../openspec/specs/buildr-web-client/spec.md)。

- 页面请求使用现有客户端与会话、工作空间上下文，不绕过它们直接请求。
- 正式浏览器验收使用生产托管的构建产物。改名或删除测试依赖的稳定页面标记（`id`、`data-*`）前，核对并按需同步对应检查。
- 引入 Redux、Zustand 等全局状态库前，须证明多个无关页面确实需要稳定共享可变业务状态，且现有方式造成明显重复渲染、难以维护的层层传参或独立测试困难；说明共享范围、现有不足和边界，并取得用户授权。
