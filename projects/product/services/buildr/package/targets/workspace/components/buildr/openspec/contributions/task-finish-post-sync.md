在 canonical spec sync 后、archive 前运行 `buildr openspec check <change> --stage post-sync --project <project> --target <workspace> --json`。只有 check 返回 `ok: true`，且同一 convergence receipt 的 delta identity 未变、canonical identity 与 sync 后记录匹配时，才把 receipt 推进到 `post-sync`。失败时保留 worktree、change、canonical diff 与 receipt，停止尚未执行的 archive、commit、rebase、merge、push 或 cleanup；不得刷新 baseline、重跑 pre-sync或采用当前 post-sync canonical 来掩盖结果。
