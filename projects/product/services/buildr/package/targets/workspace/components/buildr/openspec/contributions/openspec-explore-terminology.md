## Buildr Terminology Sidebar

探索中出现新术语、同义词、一词多义、中英不一致、Context/Context Window 或 Project/Service 作用域冲突时，读取 optional `buildr.terminology-governance/v1` binding、contract 和 selected provider，记录 `aligned|updated|unresolved|not-applicable` evidence。Provider 未绑定时继续探索，但明确标注未治理术语和后续确认点；不得把 optional 缺失升级为探索阻塞。

本 sidebar 只组合能力，不修改外部 `openspec-explore` Skill 源，也不要求固定 provider identity。
