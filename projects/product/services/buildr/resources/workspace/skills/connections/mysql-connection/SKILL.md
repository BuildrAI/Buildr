# MySQL 连接

本技能（Skill）维护 MySQL 接入方法。Buildr 的查询工具是独立内置能力（Builtin），负责数据库展示偏好、表结构浏览和受限只读查询；这些内容不写入连接声明或连接配置。

先从用户目标、服务配置与已登记连接找到准确主机、端口、环境和数据库。执行 `buildr connection-skill --help`，再读取 `definitions list --json` 与 `list --json`；核对所选实例明确绑定 `mysql-connection` 的 `mysql` 定义，不按系统名称、类别或同名旧实例推断绑定。新建和认证录入使用当前管理入口及其已观察版本，不按同名接管实例，不自动搬运个人密码。

团队认证与个人认证均为包含用户名、密码的完整认证组（Authentication Group）；个人组存在但失效时停止，不回退团队组。目标主机、端口、账号或程序接收方变化后重新配置完整认证。允许明确的空密码；不得把用户名保留为共享配置、只覆盖个人密码。

程序 `buildr-mysql` 随 Buildr 主包安装，以独立进程间通信（IPC）接收本次明确选中的连接上下文；认证不进入参数、普通环境或业务标准输入（Standard Input）。先执行通用 `check` 与 `help` 核对当前程序和版本；缺失时按声明的安装指引恢复，不绕过绑定调用其他程序。帮助与版本检查离线运行。具体命令及结果见 [命令与结果](references/commands-and-results.md)。

只读测试执行受限版本查询，数据库发现只读取当前账号可见范围。它们不修改数据库或连接配置，也不证明用户业务目标完成。用户查询通过独立查询工具进行，并明确选择本次实例版本和数据库；查询工具保留每个实例独立的本机偏好（Preference）。测试失败时区分网络、认证、权限和版本问题，不打印远端认证回显，不自动更换认证或实例重试。

使用真实工作空间（Workspace）验收时，仅在用户授权的实例、环境和数据范围内执行。只读验证不能替代结构变更、数据修改或业务效果验证。本接入不提供数据写入命令；遇到写入目标应转交具有明确授权与结果核验的专业能力。
