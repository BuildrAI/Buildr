# 旅程、动机与记忆

这些法则用于长流程和关键时刻。进度与情绪设计必须忠实表达真实状态，不以心理效应诱导用户违背自身利益。

## 目标梯度效应（Goal-Gradient Effect）

- **关注**：当用户感到目标更近时，完成动力通常更强。
- **信号**：长流程看不到剩余工作；接近完成时仍出现意外步骤；阶段价值不清楚。
- **动作**：展示真实的阶段、剩余工作和已取得成果，把接近完成的关键路径保持清晰稳定。
- **警戒**：不要伪造起始进度、移动终点或隐藏后续条件；复杂度不确定时使用阶段状态而非虚假百分比。
- **验证**：观察各阶段退出率、接近完成时的速度、意外返回和对剩余工作的理解。
- **来源**：[Goal-Gradient Effect](https://lawsofux.com/goal-gradient-effect/)

## 峰终定律（Peak-End Rule）

- **关注**：情绪最强烈的时刻和结束体验会显著影响事后评价。
- **信号**：高风险提交、支付、失败或首次成功缺乏支持；流程结束后用户不知道结果和下一步。
- **动作**：先消除负面峰值，再强化真正有价值的成功时刻；结束时明确结果、后续影响和可继续动作。
- **警戒**：好的结束不能补偿中间持续失败；品牌动画不能遮蔽错误、延迟或不确定结果。
- **验证**：分别记录过程中的即时感受、关键节点行为和完成后的回忆与信心。
- **来源**：[Peak-End Rule](https://lawsofux.com/peak-end-rule/)

## 蔡格尼克效应（Zeigarnik Effect）

- **关注**：未完成或被中断的任务更容易持续占据注意和记忆。
- **信号**：用户返回后找不到未完成内容；草稿、待处理状态或后续步骤不可见；中断意味着重做。
- **动作**：保存真实进度，提供清楚的未完成标记、恢复入口和下一步；允许用户主动结束或放弃任务。
- **警戒**：不要用无休止红点、强迫完成或故意制造悬念增加焦虑。
- **验证**：测试中断后的恢复率、恢复时间、重复劳动和用户对未完成状态的控制感。
- **来源**：[Zeigarnik Effect](https://lawsofux.com/zeigarnik-effect/)
