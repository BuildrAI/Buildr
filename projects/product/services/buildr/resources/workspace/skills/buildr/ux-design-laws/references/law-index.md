# 法则索引

本索引用于从当前问题找到相关法则，不用于逐条检查。中文名称是本技能内部的稳定叫法；来源页以英文标题为准。

| 可观察信号 | 优先考虑 | 参考文件 |
|---|---|---|
| 界面漂亮但任务仍难完成 | 审美可用性效应（Aesthetic-Usability Effect） | [基础与设计策略](foundations-and-strategy.md) |
| 选项过多、比较困难、用户放弃选择 | 选择过载（Choice Overload）、希克定律（Hick's Law） | [信息与决策](information-and-decisions.md) |
| 长内容难扫描、信息关系不清 | 组块化（Chunking）、共同区域定律（Law of Common Region） | [信息与决策](information-and-decisions.md)、[视觉感知与布局](visual-perception-and-layout.md) |
| 任务需要记住前页内容或多个值 | 工作记忆（Working Memory）、米勒定律（Miller's Law） | [信息与决策](information-and-decisions.md) |
| 无关元素分散注意力 | 认知负荷（Cognitive Load）、选择性注意（Selective Attention） | [信息与决策](information-and-decisions.md) |
| 设计判断受个人偏好或既有结论支配 | 认知偏差（Cognitive Bias） | [基础与设计策略](foundations-and-strategy.md) |
| 新界面违反用户熟悉的模式 | 雅各布定律（Jakob's Law）、心智模型（Mental Model） | [基础与设计策略](foundations-and-strategy.md) |
| 方案元素太多或依赖过多假设 | 奥卡姆剃刀（Occam's Razor） | [基础与设计策略](foundations-and-strategy.md) |
| 简化后仍有不可消除的复杂度 | 泰斯勒定律（Tesler's Law） | [基础与设计策略](foundations-and-strategy.md) |
| 不知道先优化哪些功能或路径 | 帕累托原则（Pareto Principle） | [基础与设计策略](foundations-and-strategy.md) |
| 视觉分组与实际关系不一致 | 接近律（Law of Proximity）、相似律（Law of Similarity）、一致连通律（Law of Uniform Connectedness） | [视觉感知与布局](visual-perception-and-layout.md) |
| 复杂图形或页面难以形成整体 | 简洁律（Law of Prägnanz） | [视觉感知与布局](visual-perception-and-layout.md) |
| 关键动作不突出或所有元素都在争抢注意力 | 冯·雷斯托夫效应（Von Restorff Effect） | [视觉感知与布局](visual-perception-and-layout.md) |
| 列表首尾与中间项目的重要性不匹配 | 序列位置效应（Serial Position Effect） | [视觉感知与布局](visual-perception-and-layout.md) |
| 按钮小、远、拥挤或难以命中 | 菲茨定律（Fitts's Law） | [操作与系统反馈](actions-and-feedback.md) |
| 操作后没有及时反馈或等待感明显 | 多尔蒂阈值（Doherty Threshold） | [操作与系统反馈](actions-and-feedback.md) |
| 表单拒绝合理输入或错误难恢复 | 波斯特尔定律（Postel's Law） | [操作与系统反馈](actions-and-feedback.md) |
| 用户跳过说明，直接尝试操作 | 主动用户悖论（Paradox of the Active User） | [操作与系统反馈](actions-and-feedback.md) |
| 流程耗时超过用户预期 | 帕金森定律（Parkinson's Law） | [操作与系统反馈](actions-and-feedback.md) |
| 连续操作频繁被打断、难以专注 | 心流（Flow） | [操作与系统反馈](actions-and-feedback.md) |
| 长流程中途放弃或看不到完成距离 | 目标梯度效应（Goal-Gradient Effect）、蔡格尼克效应（Zeigarnik Effect） | [旅程、动机与记忆](journey-motivation-and-memory.md) |
| 关键时刻或完成后的感受很弱 | 峰终定律（Peak-End Rule） | [旅程、动机与记忆](journey-motivation-and-memory.md) |
