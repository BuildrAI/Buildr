# 本机智能体接入与调用

内部对话与单次生成共用智能体（Agent）和模型（Model）配置。外部桌面会话（Session）关联已退役，不再建立或保留这些关系。

## 内部对话与持续执行

独立账号目录用于隔离登录，不代表本机工具缺失。需要额外工具时，结合 `PATH`、项目依赖及 `BUILDR_HOST_HOME` 指向的原用户目录检查已有安装；浏览器缓存使用实际 `PLAYWRIGHT_BROWSERS_PATH`，保留用户明确覆盖，未设置时指向原用户的官方默认缓存。缺少工具时，由智能体（Agent）根据当前任务选择相应技能（Skill）或官方说明准备并验证，不复制桌面凭据。

用户想在 Buildr 内使用 Codex、DSH 或 Qoder 时，从全局对话打开“账号与模型”，在账号卡片登录；本机程序缺失时由同一入口准备，低频的程序检查位于卡片“更多”菜单。发现多个程序时选择准确来源；缺少程序时按页面官方入口安装后重新检查，或显式准备独立程序。Codex 可复用经核验的 ChatGPT App 内程序或独立 CLI；DSH 使用独立 CLI，Qoder 由 Buildr 管理配套 SDK 与执行程序。通过官方登录建立独立账号，再核对实际账号及非空模型目录；不把程序安装成功或打开登录页当作接入可用。需要用户本人登录时，只交接当前尝试的官方页面；不要提取桌面令牌（Token）、复制默认账号文件或把秘密写入任务、消息、日志及 Git。当前没有新的 `buildr agent-conversations` 命令，不猜造命令或使用已退役的接入命令。

- Codex 使用独立 `codex app-server` 应用服务（App Server）；DSH 使用独立 `dsh web --no-open --port 0` 完整本机网页宿主（Web Host）及官方客户端（Client）；Qoder 使用官方软件开发工具包（SDK）与 `qodercli`。不要求外部桌面应用保持运行，也不等于提供桌面版全部功能。
- 每家一套本机独立配置，可供多个工作空间（Workspace）使用。配置和统一交互库属于 Buildr 本机运行配置（Profile）的私有数据，不是组织源资产；不自动复制桌面插件、用户级规则（Rule）、技能（Skill）、工具连接或任意第三方模型凭据。缺程序时发现并核对真实安装及兼容版本，不静默下载程序或改绑用户默认配置。
- 准备进度可查询、可取消；切换厂家和关闭面板不取消后台准备，重启后重新观察安装和账号。版本准入按主版本：Codex、DSH 为 `0.x.x`，Qoder CLI 为 `1.x.x`，包含有效预发布版本与构建标记。符合范围只允许继续实际协议、账号和模型检查，不单独代表接入可用；固定下载版本不等于唯一兼容版本；同来源兼容更新保留账号和原生上下文，仍检查实际协议。原程序缺失或版本不兼容时保留账号与历史，不通过切换程序、配置或会话编号冒充恢复。浏览器工具由智能体（Agent）按已有技能（Skill）检查、准备并真实验证；本机浏览器品牌或安装成功都不等于已具备浏览器操作能力。
- 普通对话先确认工作空间（Workspace）及真实起始目录（Working Directory）；任务页“打开对话”创建或打开关联该任务（Task）的内部对话。起始目录是原生规则（Rule）、技能（Skill）发现的起点，不是跨目录访问的禁止边界；实际访问仍按原生权限和用户授权。任务关联不自动把任务全文、当前页面或其他工作空间资料注入模型。
- 发送前核对接入、模型、起始目录及“查看发送内容”。流式回答、工具观察、待答问题、授权与停止在同一对话处理；授权只对应准确本轮请求。不要因历史中有人同意过，就重放原工具或复用旧许可。
- 权限选择位于当前对话输入区，新对话默认为“默认权限”；用户明确选择“完全访问”后，后续执行按各家原生免逐次工具审批模式工作，同一对话换家时分别应用，不改变外部桌面配置或旧一次生成。业务问题仍需用户回答，未知交互不能自动批准；改回默认时必须逐轮重新应用，不继承上次完全访问。发送预览与实际本轮模式分别核对，不能只凭界面选择推断原生已经生效。
- 同一段对话可以依次使用多个智能体（Agent），历史不按厂商分类。首次换一家创建它自己的原生上下文；换回时恢复它原来的上下文，补交它未见的可见历史。隐藏推理、工具内部状态和权限不会迁移；接续信息过大或图片能力不兼容时，继续原参与者或由用户明确提供精简说明后重新预览，不静默截断历史。
- 重新打开、刷新或服务（Service）重启不重发指令。遇到“待确认”（`unknown`）先观察原执行；“模型已中断，仍有命令运行”需要按准确命令继续停止。已发送、已受理、已结束和已确认停止分别判断；断开账号或关闭面板不等于执行已经停止。
- 原生执行连接确认断开后，系统会保留原绑定并自动核对准确执行；开发版仅对已确认停止、无活动或未知工具且无待用户决定的系统中断接续一次。用户主动停止不自动恢复，正式版只核对状态。存量“状态待确认”缺少系统中断来源时，只更新已确认的原生终态，不推定可以续做；不能以通用连接提示认定账号过期或程序不兼容。自动接续再次中断时停止自动重试，保留原因。
- DSH 对话选择模型会更新这套独立配置的后续默认模型；外部桌面配置不受此独立配置改动。检查可用不等于某次真实模型执行成功，图片也只按对应执行器（Executor）实际开放的能力使用。

内部对话只保存交流和执行观察；代码、文档、任务状态与业务数据仍以各自当前对象为准。继续工作前重读实际成果。后续图形界面（GUI）与对话界面（Talk UI）接入业务动作时，仍须交接明确对象身份和已观察版本，由原能力保护写入；首版没有自动捕获所有页面现场或通用图形操作能力。

### 统一模型与额度设置

在“账号与模型”中，已登录账号直接显示真实额度窗口，未登录或过期在同一卡片登录；Codex、DSH、Qoder 复用本应用原生登录，Devin 使用明确发起的独立登录。未知额度不能当作零余额，旧观察不能冒充本次读取。模型页只把已启用项目加入新选择；刷新保留开关，新发现模型默认停用，组合预设单独管理。

Devin 的当前已验证组合是 DSH，以及 Codex + SWE-2 的默认权限或用户显式选择的完全访问。其他 Codex/Devin 模型组合、Qoder + Devin 暂不可选；保留原选择及草稿，切换到已验证组合后再发送；Devin 来源的 Codex 会按所选权限使用对应原生上下文，旧记录保留并通过现有可见历史接续。已知审批问题说明仅作等义兼容，保留示例、必要规则及原生沙箱和审批策略。不要自动提高权限、删除原生权限说明或以额度错误冒充整轮成功；完全访问会跳过逐次工具审批，仍遵守本轮用户授权与厂家限制。

上下文数字是本地执行偏好，不扩大上游容量；可恢复平台默认，已知上限时不得设置更大数字。Devin 按真实支持配置提供思考和速度档位，不推导笛卡尔积；未知档位保留语义，不伪装有序深度。设置改变用于新的执行上下文，现有对话历史保留，不能静默重发指令。通过已发现的 HTTP 操作管理偏好时，先读取准确账号和模型身份，再携带当前 `expectedRevision` 调用 `/api/v1/app/agent-service/model-accounts/:accountId/preferences`；冲突后重新读取，不覆盖其他入口，也不直接修改私有账号文件。

## 提交说明单次生成

提交说明从已配置模型（Model）目录选择明确来源。Buildr 准备有界变更材料，只调用一次模型，不创建持久对话、不提供工具；失败或取消保留草稿。没有可用模型时仍可手写说明并提交。

旧 `buildr agent`、`buildr codex` 和 `buildr dsh` 生成及外部关联入口已删除，不再采集当前外部会话身份。任务（Task）可关联 Buildr 内部对话，也可独立工作；关联不成为创建、验证或完成的前提。
