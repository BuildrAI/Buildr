# 在 DSH 里使用 Buildr

装了 Buildr，又装了 DSH（DeepSeek Harness）桌面版，就可以在 DSH 的侧栏底部直接打开 Buildr，不用切浏览器或另找启动器。

## 开始之前

两样东西都得有：

- **Buildr**：本机已经安装并能正常运行。
- **DSH 桌面版**：只有桌面版有侧栏底部这个位置；在浏览器里打开的 DSH 没有这个按钮。

## 装上插件

插件有两种装法，选一种即可。

### 从 npm 或 GitHub 安装

在 DSH 的“添加插件”里填插件包名或仓库地址即可。DSH 会自己下载安装。

装完**重启 DSH** 就能用了：插件第一次打开时会自己找到本机的 Buildr，你不需要填路径、不需要选版本。

### 让智能体（Agent）帮你装

直接跟 DSH 里的智能体说“把 Buildr 加到 DSH 里”。它会装好插件并告诉你要重启 DSH。

## 用起来是什么样

- 按钮在 **DSH 侧栏底部**，和设置、账号这些入口放在一起。
- 点一下：如果 Buildr 已经在运行，直接打开它；没有运行，就先把 Buildr 启动起来再打开。
- **你正聊着的对话不会丢**：Buildr 在另一个窗口打开，DSH 这边的会话保持原样。
- 刚点完还在启动时，按钮会显示正在准备；失败会给出可以重试的说明，不会假装成功。

## 什么时候会提示你

| 提示 | 意思 | 怎么办 |
|---|---|---|
| 没检测到 Buildr | 这台机器上没找到能用的 Buildr 安装 | 先装好 Buildr，重启 DSH |
| 入口已变化 | Buildr 被移动或替换了位置 | 重启 DSH；仍然提示时重新安装插件 |
| 暂时不可用 | 启动或查询没成功 | 按提示重试 |
| 请先选择对话 | 还没有打开任何对话 | 先进入一个对话再点 |

## 不想要了怎么办

在 DSH 的插件管理里把它**禁用**或**卸载**即可。禁用后按钮消失，Buildr 本身不受影响——插件从不改动 Buildr。

## 开发者额外说明

上面说的是日常使用。**正式版入口只打开正式版 Buildr**，不会打开开发版。

如果你在同一台机器上还有一份 Buildr 开发版源码，需要一个单独的入口来打开它，那是开发者用法：开发版入口由源码工作空间单独构建，装进你自己的 DSH，且不随正式发布提供。细节见 [DSH 桌面接入](dsh-desktop-plugin.md)。
