# DSH 插件变更记录

## 0.1.0-rc.3 - 2026-10-19

- 将 DSH（DeepSeek Harness）宿主（Host）兼容范围统一为 `>=0.2.0-0 <0.3.0-0`，支持 `0.2.1-rc.2` 等预发布版，并保留准确构建来源校验。
- 与 Buildr `0.1.0-rc.45` 联合准备；插件源码、原包验证与公开发布分别记录，不因主包版本变化递增插件版本。

## 0.1.0-rc.2 - 2026-10-15

- 以独立的 `@buildr-ai/buildr-dsh-plugin` 预编译组合包交付，通过可撤销组合层接入官方 DSH（DeepSeek Harness）应用。
- 在原事件中保存并读取 Buildr 当次来源，统一来源列、详情与 Buildr 页面中的已确认记录，保留原事件内容与执行结果。
- 保留组合入口的用户配置身份，复用桌面后台并支持原生会话（Native Session）打开及桌面窗口确认。
- 支持独立版本、真实 Buildr 原包兼容检查和受保护发布，最低运行要求为稳定版 Node `>=24.15.0`。

本节描述候选（Candidate）内容；公开发布及真实桌面验收以对应版本的实际结果为准。
