# 已安装桌面验收

使用本机 DSH Desktop 0.2.2-rc.5、该检出的预编译开发插件和含生产 Web 的 Harness 安装包。在独立 DSH 配置和 Harness 数据域中检查：

1. 用厂商命令安装开发包；核对版本和启用状态。启动无 DSH 账号、无活动 DSH 会话的桌面，从左侧 **Buildr Harness** 打开。主工作区应显示 Harness 自己的页面和返回栏，子页面不得用 iframe 或外部浏览器承载。
2. 核对嵌入页面已经登录、票据不在最终地址，可用实际桌面鼠标和键盘选择测试目录、打开已有对话和编辑未发送输入。直接不带授权访问宿主启动端点必须被拒绝。
3. 在隔离目录用 Harness 发起一次 Agent 执行并观察实际文件差异及完成结果。没有真实账号时可用受控的本地模型目录及测试执行器；如通过网页的同源接口提交，要与鼠标、键盘及真实订阅路径的验证分别记录。
4. 返回 DSH 后再次打开，核对同一个窗口、页面和后台实例，以及同一个对话。结束本次测试进程，不清理其他工作；保留已安装插件供用户打开。
