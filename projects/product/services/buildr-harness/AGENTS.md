# Buildr Harness

本服务负责账号、对话、执行和限定范围的通用操作；共用约束见[产品规则](../../AGENTS.md)。

- 宿主只使用公开入口，由宿主校验页面身份和已登记的工作对象。不得为读取配置路径、类型或使用通用文件和 Git 能力而装入执行核心。
- 凭据由对应接入或其委托的原生账号提供者唯一写入，按来源隔离。不自动继承、覆盖或接管用户默认桌面配置；秘密不进入公开视图、事件、诊断、源资产或 Git。
- 原生上下文绑定准确的程序、配置和工作目录；状态未知先核实，不重发。历史消息不授予新的工具许可。
- 同一配置域的入口复用后台；关闭或卸载入口不删除共享历史与账号。源码或包名改变不迁移现有 `agent-service` 数据根。
- 文件和 Git 操作不得超出宿主已核对的目录、工作树、任务或远端范围及授权。对话可关联任务，不替代真实任务状态或文件、Git 成果。
- 完整对话与工作界面由 `buildr-harness-web` 维护。Development 只通过公开入口接入，不导入内部组件重组对话。
