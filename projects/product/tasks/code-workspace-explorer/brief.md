# 建立代码板块、资源管理器与任务文件关联

当前工作空间（Workspace）的代码文件查看依赖外部编辑器。已有任务的“改动与提交”支持差异审阅，但尚缺一个能随时浏览所有代码库（Repository）完整文件、并从任务准确定位实现的独立入口。

## 目标与已确认布局

顶栏新增“代码”板块，与“工作台”“工作空间”并列。左侧导航提供“资源管理器”和“源代码管理”两个菜单；本子任务实现前者，后者明确处于待建设状态。中间文件树默认约 280px，宽度与普通列表、项目详情独立；右侧读取完整文件并保留多个文件标签。代码板块以当前工作空间的全部已登记代码库为范围。

## 本次范围

- 建立独立代码板块、路由、菜单和按工作空间保留的查看状态；现有代码库登记与身份继续复用。
- 代码库范围支持多选，未设置筛选时显示全部；从任务进入默认预选该任务服务引用的代码库并去重，不只展示任务改动文件。项目、服务的组合多选筛选留待实践后优化。
- 浏览已登记代码库的当前本机目录，支持展开文件树、搜索与完整源码、文档和图片阅读；明确文件身份、位置和读取失败。
- 从任务的文件入口或当前改动打开完整文件时，定位到明确代码库和实际工作目录；保留任务阶段及审阅选择，支持返回。
- 目录宽度独立调整、收起和恢复，文件阅读可使用剩余空间；同路径不同目录的文件身份不混淆。
- 先更新关键页面原型和形成方案，再依此实施。历史版文件的定位身份在方案中明确，为下一子任务保留接续边界。

## 非目标

本子任务不建设全局 Git 提交（Commit）历史、分支（Branch）操作、推送、合并、文件写入或完整编辑器。已有任务的改动与提交继续使用现有能力；全局源代码管理由 `code-source-control` 承接。原型只使用模拟数据与本地交互。

## 完成依据

1. 从任务、工作空间等任意页面均可通过顶栏“代码”进入资源管理器。
2. 能选择当前工作空间的全部代码库，浏览完整文件树并阅读文件；局部目录不可用不阻止查看其他代码库。
3. 从任务查看源文件时，按任务服务的代码库引用预选范围并展示完整文件树；可以扩展或清除筛选，浏览未修改文件后返回任务，仍保留原阶段与审阅选择。
4. 不同代码库、工作目录、版本的同名文件不会混淆；当前位置可见，文件树宽度不继承其他页面的宽度。
5. 适用构建、类型、行为和浏览器验证据实报告；演示、正式实现、集成与验收状态分别说明。

## 当前阶段

本轮第一子任务的实现与验证已完成，用户已确认收尾交付。资源管理器覆盖整库浏览、任务文件定位、搜索与大文件分段阅读；第二子任务 `code-source-control` 仍待实施。正式发布不在本轮范围。

## 实现与知识影响

本轮已进入正式实现：新增 `buildr/src/modules/code/` 只读应用与同源命令行（CLI）/HTTP 入口，前端 `features/code/` 负责范围、来源身份、懒加载和文件阅读；任务只传入定位上下文，不改变任务范围或任务记录。

已复核技术架构和系统服务资产地图：其“功能拥有页面与业务读取，应用壳只组合导航”和“代码库实例登记为唯一位置来源”的职责仍适用。新增读取能力的命令指引在 `services/buildr/docs/cli-reference.md` 校准；代码实现来源保留在本任务及变更材料中。本轮不扩展为全项目知识重写。全局源代码管理仍由第二子任务接续。

## 用户审看反馈的实施补充

当前目录搜索使用随产品交付的 ripgrep，搜索范围不再被旧的累计3000文件、16 MiB或2.5秒预算截断；保留进程和结果安全上限并如实说明覆盖。历史版本仍绑定明确提交。Markdown正文沿用其他文档的1200px限宽；阅读区右上角统一“展开阅读 / 恢复分屏”，保留文件、搜索和目录宽度；共享分隔线命中区域覆盖边界而不占空白带。新增依赖继续使用现有npm安装入口，验证源码与打包后真实搜索。

继续按用户截图统一代码顶部43px栏、短竖线和右侧对象标签；搜索结果简化为文件名与代码库，按同一来源文件聚合可展开的多个匹配行。点击匹配时定位真实行并高亮行与搜索文字，大小写及正则特殊字符按字面处理。搜索数组向后兼容首条字段，文件/匹配行及执行边界明确提示；历史对象、跨库身份和阅读状态不混用。

后续细节反馈采用全部匹配文件默认展开，网页搜索至少两个非空白Unicode字符，每库最多100文件/200匹配行，达到上限提示缩小查询。聚焦只描绘选择框外层，文件名/内容切换采用清楚选中态。“代码库目录”指登记位置实时文件，“任务关联目录”指从任务带入的已核对目录，实际路径直接可见，不汇总其他工作树。忽略开关包含当前目录中被Git规则或常见构建目录排除的内容；隐藏名称本身不是忽略条件，Git管理目录始终禁止。当前任务预览根中不存在的主目录文件不额外读取。

最新补充在两种搜索结果的文件名下展示代码库内相对路径，用查看位置承载绝对目录；折叠后路径仍可见；文件名搜索点击打开文件，内容搜索文件块点击仅展开/折叠，具体匹配行才打开定位。文本完整读取上限采用5 MiB，超过时告警并按约512 KiB分段，当前和固定历史版本采用同一能力；真实行号、UTF-8边界、修订核对与不完整状态明确，不改动图片和搜索预算。
