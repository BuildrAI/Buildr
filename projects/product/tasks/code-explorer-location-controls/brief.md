# 修复资源管理器查看位置与刷新对齐

用户反馈资源管理器刚打开、尚未选择文件时缺少查看位置说明，且刷新图标没有与代码库筛选框居中对齐。本轮修复既有页面，不改变读取、权限或版本契约。

查看位置始终可见：默认明确说明登记的本机目录与实时文件；从任务进入时使用实际观察的目录，并说明没有独立工作树时的回退。未打开文件时位置切换作用于所选代码库，打开文件后作用于该文件所属代码库，范围明确。多库路径仍各自展示，历史标签保持独立。筛选框与刷新按钮通过同一行布局对齐，不再依靠绝对定位。

以正式构建和代码页面的未打开文件、关闭最后文件、任务目录回退、范围切换与刷新对齐验证完成；保留已有搜索和任务往返检查。改动在独立工作树（Worktree）中验证，预览不代表集成或发布。
