# shared-browser-authorization Specification

## Purpose
由 Buildr 统一管理工作空间本机个人浏览器授权资源，使多个连接显式复用同一登录基础，同时隔离页面使用权、独立核验各系统凭证，并保护持久配置和其他使用方不受取消或重置误伤。

## Requirements

### Requirement: 工作空间个人共享配置有唯一资源所有者
Buildr MUST 管理个人工作空间内的浏览器配置身份、私有位置和观察版本。连接 MUST 显式引用配置编号，MUST NOT 按连接名称或环境自动共享。配置内容 MUST 留本机私有区，不进入源资产或公开结果。
#### Scenario: 不同连接显式共享
- **WHEN** 两个连接明确引用同一工作空间的同一配置
- **THEN** 系统 SHALL 使用同一浏览器登录基础，各连接仍独立获取及核验自己的认证结果
#### Scenario: 显式接管旧配置
- **WHEN** 用户按已观察版本接管已有本机私有目录
- **THEN** 系统 MUST 保留内容和原位置，拒绝符号链接、越界或已被另一配置接管的目录，不自动合并登录状态

### Requirement: 并发使用共享实例但隔离页面所有权
系统 MUST 复用每份配置的浏览器运行实例，MUST 通过私有本机通道交付本次使用权，不开放公共调试端口。调用 MUST 只控制本次创建的页面和对应会话，MUST NOT 枚举或控制其他使用方页面、读取任意浏览器配置文件或执行全局清理。
#### Scenario: 一个调用取消
- **WHEN** 多个授权并行且其中一个取消或异常结束
- **THEN** 系统 MUST 释放该调用页面，其他调用继续使用，持久登录配置保留
#### Scenario: 外部浏览器占用
- **WHEN** 同一配置已由无法安全复用的外部进程占用
- **THEN** 系统 MUST 报告该配置不可用而不终止外部进程、不删除锁、不改用其他配置

### Requirement: 共享配置重置受身份版本及占用保护
系统 MUST 要求准确配置身份和观察版本才重置整个共享配置；仍有使用方或外部占用时 MUST 拒绝。单个连接凭证失效 MUST NOT 隐式重置共享配置。
#### Scenario: 配置已变化或仍在使用
- **WHEN** 重置提交旧版本或配置仍被使用
- **THEN** 系统 MUST 保留当前配置并给出具体诊断

### Requirement: 连接授权可选接入资源模块
现有个人授权 MUST 支持可选声明browserProfile，通过私有授权通道交付受限浏览器能力。站点流程、账号校验和认证组结果 MUST 继续由连接方法负责；旧声明 MUST 保持可用，不在发现或帮助动作启动浏览器。资源故障 MUST 只影响相关授权，不替代业务操作授权。
#### Scenario: 未声明浏览器资源
- **WHEN** 现有连接不声明browserProfile
- **THEN** 系统 SHALL 保持既有授权上下文与行为，不创建共享浏览器
