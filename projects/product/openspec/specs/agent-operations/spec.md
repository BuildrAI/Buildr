# agent-operations Specification

## Purpose
为 Buildr 的有界单次生成复用统一模型（Model）目录与账号，固定准确来源、校验生成结果，并保护取消、时限、草稿与当前材料版本；旧生成接入及外部桌面关联已退役。

## Requirements

### Requirement: 单次生成复用统一模型配置

系统 MUST 使用现有模型目录与账号执行给定材料的单次生成，固定明确选择的账号、模型、身份及观察版本，MUST NOT 使用旧智能体登记或默认值，MUST NOT 自动切换账号或重发已受理请求。请求 MUST 不提供工具或创建持久对话。无可用模型时 MUST 只影响生成，保留手写说明与正常提交能力。

#### Scenario: 选择后目录变化
- **WHEN** 用户选择的账号身份或观察版本已变化
- **THEN** 生成 MUST 在模型调用前失败并保留草稿，不使用其他账号

#### Scenario: 单次生成成功
- **WHEN** 用户选择可用模型生成提交说明
- **THEN** 系统 MUST 仅传入已准备材料，不启动旧后台、不创建持久对话或调用工具，记录所选模型来源

### Requirement: 提交说明保留取消与来源保护

系统 MUST 对每次生成提供工作空间内准确查询和取消，保持有限执行预算。失败、取消、迟到输出、草稿被编辑或材料版本变化 MUST 不覆盖现有说明。输出 MUST 通过结构、任务尾注及来源校验；取消只影响本请求。

#### Scenario: 取消后响应晚到
- **WHEN** 用户取消生成而模型晚到返回成功
- **THEN** 运行 MUST 保持取消且原草稿不被覆盖，其他请求不受影响

#### Scenario: 生成期间修改来源
- **WHEN** 变更材料或适用规则在生成期间变化
- **THEN** 系统 MUST 拒绝回填并说明重新核对来源

### Requirement: 外部桌面接入退役与数据删除

系统 MUST 移除旧 Codex、DSH 接入、外部会话与任务关系及桌面导航的界面、命令和接口，不再自动关联外部会话。系统 MUST 删除当前本机配置及已登记工作空间的固定旧登记和关系数据，不迁移、不备份；MUST 不访问或删除外部聊天、账号、新模型配置、内部对话与任务。非普通文件和路径替换 MUST 局部报告，不跟随删除；清理失败 MUST 不阻止无关工作。内部对话的任务关联 MUST 保持可选。

#### Scenario: 升级后清理旧关系
- **WHEN** 当前本机存在旧登记和已登记工作空间关系文件
- **THEN** 系统 MUST 仅清理这些固定旧数据，不保全历史，内部对话和外部聊天保持

#### Scenario: 创建任务
- **WHEN** 用户从外部智能体创建任务
- **THEN** 系统 MUST 只创建任务，不再采集外部会话身份或要求关联成功
