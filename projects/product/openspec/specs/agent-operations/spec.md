# agent-operations Specification

## Purpose
为 Buildr 内部功能提供独立于具体智能体（Agent）的统一调用能力，管理本机接入身份、默认选择、执行结果与专用进程生命周期，使人无需理解本机安装细节即可使用已接入能力，同时保留来源与失败边界。

## Requirements

### Requirement: 本机接入登记与选择

系统 MUST 提供可由智能体（Agent）调用的登记、查询和默认选择能力。登记 MUST 验证真实可执行入口及所需协议能力，保存稳定调用身份而非进程编号，不保存凭证副本。相同身份重复登记 MUST 幂等；变更默认 MUST 校验已观察登记版本。网页 MUST 不要求用户填写路径、端口或密钥，MUST 不把复制接入请求当成接入成功。

登记 MUST 区分 Codex 应用服务（App Server）与 DSH 桌面后台连接，表达原生默认配置来源，MUST 兼容既有 Codex 登记和默认选择。首版 MUST 不要求用户在 Buildr 再配置模型或凭据。

#### Scenario: 接入后重复使用
- **WHEN** 智能体（Agent）按产品指引登记本机 Codex，用户随后打开其他功能
- **THEN** 系统 MUST 展示同一接入记录与唯一默认选择，调用时不再要求接入

#### Scenario: 登记版本变化
- **WHEN** 用户按旧登记版本修改默认选择
- **THEN** 系统 MUST 明确报告冲突并保留新记录，不覆盖另一个入口的选择

#### Scenario: 新增 DSH 后保留 Codex
- **WHEN** 已有 Codex 登记的用户接入 DSH
- **THEN** 两条登记 MUST 各自表达真实接入方式，原默认 MUST 不被静默替换，用户 MUST 可按同一选择交互使用 DSH

### Requirement: 统一调用与固定执行者

业务功能 MUST 经统一操作能力选择执行者、发起、查询和取消。协议适配 MUST 在具体执行适配器（Adapter）内完成，MUST 与既有文件投射能力区分。一次执行 MUST 捕获接入身份与版本；默认切换仅影响后续新执行，不迁移进行中工作或重标已有结果。失败 MUST 不静默切换执行者或自动重放已接受的模型请求。

Codex 与 DSH 生成 MUST 复用同一业务输入、执行状态和结果校验。临时上下文 MUST 由提供者在一次生成内部创建和释放；首版 MUST 不以新增公开会话管理接口或持久会话存储作为生成前提。

#### Scenario: 本次覆盖后切换默认
- **WHEN** 用户为一次生成覆盖执行者，并在生成期间修改全局默认
- **THEN** 本次执行 MUST 保持原执行者，覆盖在发起后消费，后续执行按新的默认选择

#### Scenario: 选择 DSH 生成
- **WHEN** 用户选择已通过生成能力验证的 DSH
- **THEN** 业务 MUST 通过同一入口获取运行状态、取消及可校验结果，MUST 不要求业务直接操作桌面后台协议

### Requirement: 临时生成与只读权限

Codex 说明生成 MUST 使用明确请求的临时会话（Ephemeral Session），核对服务端确认，不保存持久生成对话。提交说明 MUST 使用供应资料模式，MUST 关闭原生工具（Tool）、代码执行宿主（Code Mode Host）及外部工具（Tool），并关闭自动项目文档注入和宿主技能发现；MUST 仅按业务给定资料发起一次生成，不自行读取、写入或联网。出现工具执行事件 MUST 拒绝本次结果并有界关闭自有实例，MUST NOT 自动回退到原生读取。其他明确请求的内部原生读取调用 MAY 保留具名受限只读环境及实际权限边界；该模式 MUST 核对成功读取且禁止写入、联网和越界。按结构化输出要求返回结果；取消、超时及失败 MUST 保留用户已有说明。临时会话（Ephemeral Session）不承诺删除供应商自身诊断日志。

#### Scenario: 连续生成两次
- **WHEN** 用户连续生成两次提交说明
- **THEN** Codex 每次 MUST 使用独立临时会话（Ephemeral Session），DSH 每次 MUST 使用不创建会话（Session）的独立调用，结果可原位编辑，MUST 不新增持久对话历史

#### Scenario: 取消生成
- **WHEN** 用户取消已开始的生成
- **THEN** 系统 MUST 中断本次执行，迟到结果 MUST 不替换草稿，其他来源仍可读取或提交

#### Scenario: 其他内部调用受限原生读取
- **WHEN** 明确请求原生读取的内部调用查看已授权工作位置或规则入口
- **THEN** 允许范围 MUST 可读；范围外文件、文件写入及网络 MUST 被实际权限拒绝，工具环境 MUST 不继承供应商认证与父进程通信秘密

#### Scenario: 提交说明只使用所给材料
- **WHEN** 提交说明向Codex发起生成
- **THEN** 原生及外部工具（Tool）MUST 不可用，自动项目文档及宿主技能 MUST 不注入，出现工具执行 MUST 局部失败，MUST NOT 自动补读或重放请求

### Requirement: 专用实例复用与回收

Codex MUST 首次调用才启动自有服务进程并复用，每个登记最多一个存活自有进程。DSH MUST 仅连接正在运行且身份匹配的桌面后台，MUST NOT 启动独立 DSH 生成进程或回退。两者 MUST 按登记串行执行；完全空闲30分钟释放自有实例或连接，排队和执行不计空闲，查询不延长空闲。再次请求 Codex 可重建自有实例，DSH 只能重新连接已确认桌面。

Buildr 退出 MUST 停止新请求并有界清理自身资源。DSH MUST 只取消本连接拥有的请求和断开，不能关闭桌面或全局取消其他工作。Codex 重启及取消无法确认 MUST 有界关闭自有进程，退出未确认禁止替代启动。准备及等待计入预算，不重放已接受请求。浏览器关闭不等于 Buildr 退出。

#### Scenario: 空闲后继续生成
- **WHEN** 自有实例或连接完全空闲30分钟释放后再次请求
- **THEN** Codex MUST 可重新启动，DSH MUST 核对并重连桌面，保留登记和说明

#### Scenario: 两次生成复用实例
- **WHEN** 同一登记连续生成
- **THEN** 系统 MUST 复用同一桌面后台串行处理，不新增生成进程

#### Scenario: 退出清理
- **WHEN** Buildr 退出
- **THEN** 系统 MUST 有界释放自有资源，桌面和其他聊天保持

#### Scenario: 默认配置需要重启
- **WHEN** Codex 后续请求的配置必须重启生效且仍有执行
- **THEN** 系统 MUST 等待、关闭旧自有进程并启动新进程，不并行保留策略实例且不超预算

### Requirement: 确认实际会话配置

Codex 调用 MUST 沿用本次目录解析的模型（Model），普通调用 MUST 继续继承推理级别（Reasoning Effort）。业务 MAY 经内部端口指定本次低推理级别（Reasoning Effort）及有界调用预算；MUST NOT 修改全局配置或开放任意网页覆盖。显式低推理级别（Reasoning Effort）MUST 经服务端确认，否则 MUST 在模型请求前失败。系统 MUST 从会话（Session）确认响应捕获模型（Model）、提供者（Provider）和推理级别（Reasoning Effort），固定到本次运行；普通继承调用的缺失展示字段 MUST 明示未确认，不推断默认值，也不因此阻断。公开结果 MUST 不含完整配置、路径或凭证，详情 MAY 展示最近一次确认值，MUST 不为展示启动模型服务。

指定调用预算 MUST 涵盖排队、准备、执行和结果校验；到期 MUST 将本次结果终止为失败并保留草稿，MUST NOT 发布迟到结果。排队过期 MUST NOT 中断别的运行（Run）；执行过期 MUST 中断并有界回收本次自有资源。

DSH MUST 直接继承桌面当前模型（Model）、原生认证、路由和推理级别（Reasoning Effort），经原生准备调用固定本次配置；MUST 不复制凭据或强制低级别覆盖桌面选择。必要配置不能确认时 MUST 在模型请求前局部失败。

#### Scenario: 配置变化后再次生成
- **WHEN** 两次生成解析到不同模型（Model）或推理级别（Reasoning Effort）
- **THEN** 每次结果 MUST 保持自己的确认配置，详情 MUST 表达最近一次使用值，不重标旧结果

#### Scenario: 首次使用或字段未返回
- **WHEN** 尚未调用或服务端未返回某确认字段
- **THEN** 界面 MUST 明确尚未确认，MUST 不把模型目录建议值或配置推断当成实际值

#### Scenario: 提交说明的专用执行预算
- **WHEN** 提交说明向 Codex 指定低推理级别（Reasoning Effort）和60秒预算
- **THEN** 本次 MUST 使用已确认低级别、保持原模型（Model）与全局配置；其他调用 MUST 继续继承原配置，到期 MUST 拒绝迟到结果且不打断其他运行（Run）

#### Scenario: DSH 继承包含自定义路由的默认配置
- **WHEN** DSH 桌面有效默认使用自定义提供者
- **THEN** 本次调用 MUST 使用对应原生认证及必要路由，并展示真实确认值；无法确认必要配置时 MUST 在模型请求前局部失败

### Requirement: DSH 临时生成的实际限制

DSH 提交说明 MUST 在真实桌面后台直接执行一次独立调用，不提供会话编号、不创建或写入持久会话（Session）、不带前次上下文。工具列表 MUST 为空，不注入项目上下文，保持原生认证，不以普通聊天生成再删除冒充临时能力，不使用全局工具守卫或其他插件内部控制。

一次返回 MUST 经结构和业务规则校验，没有原生结构约束须如实表达，不能追加修复请求。取消、超时及失败 MUST 保留已有说明和直接 Git 操作；中断 MUST 只针对本连接拥有的请求，迟到结果不回填，不承诺删除供应商全部诊断日志。

#### Scenario: DSH 连续生成不积累对话
- **WHEN** 同一桌面后台连续生成两次
- **THEN** 两次 MUST 独立，无新增持久聊天、历史消息或跨次上下文

#### Scenario: DSH 仅使用给定材料
- **WHEN** DSH 接受生成
- **THEN** 工具 MUST 为空，不注入自动上下文、不补读或静默回退

#### Scenario: DSH 返回格式不合规
- **WHEN** 返回不能通过结构或业务校验
- **THEN** 系统 MUST 明确失败、保留草稿，不追加模型请求

#### Scenario: 取消隔离
- **WHEN** 用户取消本次生成且另有请求执行
- **THEN** 插件 MUST 只中断本请求，其他聊天及后台保持

### Requirement: 本机 Codex 发现与一次确认

系统 MUST 有界发现本机 Codex 安装、内置程序和已有登记，显示安装及配置来源，不要求网页用户填写路径、端口或凭证。发现 MUST 不启动模型或创建聊天。确认 MUST 校验候选及已观察版本，保存生成来源；桌面安装可用时同时保存稳定关联登记。仅有独立程序时 MUST 明确只配置生成、关联尚未配置，不冒称两项均成功。确认 MUST 不安装插件（Plugin）、不启动卡片工具服务、不要求重启或加载扩展。只有明确请求才切换默认项；局部失败 MUST 保留其他已成立配置，身份变化 MUST 不静默换范围。

#### Scenario: 桌面安装没有搜索路径命令
- **WHEN** Codex 内置程序不在搜索路径（PATH）
- **THEN** 系统 MUST 提供真实安装供选择并登记原生配置，不启动模型检查安装

#### Scenario: 确认期间安装变化
- **WHEN** 实际安装或配置身份在确认前变化
- **THEN** 系统 MUST 返回冲突，不按旧输入操作其他路径

#### Scenario: 桌面组件准备失败
- **WHEN** 用户确认接入且旧 Buildr 插件不可用
- **THEN** 系统 MUST 完成基础登记，不执行插件安装、启用或重启

#### Scenario: 仅有独立程序
- **WHEN** 发现可用于生成的 Codex 程序但没有可确认的桌面安装
- **THEN** 系统 MUST 只登记生成来源并说明关联尚未配置，已有接入维护不得按不完整候选确认关联

### Requirement: Codex 分层接入与明确退出

接入 MUST 先选择智能体（Agent）种类，选择 Codex 后打开二级抽屉，展示检测、候选、配置来源及确认/取消。一级抽屉 MUST 保持列表职责。取消 MUST 无登记和默认值写入；未发现安装 MUST 有空状态、重新检测及取消，确认不可用。成功 MUST 返回父列表并说明生成与关联配置结果，不要求加载插件或重启，DSH 既有行为 MUST 保持。

#### Scenario: 取消本机接入
- **WHEN** 查看候选后取消
- **THEN** 系统 MUST 只关闭二级抽屉，登记和默认值不变

#### Scenario: 没有本机安装
- **WHEN** 未发现可接入的 Codex
- **THEN** 系统 MUST 说明未发现，允许重新检测或取消，确认不可用

### Requirement: Codex 新接入与已有连接维护分开

已有 Codex 时界面 MUST 禁用重复新接入，后端 MUST 在登记锁内校验版本并拒绝重复登记。旧命令登记更新 MUST 兼容。维护 MUST 显式携带原登记编号，只允许同一程序和配置范围，保留编号及默认项，不新建其他项或接受切换默认。维护 MUST 只重新检查关联配置，不安装插件或要求握手。目标丢失、范围不符或候选不完整 MUST 局部失败；取消无写入，结果不明先查询。

#### Scenario: 已接入后再次请求新接入
- **WHEN** 已有 Codex 而再次请求新接入
- **THEN** 系统 MUST 拒绝，登记不变且不启动扩展

#### Scenario: 已有连接明确维护
- **WHEN** 从原登记详情确认重新检查接入
- **THEN** 系统 MUST 保留身份、默认项及其他接入，只确认匹配范围的配置

### Requirement: 接入列表简洁与全部登记可见

一级抽屉 MUST 展示本机目录中全部已接入智能体（Agent），不隐藏 DSH 或旧 Codex。默认、详情及移除操作 MUST 分开；详情 MUST 使用对齐条目且在视口内的紧凑浮窗，仅突出生成与原聊天关联配置，低频说明折叠。接入选择 MUST 支持悬停、点击、键盘及窄屏；目标失效或关闭抽屉 MUST 清理浮窗。

#### Scenario: Codex 与 DSH 已登记
- **WHEN** Codex 和 DSH 均已登记
- **THEN** 两项 MUST 均显示且保留默认，查看或取消不得修改登记

### Requirement: Codex 移除接入与自有服务停止

系统 MUST 允许按已观察版本移除指定 Codex 接入，不修改 DSH 或其他接入。存在排队、生成或连接准备时 MUST 保留全部状态并局部报告原因。执行移除时，当前 Buildr 应用实例 MUST 阻止相同范围的新生成、登记、默认选择和连接准备，先确认 Buildr 自有生成实例退出，再以已观察登记版本删除该接入；关闭结果不明或版本漂移 MUST NOT 静默删除登记。移除默认项 MUST 清空默认值，MUST NOT 自动选择另一接入。移除 MUST 停用桌面业务连接，MUST NOT 删除桌面聊天、记忆（Memory）、配置、插件（Plugin）、任务或长期关系，也不结束桌面进程。删除登记后即使桌面断开状态保存失败，系统 MUST 继续禁止旧连接调用并报告局部警告；结果不明 MUST 查询当前登记，MUST NOT 自动重发移除。独立桌面进程在登记删除前接受的请求可完成并保留结果；本能力 MUST NOT 宣称跨进程全局撤销或完全相同内容重新登记的原子保护。

#### Scenario: 空闲 Codex 移除
- **WHEN** 用户确认移除空闲 Codex
- **THEN** 系统 MUST 先确认自有服务停止，再移除本项并停用连接，其他接入和用户工作记录保持

#### Scenario: 有未结束工作
- **WHEN** 指定 Codex 尚有排队、生成或连接准备
- **THEN** 系统 MUST 提示先结束或取消相关工作，登记、默认项和连接不被部分移除

#### Scenario: 退出未确认或登记并发变化
- **WHEN** 关闭自有服务未确认退出，或关闭期间登记版本发生变化
- **THEN** 系统 MUST 保留登记并报告当前局部失败，退出未确认时仍禁止替代启动，MUST NOT 改动其他接入

### Requirement: Codex 临时创建不明与自有清理

独立 Codex 生成 MUST 从创建前覆盖清理与取消。创建请求发出后响应丢失、超时或临时身份不明时，系统 MUST 有界关闭自有生成实例并确认退出，MUST NOT 复用、不等待空闲回收、不重发创建。关闭未确认 MUST 阻止同登记启动替代实例，不影响桌面后台。创建中取消、迟到身份与终结后迟到结果 MUST 不继续执行或覆盖草稿。有效输出与清理结果 MUST 分开表达，回填 MUST 仍通过全部输出与版本检查。系统 MUST 不采用桌面共享服务，MUST 不写原聊天生成轮次。

#### Scenario: 创建已发生但响应丢失
- **WHEN** 服务接受创建但 Buildr 未获得准确临时身份
- **THEN** 系统 MUST 关闭自己拥有的实例，退出未确认时禁止替代启动，MUST NOT 重放创建

#### Scenario: 创建期间取消后迟到
- **WHEN** 用户取消创建中的操作，随后收到创建结果
- **THEN** 系统 MUST 清理本次自有资源，MUST NOT 启动生成或覆盖用户草稿

### Requirement: Codex 配置与桌面连接分别表达

列表和详情 MUST 分别表达生成来源与关联配置当前事实。已配置只证明安装及配置范围已确认，不得宣称桌面在线、聊天已打开或模型已执行。读取中、失败、缺失、范围变化和已移除 MUST 明确表达，不沿用旧成功。界面 MUST 不显示插件版本、等待加载或重启要求，不周期轮询扩展存活。反馈 MUST 对应真实登记结果。

#### Scenario: 生成已配置但桌面未就绪
- **WHEN** 生成及关联范围已确认而本机没有 Buildr 插件
- **THEN** 系统 MUST 显示配置可用，不提示等待插件或要求重启

#### Scenario: 桌面状态读取失败
- **WHEN** 读取失败而之前读到已配置
- **THEN** 界面 MUST 显示无法确认，不冒充当前可用

#### Scenario: 详情位置与部分结果明确
- **WHEN** 打开 Codex 详情
- **THEN** 浮窗 MUST 与条目外右框对齐，宽窄视口完整可见，支持键盘和点外关闭

### Requirement: DSH 桌面接入发现维护与迁移

系统 MUST 复用二级抽屉提供只读发现、确认、同范围检查和移除；发现不启动模型或桌面，不要求网页填写端口或凭证。确认 MUST 核对候选及登记版本、真实安装和配置目录；旧登记准确匹配后原地迁移，保留编号、名称和默认项。范围不符、离线或协议不兼容 MUST 明确失败，不猜其他安装、不启旧后台。维护 MUST 明确原编号；新接入拒绝重复 DSH，取消无写入。

移除 MUST 核对已观察版本，拒绝未结束工作，只释放自有连接并停用业务调用，保留聊天、配置、插件、任务和关系；默认项移除只清空不替选。状态 MUST 区分已配置、不可用和已断开，不能沿用旧成功冒充在线。

#### Scenario: 原地迁移
- **WHEN** 已有旧登记和默认，确认完全匹配的候选
- **THEN** 系统 MUST 保留编号、名称及默认，改用桌面后台且不改历史

#### Scenario: 范围不同
- **WHEN** 已有登记维护时选择不同配置目录
- **THEN** 系统 MUST 拒绝并保留原记录

#### Scenario: 桌面离线
- **WHEN** 桌面或插件不可用
- **THEN** 系统 MUST 局部失败，不启动独立生成进程

#### Scenario: 移除
- **WHEN** 按当前版本移除空闲 DSH
- **THEN** 系统 MUST 移除登记并停用连接，保留聊天和长期关系
