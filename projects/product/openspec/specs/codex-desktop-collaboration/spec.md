# codex-desktop-collaboration Specification

## Purpose
为用户日常使用的 Codex 桌面原聊天提供与 Buildr 任务共享当前事实的连接，支持准确身份绑定、独立多对多关系、原聊天交接、双向打开和侧边固定入口导航，同时保全桌面自己的历史、记忆与执行能力。

## Requirements

### Requirement: 桌面连接保持原生后台

Buildr MUST 通过受支持扩展准备桌面连接，不替换后台、不修改桌面启动配置、不复制聊天库或凭证。连接身份 MUST 持久，并与生成登记显式关联而非替代。安装、启用和实际活跃能力 MUST 区分；宿主强制确认或刷新 MUST 如实显示且不得自动打断聊天。同安装升级和重连 MUST 保留身份，实质账号或配置范围变化 MUST NOT 原地重定向旧关系。

#### Scenario: 安装后尚未加载
- **WHEN** 连接组件安装成功但桌面尚未完成握手
- **THEN** 系统 MUST 显示待桌面加载，不将该状态当成原聊天可交接

### Requirement: 移除后的桌面连接不复活

连接 MUST 明确保存已断开状态，并以生成登记是否存在作为业务调用可用性的当前权威。移除后每次握手、绑定或交接 MUST 重新检查可用性，旧准备返回和已加载组件 MUST NOT 恢复连接或继续发送业务指令；断开状态无法落盘时缺失登记仍 MUST 阻止调用。原任务关系和原聊天链接 MUST 保留；重新明确接入同一范围 MUST 恢复稳定连接编号。移除 MUST 不卸载桌面组件、不改桌面配置或结束桌面后台。

#### Scenario: 旧组件仍加载
- **WHEN** 接入登记已移除而旧桌面组件仍在运行
- **THEN** 系统 MUST 显示断开并拒绝新绑定或交接，不把旧握手当作重新授权

#### Scenario: 迟到准备与重新接入
- **WHEN** 旧组件准备结果在断开后返回，或用户随后明确重新接入相同范围
- **THEN** 迟到结果 MUST 不复活连接；重新接入 MUST 保留稳定连接身份和既有关系

### Requirement: 具体原聊天绑定与恢复

系统 MUST 接受用户在具体 Codex 聊天中明确要求关联指定任务，由该聊天直接提供具体原生身份；此直接关联 MUST NOT 以网页创建请求或面板二次确认为前提。系统 MUST NOT 使用共享根身份、子执行身份、工具服务环境或匿名页面编号代替当前聊天身份。已明确接入且配置范围有效时，直接关联 MUST 不依赖面板是否加载；接入已移除或配置范围变化时 MUST 拒绝新关联并保留现有关系。既有面板继续通过有界请求确认实际承载聊天，绑定结果 MUST 可查询并校验请求及接入范围。重开或承载聊天变化 MUST 重新核对身份，句柄过期 MUST 不删除长期关系。结果不明 MUST 先查询，不自动重发工作指令。

#### Scenario: 聊天直接关联任务
- **WHEN** 用户在具体 Codex 聊天中给出工作空间内的任务编号并明确要求关联，聊天直接提交准确身份
- **THEN** 系统 MUST 幂等保存该任务与该聊天的关系并返回双向链接，无需先创建待确认请求

#### Scenario: 分叉聊天绑定
- **WHEN** 原聊天及分叉共享根编号但具体身份不同
- **THEN** 系统 MUST 绑定实际承载聊天，不绑定共享根或代执行子聊天

#### Scenario: 面板重开
- **WHEN** 用户重开已绑定面板
- **THEN** 面板 MUST 核对承载身份后恢复关联任务，MUST NOT 只因缓存存在就认定当前聊天相同

#### Scenario: 旧请求兼容
- **WHEN** 直接关联成功后旧请求仍待确认或晚到
- **THEN** 系统 MUST 保留兼容并去重关系，已绑定旧回执重放 MUST NOT 恢复已解除关系

#### Scenario: 接入范围无法唯一确定
- **WHEN** 没有有效 Codex 接入，或存在多个有效接入而未指定目标
- **THEN** 系统 MUST 明确返回未关联原因，不猜测接入，不自动接入或修改默认智能体

### Requirement: 任务与原聊天多对多

系统 MUST 独立保存工作空间（Workspace）、任务、桌面接入和具体聊天的关联，一个任务可关联多个聊天，一个聊天可关联多个任务。建立 MUST 幂等，解除 MUST 校验关系自身版本，不改变任务正文或状态。正反向查询 MUST 可用。聊天失效、关闭或接入默认变化 MUST 不删除关系或自动改绑；临时生成身份 MUST 不作为长期会话关系。

#### Scenario: 双向多对多查询
- **WHEN** 一个任务关联两个聊天且其中一个聊天另关联其他任务
- **THEN** 任务详情和聊天面板 MUST 返回各自完整准确关系，重复建立不增加重复关系

#### Scenario: 并发解除关系
- **WHEN** 用户以过期关系版本解除关联
- **THEN** 系统 MUST 报告冲突并保留当前关系，MUST NOT 修改任务正文版本

### Requirement: 原聊天交接与双向打开

任务详情 MUST 打开准确关联原聊天，聊天面板 MUST 提供关联任务链接。交接 MUST 携带稳定单次编号、任务身份、目标聊天、观察版本及目标，收到的原聊天 MUST 核对身份并重新读取当前任务事实。接收回执 MUST 可查询且不得冒充执行完成。打开聊天、恢复面板、消息送达及任务完成 MUST 分别表达；结果不明 MUST 不自动重发或新建聊天替代。

#### Scenario: 目标聊天不是当前聊天
- **WHEN** 用户从任务选择另一个关联原聊天
- **THEN** 系统 MUST 先打开准确聊天，再在其可用入口绑定与交接，MUST NOT 改发当前聊天

### Requirement: 固定入口优先复用侧边页

Codex 协作新任务链接 MUST 使用同一工作空间的固定基址，将具体目标放入网址片段（URL Fragment）。存在宿主匹配页时 MUST 利用其原页导航，不为每个任务新建页。Buildr MUST 在首次加载、片段变化、刷新和返回／前进时显示准确目标，保护未保存内容，旧资源状态 MUST 不覆盖新目标。当前可控制旧页 MUST 可安全采用固定入口；原路径链接 MUST 继续正确到达。系统 MUST 如实保留历史任意路径、多页精确选择及跨窗口能力边界，不以地址变化或请求接受冒充任务到达。

#### Scenario: 概览原页打开任务
- **WHEN** 侧边已打开固定入口概览，用户点击同入口任务链接
- **THEN** 原页身份 MUST 保持且页面数不增加，实际任务内容 MUST 与目标相同

#### Scenario: 旧页采用及草稿
- **WHEN** 用户在当前旧路径页面启用 Codex 协作入口
- **THEN** 系统 MUST 在同页保留可恢复位置及草稿，不刷新或关闭其他页面

#### Scenario: 历史旧链接
- **WHEN** 用户点击历史聊天中的旧路径任务链接
- **THEN** 目标任务 MUST 正确到达；宿主新增页时 MUST 如实说明，MUST NOT 将其计为任意旧页复用已覆盖

### Requirement: Codex 聊天新建任务默认关联

任务管理技能（Skill）在 Codex 原聊天中新建任务成功后 MUST 默认使用本聊天直接采集的具体身份显式建立关联，用户明确不关联时 MUST 尊重其选择。任务记录命令 MUST NOT 从工具服务或继承进程环境隐式猜测聊天身份。没有准确身份或有效 Codex 接入时 MUST 保留新任务并明确说明尚未关联，不把关联失败当作创建失败，不影响 DSH 或无聊天的任务创建。

#### Scenario: 从 Codex 聊天创建任务
- **WHEN** Codex 原聊天创建任务成功，已取得准确聊天身份且存在明确有效接入
- **THEN** 任务管理技能 MUST 默认调用显式关联动作，并核对返回的任务与聊天身份

#### Scenario: 创建成功但不能关联
- **WHEN** 新任务已创建但聊天身份或有效 Codex 接入不可用
- **THEN** 系统 MUST 保留任务并说明尚未关联，不创建替代聊天或阻止其他任务操作

#### Scenario: 无聊天来源或明确不关联
- **WHEN** 任务来自 DSH、无聊天的命令入口，或用户明确要求不关联
- **THEN** 系统 MUST 不自动建立 Codex 关系

### Requirement: 任务关联入口清楚展示当前事实

任务未关联聊天时 MUST 简洁显示“尚未关联聊天”，MUST NOT 默认展示待确认流程、大块空状态或不可操作的确认入口。用户展开关联帮助时 MUST 得到包含明确任务编号与工作空间定位的可复制聊天指令，不跳转无法确认身份的全局总览。已关联任务 MUST 展示准确聊天的打开与解除操作；保存的关系及聊天链接 MUST 不因面板未加载而隐藏或禁用。旧待确认请求 MUST NOT 阻塞或覆盖长期关系的当前展示。

#### Scenario: 空状态
- **WHEN** 任务没有任何聊天关系
- **THEN** 任务页 MUST 简洁显示尚未关联，并允许复制具体关联指令到目标聊天

#### Scenario: 已有关联无需面板
- **WHEN** 任务已有准确聊天关系但桌面面板尚未加载
- **THEN** 任务页 MUST 继续提供准确聊天链接，不要求先去总览确认
