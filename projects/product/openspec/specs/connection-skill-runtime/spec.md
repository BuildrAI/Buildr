# connection-skill-runtime Specification

## Purpose
让组织在 Buildr 未预先认识具体系统及专业命令的情况下，使用现有技能（Skill）机制交付、发现和选择连接方法。Buildr 维护声明、实例身份、配置与认证交接及必要版本边界，专业技能（Skill）和程序负责实际方法、业务授权、执行保护与结果核验。

## Requirements

### Requirement: 连接声明承载用途及受限管理槽位
Buildr MUST 解析登记技能（Skill）的连接声明，识别 `schemaVersion`、`definitionId`、名称、说明、类别（Category）、`configVersion`、配置与认证字段、程序声明 `programs` 及可选槽位。字段 MUST 使用受支持的类型、必填项、默认值和有限校验；槽位 MUST 限于摘要、网站入口、连接测试和动态选择，不加载任意前端代码。类别（Category）MUST 只帮助发现，不推导构建、部署、回滚等统一专业动作。

固定枚举及条件相等值中的数值 MUST 为有限数值。动态选项 MUST 使用文本编号与文本标签，单选及多选分别保存文本编号和文本编号数组；非法动态选项 MUST 仅使该次发现失败，不使连接整体不可用。

#### Scenario: 不同持续交付方法属于同一类别
- **WHEN** 两份技能（Skill）的声明属于持续集成与交付（CI/CD）类别但支持的专业动作不同
- **THEN** Buildr MUST 展示各自声明的字段和槽位，不要求它们实现相同动作清单

#### Scenario: 声明包含不受支持的代码槽位
- **WHEN** 连接声明要求注入可执行前端代码或未知字段类型
- **THEN** Buildr MUST 报告该声明的具体错误，不执行注入内容，不影响无关连接的发现

#### Scenario: 接入声明需要有序折叠区块
- **WHEN** 合法声明通过 `presentation.groups` 引用配置及认证字段并声明顺序和默认折叠
- **THEN** Buildr MUST 仅接受存在且不重复的字段引用和有限区块属性；展示标签不参与来源或身份判断，未知表达式或可执行代码被拒绝

### Requirement: 连接实例明确选择技能资产及声明身份
Buildr MUST 以 `(assetIdentity, definitionId)` 定位连接定义，并保留绑定的来源身份。连接实例（Connection Instance）MUST 明确选择一个定义，不能按类别、系统名称、技能名称相似性或安装顺序自动替换；来源变化 MUST 显式处理，不能静默接管已有绑定。

#### Scenario: 用户安装另一份 Nacos 方法
- **WHEN** 工作空间（Workspace）新增自制 Nacos 技能（Skill），已有实例绑定官方定义
- **THEN** 新方法 MUST 作为独立候选出现，已有实例绑定 MUST 保持不变

#### Scenario: 同身份对应的来源被替换
- **WHEN** 已绑定定义的来源身份与当前可解析来源不同
- **THEN** Buildr MUST 显示来源差异并停止向新来源交接认证，直到来源及绑定被明确处理

### Requirement: 专业程序自行声明来源与运行依赖
连接声明 MUST 支持技能（Skill）随附脚本和独立安装程序两种来源，并明确启动目标、参数、运行依赖及安装指引。Buildr MUST 根据所选来源定位程序，报告声明、安装、启用、可执行和连接测试的分别结果；MUST NOT 要求所有专业命令行接口（CLI）先登记到公共命令目录，MUST NOT 在发现或打开页面时自动安装程序、依赖或执行登录。

#### Scenario: 随附脚本缺少运行依赖
- **WHEN** Nacos 技能（Skill）及脚本存在，但其声明的运行依赖不可用
- **THEN** Buildr MUST 显示缺失依赖和该技能（Skill）的安装指引，不把已投射判定为程序可执行

#### Scenario: 独立程序不在公共目录登记
- **WHEN** 私有技能（Skill）明确声明独立安装程序，来源及本机安装可核对
- **THEN** Buildr MUST 允许使用该程序，不因 Buildr 公共命令目录未定义其名称而拒绝

### Requirement: 标准槽位执行受明确输入输出与副作用约束
连接测试及动态选项发现 MUST 通过声明 `hooks` 引用确定程序，并声明输入、结果结构和限定副作用。Buildr MUST 仅在相应明确动作发生时调用，MUST NOT 通过保存配置、读取列表或打开编辑页隐式触发外部请求；专业操作及其授权 MUST 由对应技能（Skill）和程序处理，不能借标准槽位执行未声明的配置发布或部署。

#### Scenario: 用户请求发现业务空间
- **WHEN** 用户对所选实例请求声明支持的业务空间发现
- **THEN** Buildr MUST 调用该定义的发现程序并展示结果或明确失败，不修改远端业务对象

#### Scenario: 发现声明有限前置输入
- **WHEN** 动态发现槽位的 `inputs` 明确引用地址和认证字段，而必填范围尚未选定
- **THEN** Buildr MUST 允许仅满足所需配置前置项的发现，校验所有已提供值和完整所选认证及目标，不因缺少待发现范围阻塞；完整测试、保存及专业执行仍完整校验

### Requirement: 通用入口发现连接并交给程序专业帮助
Buildr MUST 提供 `buildr connection-skill ...` 通用入口，支持发现、检查、查看专业帮助及启动所选程序。发现结果 MUST 提供实例、绑定定义、技能（Skill）入口、程序来源及必要依赖状态，不展开认证；专业命令及参数 MUST 由程序自己的命令行接口（CLI）定义，Buildr MUST NOT 预定义各系统业务命令。

#### Scenario: 查看所选程序帮助
- **WHEN** 智能体（Agent）通过 `help` 查看 Nacos 程序支持的命令
- **THEN** 帮助 MUST 来自所选程序或其声明，不交接认证，不发起真实系统请求，也不据此报告连接成功

### Requirement: 运行上下文通过私有子进程通道交接
`run` MUST 将所选实例身份、有效配置、有效整组认证及观察版本通过私有子进程通道（Private Subprocess Channel）交给所选程序。认证 MUST NOT 进入普通发现输出、命令参数、普通提示词（Prompt）、公开环境变量或运行日志；程序业务标准输入（Standard Input）MUST 保留给专业输入，不能被上下文传输占用。个人认证组存在时 MUST 使用完整个人组，不与团队组逐字段拼接；个人组失效 MUST 报告错误而不自动回退。

#### Scenario: 程序从标准输入读取配置正文
- **WHEN** 智能体（Agent）通过 `run` 启动 Nacos 程序并以标准输入（Standard Input）传递配置正文
- **THEN** 程序 MUST 同时获得完整业务正文和私有上下文，认证值 MUST 不出现在调用参数或普通输出中

#### Scenario: 本机个人组缺少密码
- **WHEN** 实例拥有团队认证及缺少必填密码的个人认证组
- **THEN** Buildr MUST 报告个人认证组不可用，不把团队密码补入个人组，不向程序交接混合认证

### Requirement: 专业写入前能够再次校验通用上下文版本
Buildr MUST 为运行程序提供写入前再次校验上下文的通用能力，核对实例身份、定义及来源、配置版本和认证观察版本。专业程序 MUST 在执行外部写入前使用该能力；上下文变化时 MUST 停止使用旧上下文的写入并明确报告。通用校验 MUST 不解释具体业务许可、不新增生产权限开关，也不替代专业对象版本和授权检查。

#### Scenario: 程序调查后实例配置被另一入口修改
- **WHEN** 程序完成读取后准备发布配置，但写前通用校验发现实例配置或认证版本变化
- **THEN** 旧上下文的写入 MUST 被拒绝，程序 MUST 重新取得上下文并核对专业对象，不静默采用新配置重试

### Requirement: 程序更新保留来源与执行边界
Buildr MUST 区分稳定身份、声明格式、配置兼容版本和当前观察摘要。受授权的同来源兼容更新 MUST 保留实例绑定；不兼容配置 MUST 明确展示迁移缺口，不能打开页面即改写。程序来源或接收认证的目标变化 MUST 显示具体差异；单纯方法文档摘要变化 MUST NOT 自动被解释为来源接管或要求重新授权所有实例。

#### Scenario: 只更新专业说明
- **WHEN** 已绑定技能（Skill）的参考文档变化而定义、程序来源及执行边界不变
- **THEN** Buildr MUST 保持绑定并更新观察信息，不仅因全文摘要变化要求重新建立连接

### Requirement: 局部不可用保留实例及其他安全工作
技能（Skill）停用、声明缺失、程序未安装或依赖不可用 MUST 只阻止需要该能力的动作。Buildr MUST 保留实例与配置，允许查看、诊断和适用的编辑，不自动换绑、安装程序或删除认证；技能（Skill）可发现 MUST 不等价于程序可执行或实际连接已验证。

#### Scenario: 技能源入口缺失或身份不符
- **WHEN** 声明和程序仍存在，但 `SKILL.md` 缺失、无法读取或声明的名称不符合登记身份
- **THEN** 系统局部报告该技能源不可用，保留实例及认证，不影响其他来源；合法的普通正文更新不会单独要求重新授权

#### Scenario: 已绑定技能被停用
- **WHEN** 用户停用某实例绑定的技能（Skill）
- **THEN** Buildr MUST 显示该实例无法启动的原因并保留配置，无关连接和安全查看动作 MUST 继续可用

### Requirement: 启动与业务结果分别解释并保留未知结果
Buildr MUST 报告程序启动、退出、超时及输出通道状态；专业技能（Skill）和程序 MUST 根据系统记录核验实际业务结果，不能以退出码或请求受理替代专业成功。输出 MUST 避免披露认证；写入请求超时或结果未知时 MUST 先调查实际记录，不自动重复提交。Buildr MUST NOT 将通用启动机制变成业务编排或许可层。

#### Scenario: 程序在结构化输出的键中回显秘密
- **WHEN** 程序将已知秘密嵌入标准输出或标准错误的 JSON 字符串值或对象键
- **THEN** 普通结果不披露该秘密，不因对象键包含前后缀或转义形式而绕过保护

#### Scenario: 专业写入请求超时
- **WHEN** 程序提交配置发布后超时且未能核对实际结果
- **THEN** 结果 MUST 明确为未知并保留可调查的非秘密对象依据，不自动再次提交，不宣称发布成功

### Requirement: 官方作者技能指导完整接入成果及分层验收
Buildr MUST 提供 `connection-authoring` 技能（Skill），指导智能体（Agent）在 `skills/connections/<skill-id>/` 交付 `SKILL.md`、连接声明、所需程序、依赖与安装说明及必要参考材料。指导 MUST 覆盖受限展示分组与发现输入依赖、真实能力调查、上下文使用、对象定位、授权、副作用、成功失败未知判断、写前再校验、秘密输出检查、兼容更新和停用处理；MUST 区分源已制作、已登记启用、程序可执行和实际接入已验证，不要求每个系统制作完整控制台或建立统一专业命令。

#### Scenario: 制作公司私有连接方法
- **WHEN** 用户授权智能体（Agent）为未知私有系统制作接入成果
- **THEN** 官方指导 MUST 引导其制作可独立维护的完整技能源目录与检查证据，不包含真实密码，不把安装或真实外部写入当作制作完成的默认动作
