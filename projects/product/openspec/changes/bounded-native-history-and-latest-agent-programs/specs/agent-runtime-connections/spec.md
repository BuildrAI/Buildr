## MODIFIED Requirements

### Requirement: 首次程序准备与连接
系统 MUST 发现明确来源的本机可用程序并按主版本范围进行版本准入；Codex、DSH 接受 `0.x.x`，Qoder CLI 接受 `1.x.x`，包含有效预发布版本与构建标记。系统 MUST NOT 仅因同主版本内的次版本或补丁变化拒绝继续连接验证。版本符合范围 MUST 只表示可以进入实际协议、账号、模型和所需能力检查，不能单独证明接入可用；其他主版本或无效版本 MUST 返回相关程序的局部诊断。显式或已绑定程序缺失 MUST NOT 静默回退。多来源 MUST 允许明确选择，已有原生绑定和独立配置 MUST 保留；本次准入策略调整 MUST NOT 改变既有绑定指纹或原生会话编号，也不能放松准确来源和配置身份检查。缺失时 MUST 提供官方安装引导或按显式安装动作准备官方默认发布的最新独立程序；下载前 MUST 从固定厂商包源核对最新版本，不能以产品内固定版本或旧受管包代替，读取失败时 MUST 明确停止且不降级安装。下载版本 MUST NOT 被当作唯一兼容版本。用户 MUST 不必手动安装 SDK 或单独下载 App Server。浏览器工具 MUST 继续由智能体（Agent）按技能（Skill）准备。

#### Scenario: 缺失程序到首次登录
- **WHEN** 用户选择一家尚无可用程序的接入并执行准备
- **THEN** 系统 MUST 展示对应官方安装入口或独立安装动作，按准确尝试显示进展和失败，并在程序验证后进入独立官方登录
- **AND** MUST 仅在实际账号和非空模型目录检查通过后显示可用

#### Scenario: 重试、取消与原绑定
- **WHEN** 准备重复、取消、失败或发现外部安装版本变化
- **THEN** 系统 MUST 保留既有程序、账号和对话，取消本次拥有的动作并拒绝陈旧改绑；重试 MUST 重新观察当前事实
- **AND** MUST NOT 自动更新、覆盖原程序或复制桌面凭据

#### Scenario: 主版本内更新
- **WHEN** Codex 从 `0.163.x` 更新到 `0.164.0-alpha.11.1`，或 DSH、Qoder CLI 在各自准入主版本内更新
- **THEN** 发现与执行 MUST 使用一致的主版本范围允许实际连接检查，不因旧的次版本范围直接拒绝
- **AND** 既有受管安装版本 MUST 保持独立，不因下载策略变化自动替换，也不要求用户降级或重新下载

#### Scenario: 版本符合而协议失败
- **WHEN** 程序符合主版本范围，但实际协议握手、账号或模型检查失败
- **THEN** 接入 MUST 如实显示对应失败或未认证状态，MUST NOT 显示已可用、自动重新登录、发送工作指令或改用其他程序

#### Scenario: 策略放宽后保留旧绑定
- **WHEN** 已有 v2 绑定仍指向同一准确程序和同一配置来源，程序进行了主版本内更新
- **THEN** 系统 MUST 保留原绑定指纹、原生上下文编号和账号，继续核对实际协议
- **AND** 程序来源、配置来源或既有绑定字段不匹配时 MUST 仍拒绝借用该上下文

## ADDED Requirements

### Requirement: 原生历史恢复必须按有界分页完整重建

系统 MUST 在恢复、历史读取、执行观察和派生时使用厂家提供的元数据与分页能力，不得要求单次原生响应携带完整线程历史。页面大小 MUST 低于本机原生传输上限，并 MUST 校验会话、回合、条目及游标身份，拒绝重复游标、越界游标或混合不同读取周期；长历史 MUST 保持全部可见消息和工具事实的顺序与身份，不能把部分页当作完整历史。单个不可分页条目超过安全上限时 MUST 局部失败并保留原生会话与已有事实，不能扩大全局传输上限、杀死整个原生控制通道或伪造恢复成功。Qoder 的分页快照 MUST 绑定准确上下文、目录和读取周期，过期或替换后 MUST NOT 与其他历史混合。

#### Scenario: 超大 Codex 线程恢复
- **WHEN** 既有 Codex 线程的完整历史超过单个原生响应安全上限
- **THEN** 恢复、历史读取、执行观察和派生 MUST 通过元数据及有界分页完成，保留全部回合、消息和工具事实
- **AND** MUST NOT 以完整 `includeTurns` 响应作为恢复前提，也 MUST NOT 把截断结果报告为完整历史

#### Scenario: Qoder 长历史跨页读取
- **WHEN** Qoder 会话包含大量消息，单个工作进程响应不能安全承载完整结果
- **THEN** 系统 MUST 在同一稳定快照内按游标读取全部页面，并按原顺序重建完整历史
- **AND** 每页响应 MUST 保持在安全帧预算内，分页 MUST NOT 改变对话、执行或工具来源身份

#### Scenario: 分页身份失效或单条过大
- **WHEN** 分页游标重复、快照过期、页面身份不匹配，或单个条目本身超过安全帧预算
- **THEN** 系统 MUST 明确返回该读取的局部失败并保留已有会话和记录
- **AND** MUST NOT 重放执行、提交部分历史、扩大全局帧上限或终止其他仍可用的原生连接
