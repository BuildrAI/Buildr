## Context
动机见 proposal.md。当前 `ConversationOptions.tsx` 只读取 `conversation.run.contextUsage`，并以当前选择的模型、账号和提供方过滤；新执行替换 run 或选择变化会直接丢失展示。`ConversationPanel.tsx` 还按选择和面板状态重建选项组件，因此不能仅在选项组件中放一个引用保存旧值。输入区样式使用混合行内元素，按钮未统一继承行高。

## Goals / Non-Goals
目标是当前页面内连续展示可信观察，并防止跨对话或跨模型窗口混算。不新增持久化统计历史，不估算未上报用量，不改变模型执行、发送准入、补充输入及权限边界；完整页面重载仅依据现有可读取事实恢复。

## Decisions
- 保留最近报告而不是禁止选择下一轮模型。选择与执行已有明确分离，禁止选择会增加不必要限制；当前执行仍遵守原绑定。
- 在不会随选项重建的既有对话状态所有者维护有界、按工作空间及对话身份隔离的最近观察。报告保存运行身份、模型、账号来源、用量和窗口口径；不把报告复制到新 run 冒充新一轮数据。
- 优先使用报告窗口，缺失时只以该报告真实来源和档位对应的目录窗口补足；冻结已采用的口径。当前模型配置单独显示，不参与旧报告百分比。没有可信窗口时只展示用量。
- 新报告整体替换，包括零值和压缩后下降值，不取历史最大值。既有事件版本及选择保护继续拒绝迟到的无关结果。
- 说明区显示最近报告的来源与非累计计费说明，不新增弹窗提醒。此选择以心流（Flow）为启发减少无价值打断，但不将旧数据冒充实时报告。
- 输入区采用局部同行对齐与继承字体、行高，保持现有主题及可换行边界，不重画布局。

## Risks / Trade-offs
- [组件重建丢数据] → 最近观察置于稳定状态所有者，并覆盖发送、模型选择和面板开合测试。
- [不同来源同名模型] → 使用准确账号、模型及执行身份，不按显示名称匹配。
- [缓存无限增长或泄漏] → 有界保存并按对话隔离；不写浏览器永久存储。
- [窗口未知或目录短暂缺失] → 保留可信窗口；从未获得窗口则不伪造百分比。
- [页面重载丢失内存观察] → 本轮不扩展服务端协议，明确只恢复已有可读取报告；后续若需跨重载历史统计另行设计。

## Migration Plan
无数据迁移与新依赖。新增状态可选，不要求模拟调用方强制提供；已有执行事实结构保持不变。部署与回退均沿用常规前端构建及开发应用更新，本轮规划不执行更新。
