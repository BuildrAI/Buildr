## MODIFIED Requirements

### Requirement: 知识导航必须保留项目阅读上下文
项目知识 MUST 在同一项目主标签内进入，保留返回项目及浏览历史。左侧目录中的主题与成果入口 MUST 统一进入主屏详情，文中关联的技术图、地图与文件 MUST 在副屏阅读；同一范围切换正文、阅读方式或筛选 MUST 保留已有副屏及其阅读状态。源码与技能详情 MUST 复用已有副屏模式，关闭后回到原阅读上下文。

#### Scenario: 从文章对照图示与代码地图
- **WHEN** 用户从项目进入知识文章并打开内嵌成果
- **THEN** 不增加第二个项目主标签，副屏显示同一成果，主文档仍可阅读
- **AND** 切换项目、返回或关闭副屏不静默混用其他主题与来源

服务知识 MUST 在当前服务副屏进入，目录、成果与下级资料在原位阅读且支持返回服务；直接地址也 MUST 保留对应目录与服务身份，不新增服务知识主标签。文章关联知识 MUST 具有与知识入口一致的链接、图示、代码地图和来源诊断能力，合法引用不得显示原始标记或默默失效；读取仍限于已登记范围。

#### Scenario: 从服务及文章接续知识阅读
- **WHEN** 用户从服务详情进入知识，或从文章相关资料打开知识正文并跟随其链接
- **THEN** 主屏来源 MUST 保持，副屏原位展示完整内容、可读图示和链接，并可返回上一级
- **AND** 未登记或不可读引用 MUST 局部提示，不能扩大文件读取范围

从代码地图（Code Map）、来源文件或关联资料进入的 Markdown 阅读模式 MUST 与同一范围成果正文具有一致的链接、内嵌技术图及地图能力；只在选择查看原文后显示源标记。来源属于其他登记范围时 MUST 按其实际身份解析引用，不套用宿主范围。服务主页 MUST 以身份与职责为首；仅已有独立成果时在资料区提供次要知识入口，无内容不显示空卡，读取失败不得冒充尚无内容。

#### Scenario: 从代码地图打开正文来源
- **WHEN** 用户从项目代码地图打开含相对链接与内嵌成果的 Markdown 来源文件
- **THEN** 副屏 MUST 展示可点击链接和已登记的图示与地图，并可继续阅读及返回
- **AND** 查看原文 MUST 展示同一文件真实内容，不能因阅读入口不同退化为裸标记

#### Scenario: 服务尚无知识内容
- **WHEN** 用户打开没有独立知识成果的服务主页
- **THEN** 页面 MUST 先展示服务身份与职责，不显示顶部知识卡；已有资料、代码库与编辑仍可用
- **AND** 服务确有独立成果时 MUST 在资料区提供次要入口，旧知识地址继续可访问

### Requirement: 三类成果目录必须共享检索方式
主题阅读与文档目录 MUST 共用位于左侧目录上方的关键词检索和可选类型过滤，支持说明文档、技术图与代码地图，默认可查阅全部适用类型；检索范围明确为标题、主题或章节说明和已登记路径，空结果可清除条件。目录 MUST 保留匹配项祖先并展开可达条目，包括命中的补充阅读；过滤只影响导航，不清空右侧正文。代码地图 MUST 按实际成果提供专题与实现定位入口；没有明确建设状态依据时 MUST NOT 推断全景地图尚未建设。页级动作 MUST 保留单独构建技术图入口，指令以图示与事实依据为交付，不强制新建文章。

#### Scenario: 检索与单独构建技术图
- **WHEN** 用户切换分类或检索词后选择构建技术图
- **THEN** 目录展示匹配条目并保留当前范围，接续指令明确只构建所请求图示和必要关联
- **AND** 生成或复制指令不创建空图、不报告建设完成

### Requirement: 知识目录必须按页查询并返回有限摘要
兼容保留的项目与服务成果分页接口 MUST 使用目录专用只读查询，支持架构知识、技术图、代码地图分类及现有关键词匹配范围。每页默认且最多返回 20 项，响应 MUST 包含当前范围、索引版本、匹配总数、当前页条目及后续游标；条目仅提供导航所需摘要，MUST NOT 随目录响应返回完整索引、全部来源或正文。原有对象、成果和来源读取接口 MUST 保持兼容与既有读取边界。

#### Scenario: 打开有超过一页内容的目录
- **WHEN** 调用方通过分页接口读取包含 45 项匹配内容的目录
- **THEN** 首次请求仅返回前 20 项摘要、匹配总数与续页游标
- **AND** 分页查询不隐式读取完整索引正文或全部来源；主阅读导航可使用独立的有界元数据查询

#### Scenario: 分类检索与空结果
- **WHEN** 调用方以分类或匹配标题、主题说明或路径的关键词请求分页接口
- **THEN** 后端按条件分页，最后一页允许少于 20 项且没有后续游标
- **AND** 空结果返回零条目和无后续游标，不影响其他读取

### Requirement: 知识目录必须连续续载并保护阅读上下文
主阅读界面 MUST 使用独立的有界完整导航，不依赖滚动追加才发现主题或成果。查询、类型过滤、用户展开和选中正文 MUST 独立保留；进入正文、切换阅读方式及历史返回 MUST 恢复适用导航与阅读定位。搜索临时展开 MUST NOT 覆盖用户原展开状态。范围变化后旧异步响应 MUST NOT 污染新范围，失败 MUST 保留可用内容并允许显式重试，不无界自动重试。

#### Scenario: 滚动到续载触发位置
- **WHEN** 导航包含45项成果，用户滚动经过旧第15项续载位置或检索第45项
- **THEN** 无需加载更多即可定位该成果，导航不预读正文

#### Scenario: 检索与阅读独立
- **WHEN** 用户阅读正文时改变检索、选择匹配条目，再清空搜索或返回
- **THEN** 输入过程中原正文持续可读，选中文章后才切换正文，清空搜索恢复原树展开
- **AND** 历史返回恢复适用查询、过滤与阅读位置，其他范围的响应不得混入


#### Scenario: 续载失败或筛选在请求中改变
- **WHEN** 旧调用者的分页请求失败，或导航请求期间用户改变范围或筛选
- **THEN** 已读内容保持且可显式重试，过时响应被取消或忽略，成功条目按身份去重
- **AND** 主阅读目录不依赖续页，不因查询变化清空已选正文

### Requirement: 主题目录与全部资料必须共享唯一成果登记
主题目录 MUST 从当前范围索引的主题及父子关系呈现，主题资料（旧称“全部资料”）MUST 从同一索引的成果登记检索；两种入口 MUST 读取同一正文，MUST NOT 各维护一套文件或资料清单。主题阅读与文档目录 MUST 在顶部清晰切换，下方只展示当前阅读方式需要的目录；文档模式 MUST NOT 同时展示无关主题侧栏。全部主题资料 MUST 可从同一目录检索到，不用额外醒目的模式按钮与正文列表竞争；默认阅读仍由已登记默认主题决定。说明文档分类 MUST 包含普通说明与术语资料。

#### Scenario: 一份资料关联多个主题
- **WHEN** 同一已登记成果关联多个主题或暂未关联主题
- **THEN** 全部资料仍只列出该成果一次；关联主题中的入口指向同一份正文，未关联资料仍可检索

#### Scenario: 术语资料参与统一检索
- **WHEN** 当前范围登记了术语资料
- **THEN** 用户可在全部资料的说明文档分类检索和打开该成果，无需额外复制为普通说明

### Requirement: 知识入口必须呈现可持续探索的主题结构
项目与服务知识 MUST 复用索引中主题的父子关系与顺序呈现完整目录，MUST NOT 根据成果分页推断主题全集。索引 MAY 声明已登记的默认主题；正常进入时 MUST 阅读该主题，未声明时 MUST 提供主题入口，未建设时仍可发起探索和建设。目录读取 MUST 只获取有界主题和成果导航元数据，不读取成果正文和来源；成果只包含身份、标题、类型、路径及关联主题，MUST NOT 重复扩张主题长说明。用户指定的主题、成果、来源和文档定位 MUST 优先于默认主题；检索定位保留在左侧且不改变已经选中的正文，旧索引与旧链接 MUST 保持有效。

#### Scenario: 从整体认识进入专题
- **WHEN** 用户进入已声明默认主题的项目知识
- **THEN** 页面打开该主题，目录展示可继续选择的主题及其父子关系
- **AND** 切换主题后目录仍可到达，宽阅读区并列展示，窄阅读区可折叠展开

#### Scenario: 在主题内选择表达形式
- **WHEN** 主题关联了说明、技术图或代码地图
- **THEN** 用户可在该主题内查看这些成果，阅读引用与返回能力保持
- **AND** 没有直接成果的父主题仍提供子主题入口，不伪造正文

#### Scenario: 资料分页不隐藏主题
- **WHEN** 当前范围的成果超过目录单页数量，或某主题没有直接成果
- **THEN** 主题导航仍完整展示已登记结构，不依赖加载更多资料

#### Scenario: 保留全部资料与明确定位
- **WHEN** 用户主动进入全部资料、检索内容或打开已有成果链接
- **THEN** 页面遵守明确内容定位，检索保留在目录，旧全部资料地址仍进入主题阅读；未归入主题的成果仍可找到
- **AND** 从目录阅读内容后返回仍回到原检索范围

#### Scenario: 旧索引与无知识范围
- **WHEN** 有效索引没有声明默认主题，或范围尚无知识索引
- **THEN** 前者呈现主题入口与全部资料，后者保留只读探索与建设入口，不因新字段缺失报错

## ADDED Requirements

### Requirement: 两种知识阅读方式必须共享持续导航布局
主题阅读与文档目录 MUST 使用相同层级和交互：顶部切换阅读方式，左侧检索、可选类型过滤和语义目录树，右侧展示选中内容。选择内容后目录 MUST 仍可到达，不用物理文件树或大卡片列表替代语义阅读结构。宽阅读区 MUST 并列显示，窄屏和服务侧读 MUST 提供可折叠目录并保证搜索在目录上方，不挤出正文。探索与建设动作 MUST 与检索分离，主题内部成果切换仍限于当前主题。

#### Scenario: 主屏和侧读阅读
- **WHEN** 用户在项目主屏、服务侧读或窄屏切换两种阅读方式并打开内容
- **THEN** 使用同一目录和搜索交互，正文留在原阅读区，目录不消失或造成横向溢出
- **AND** 文内关联仍复用既有安全阅读器和主副屏身份

### Requirement: 文档目录必须支持已有真实文件作为入口
知识索引 MAY 可选指定文档入口的位置和相对路径；系统 MUST 仅从当前安全发现的文件中解析入口并返回可空的真实文档身份。正常进入文档模式时 MUST 打开有效入口，显式文档或成果定位优先。入口 MUST 在导航中可达，同一文件不得重复列入章节或计数；未配置、失效或格式错误时 MUST 保留文档目录供选择，局部诊断不得破坏主题读取或扩大扫描和读取权限。

#### Scenario: 默认阅读和明确定位
- **WHEN** 当前范围有有效文档入口且用户没有指定其他内容
- **THEN** 页面打开该入口，左侧选中同一真实文档，全部文档计数只包含它一次
- **AND** 带明确文档或成果身份的旧链接仍打开指定内容

#### Scenario: 入口不存在或试图越权
- **WHEN** 入口引用已删除、敏感、范围外或未发现文件，或入口配置无效
- **THEN** 文档目录保留合法内容，显示适用局部诊断，入口身份为空
- **AND** 不猜测打开其他文件，不阻止正常主题阅读，不通过入口绕过原安全扫描
