## Context

同一 Codex 工具名称及参数不变时，两个命令工具的原用途说明触发 MCP 拒绝；同义说明可被 SWE-2 接纳。默认权限的原生审批说明独立被内容策略拒绝，原生完全访问说明则可真实完成 high/max 读取回合。GPT-6.1 Sol 的额度错误尚不能证明整轮可用。

## Goals / Non-Goals

交付可核验的最小兼容路径。保留原生权限、工具身份、结果配对、参数语义和准确来源；不删原生权限指令，不自动改成完全访问，不将 SWE-2 结果推广到其他模型或 Qoder。

## Decisions

- 在 Devin 请求构造内部精确匹配 Codex 的两个已知说明，使用保持用途的同义说明。未知文本原样传递；不全局改名、不删除说明，也不改协议转换公共层。
- 兼容提示同时观察执行方、模型编号和当前显式权限。DSH 保持可选；仅 Codex/SWE-2/完全访问新增可选；其他组合继续可见但禁用。每个选项单独校验，分组提示解释部分可用。
- 复用现有选择、草稿与发送状态；切回默认权限后原选择和草稿保留，但预览及发送均禁止。权限选择仍由既有原生模式执行，不在模型选择中提升权限。
- 现有架构说明补充这条边界，操作指引给出准确条件。模块职责、接口及数据身份不变，不另建地图、图示或持久兼容注册表。

## Risks / Trade-offs

- 上游拒绝规则未知且可能变化 → 精确匹配已测文本，保留其他原值和真实失败，使用真实候选及开发版复核。
- 完全访问权限较宽 → 只承接用户显式选择，默认权限不自动更改；所测行为仅随机文件读取及结果接续。
- GPT 及其他模型未验证 → 保持不可选提示和原后端诊断能力，不能以额度错误或声明接纳冒充完整成功。

## Migration Plan

无持久迁移。交付后既有选择按当前权限重新观察；必要恢复使用新的普通变更，不改账号或会话历史。
