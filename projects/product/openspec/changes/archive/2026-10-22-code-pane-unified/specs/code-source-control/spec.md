## ADDED Requirements

### Requirement: 源代码管理双视图页签与单对象阅读
源代码管理 MUST 保留“列表 + 阅读区”两栏。阅读区顶部 MUST 固定渲染两个不可关闭的视图页签：“未提交变更”和“提交历史”，MUST NOT 为文件或提交创建阅读页签。左栏 MUST 保留紧邻列表的同名视图切换。两处入口 MUST 各自独立：左栏切换 MUST 只决定列表显示哪一类记录，阅读区页签 MUST 只决定阅读区显示哪个视图，切换任一处 MUST NOT 改动另一处的选中状态。用户在列表中选择文件、比较层或提交时，阅读区 MUST 切换到该对象所属视图并替换当前阅读对象。

阅读区同一时刻 MUST 只显示一个对象：当前未提交差异、当前固定历史差异、临时完整文件或提交详情。用户从左侧选择另一个文件、比较层或提交时 MUST 替换当前阅读对象，而不是保留为另一个页签。切换到“提交历史”并选择提交时 MUST 显示提交详情，展开并选择文件后 MUST 显示该固定提交的差异。

两个视图 MUST 分别保留自己的阅读现场：未提交视图保留变更文件与比较层，历史视图保留固定提交、历史文件与提交详情状态；切换视图后 MUST 恢复对应现场，MUST NOT 把另一视图的选择当作当前对象。切换视图 MUST NOT 关闭或清理另一视图的选择。

完整文件和提交详情 MUST 作为当前阅读对象的临时视图：查看完整文件后 MUST 提供“返回差异”，提交详情后 MUST 能通过选择历史文件回到差异；返回目标 MUST 遵循当前视图。当前对象被清空时 MUST 显示空态并说明从左侧重新选择。

源代码管理 MUST 按工作树保存两个视图最近选择的变更文件、历史文件、提交详情状态、对比模式、完整文件分页与阅读位置，切换工作树后返回时恢复该工作树现场，MUST NOT 混入其他工作树的对象。阅读视图与左栏列表模式各自保持全局：切换工作树 MUST 保持两处当前的“未提交变更 / 提交历史”选择，不切换到另一工作树保存的旧状态。

#### Scenario: 阅读区固定两个视图页签
- **WHEN** 用户打开源代码管理并查看阅读区顶部
- **THEN** MUST 只显示“未提交变更”和“提交历史”两个不可关闭的视图页签，默认激活“未提交变更”
- **AND** 阅读区 MUST NOT 出现文件或提交页签，左栏 MUST 保留紧邻列表的同名视图切换

#### Scenario: 两处视图入口各自独立
- **WHEN** 左栏列表显示未提交变更，用户点击阅读区的“提交历史”页签
- **THEN** 阅读区 MUST 切换到提交历史视图，左栏列表 MUST 仍显示未提交变更且切换选中项保持不变
- **AND** 用户改点左栏“提交历史”切换时 MUST 只显示提交历史列表，MUST NOT 替换阅读区当前对象
- **AND** 用户在任一列表中选择文件或提交时 MUST 让阅读区显示该对象并激活其所属视图页签

#### Scenario: 视图切换保留各自现场
- **WHEN** 用户在“未提交变更”选择未暂存差异，切换到“提交历史”选择提交与历史文件，再切回“未提交变更”
- **THEN** 第一次返回 MUST 恢复先前的未暂存差异，且不创建文件页签
- **AND** 再次切换到“提交历史” MUST 恢复先前的固定提交与历史文件差异

#### Scenario: 选择另一差异替换当前阅读
- **WHEN** 用户依次打开同一工作树的已暂存差异与未暂存差异
- **THEN** 阅读区 MUST 只显示最后一次选择的差异，MUST NOT 出现两个文件页签
- **AND** 从左侧重新选择先前文件时 MUST 重新读取并显示该对象，不保留为隐藏页签

#### Scenario: 完整文件与提交详情为临时对象
- **WHEN** 用户从差异查看完整文件，或从提交历史打开提交详情
- **THEN** 阅读区 MUST 用当前对象显示完整文件或提交详情，MUST NOT 新增文件页签
- **AND** “返回差异”或选择历史文件 MUST 回到当前视图对应的差异；清空对象后 MUST 显示可重新选择的空态

#### Scenario: 工作树现场恢复
- **WHEN** 用户在工作树 A 的某个视图选择差异或历史对象，切换到工作树 B 后再切回 A
- **THEN** 工作树 B MUST 只显示它自己的当前对象，MUST NOT 显示 A 的对象
- **AND** 返回 A 时 MUST 恢复 A 在当前视图最近选择的文件、比较层、对比模式、分页和阅读位置
- **AND** 切换工作树 MUST 保持当前视图，不恢复到其他工作树曾使用的视图

#### Scenario: 视图切换不累积
- **WHEN** 用户在同一工作树反复切换阅读区“未提交变更”和“提交历史”页签
- **THEN** 左栏列表 MUST 保持用户离开时的模式，阅读区 MUST NOT 因切换而创建文件页签
- **AND** 两个视图 MAY 各自保留一个当前阅读对象，切换时替换显示而不并排累积
