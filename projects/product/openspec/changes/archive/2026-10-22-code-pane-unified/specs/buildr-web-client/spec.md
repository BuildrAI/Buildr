## ADDED Requirements

### Requirement: 代码页页内标识与展开阅读
代码区域的资源管理器与源代码管理 MUST 保留现有“列表 + 阅读区”两栏，MUST NOT 在页内重复渲染与中屏页面页签相同的页面级页签、标题或 `tabpanel` 包装。源代码管理左栏 MUST 以“代码库”表达代码库与工作树目录，资源管理器左栏 MUST 以“目录”表达文件树导航；两者 MUST NOT 再次以所在页面名称命名局部区域，资源管理器 MUST NOT 重复栏内“文件”分组标题。源代码管理阅读区顶部的“未提交变更 / 提交历史”MUST 只作为阅读区视图页签切换阅读内容，MUST NOT 联动改变左栏列表模式，也 MUST NOT 冒充页面级导航或复述页面名称。

代码页的“展开阅读 / 恢复分屏”控件 MUST 只显示图标，MUST 提供悬停提示、可访问名称和键盘操作；没有可阅读对象且未展开时 MUST NOT 显示该控件；资源管理器在窄屏文件树隐藏时 MAY 保留恢复目录入口，源代码管理已展开但当前对象为空时 MUST 保留“恢复分屏”入口。源代码管理的展开按钮 MUST 位于阅读区视图页签行右端，不得遮挡视图页签或其他来源操作。展开后列表收起、阅读区占满可用宽度，恢复后回到原分栏宽度与阅读对象。

#### Scenario: 页内不重复页面标识
- **WHEN** 用户打开源代码管理或资源管理器
- **THEN** 页面 MUST 只保留中屏页面页签中的“源代码管理”或“资源管理器”标识，MUST NOT 在内容区渲染第二条同名页签条或同名局部标题
- **AND** 源代码管理左栏 MUST 显示“代码库”并保留目录折叠与操作，资源管理器左栏 MUST 显示“目录”
- **AND** 源代码管理阅读区顶部的“未提交变更 / 提交历史”MUST 只切换视图，MUST NOT 与中屏页面页签混用同一导航层级
- **AND** 内容区 MUST 保留列表与阅读区两栏，不新增第三栏或共享右屏宿主

#### Scenario: 图标化展开阅读
- **WHEN** 用户查看源代码管理或资源管理器的阅读区
- **THEN** 展开控件 MUST 只显示全屏图标并保留“展开阅读 / 恢复分屏”的提示与可访问名称
- **AND** 源代码管理的展开按钮 MUST 位于阅读区视图页签行右端，资源管理器的展开按钮 MUST 位于文件页签行
- **AND** 没有可阅读对象且未展开时 MUST NOT 显示展开控件；资源管理器在窄屏文件树隐藏时 MAY 保留恢复目录入口，源代码管理已展开但当前对象为空时 MUST 保留恢复分屏入口
- **AND** 展开与恢复 MUST 保留当前视图页签、读取内容、滚动位置和已调分栏宽度
