## ADDED Requirements

### Requirement: 资源管理器左栏标题与多文件页签
资源管理器左栏标题 MUST 使用“目录”，MUST NOT 再次显示“资源管理器”这类与中屏页面页签重复的页面名称，也 MUST NOT 重复栏内已有的“文件”分组标题。多个打开文件 MUST 继续由阅读区文件页签承载，页签 MUST 保留真实代码库、工作树、路径及固定提交身份；同名文件 MUST 使用可区分标签，不得按相对路径覆盖另一份文件。

阅读区的“展开阅读 / 恢复分屏”控件 MUST 只显示图标，MUST 保留悬停提示、可访问名称与键盘操作；没有打开文件且文件树可见时 MUST NOT 显示该控件；窄屏文件树隐藏时 MAY 保留恢复目录入口。展开与恢复 MUST 保留已打开页签、当前文件、搜索结果、滚动位置和已调目录宽度。

#### Scenario: 左栏标题不与页面页签重复
- **WHEN** 用户打开资源管理器
- **THEN** 左栏标题 MUST 显示“目录”，文件树与代码库选择 MUST 保持可用
- **AND** 左栏 MUST NOT 再次显示“资源管理器”或“文件”这类重复标题，也 MUST NOT 出现第二条同名页签条

#### Scenario: 多文件页签与图标化展开
- **WHEN** 用户依次打开多个文件并查看阅读区
- **THEN** 已打开文件 MUST 以多个页签保留，激活、关闭和同名文件区分 MUST 与既有页签行为一致
- **AND** 展开控件 MUST 只显示图标并提供“展开阅读 / 恢复分屏”提示；无打开文件且文件树可见时 MUST NOT 显示，窄屏文件树隐藏时 MAY 保留恢复目录入口
- **AND** 展开或恢复后 MUST 保留页签、当前文件、搜索结果、滚动位置与目录宽度
