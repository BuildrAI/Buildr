## Purpose

让用户在 Buildr 的统一对话中使用独立管理的 Claude 原生执行能力，并选择已有模型来源；保护账号隔离、准确执行控制、历史接续及失败可解释性，不将模型兼容路径冒充厂商官方支持。

## ADDED Requirements

### Requirement: Claude 程序与账号配置必须独立

Buildr MUST 将 Claude 执行程序纳入准备、版本核验与更新管理，隔离配置、会话和认证；MUST NOT 复制用户默认账号或提供未经许可的 claude.ai 订阅登录。使用共享模型 MUST NOT 要求 Claude 订阅账号。

#### Scenario: 首次准备并使用共享模型
- **WHEN** 用户准备 Claude 执行程序并选择已就绪共享模型
- **THEN** 系统使用独立配置执行，不修改全局 Claude 设置，不要求订阅登录

### Requirement: Claude 必须复用统一模型选择

系统 MUST 将主对话、子智能体、压缩与辅助推理绑定到本轮所选来源及模型，不静默切换或额外消费未选择模型。MUST 按真实能力传递思考档位、图片与窗口；不支持时明确失败。非 Claude 模型 MUST 表达为 Buildr 兼容路径而非官方支持承诺。

#### Scenario: 子智能体与压缩
- **WHEN** Claude 使用共享模型启动子智能体或压缩上下文
- **THEN** 模型请求仍使用本轮租约和准确模型，窗口与输出上限不冒用 Claude 默认值

#### Scenario: 模型失败
- **WHEN** 所选来源拒绝请求、额度不足或协议不兼容
- **THEN** 保留具体诊断与既有结果，不回退模型、不重放结果未知的工具

### Requirement: Claude 必须接入完整交互控制

系统 MUST 投射流式文字、工具、公开思考及子调用归属，支持原生提问审批、执行中追加与准确中断。完全访问 MUST NOT 代答业务问题。停止 MUST 区分模型中断、待发队列、活动后台任务与未知副作用；仅有准确原生身份时允许单工具停止。

#### Scenario: 完全访问中的问题
- **WHEN** Claude 通过原生工具询问业务决定
- **THEN** 系统显示可回答的问题，等待明确答复，不以权限模式推断答案

#### Scenario: 追加与停止
- **WHEN** 当前执行存在追加输入与后台任务，用户停止整个对话
- **THEN** 系统处理准确已受理输入及后台任务，不能只中断模型后宣称全部停止

### Requirement: Claude 历史与成果必须可接续

系统 MUST 按准确程序、配置、工作目录与会话读取历史和原生工具详情，支持原生恢复与分叉，复用统一交接、子对话、任务关联、标题、通知及附件能力。历史缺失或执行未知 MUST NOT 触发自动重发；子智能体内部输入 MUST NOT 成为新的用户授权。

#### Scenario: 重启与详情读取
- **WHEN** 页面或后台重启后重新打开对话并展开工具
- **THEN** 从准确原生历史恢复，按有界读取提供详情，源缺失只影响相关详情

#### Scenario: 分叉
- **WHEN** 用户从已结束轮次的准确答复分叉
- **THEN** 新会话拥有独立身份，原会话及文件不被回滚或修改

### Requirement: Claude 资源释放必须依据真实执行

系统 MUST 按准确所有权维护进程、后台任务、待决定、在途输入和模型请求；仅在逻辑静止与物理控制资源退出可证明时释放。失去观察 MUST 保留 unknown，不以资源关闭证明工具成功。

#### Scenario: 工具仍在运行
- **WHEN** 主模型结束但原生后台任务尚未结束
- **THEN** 对话仍显示后台工作并保留控制，不提前回收或宣称完成
