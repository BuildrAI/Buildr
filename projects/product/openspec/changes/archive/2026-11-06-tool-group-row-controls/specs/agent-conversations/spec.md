## MODIFIED Requirements

### Requirement: 执行过程必须自然平铺并保留失败提醒

执行中助手说明与工具组 MUST 按实际顺序展示；连续工具 MUST 默认汇总折叠，第一条起 MUST 保持稳定身份与布局。工具组展开后各调用 MUST 按原顺序可读，助手说明 MUST NOT 被压入工具组。每条工具的原输入输出 MUST 可独立展开查看。展开的工具组 MUST 限制可视高度；组内条目超出该高度时 MUST 在组内滚动，MUST NOT 以条目数量撑满整个可视区域。展开状态 MUST 由工具组行自身切换收起，MUST NOT 在组内重复提供底部收起按钮。工具组行 MUST 与组内具体工具行保持可辨识的层级差异；该差异 MUST NOT 使用整行背景强调。执行结束后过程 MUST 自动折叠；再次展开 MUST 与最终答复保持同一左边界，不添加层级竖线。工具组折叠时 MUST 保留调用数量、失败及结果未知的文字与图标提醒，不增加整行背景强调。加载更早记录与实时事件 MUST 保留可见阅读位置和明确展开选择。模型思考 MUST NOT 作为处理过程节点展示：带思考标记的历史条目 MUST 被跳过，MUST NOT 计入工具组数量，也 MUST NOT 冒充助手说明。

#### Scenario: 执行从一条增长到多条

- **WHEN** 当前过程收到更多助手说明或连续工具
- **THEN** 新说明和工具组 MUST 按原顺序显示，连续工具 MUST 汇总到原组；已明确展开或收起的选择、已有工具详情和阅读位置 MUST 保持

#### Scenario: 完成后查看过程

- **WHEN** 本轮结束且用户再次展开已折叠过程
- **THEN** 说明与工具组 MUST 与最终答复同级展示，组内不得添加层级竖线；失败及结果未知摘要 MUST 仍明确可见

#### Scenario: 旧记录并入同一分组

- **WHEN** 用户主动加载更早记录
- **THEN** 系统 MUST 保留已观察的阅读位置和工具详情展开选择，不因首条来源变化丢失定位

#### Scenario: 模型只输出思考

- **WHEN** 一轮执行的中间步骤只产生模型思考片段，没有可见文字
- **THEN** 处理过程 MUST 只呈现该步的工具调用，MUST NOT 出现思考节点或思考正文
- **AND** 历史记录中被跳过的思考条目 MUST NOT 改变工具组身份、计数与最终答复判定

#### Scenario: 展开大量工具调用

- **WHEN** 一个工具组包含数十条调用并被展开
- **THEN** 组内容 MUST 在受限高度内滚动，MUST NOT 撑满整个可视区域

#### Scenario: 收起已展开的工具组

- **WHEN** 用户点击处于展开状态的工具组行
- **THEN** 工具组 MUST 收起并要求再次点击组行才能展开
- **AND** 组内 MUST NOT 存在重复的底部收起按钮

#### Scenario: 工具组行与组内条目区分

- **WHEN** 工具组被展开或处于执行中
- **THEN** 组行 MUST 通过字重、颜色、间距或展开态分割线与组内具体工具行区分
- **AND** 组行 MUST NOT 使用整行背景强调，执行中 MUST NOT 额外增加行前光点
