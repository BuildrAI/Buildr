## Context

参见 proposal.md。当前 ConnectionsPage 使用局部页签（Tabs）；WorkspaceStage 已提供中屏目录与右屏对象，ResizablePanels 已提供与三屏共用 SplitDivider 的拖动、键盘及尺寸记忆。此轮属于明确布局修正，无需新建原型（Prototype）；历史原型的资源栏、编辑器和下方结果关系保持。

## Goals / Non-Goals

让功能工作面（Workbench）沿既有三屏承载且贯通高度。只保存当前页面的查询实例和本机布局偏好，不新增查询会话持久化或路由（Route）；普通实例的连接行为、数据库偏好及执行规则保持。

## Decisions

1. ConnectionsPage 通过 WorkspaceStage 的对象页签（Object Tab）打开一个查询工作面；通过可选保留内容属性（retainObjectContent）保持右组实例挂载，关闭仅隐藏并令 active=false；重复打开同一连接不清空草稿。相较新增全局资源预览类型，本地装配范围更小，也没有未经要求的深链承诺。
2. 两层 ResizablePanels：外层纵向分配上方数据库/编辑与下方全宽结果，默认 40%/60%；内层仅在上方左右排列数据库与编辑器，数据库栏默认 200 像素。数据库栏最小约 130 像素，编辑器最小约 260 像素；上下区域最小约 160 像素，不可能满足时由组件按比例收缩。尺寸记忆沿用同一工作空间键；数据库宽度比例在上方宽度中计算。
3. 重开刷新保留同一连接及版本的已确认数据库偏好快照（Snapshot），只在权威响应确认目标变化时隔离结果。失活只取消未完成请求、关闭浮层，不清理已返回的结果。
4. 右屏增加可选功能内容模式（Content Mode），将高度和无内边距明确传递给工作面；默认阅读行为不变。操作区域使用“展开查询”等适当文案。
5. 结果表格（Table）测量实际容器高度，扣除头部、表头及实际语句区，以现有表格滚动机制呈现数据；空态居中。警告和错误放在结果区域内，避免从编辑区挤出未受控高度。

6. 开发预览（Preview）可显式选择同渠道默认的只读认证来源，仅适用于规范工作空间实时数据模式。预览身份（Identity）记录该选择和目标来源，运行时（Runtime）校验后只读访问已有认证，保留认证编号与目标绑定；拒绝连接配置写入，避免实时元数据指向隔离认证。原模式与任务快照模式保持隔离，不复制密钥。实际验收入口须指向已保存连接所属的准确工作空间。

## Risks / Trade-offs

- [关闭导致草稿丢失] → 保持查询实例挂载并关闭活动请求来源；重新打开同一连接不重置草稿。
- [多层容器仍出现空白或溢出] → 显式功能内容模式贯通满高，浏览器核对不同窗口、展开及空态/结果态。
- [右屏较窄导致工具栏拥挤] → 局部工具栏允许换行，数据库栏有下限，用户可展开查询。
- [结果表格高度观测产生反馈循环] → 观察稳定容器和内容头部，不观察由计算值直接决定的表格主体。


## Migration Plan

无数据迁移。重新构建前端并重新启动对应代码版本的预览后生效；真实连接验收须选择正确的规范工作空间并显式启用同渠道只读认证来源。回退代码并重启预览可恢复原展示及隔离模式，不触及正式连接配置或认证。现有知识入口中没有说明查询中屏布局或固定高度的长期文章与图示，此轮只复核已有职责描述，不新建知识成果。
