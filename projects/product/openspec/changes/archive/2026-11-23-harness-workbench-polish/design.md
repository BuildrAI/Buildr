## 取舍

- 在源代码管理活跃且网页可见时，低频比较已绑定目录的轻量 Git 拓扑。工作树、分支或 HEAD 改变才读取完整状态，合并并发读；关闭或切换取消旧观察。独立版与 DSH 共用这一处理，不将对话执行状态视为 Git 事实。
- 共用受控搜索控件，调用方继续持有范围、输入和查询规则。对话范围选择立即生效；资源管理器空输入仅切换模式。模型使用锚定在标题行的延迟提示，保留键盘可达性、不改变行高；独立导航仍保留。
- 自举在保留检出判读包输入，使用已有 DSH 安装入口，按配置和旧包来源确认同一所有者。运行中只准备候选并报告，不重启；未安装不新建。首次接入以本工作空间的旧本地包为准，不迁移正式包或其他工作空间的绑定。
