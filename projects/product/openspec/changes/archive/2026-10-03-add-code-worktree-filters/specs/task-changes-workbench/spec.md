## ADDED Requirements

### Requirement: 任务当前改动保留实际检出来源
任务未提交文件列表 MUST 为每个可读改动返回实际检出来源身份；全文差异读取、刷新及完整文件跳转 MUST 传递并核对该身份。显式来源读取 MUST 限定当前任务允许的代码库与检出集合，MUST NOT 因目录失效或同路径另一改动出现而自动重选。未带来源的既有请求 MUST 保持兼容，历史提交（Commit）仍以完整提交标识固定版本。

#### Scenario: 主目录改动与任务目录不同内容
- **WHEN** 任务工作树（Worktree）没有某文件改动，而主目录具有该改动，两个目录的同名文件内容不同
- **THEN** 列表 MUST 返回主目录来源，全文差异和完整文件阅读 MUST 使用主目录内容，不以任务身份重选目录

#### Scenario: 列表来源失效
- **WHEN** 列表返回的具体检出位置在全文读取前被移除
- **THEN** 读取 MUST 返回明确来源失效诊断，不从其他目录重新选择同路径文件

#### Scenario: 外部检出身份
- **WHEN** 请求携带不属于任务当前允许检出集合的来源
- **THEN** 系统 MUST 拒绝该来源，不扩大任务范围且不执行Git写入
