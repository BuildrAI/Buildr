# 代码库与工作树联动筛选

本次变化让资源管理器独立选择真实工作树（Worktree），并保证任务跳转到改动实际所在目录，便于继续阅读完整实现。[任务说明](@task/code-worktree-filters)说明目标、范围与验收。

代码库多选与工作树（Worktree）单选互相限定候选；不选择工作树（Worktree）时查看主目录，清空代码库时查看全部实例；任务跨库成员按真实任务关联归为一个同名组选项。技能（Skill）在实际创建职责中补充同任务跨库统一命名，既有目录继续保留。目录消失时报告该来源失效，保留已打开文件身份，不改读主目录。首版保留既有布局与源代码管理待建范围。

技术取舍见[设计](design.md)，行为约束见[资源管理器变化](specs/repository-file-explorer/spec.md)及[任务改动变化](specs/task-changes-workbench/spec.md)。
