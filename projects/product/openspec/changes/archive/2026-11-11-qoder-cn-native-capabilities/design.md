## Context

依据本机官方 Qoder CN 1.1.86 包与 Buildr 四个执行器。官方 ACP host 已实现表单 elicitation、多个 pendingCommands、带 userMessageId 的结束回执和 usage 计费汇总；实时 assistant 更新不携带原生消息 UUID。执行使用 model-access/accounts/native-qoder-cn，原生详情读取却使用 connections/qoder-cn。

## 能力核对

| 能力 | 其他执行器 | Qoder CN 原生证据与结论 |
|---|---|---|
| 业务问题卡片 | 三家均接入 | 官方 elicitation.form 开关及问答 schema，实施 |
| 执行中图文追加 | 三家均接入 | session/prompt→pendingCommands→命令队列，实施队列追加；接收回执可能迟于当前轮结束，不虚构即时 steering |
| 工具批准、权限模式 | 均支持，各家语义不同 | 已接入，保留原生选项和 yolo/default |
| 停止与原生上下文恢复 | 均支持 | 保留准确执行校验，取消覆盖原生排队请求 |
| 工具正文按需引用 | 均支持 | 修复账号根错位、旧引用和历史执行 context 证据 |
| 上下文占用 | Codex/DSH有事件，Qoder国际适配同样缺直接投射 | Qoder原生保存末次 assistant usage 的 input_tokens/context_usage_ratio；不拿累计 usage 当占用。实施有界读取及 usage_update 兼容 |
| 原生历史读取 | 三家 readHistory 均有实现 | ACP load 能回放；实时段落无原生UUID，不能无损回填已有消息；不新建“外部导入”，不把部分投射冒充完整恢复 |
| 从指定历史回复派生 | 三家有 forkContext | 官方 forkSession 复制当前全会话，无指定历史条目截止，不能等同 Buildr 历史派生，暂不声明 |
| 自动标题 | 三家有 generateTitle | ACP 无独立无工具标题接口；不能复用工作 prompt 产生额外推理，本次不伪造原生标题能力 |
| 压缩状态/窗口更新 | Codex/DSH有专项状态 | ACP当前桥接未转发原生压缩生命周期；用量读取识别压缩边界后等待新值，不模拟压缩事件 |
| 子智能体主从事件 | 其他执行器有原生父工具关联 | ACP当前更新缺少稳定主从身份，不能靠标题推断；保留原生文件工具读取支持，不把子输出伪造为主轮回执 |
| 第三方模型来源 | Codex/DSH/Qoder国际可使用统一网关 | CN当前绑定同账号原生模型；不能绕过当前来源选择和账号隔离约束，本次不扩展该路由 |
| 单独停止后台工具 | 各执行器依原生能力提供 | ACP仅会话cancel，无准确工具级stop，不能伪装支持 |

## Decisions

1. 表单提问按 schema 转为现有问题卡片，回答回传原始属性类型并验证。未知复杂schema局部拒绝，不自动代答；完全访问仍保留业务问题。
2. 追加使用同一 session/prompt。串行本地准入，所有待处理请求保持原执行的控制归属。只在原生 response 带准确 userMessageId 时确认追加；超时/断连保留未知，迟到回执可更新准确用户条目，不自动重发。主请求结束不等于排队追加结束。
3. 工具只从固定命名空间读取。新引用使用账号根；旧connections/qoder-cn引用在原位置不存在时按产品唯一账号根解析，并仍校验会话/CWD/工具唯一性，不按名称扫描其他账号。执行回执加入 resourceContext/resourceBinding，避免后续轮次丢失来源。
4. 上下文读取只查看准确文件的有界尾部完整记录，验证文件身份和会话/CWD/主链标记；取末次usage而不是求和。原生占比可独立报告，token数隐藏时不按配置窗口反推；界面在原有指示器展示原生百分比与“token数未报告”；压缩边界后不再把旧值作为新观察发布，等待新模型回执；界面保留的值标为最近一次报告。

## Risks / Trade-offs

- 原生追加回执较晚 → 允许发送状态持续，未知不伪造成功，保持控制资源到全部请求结算。
- 通用表单字段和现有问题卡片表达不同 → 仅转换可验证的标量/枚举/多选schema，类型和必填规则验证由适配负责；未实现的format约束明确拒绝。
- 巨大单条历史记录超过有界尾部 → 跳过不完整记录，不加载整会话、不虚构用量。
- 真实付费推理未授权 → 官方源码证据加真实子进程/文件集成测试，不宣称已验证真实模型行为。
