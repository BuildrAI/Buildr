# project-knowledge-browsing Specification Delta

## MODIFIED Requirements

### Requirement: 共享正文必须安全渲染本地 Mermaid 图示

对话、任务、项目文档及文章使用的共享正文阅读器 MUST 将完整 Mermaid 围栏默认渲染为图示，依赖 MUST 本地打包，不加载远程脚本。图示 MUST 保留查看源码和复制原始源码的能力；不完整围栏、加载失败、语法错误或安全限制 MUST 显示可读源码与真实说明，不得将回退报告为渲染成功。单图失败 MUST 不阻止其他正文或图示。

已渲染的图示 MUST 提供显式放大查看入口，并支持点击图示与键盘触发全屏矢量预览；在嵌套对话网页中预览 MUST 呈现在外层页面视口，支持自适应窗口、缩放、平移、1:1 比例切换、复制源码及导出图片，按 `Escape` 或关闭操作返回原阅读位置。在对话信息流（`.ac-stream`）中，已渲染的 Mermaid 图示 MUST 在保持原始纵横比的前提下按容器宽度和有界高度（`min(65vh, 520px)`）自动等比缩放适配显示，不出现水平或垂直滚动条，且在图示区域滑动滚轮直接顺畅滚动信息流；在任务资料、知识正文等非信息流阅读容器中，超限宽图或高图 MUST 保持在自身容器内局部滚动而不撑开页面，且当纵向滚动到达顶部、底部或无纵向溢出时继续同向滑动 MUST 自然衔接外层阅读容器滚动。

图示内容 MUST NOT 执行脚本、回调或加载外部资源，内嵌配置 MUST NOT 降低安全约束。正文更新和卸载后 MUST NOT 将旧异步图示插入新内容；重复图示 MUST 使用独立标识。宽图与高图在任何容器中均 MUST NOT 撑开页面水平布局。

#### Scenario: 多入口默认绘图及查看源码
- **WHEN** 用户在共享阅读入口打开包含完整流程图或时序图的正文
- **THEN** 默认显示真实图示，可查看与复制原始源码，中文和多个图示可独立阅读

#### Scenario: 信息流内已渲染图示等比适配无滚动条
- **WHEN** 对话信息流渲染宽高均大于可用预览区的 Mermaid 图示（含宽图、高图或缺少显式尺寸属性的 SVG）
- **THEN** 图示容器 MUST 完整等比缩放显示整张图示且不产生横向或纵向滚动条，在图示上滑动滚轮 MUST 直接带动信息流滚动；点击图示或放大按钮仍 MUST 打开全屏矢量预览

#### Scenario: 点击放大与全屏查看流程图
- **WHEN** 用户点击已渲染 Mermaid 图示、点击放大按钮或通过键盘激活图示
- **THEN** 系统 MUST 打开全屏矢量预览弹层完整呈现该图示，支持放大、缩小、拖拽平移、适应窗口与实际大小切换、复制源码及导出图片

#### Scenario: 图示内纵向滚动衔接外层信息流
- **WHEN** 鼠标位于 Mermaid 图示容器内并向下或向上滑动（信息流中自适应图示无内部滚动，或任务、知识正文等非信息流阅读区的图示自身无纵向溢出或已滚到顶部/底部）
- **THEN** 继续同向滑动 MUST 顺畅带动外层信息流或正文滚动容器滚动，不得在边界锁死外层滚动

#### Scenario: 流式更新与失败回退
- **WHEN** 围栏尚未闭合，或绘图失败、正文已更新或阅读器已卸载
- **THEN** 当前正文保持可读，不完整或失败图示保留源码，旧结果不覆盖新内容，其他图示正常显示

#### Scenario: 不可信图示与窄屏
- **WHEN** 正文含内嵌安全配置、外部图片、链接或脚本内容，或在窄屏/超宽图示下阅读
- **THEN** 内容不执行脚本、回调或请求外部资源，安全拒绝时回退源码；非信息流阅读区宽图只在自身容器横向滚动而不撑开页面，对话信息流内已渲染图示则等比自适应显示且不产生横向滚动条
