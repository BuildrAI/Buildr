## Context

HTML 预览已有经认证的只读端点；浏览器可在隔离框架内原生定位锚点。

## Goals / Non-Goals

让对话链接直达报告章节，不改后端路径语义、文件权限或沙盒；不新增其他文档格式的章节解析。

## Decisions

- 在对话链接打开层拆分路径与锚点；共享两种入口的解析规则，原样文件引用不拆。
- 锚点只参与前端显示，不参与文件定位或 API 请求；预览与新标签页共用最终地址。
- 用 `file://` 中的 `%23` 表达含 `#` 的文件名，保留该字符在路径中的语义，不把编码后的分隔符当成锚点。

## Risks / Trade-offs

裸路径在 `.html#` 处有歧义，因此链接使用锚点语义；有歧义的字面文件路径仍可用原样入口或编码文件链接打开。
