## ADDED Requirements

### Requirement: 受管程序包按真实引用回收
服务 MUST 将受管程序安装目录（`programs/<执行器>/` 下的版本包目录及遗留准备目录）纳入既有只读维护计划与条件执行。包目录仍被任何连接绑定、未完成的程序更新记录（含回退来源与待切换目标）或当前策略默认安装位置引用，仍被系统进程占用，未超过稳定窗口，或身份发生变化时，MUST 保留并报告理由；引用观察失败 MUST 保守保留受影响范围。全部引用解除且复查通过后，后续维护周期 MUST 能自动回收，不要求人工逐项清理，不长期遗留。回收 MUST NOT 触碰账号配置、原生会话或非受管外部程序。

#### Scenario: 更新换绑后的旧包
- **WHEN** 程序更新已完成换绑，旧包目录超过稳定窗口、无连接绑定、无未完成更新引用且无进程占用
- **THEN** 后续维护周期回收该旧包并报告实际效果，新包与账号配置不受影响

#### Scenario: 旧包仍被占用或引用
- **WHEN** 旧包仍被某连接绑定、被未完成更新记录作为回退来源引用，或仍被进程打开
- **THEN** 维护保留该目录并报告原因；引用与占用解除后的后续周期可回收，首次保留不阻断其他对象

#### Scenario: 计划后引用或内容变化
- **WHEN** 预览后出现新绑定指向该包、目录内容变化或引用观察失败
- **THEN** 执行跳过该包并报告原因，不采用过期计划，不扩大删除范围

#### Scenario: 崩溃遗留的准备目录
- **WHEN** 安装中断遗留的 `.prepare-*` 目录超过稳定窗口、无进程占用且身份复查通过
- **THEN** 维护可回收该目录；仍在写入或占用中的准备目录保留
