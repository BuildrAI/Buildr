## MODIFIED Requirements

### Requirement: 对话面板必须与原工作双屏独立共存
对话 MUST 默认位于原工作区最右侧，并支持收起、调整宽度、单独展开及移到左侧。移到左侧 MUST 将整个对话面板放在一级图标列之前；分屏模式下对话历史 MUST 在同一面板内替换显示并随面板移动，不新增并排历史栏。专注模式下对话历史 MUST 以对话左侧的临时列表栏打开，当前对话 MUST 保持可见且不被替换；选择对话、再次点击列表入口或导轨当前对话入口 MUST 关闭该栏并恢复完整专注布局。打开、关闭、调整或移动对话 MUST 保留原导航、中屏、右屏的页面、对象、折叠状态、滚动、未保存输入与手动宽度偏好。窄窗口 MUST 保持主要操作可达，无页面级横向溢出；关闭临时阅读或展开状态 MUST 恢复原工作现场。

悬停二级导航 MUST 保持工作区完整上下高度并使用紧凑内部间距；固定导航与对话 MUST 复用原有拖动组件及标题栏分隔标记。固定展开与专注模式下对话顶部 MUST 只常驻短标题与更多等高频入口；已创建对话的短标题点击 MUST 打开重命名，MUST NOT 弹出工作空间选择，未创建的新对话标题 MUST 为不可点击占位；对话信息与工作空间 MUST 改由底部所属工作空间名称触发查看。对话列表、返回对话与新建对话 MUST 由停靠导轨（窄屏为全局顶栏）的独立入口承担，MUST NOT 在对话或列表标题栏重复；导轨新建入口 MUST 在当前可见状态（固定或暂看）下保持原显隐，不强制固定或收起。暂看（peek）状态标题栏 MUST 保留列表、返回与新建入口，且使用它们 MUST NOT 固定布局。低频位置、账号、专注、停靠及标题操作 MUST 归入对应浮层或更多菜单；底部模型与思考深度（Reasoning Effort）MUST 按真实能力紧凑呈现，不以空白宽度填满输入栏。

#### Scenario: 日常两屏与展开四屏
- **WHEN** 二级导航和对话都收起，且原工作中屏与右屏均打开
- **THEN** 原工作内容 MUST 保持两屏；固定展开二级导航时 MUST 成为三屏，再打开对话时 MUST 成为四屏
- **AND** 用户收起原中屏或原右屏 MUST 仍能保留一块主工作屏，不要求关闭或重建当前对话

#### Scenario: 将对话移到一级目录之前
- **WHEN** 用户选择将对话移到左侧，再移回右侧
- **THEN** 左移时整个对话面板 MUST 位于一级图标列左边，右移时 MUST 位于原工作区右边
- **AND** 对话身份、历史、草稿与原工作屏状态 MUST 保持，移动 MUST NOT 触发执行

#### Scenario: 收起或单独展开对话
- **WHEN** 用户收起对话，或暂时单独展开后返回
- **THEN** 当前执行 MUST 不因界面显隐而停止，原工作页面与编辑现场 MUST 保持
- **AND** 窄窗口中对话输入、停止及关闭入口 MUST 可达，MUST NOT 以强行压缩所有屏幕造成页面横向溢出

#### Scenario: 专注模式浏览对话列表
- **WHEN** 用户在专注模式点击对话列表入口
- **THEN** 界面 MUST 在对话左侧打开临时列表栏，当前对话保持可见，MUST NOT 切换为整页历史视图或收起专注面板
- **AND** 再次点击列表入口或导轨当前对话入口 MUST 关闭该栏；选择一段对话 MUST 关闭该栏并打开准确对话，原执行与草稿 MUST 不受影响

#### Scenario: 入口收敛不重复
- **WHEN** 用户在固定展开或专注模式查看对话或对话列表
- **THEN** 标题栏 MUST NOT 显示与导轨重复的列表或返回入口，导轨入口 MUST 能完成视图切换与关闭临时栏
- **AND** 暂看状态标题栏 MUST 保留列表、返回与新建入口，使用它们 MUST NOT 固定布局

#### Scenario: 标题即重命名与全局新建
- **WHEN** 用户点击已创建对话的短标题，或在任意视图需要新建对话
- **THEN** 短标题点击 MUST 打开重命名而非工作空间弹层，工作空间与对话信息 MUST 改由底部所属工作空间名称查看
- **AND** 新建对话 MUST 由导轨（窄屏为全局顶栏）独立入口在对话、列表与专注视图均可用；固定与专注下列表与对话标题栏 MUST NOT 再提供新建按钮，暂看标题栏新建 MUST 保持不固定布局
