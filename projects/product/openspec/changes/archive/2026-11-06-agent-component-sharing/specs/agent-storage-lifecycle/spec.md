## ADDED Requirements

### Requirement: 默认复用宿主环境且定点隔离Agent数据

服务 MUST 优先复用明确提供的宿主HOME及工具环境，适配器 MUST 将账号、配置及会话隔离至原有私有目录。原生目录覆盖能力未经验证、不能完整覆盖或宿主路径缺失时 MUST 保留私有HOME兼容模式。切换不得停止或重发当前任务、改写原生历史或改变绑定身份。未知组件发现及共享 MUST 仅处理Buildr受管目录，不得扫描整理真实用户HOME。

#### Scenario: 已验证完整私有数据目录覆盖
- **WHEN** 新执行的适配器已验证目录覆盖且宿主HOME明确
- **THEN** 工具及子进程使用宿主HOME，账号及会话仍使用原私有目录，新组件无需逐个编写共享规则

#### Scenario: 无法验证完整私有数据隔离
- **WHEN** 提供者缺少目录覆盖能力或尚未核实
- **THEN** 保留私有HOME及准确兼容原因，不继承用户默认Agent账号

### Requirement: 未知组件通过安装证据自动共享

服务 MUST 在现有维护线程中持续发现受管HOME中的安装证据，按安装器协议核验而非逐个组件名配置。自动共享 MUST 校验完整性、准确文件范围、归属及版本；不得只凭名称、大小、年龄、package.json或相同内容共享未知文件。账号、会话和可变业务成果 MUST 保持私有。

#### Scenario: 新包名使用已有安装协议
- **WHEN** 从未见过的组件具有可核验安装清单和完整本地归档
- **THEN** 后台自动校验并复用公共内容，同版本同架构同内容不重复保存正文，无需用户提醒

#### Scenario: 证据缺失或内容冲突
- **WHEN** 清单、归档或文件不能完整核对
- **THEN** 保留对象及准确原因，内容变化后自动重新核验，不执行未知程序获取证据

### Requirement: 可写组件共享不传播修改

服务 MUST 为没有不可变运行契约的安装和缓存使用写时复制或具有同等写入隔离的共享机制。MUST 保留原路径、权限及运行兼容；不支持安全共享的平台 MUST 保留并报告，不得以可写硬链接替代。

#### Scenario: 共享后工具修改自身文件
- **WHEN** 任一Agent修改自己安装视图中的文件
- **THEN** 公共内容及其他Agent视图字节不变

### Requirement: 发现和迁移持续接续

服务 MUST 在原后台周期保存有界发现与共享游标，单个大HOME不得永久阻塞后续目录；活动、内容变化和暂时失败的对象 MUST 自动重试，状态包含原因及实际效果。执行结束后 MUST 能由后续周期接续而不需要人工提醒；MUST NOT 停止或重发用户工作。

#### Scenario: 目录超过单轮预算
- **WHEN** 发现或共享达到本轮预算
- **THEN** 保存接续位置并在后续轮次推进，不把部分扫描当完整证明

#### Scenario: 活动组件稍后闲置
- **WHEN** 前一轮组件因占用保留而后续确认闲置且版本稳定
- **THEN** 原维护机制自动完成符合条件的共享，报告真实结果

### Requirement: 优先复用电脑已有工具与缓存

服务 MUST 优先复用宿主已配置的工具安装和公共缓存路径，Buildr公共缓存仅作缺少系统来源时的兜底。配置读取 MUST 限于公开路径字段，账号配置不得复制。迁移 MUST 只向明确选择的缓存命名空间发布，MUST NOT 因共享而取得整个宿主目录的删除权。宿主缓存完整性与失效处理 MUST 保持原包管理器管理责任；Buildr自有旧缓存迁移 MUST 在活动时保留，并在后续空闲周期自动接续；项目锁文件、可变成果和第三方App内置内容 MUST 保留。

#### Scenario: 系统已有npm与Yarn缓存
- **WHEN** 宿主已有可核对的公共缓存位置
- **THEN** 所有Agent实际使用该位置，旧Buildr缓存安全合入，私有账号配置不被继承

#### Scenario: 系统来源暂不可用
- **WHEN** 路径不存在、声明冲突或原生维护被占用
- **THEN** 保留现有内容并使用明确的公共兜底或延迟维护，不阻止其他执行，不要求用户记起后人工检查
