## Why

已交付界面仍在栏目切换时丢失查看上下文，项目关联操作绕到抽屉，项目内服务详情重复展示关联项目，设置页也未采用共同页面宽度。本次只修正这四处连续工作体验，不改变数据结构或 Git 操作；无破坏性数据变更。

## What Changes

- 菜单恢复当前工作空间各栏目最近页面及副屏状态；显式从项目列表进入仍显示项目主页。
- 项目卡片内直接使用现有过滤、新增、选项组件关联服务，取消独立关联抽屉；新增服务仍沿用创建抽屉。
- 服务详情明确接收项目查看上下文，仅在该上下文省略反向关联项目区，全局目录保留完整关联信息。
- 设置页沿用目录页面的宽度、页头、留白和卡片表达，保留原有保存及冲突处理。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `buildr-web-workspace-application`：按用户补充移除编辑抽屉关闭时的二次确认，保存中保护及保存失败反馈不变。

- `workspace-asset-management-interactions`：栏目恢复、就地关联、项目视角与设置页一致性。

## Impact

影响前端应用导航、资源详情、项目关联选择和设置布局；通过已有后端关联接口读写，不新增接口、依赖、自动迁移或 Git 副作用。更新相关浏览器检查及已有代码地图的导航说明。
