## MODIFIED Requirements

### Requirement: 来源观察必须表达实际内容和局部限制
每次读取知识正文、图示、地图或来源 MUST 返回当前本地文件内容及可读性；成功状态 MUST 为 `readable`，缺失或不可读 MUST 分别表达。历史摘要字段 MUST 不触发变化、过期或待核对状态；读取 MUST 不写回文件或核对记录，不提供本轮新增的历史比较、确认与正文编辑接口。当前内容摘要可用于读取一致性，不得解释为语义验证或历史版本。

#### Scenario: 来源在两次阅读间改变
- **WHEN** 用户再次展开或刷新对象，其正文或来源内容已改变
- **THEN** 页面显示当前文件内容，不显示基于历史版本的告警，不要求更新索引摘要或人工确认
- **AND** 读取前后的文件及索引内容保持不变

#### Scenario: 一项来源缺失
- **WHEN** 相关来源被删除或访问失败
- **THEN** 页面明确该项限制，其他可读内容仍能查看，不用空白或全局故障隐藏事实

#### Scenario: 旧索引保留观察摘要
- **WHEN** 现有索引携带与当前内容不同的 observedDigest 或 graphDigest
- **THEN** 当前内容正常读取，旧摘要不影响可读状态，也不产生待核对要求

### Requirement: 阅读内容必须按理解目标组织来源
正文与地图 MUST 就近呈现必要规范、技能职责、代码位置和协作解释，默认不重复展开全部来源清单；实际来源缺失或不可读 MUST 保持可发现，并可打开相应文件查看；不为文件内容变化增加核对入口。目录与文件 MUST 使用原生可点击引用，范围根明确，长路径不得挤压职责文字。

#### Scenario: 不阅读源码理解实现
- **WHEN** 用户查看地图
- **THEN** 能结合职责说明、协作次序和带说明的目录结构理解实现，点击文件或技能后才进入具体内容

### Requirement: 独立技术图必须保留原生呈现
独立技术图详情 MUST 使用原 Archify HTML 的完整查看界面，只有文内预览使用嵌入模式；Buildr MUST 不复制图示内部工具栏或改写生成内容，列出明确关联的图源、展示、依据与引用文件。图示导出只允许下载本地成果，仍禁止主页面同源访问、外部连接及顶层导航。来源读取 MUST 只在缺失或不可读时提示，不保留独立来源核对栏目，也不因图源或展示与历史摘要不同而要求确认。

#### Scenario: 查看原图与维护文件
- **WHEN** 用户从技术图列表进入独立详情
- **THEN** 原生主题、检索、缩放及适用导出入口保持，图示文件树可以读取对应的实际文件
- **AND** 文件打开不执行其内容或放宽其他页面的隔离策略
