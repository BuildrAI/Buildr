## Context

模型供应商由 `buildr-agent` 的 `model-access` 统一管理：内置 `ModelProvider` 在服务启动时声明，账号行保存在应用私有 `accounts.json`，每个账号按 `ModelProviderRuntime` 执行 `inspect`、`configure`、`infer`。账号凭据只存在于账号私有目录（`model-credential.json`、`model-api-key.json` 或原生程序自己的私有配置）；linked 供应商（当前为 Qoder CN）由 `ensureLinked` 自动建立唯一账号行。执行器通过本机网关使用模型，不接触凭据。

现有界面把添加入口写死为两个 API 预设和自定义端点，供应商视图也没有声明哪些来源由智能体连接托管。删除能力此前被明确列为非目标，当前只有“断开”，且断开保留凭据文件。

本次变更在不改变模型调用与租约语义的前提下，补齐供应商目录呈现、独立凭据来源的删除与凭据清理，并明确托管登录的边界。相关约束见 `specs/model-provider-api-access/spec.md`、`specs/custom-model-providers/spec.md`、`specs/unified-model-subscriptions/spec.md` 与 `specs/shared-native-model-accounts/spec.md`。

## Goals / Non-Goals

**Goals:**

- 添加供应商列表与后端供应商声明保持单一来源，覆盖全部内置 API Key 与订阅登录来源。
- 为拥有独立本机凭据的供应商提供可确认、可审计的删除动作，并真正清理私有凭据。
- 删除前展示仍引用该供应商的对话数量，删除后保留对话并引导重新选择模型。
- 收敛历史重复的单账号内置供应商数据，避免列表出现无法再新增的旧卡片。
- 保留由智能体连接托管的登录来源，不让模型页的删除静默破坏智能体执行；同时提供明确的托管登录退出动作。
- linked 供应商删除后可再次接入，不被自动发现立即恢复。
- 供应商侧栏支持搜索与分类分组，适应自定义供应商数量增长。

**Non-Goals:**

- 不在模型页删除由智能体连接托管登录的账号；托管来源的登录退出通过断开对应智能体连接完成。
- 不删除供应商侧的远端账号、订阅或 API Key，只清理本机 Buildr 私有数据。
- 不删除、隐藏或改写任何对话；删除供应商只影响后续模型选择。
- 不改变模型调用、协议转换、额度观察、模型偏好合并与现有租约选择语义。
- 不实现供应商导入导出或跨机器同步。

## Decisions

### 1. 供应商目录由 Agent Service 声明，前端只消费

`ModelAccessApplication.list()` 返回全部供应商声明，并补充 `connectionId` 与 `linked` 元数据。前端不再维护预设数组，直接按供应商声明生成“添加供应商”选项。已存在的非自定义供应商显示“已接入”并禁用重复添加；自定义供应商允许多个端点。

备选方案是继续在前端维护预设并定期同步。该方案会让新增适配器仍需要改前端且容易漏项，不采用。

### 2. 删除只作用于模型服务拥有的本机凭据

删除资格由 `ModelAccountView.connectionId` 判断：没有 `connectionId` 的账号拥有 `model-access/accounts/<id>` 私有目录，可以删除；有 `connectionId` 的账号登录由智能体连接持有，模型页拒绝删除并指引到智能体页。该边界避免用户在一个入口删除后另一个入口仍保留可用登录，或让模型页删除破坏正在使用的智能体程序。

删除按已观察修订校验，停止登录尝试、等待进行中的检查结束、拒绝存在活动模型请求的账号，然后关闭运行时、撤销租约、移除账号行与模型偏好，最后删除私有目录。私有目录必须是普通目录，符号链接或其他异常来源拒绝删除。

### 3. linked 供应商使用抑制标记而不是禁止删除

Qoder CN 由 `ensureLinked` 自动建立账号行。删除后若只移除行，下一次后台核对会立即重建一个空账号。`accounts.json` 新增可选的已删除 linked 供应商集合；`ensureLinked` 跳过集合中的供应商，用户再次添加时清除标记并复用供应商 id 建立账号行。

备选方案是禁止删除 linked 供应商。它与“订阅账号也要能删除并清理登录”的目标冲突，不采用。

### 4. 删除接口使用条件修订并返回剩余目录

HTTP 新增 `DELETE /api/v1/agent-service/model-accounts/:accountId`，请求体携带 `expectedRevision`，成功返回剩余账号与供应商目录。删除是账号级动作，不广播“删除事件”：调用方重新读取目录即可；失败保留原账号与其他来源。

### 5. 确认与状态表达在界面完成

供应商操作菜单新增“删除供应商”。确认弹层列出将清理的内容（登录凭据、API Key、模型列表与启用偏好），并说明删除不可撤销、不会删除服务商远端账号。由智能体托管的来源不显示删除项，改为提供“退出登录”，确认后断开对应智能体连接。删除成功后刷新目录并把选择退回“全部供应商”。

### 6. 删除影响统计只读取当前执行选择

Agent Service 新增账号级引用统计读取：对指定账号返回仍以其当前运行模型来源绑定的对话数。统计在删除确认打开时按需读取，不进入供应商列表的轮询响应；没有对话存储或统计失败时返回零/不可用，不阻塞删除。删除保持账号级动作，不删除对话；删除成功后界面明确告知这些对话下一次发送需要重新选择模型，对话侧的既有“所选模型暂不可用，请重新选择”提示继续生效。

### 7. 历史重复账号在读取时收敛

单账号供应商由声明上的 `singleton` 标记约束。旧存储可能在同一供应商下保留多个账号；读取 `accounts.json` 时按“可用状态优先、模型与凭据更完整优先”保留一个，移除其余账号行、偏好与私有目录。该迁移只在可写元数据模式执行，收敛后立即持久化，避免每次启动重复清理。

### 8. 托管登录退出复用连接断开边界

托管来源的凭据由原生智能体程序持有，模型页不能安全地单独删除。退出登录因此调用对应智能体连接的断开能力：确认后关闭运行时、撤销该来源租约并断开连接，使来源回到未登录状态；对话与远端账号保持不变。模型页的菜单文案对托管来源显示“退出登录”，普通来源仍显示“断开供应商”。

### 9. 侧栏搜索与分组只影响呈现

供应商侧栏在客户端按供应商名称、账号标签、认证方式与自定义端点过滤，并按订阅账号、API Key、自定义供应商、智能体接入分组。搜索不改变选中项和模型偏好；没有匹配时显示空状态。该能力只依赖现有账号与供应商声明，不新增服务端查询。

## Risks / Trade-offs

- **删除共享登录会影响智能体连接**：Qoder CN 的模型账号与 Qoder CN 智能体连接共享私有目录，删除后连接显示未登录。这是用户明确删除登录来源的预期结果，确认文案会说明；ChatGPT/Qoder/DSH 托管连接不提供模型页删除。
- **凭据删除失败**：先删除私有目录再保存元数据，失败时保留账号并报告具体原因，避免元数据已消失但凭据仍存在。
- **并发核对**：删除前等待进行中的检查结束，并递增操作序号；检查结果不得把已删除账号重新写回。
- **活动请求**：删除在存在活动模型请求时拒绝，避免静默中断对话；用户可先停止执行再删除。
