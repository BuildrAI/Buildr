## MODIFIED Requirements

### Requirement: 原生会话只能由显式操作在完整引用证明后回收

自动维护 MUST 继续保留原生会话正文，MUST NOT 因日志过期、进程退出、体积或年龄删除或计划删除原生会话；周期性维护计划 MUST NOT 包含原生会话候选。服务 MAY 提供显式运维操作，仅在完整证明无引用后回收单个原生会话对象。

显式操作 MUST 默认只读，并逐项报告对象、大小、观察身份、提供者、绑定、会话身份及保留理由；只有调用方显式确认后才 MUST 实际删除。回收范围 MUST 仅限受管模型绑定内的 Codex rollout 会话文件、DSH 会话目录与 Claude Code 独立会话文件（无同身份伴生子目录的 `<uuid>.jsonl`），以及已完整证明无引用的旧租约绑定 home；MUST NOT 包含账号目录、凭据、配置、共享状态库、插件、附件或其他提供者数据。

删除前 MUST 汇总全部持久引用来源：全部对话头（当前与历史参与者、全部尝试）、全部原生工具内容记录（含旧编码的来源路径）与全部交接来源索引，并解析到准确的提供者与会话身份；记录同时带有可解析模型绑定时应核对绑定一致。任一来源不可读、记录无法解码、绑定证据互相冲突或引用缺少准确的提供者与会话身份时，MUST 仅保留受影响提供者或绑定并报告原因，MUST NOT 推断为无引用。仅记录账号根但带有准确会话身份的引用，受影响范围 MUST 收敛到该会话，MUST NOT 扩大为整个提供者。

执行 MUST 沿用既有条件回收：稳定窗口、系统占用观察（含打开文件与工作目录）、删除前后身份与引用复核、租约锁与分批预算。变化、占用、观察失败或身份不符 MUST 恢复原对象并只保留该项。

#### Scenario: 无引用且稳定的会话
- **WHEN** 原生会话（包括 Codex、DSH 与无伴生目录的 Claude Code 独立会话）不在任何对话头、原生工具记录或交接索引中，绑定可解析，引用清单完整，超过稳定窗口且无系统占用
- **THEN** dry-run 报告该项为可回收并给出大小与身份；显式确认后删除该会话对象，账号、配置与其他会话不变

#### Scenario: 任一会话仍被引用
- **WHEN** 对话头、工具记录或交接索引引用该提供者与会话身份
- **THEN** 该项保留并报告引用理由；其他已证明无引用的会话仍可在同次操作中处理

#### Scenario: 引用观察不完整或身份无法确认
- **WHEN** 对话库或交接索引不可读、工具记录无法解码、绑定证据互相冲突或引用缺少准确的提供者与会话身份
- **THEN** 受影响提供者或绑定的全部会话保留并报告原因，不执行部分推断删除；仅记录账号根但带有准确会话身份的引用只保留该会话

#### Scenario: 自动维护或未确认调用
- **WHEN** 周期性维护运行，或调用方未显式确认原生会话删除
- **THEN** 计划不包含原生会话候选，或执行逐项保留并报告需要显式确认

#### Scenario: 删除前出现活动或内容变化
- **WHEN** 预览后会话文件被进程打开、出现新的引用或目录身份变化
- **THEN** 该项恢复并保留，报告实际原因，不中断其他独立对象

#### Scenario: 无引用的 Claude Code 死租约绑定目录
- **WHEN** `connections/claude-code/model-bindings/<64hex>` 内含的会话均无对话头、工具记录或交接索引引用，绑定目录本身也无引用且超过稳定窗口、无进程占用
- **THEN** dry-run 将该目录报告为可回收 `native-home` 候选，显式确认后整目录安全回收，其他仍被引用的绑定目录保留

## ADDED Requirements

### Requirement: 过期瞬时验证证据目录按受管标记自动清理

自动维护 MUST 将连接隔离 `tmp/` 中带有受管瞬时生命周期标记（`timing.json` 符合 `buildr.verification-timing/v1`、`evidenceRetention` 为 `transient`、`cleanupStatus` 为 `retained` 且 `cleanupReference` 与 `summaryPath` 严格指向自身目录）的验证证据目录纳入 `test-artifact` 条件清理；无有效标记、仍在稳定窗口内或仍被进程占用的目录 MUST 保留。

#### Scenario: 过期的瞬时验证证据目录自动回收
- **WHEN** `tmp/buildr-<kind>-evidence-*` 存在本用户所有的合法 `timing.json` 瞬时生命周期标记，超过稳定窗口且无进程占用
- **THEN** 自动维护将该目录列为可清理 `test-artifact` 并在复核标记与占用后安全删除；未过期或无标记的相邻目录保留
