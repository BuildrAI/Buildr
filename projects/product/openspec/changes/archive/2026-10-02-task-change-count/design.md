## Context

完整读取先扫描任务提交，再获取各检出位置状态、增删和预览。标签数字只依赖工作区路径数量。现有读取工作进程保护页面响应，不应在列表全量扫描任务。

## Goals / Non-Goals

目标是打开详情时快速计数，并使说明直接使用现有主区域。范围不包含后台轮询、全列表预取、持久计数缓存或 Git 写入。

## Decisions

复用任务仓库范围解析和状态解析，在状态读取中增加内部仅元数据模式，跳过提交扫描、增删计算、文件内容与差异。计数使用同仓库路径集合和现有上限。新增闭合计数响应，由现有读取工作进程执行。完整接口保持兼容，前端将计数和完整列表的触发条件分开，已缓存数量立即展示后重核；完整列表成功后也可直接更新数字。

说明沿用 `.task-reader` 正文和 `.task-node-reading` 主区域，移除额外来源、版本以及单正文菜单和重复“任务说明”文字，不增加额外阅读限宽。原文切换与错误反馈保留。共享阅读器允许显式空工具栏起始内容，其他文档保留默认文件名。

所选文件完整差异读取结束后，仅针对当前文件身份、提交来源、模式和显式点击定位首个增删行；同身份刷新和普通重绘保留人当前阅读位置。左右对比以同一个配对行定位三列，上下对比只显示一列有效行号。

## Risks / Trade-offs

计数与列表是两个只读观察，期间文件可能变化；使用各自读取时间和显式刷新，不承诺同一快照。局部失败及截断继续真实报告。无迁移和破坏性契约变更。独立计数增加一次小请求，避免大请求阻挡数字。
