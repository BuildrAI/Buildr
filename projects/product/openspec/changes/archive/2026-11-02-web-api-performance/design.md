## Context

参见 proposal 的采样事实。前端已有在途对话请求共享，源代码观察已有共享读缓存、事件通知及 120 秒兜底；不能复制一套缓存或取消安全校验。静态文件目前同步读取并走通用 no-store 响应。

## Goals / Non-Goals

目标是降低传输、重复工作及阻塞，保持 5 秒观察及时性与现有 UI。此轮不改变对话执行、存储版本、账号权限、默认实例和发布流程，也不通过增大线程数掩盖耗时。

## Decisions

- 构建期生成 gzip/Brotli 旁文件，静态托管异步读取并协商编码，只有带哈希资源使用 immutable。相比运行期同步压缩，避免请求阻塞；相比一律缓存，不缓存会话 HTML。无旁文件时回退原始内容，编码禁用时尊重 q 值。
- 增加 activity-summary 联合接口，按传输需要投影现有列表，保留必要运行模型/活动事实，去掉参与者上下文与历史执行。用摘要内容哈希作 revision，客户端显式传 revision；不建立持久状态或数据库迁移。旧接口不改。
- 新接口继续 5 秒观察；关闭页面时暂停，失败保留观察。相同版本返回小标记；旧测试或替代 client 缺少新能力时仍可沿用旧接口。
- 目录仅共享在途读取；写动作前后失效，单个消费者取消独立，不使用长期 TTL。代码观察只抑制首次无游标握手的重复全量调度，保留 attach gap 与真实文件变更校准。
- 默认目录与执行连接共享同一进程内运行配置绑定，保留每次目录真实路径核对，避免每次只读请求重新执行 Git 身份观察；不全局缓存产品身份或影响写入安全校验。
- 发布提示的同步产品来源与 registry 观察委派现有有界读工作池，只接受当前产品根及固定操作；既有持久通知事实仍由同一应用方法与锁处理。不新增线程池、不缓存可变来源，避免同步 Git 阻塞首页其他请求。
- 请求增加 Server-Timing 处理时长；静态异步读取消除一类同步阻塞，进一步尾延迟优化以实际计时为依据，不宣称所有尖峰均已消除。

## Risks / Trade-offs

- 压缩旁文件增加包体 → 无新增依赖，生成产物受忽略，实际网络与包检查验证。
- 摘要裁剪遗漏展示字段 → 使用现有活动组件消费面核对并验证等待、未知、未读与运行计数；详情始终读取权威接口。
- 缓存/取消竞争 → 增加写入后失效、失败重试与独立取消回归。
- 多任务正在修改代码库 → 使用隔离候选、保留外部变更，时间指标仅报告本次样本。

## Migration Plan

新增接口与旁文件均可独立回退；旧 JSON 路由保持原契约，无存储迁移。正式构建、HTTP 集成与隔离浏览器验证后交付候选，当前不集成或激活。
