## ADDED Requirements

### Requirement: 连接声明限定允许的认证来源

连接定义 MUST 支持可选 `authentication.allowedSources`，只接受非空、不重复的 `team|personal` 列表，省略时兼容现有双来源行为。宿主 MUST 在共享认证保存、有效组选择、草稿测试、发现及运行统一执行约束。仅个人模式缺少或失效个人组时 MUST 明确报告，不使用共享组，不自动迁移既有认证。来源不表示远端账号类型或业务权限。

#### Scenario: 仅个人定义已有共享凭据
- **WHEN** 定义只允许 `personal` 且实例遗留共享组，没有可用本机个人组
- **THEN** 目录保留配置并说明待配置或迁移，测试、发现及运行不得使用共享组，合法非秘密配置仍可保存

#### Scenario: 旧定义没有来源约束
- **WHEN** 既有定义省略 `allowedSources`
- **THEN** 宿主保持原个人整组优先及无个人组时选择共享组的行为

#### Scenario: 草稿尝试绕过来源限制
- **WHEN** 调用方为仅个人定义提交共享认证候选或要求恢复共享认证
- **THEN** 宿主拒绝对应动作且不访问外部系统，不影响其他连接

### Requirement: 本机个人认证在受限工作空间目录显式迁移

个人认证密文 MUST 保存在规范工作空间（Workspace）`.buildr/local/` 的受限、Git 忽略目录，并按当前本机应用身份隔离；加密密钥 MUST 继续只留本机应用数据目录。普通读取 MUST 不改写认证文件或执行迁移；旧路径兼容读取 MUST 保留准确来源和版本。显式迁移 MUST 校验当前旧组和目标观察，确认目标文件、必要父目录及本机密钥的持久化后才删除准确源；无法确认时 MUST 保留来源并报告目标即时可读与持久保全的区别。新旧冲突 MUST 保留两侧并报告。

#### Scenario: 旧本机个人组尚未迁移
- **WHEN** 当前用户的准确实例只有旧本机密文
- **THEN** 普通读取继续反映该组且不改写认证文件，显式迁移成功后使用私有新路径，秘密不进入共享文件和结果

#### Scenario: 目标目录同步失败
- **WHEN** 目标文件即时可读但其文件名、目录或密钥的持久化无法确认
- **THEN** 迁移保留旧来源，明确报告持久化未确认，不宣称唯一凭据已经保全

#### Scenario: 新旧目录都有不同个人组
- **WHEN** 同一当前用户与准确实例的新旧路径存在不同内容
- **THEN** 迁移拒绝覆盖并保留双方，其他实例继续可用

### Requirement: 明确动作迁移认证且不披露秘密

Buildr MUST 支持明确指定源实例、认证来源、目标实例、双方观察及是否移除源的认证迁移。迁移 MUST 只在相同绑定来源、兼容完整认证字段及准确认证接收目标之间进行；秘密 MUST 由应用内部重新绑定并保存为目标本机个人组。目标已有不同个人组时 MUST 拒绝覆盖；移除源 MUST 在目标保全后且有明确输入时执行，不因普通保存或读取发生。

#### Scenario: 当前共享账号迁为本人本机认证
- **WHEN** 用户明确授权迁移准确共享组到同实例个人组，且双方观察仍匹配
- **THEN** 应用保全个人组后按输入移除共享认证，返回非秘密结果并保留配置

#### Scenario: 合并相同站点实例
- **WHEN** 用户明确迁移旧实例个人组至相同认证目标的新实例
- **THEN** 应用重新绑定目标身份后保存，不复制旧绑定密文，不把秘密返回给调用方

### Requirement: 本人显式查看已保存的单个秘密

Buildr MUST 提供显式按字段查看当前本机个人秘密的动作，核对当前实例、定义、个人组观察及字段类型；只允许声明为秘密的字段，失效或冲突时不返回值。响应 MUST 禁止缓存，秘密 MUST NOT 加入普通列表、详情、诊断或日志。该动作不得读取共享组或其他用户的认证。

#### Scenario: 当前本人查看密码
- **WHEN** 用户明确查看当前有效个人组的密码字段且观察匹配
- **THEN** 单次响应只返回该字段原值且不缓存，普通详情仍不返回秘密

#### Scenario: 查看期间认证被另一入口更换
- **WHEN** 查看请求的个人观察已过时
- **THEN** 请求明确冲突且不返回旧密码，调用方重新读取当前事实

## MODIFIED Requirements

### Requirement: 共享接收方身份与本机执行观察分离
本条共享认证使用仅适用于声明允许 `team` 的接入；只允许 `personal` 的定义仍保留接收方与执行观察保护，但不得使用或回退共享组。

共享认证绑定 MUST 使用稳定的声明接收方，不包含本机独立程序或解释器的绝对安装路径。本机实际接收方 MUST 可观察，并纳入测试、发现及专业执行所消费的当前观察版本；安装位置变化 MUST 拒绝旧观察，不静默交接旧上下文。新机器 MUST 能在程序可用、绑定有效且没有个人组时使用共享团队认证，不修改团队文件；读取目录 MUST 不执行版本探测或真实登录。

#### Scenario: 同一声明在两台机器使用不同安装目录
- **WHEN** 两台机器取得同一团队实例，声明接收方相同但实际安装目录不同
- **THEN** 两台机器各自观察并使用当前程序，团队认证不因路径差异失效，任一机器的观察不改写共享认证

#### Scenario: 观察后程序搜索路径被改变
- **WHEN** 所选程序实际接收方在观察后改变
- **THEN** 使用旧观察的测试、发现及专业执行被拒绝，重读显示当前接收方供核对，不自动沿用旧上下文
