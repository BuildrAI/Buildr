## Context

独立 Harness 包已包含完整 Web，旧 DSH 插件服务 Development。DSH Desktop 0.2.2-rc.5 有全局面板入口、桌面网页租约和经过认证的本机 Host；普通网页 iframe 不能承载 Harness。

## Goals / Non-Goals

- 在本机 DSH 一键切换到完整 Harness 主工作区，可返回且不重置已打开的 Harness 页面。
- 保持 Harness 书写真实对象与共享后台的责任，保全 DSH 自有状态。
- 不做执行事件互通、不复制模型账号、不做公开分发、浏览器版或其他桌面版本适配。

## Decisions

1. 使用 DSH 正式面板切换和外层可返回的原生模态承载。后台 DSH 界面不接收焦点或点击；保持单一已挂载的 Harness 客体直到插件卸载。桌面租约为每个窗口提供隔离，浏览器缺少桥接时不开放入口。
2. 开发版只消费启动时显式绑定的独立包与数据域。请求只来自经过 DSH 桌面原生代理认证的浏览器，确认为本机 Host 后，使用公开 Harness 客户端复用或启用网页，再取得单次票据。不回传后台凭据、不在地址记录或日志保存票据，不重绑或关闭共享后台。不允许客户端选择执行程序、路径或域。
3. 开发包预编译，不包含 Harness Web、核心、机器路径或安装脚本。通过 DSH 桌面命令在独立配置安装，本机验证后保留可重开入口；公开发行单独处理。

## Risks / Trade-offs

- DSH 安装兼容和 Electron 前端限制不能用假 DOM 测试代替，验收固定为本机 0.2.2-rc.5。
- 保持一个已打开客体能保全草稿和当前页；关闭插件只释放客体，不撤销其他入口和原执行。端口或认证不匹配时显示失败，不使用任意回退网页。
