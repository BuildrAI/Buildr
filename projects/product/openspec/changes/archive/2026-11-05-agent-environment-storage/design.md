## Context

动机见proposal。已有ExecutorStorage为连接生成cacheRoot，isolatedEnvironment供三个执行器复用；prepareAgentRuntime将Node和整份私有包复制到每个内容版本；维护已有独立worker、storage锁、占用观察和身份指纹。Java/Maven当前在宿主.local/opt有一套真实安装，未观察到私有HOME中的Java/Maven副本。

## Goals / Non-Goals

所有Agent默认共享工具与缓存，同一不可变内容不反复物化；不同版本/架构/内容仍可并存。账号、HOME、原生会话、项目源码与可变安装结果不合并。只为已存在或实际使用的工具准备共享路径，不建立自动下载所有语言的安装平台，不改写原生历史，不停止活动用户任务。

## Decisions

1. 由服务公共执行入口分配agent-service/toolchains/cache，取消storage声明作为获得共享环境的前提。按npm、yarn、node-compile、pip、uv、python、maven等工具分区。三个适配器继续使用原隔离环境方法，未来执行器从同一OpenOptions得到公共环境，无需重复登记缓存根。
2. 保留PATH及已声明工具安装位置，传递JAVA_HOME等非凭据运行位置；Maven仓库通过-Dmaven.repo.local指定，settings.xml及.npmrc等凭据配置继续私有。版本管理器的数据位置集中到受管toolchains，保留显式项目/用户版本选择，不以共享强行升级版本。
3. 保留运行时使用内容寻址的只读对象，键包含完整字节和执行权限（架构与版本变化会产生不同字节）。Node使用唯一受管可执行对象并保留每个旧manifest所需的本地Node硬链接路径；包内不可变文件以受管硬链接提供原路径视图，新准备的原生程序包在私有安装结束和版本验证之后也复用同一内容存储，不共享可写项目node_modules。拒绝损坏对象和源身份变化，不回退为隐蔽重复复制。兼容旧Node在运行时目录内的manifest，旧活动版本不原地改写。
4. 既有缓存按明确的服务环境声明发现。迁移仅在对应旧环境与目录无活动占用、指纹稳定时执行，复用storage锁及删除前后核验；先保全可复用内容，再回收旧副本。包管理器内容索引冲突必须使用可验证规则合并或保留，不按同名推断相同。旧路径已被新共享别名替代时核验准确目标，不遍历别名重复统计或删除共享目标。
5. 受管不可变运行时副本仅在旧owner无当前/待采用/存活引用及无系统占用时迁移；新版本直接复用对象。可变缓存只合并缺失项，不硬链接，不将迁移字节计为净回收。共享对象仍被任一视图引用时保留，不将文件链接数或逻辑大小冒充独占释放空间。
6. 扫描、哈希、迁移和删除使用既有维护worker。即时退出的插件回收亦在同一入口的窄工作线程，不在HTTP/SSE线程扫描或迁移。

## Risks / Trade-offs

- 旧Agent仍运行：不强行改环境或停止任务，延迟对应副本迁移并自动接续；新执行立即使用共享位置。
- 缓存索引或同名安装差异：验证格式/完整性及真实版本，冲突保留；不能为凑单份删除业务成果。
- 共享只读对象损坏：完整内容校验报明确错误，保留其他引用，不静默覆盖或制造第二权威副本。
- APFS克隆/硬链接/并发写入：同时报告逻辑、分配、唯一inode和卷计数，分别说明文件移除与可证明物理收益。
- Java/Maven凭据混入共享：只指定二进制和仓库位置，不共享完整HOME、settings.xml、.npmrc、原生配置。

## Migration Plan

公共缓存取消容量预算，不能因体积大提前淘汰。下载正文保留30天、编译加速保留7天；已确认结束的临时现场沿原24小时窗口。运行环境和安装依赖有引用就持续保留，无引用内容对象从最后硬链接引用变化起至少保留30天。缓存保留还需有明确使用观察：真实执行起止与维护发现消费者/恢复引用时更新零正文观察标记；无标记时从首次维护观察保守起算，不把目录mtime冒充最后使用。所有原锁、引用、占用和删除前复查不变。

原维护线程对所有受管连接和模型域的HOME作有界元数据发现，包括未来Agent。报告观察大小、扫描完整性、工具归属和共享策略或待查原因；不读正文、不跟随外部链接，不根据大对象线索自动移动未知成果。补齐node-gyp与Corepack共享位置。

先完成公共入口与单份物化，补齐旧格式兼容和并发保护，再在真实数据上执行受管迁移及三Agent实测。保留早期清理报告；新验收独立保存。正式提交集成/自举启用按已有授权范围处理，不从实现授权推导发布或强推。出现活动对象或身份变化时仅保留相关对象，不扩大为全目标阻塞。

Yarn/uv等缓存可能兼作项目安装来源，外部引用不明确时不整目录过期；仅共享和诊断，不推断下载缓存一定无安装引用。六个零正文使用观察复用文件系统时间元数据，无新索引数据库；活动观察不写正文，原只读inspect保持零写入。
