## Context

动机见 proposal。当前 `startPreview` 同时以工作树计算代码身份、播种任务库并启动 Web；`ensureRegisteredTarget` 因共享登记里已有主目录而拒绝同 ID 工作树。工作空间查询已经支持共享登记视图，不需要另复制列表。

## Goals / Non-Goals

目标是让代码来源与数据来源独立且可核验。非目标包括共享默认实例、复用开发版会话、迁移旧预览数据、放宽结构化数据库写入来源校验及接管其他预览。

## Decisions

1. 默认 `shared`，而非关闭身份去重。任务工作树仍用于产品入口和 owner，Web 的 `--target` 使用受管证据中的主工作空间；共享列表内其他工作空间沿用原有解析。
2. 显式 `snapshot` 继续从 canonical 播种工作树数据库，但不合并共享登记。保留“数据快照隔离”的实际语义，避免同一 UUID 在一个列表映射到两处目录。独立 checkout 预览同样可选择不合并共享登记，但不自动播种任务库。
3. owner 增加 `workspaceMode` 和 `environmentRoot`。旧记录缺少字段时按旧快照理解，但旧运行进程未明确声明数据根和登记模式，不能直接复用来承诺新语义；停止仍核对原有任务证据，不要求补造旧字段。普通 stop 保留的快照登记不得直接混入 shared，使用新实例名或显式安全清理后重建。
4. 复用判断先于快照播种；模式不匹配不应顺带产生数据库副本。共享模式不触碰工作树库。
5. 共享只限制登记来源写入，不将整个业务页面冒充只读。真实工作空间上的动作继续执行各应用原有授权、版本、管理归属与候选写入保护；不伪造当前预览拥有其他目录。
6. 共享根和服务目标按真实文件系统身份比较，兼容 macOS `/var` 与 `/private/var` 等同目录别名；不同物理目录仍做 UUID 冲突检查。浏览共享条目不触发本地 lastOpenedRoot 写入。
7. 页面打开接口对共享条目只返回可导航身份，不调用本地目录的资源准备流程；本地登记仍保留原有自动收敛与管理校验。真实浏览器点击进入和真实 HTTP POST 都纳入验收。

## Risks / Trade-offs

- [默认数据来源变化] → CLI 输出与技能明确标注，旧实例拒绝无声复用；写入验收显式选择 snapshot。
- [候选自举代码不能写主目录数据库] → 保留保护，以快照完成相关写入验收。
- [快照中不可见开发版列表] → 这是显式隔离模式；需要真实配置时回到 shared。
- [来源或模式漂移] → 新实例名或按原身份停止后重启，不覆盖已有数据库、登记或会话。

## Migration Plan

无数据库或登记迁移。模式或数据目标变化使用新实例名；同模式代码更新按原 owner 停止后重启。历史 owner 可按既有方式停止。回退代码不会删除预览或工作空间数据。
