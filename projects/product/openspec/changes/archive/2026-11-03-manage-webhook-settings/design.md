## Context
当前 webhookConfiguration 只读安全私有文件，ConversationWebhooks 随服务创建；ConversationEvents 持有投递器。宿主已有认证 HTTP、进程操作白名单、JSON Schema 和前端客户端。

## Goals / Non-Goals
目标是复用这条链路提供可验证的本机配置管理。不做工作空间配置、自动测试发送、多目标或通知路由。

## Decisions
- 配置与秘密读写由 Agent Service 唯一持有；宿主只认证并转发，不直接读取私有文件。
- 外部指定文件及旧环境变量来源显示为外部管理、只读；避免 UI 意外覆盖运维配置。默认私有文件允许显式保存，启用字段兼容旧文件（缺省启用），停用保留地址与密钥。
- 读取返回无明文视图及摘要版本；保存与查看、测试提交已观察版本。以私有锁、写前重读、独占临时文件和原子替换保护受管写入；外部任意编辑器的并发不承诺原子 CAS，发现漂移拒绝。
- 用稳定管理器承接事件并在配置变化时切换投递器；保留原有 target 隔离，不向新地址迁移旧队列。轮询配置变化让同一 profile 的保留执行也停止使用旧目标。
- 最近投递仅保存时间、成功/失败和 HTTP 状态；不保存响应正文或网络错误原文。测试走独立、标注 test 的轻量请求，不伪造业务事件、不重试。
- UI 使用与“模型”“智能体”并列的“事件通知”页签，不追加到账号内容下方；显式保存；密钥查看为独立认证 POST，关闭或隐藏清除前端明文，异步返回须核对组件生命周期。

## Risks / Trade-offs
- 文件由外部管理 → 明确只读来源，不隐式接管。
- 查看明文风险 → 仅主动查看、no-store、无日志、关闭清除；保持现有本机会话认证。
- 新目标接收旧积压 → 延用地址与密钥绑定的投递隔离，不迁移。
- 停用时已在途请求可能到达 → 中止本实例请求，不承诺撤回已发出的网络请求。

## Migration Plan
旧默认文件无需迁移，缺省 enabled 为 true；旧环境只读兼容。回退旧版本前注意 enabled 字段旧程序不识别，应由运维移除有效配置以保持停用。候选工作树不激活到共享开发环境。
