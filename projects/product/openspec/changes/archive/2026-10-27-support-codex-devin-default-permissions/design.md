## Context

动机见 proposal.md。当前实现只改写两个精确已知命令工具用途说明；默认模式实际采用工作空间写入沙箱（workspace-write）与按需审批（on-request），默认权限区块由原生 Codex 生成。逐段对照定位到 `justification` 审批问题说明单句；示例不变的等义改写已通过完整说明控制和原生工具读取。Devin 服务端内部判定原因未知，不能将此误报为实际权限不足。

## Goals / Non-Goals

**Goals:** 保持用户所选权限、必要说明、原生工具及准确来源，使 Codex 默认模式使用 SWE-2 完成工具接续。

**Non-Goals:** 不移除说明，不批准测试外动作，不改成完全访问，不开放其他未验证模型，不改变账号凭据、额度或原生沙箱实现。

## Decisions

1. 在 Devin 请求适配边界，仅处理 Codex 的系统或开发者消息中带已知默认沙箱标记的权限区块；精确匹配原句并等义替换。用户消息、非 Codex、未知原句及区块外同文保持原样。选择有限匹配以避免广泛摘要权限规则或维护另一份规则全文。
2. 原句和改写均要求在 `justification` 中向用户简短询问是否允许所提动作，保留同一个安装依赖的示例。沙箱范围、命令拆分、提权时机、禁止过宽规则和可写根均不改变；执行器配置完全沿用当前实现。
3. 在真实默认权限下验证读写、工具结果接续和被拒绝审批后的文件不变，再取消 SWE-2 的默认模式限制。按权限区分原生参与上下文继续保留，旧选择及草稿不被重写。
4. 当前知识影响：只更新 agent-integration.md 可用条件及随包 agent-operations.md 使用指引；代码地图和图示职责关系未变，无新增术语。

## Risks / Trade-offs

- [上游判定会漂移] → 只匹配已知原句，保留真实错误；控制请求成功不代替真实工具验收。
- [原生版本改变说明] → 未知原句原样传递并回归验证，不使用模糊删除或全区块重写。
- [说明改写误伤权限] → 单元检查只允许单句差异，原生配置回归检查及真实拒绝审批场景证明边界。

## Migration Plan

不迁移持久数据，不接管已有账号。通过既有权限绑定上下文继续；回退当前有限改写和默认模式界面放行即可恢复先前条件，原记录和选择保留。
