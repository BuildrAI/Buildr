## MODIFIED Requirements

### Requirement: 网页和命令必须呈现同一真实提交内容
任务详情 MUST 在「改动与提交」内容标签内按仓库分组展示本任务关联提交，组内按提交时间从新到旧；不再有独立的「提交记录」阅读标签。展开一条提交 MUST 保留完整提交说明（Commit Message）与完整哈希（Hash），并列出该次提交改动的文件；文件可进入与未提交改动相同的差异阅读面。该入口 MUST NOT 新增为任务工作阶段或状态；网页和命令继续使用同一真实提交内容，本机可达读取范围与关联判定保持不变。

#### Scenario: 查看并展开提交
- **WHEN** 用户从任务详情打开「改动与提交」并在左侧仓库树的「提交」分组中展开一条提交
- **THEN** 页面 MUST 显示同一提交的完整说明和完整哈希值（Hash），并支持复制
- **AND** 显示该次提交改动的文件列表，选择文件在右侧差异面查看其改动
- **AND** 原有任务状态和当前工作阶段 MUST 保持不变

#### Scenario: 成功读取没有匹配项
- **WHEN** 全部声明的范围读取成功且没有符合条件的提交
- **THEN** 页面 MUST 显示当前检查范围内无关联提交，区别于读取失败

#### Scenario: 入口并入工作台
- **WHEN** 用户打开「改动与提交」
- **THEN** 在左侧仓库树的「提交」分组中查看本任务提交，不再有独立的「提交记录」内容标签

#### Scenario: 关联范围不变
- **WHEN** 提交记录读取返回结果
- **THEN** 关联判定、读取范围与本机可达提交（含未推送）与变更前一致
