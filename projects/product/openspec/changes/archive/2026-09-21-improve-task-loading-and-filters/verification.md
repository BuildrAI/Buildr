# 任务加载与筛选验证

已在独立工作树（Worktree）实现并验证，尚未提交、集成或更新本机运行版本。

## 原因及修复

- 50项工作摘要逐项打开数据库，拖慢其他请求；改为共享一次数据库读取，继续逐项检查任务与摘要。
- 普通详情同时读取未查看的审查、验证和协调；改为按当前节点读取并复用本任务已读内容。
- 材料关联校验先读完整任务、再重复解析；改为读取持久记录后校验关联并解析目标。
- 详情复用应用壳的工作空间（Workspace）信息，不再每次重读并等待。
- 去除列表及共用个人偏好的 focus/visibilitychange 刷新；保留主动及保存后更新。
- 漏斗旁新增重置筛选，立即恢复未结束状态、清空搜索及过滤并保留分组。弹层重置仍只改草稿。

## 性能样本

经已有隔离测试入口复制真实数据库和规范材料，旧版与新版读取同一副本并托管各自生产构建。副本不含真实 Git 工作树登记，结果不代表所有本机状态或负载。

| 指标 | 修改前 | 修改后 |
|---|---|---|
| 点击至正文出现，三次毫秒值 | 2039 / 1528 / 1479 | 1472 / 945 / 485 |
| 正文出现中位耗时 | 1528 毫秒 | 945 毫秒，减少约38% |
| 50项摘要，三次毫秒值 | 645 / 580 / 571 | 22 / 21 / 22 |
| 摘要中位耗时 | 580 毫秒 | 22 毫秒，减少约96% |
| 普通任务打开相关请求，含访问记录、不计列表批量读取 | 8 | 4 |

后台读取首次启动仍有成本，新版首次正文约1.47秒。此前真实运行页面另有1.7～4.0秒样本，未与隔离副本混算。
