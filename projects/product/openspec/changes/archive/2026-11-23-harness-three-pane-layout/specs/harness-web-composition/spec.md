## MODIFIED Requirements

### Requirement: Harness 外壳必须支持可选工作环境且保持对话独立

Harness MUST 提供构建时显式装配的前端外壳，接收完整对话区域和单个可选工作环境。不装配环境时 MUST 保留完整对话，不显示空的环境入口。装配环境后 MUST 默认保持对话为主，环境仅在用户打开时挂载；收起和重新打开 MUST 保留已挂载环境及对话的本地状态，MUST NOT 发送消息、改变对话身份或执行目录。

工作环境区域的渲染失败 MUST 只影响该区域，外壳 MUST 提供明确的局部不可用提示且仍允许收起。该边界只隔离组件渲染失败，MUST NOT 声称同页工作环境是不可信代码安全沙箱。Development 当前网页嵌入协议及完整对话的唯一实现责任 MUST 保持，不因本步框架建立而迁移工程业务。

当 Harness 作为独立完整网页运行（未嵌套于父窗口且未装配可选工作环境，或使用内置工作区运行在独立网页外壳中）时，页面 MUST 保持当前对话始终展开并固定左侧导轨，未展开右侧工作区时保持全宽，MUST NOT 在主对话右上角更多菜单中展示面向宿主分屏的布局项（`收起对话`、`专注对话`/`恢复分屏`、`对话移到最左侧`/`对话移到右侧`），也 MUST NOT 在左侧导轨展示用于收起或展开当前对话的入口；子对话浮窗自身的收起入口以及 Buildr Development 同页或嵌入场景中的分屏与折叠控制 MUST 保持不变。独立网页在支持左右并排分栏的桌面视口下无明确偏好时 MUST 默认展开左侧对话列表，并跨刷新记住用户在该配置域对桌面对话列表的展开或收起选择；在不支持左右并排分栏的窄屏视口下 MUST 默认先显示当前对话而不覆盖桌面展开偏好，且用户切换到对话列表时 MUST 在列表标题栏提供“返回当前对话”入口。

当独立 Harness 外壳展开右侧可选工作环境时，外壳 MUST 使用统一的 `ResizablePanels` 与 `SplitDivider` 组件在桌面视口提供横向可调分栏（并在窄屏视口自动切换为纵向上下分栏），支持指针拖拽、方向键微调与双击复位并记住桌面比例偏好；在宽度满足桌面三分屏条件（至少容纳 52px 导轨、240px 对话列表、520px 核心对话信息流与 360px 工作区）且桌面对话列表处于展开状态时，页面 MUST 支持同时展示并协同调节「对话列表」「核心对话信息流」与「右侧工作区」三栏并行布局。任何拖拽、窗口缩放、切换对话、新建对话或开合工作区操作 MUST 优先保证核心对话信息流的最小可读宽度（520px，仅当整体视口无法同时满足最小要求时按比例安全降级或自动退回非并排列表），缩小某一侧栏时释出的空间 MUST 优先归还核心对话信息流；点击任一栏分隔条而未发生指针位移时 MUST NOT 误提交比例或改变当前宽度；视口临时缩小导致列表退回单栏展示时 MUST NOT 覆盖桌面已保存的对话列表展开偏好。

#### Scenario: 不装配工作环境
- **WHEN** 独立 Harness 入口未提供工作环境
- **THEN** 页面 MUST 使用通用外壳展示现有完整对话，不出现环境占位或安装要求

#### Scenario: 独立网页移除宿主分屏控制并默认桌面展开对话列表
- **WHEN** 用户在支持并排分栏的桌面视口首次访问独立 Harness 网页（无既有布局偏好）
- **THEN** 主对话 MUST 保持展开并默认在左侧并排显示对话列表，左侧导轨按新建对话、当前对话、对话列表排序；当前对话入口仅导航，不折叠主对话或工作区，主对话更多菜单 MUST NOT 包含收起对话、专注对话/恢复分屏或左右移动选项
- **AND** 用户点击左侧导轨对话列表开关收起或再次展开列表后刷新页面，桌面列表展开状态 MUST 保持与刷新前一致，且不触发任何消息发送

#### Scenario: 独立网页窄屏默认展示对话并提供返回入口
- **WHEN** 用户在不支持左右并排分栏的窄屏视口打开独立 Harness 网页并点击对话列表入口
- **THEN** 初始页面 MUST 默认显示当前对话而非列表，切换到对话列表时列表标题栏 MUST 显示“返回当前对话”按钮，点击后返回当前对话；窄屏打开或切回对话 MUST NOT 覆盖桌面视口已保存的对话列表展开偏好

#### Scenario: 按需展开与收起
- **WHEN** 用户展开、收起并重新展开已装配的工作环境
- **THEN** 环境 MUST 在首次展开时挂载，随后保留其本地状态；原对话输入、阅读位置和身份 MUST 保持，布局操作不触发执行

#### Scenario: 工作环境渲染失败
- **WHEN** 工作环境组件在首次或后续渲染时抛错
- **THEN** 页面 MUST 只在环境区域显示不可用提示，仍能收起环境、编辑对话及操作原对话控制

#### Scenario: 桌面三分屏并行调节与核心对话信息流宽度保护
- **WHEN** 用户在桌面宽屏下同时打开独立 Harness 左侧对话列表与右侧对话工作区，并拖拽或使用键盘调节左侧列表分隔条或右侧工作区分隔条
- **THEN** 对话列表、核心对话信息流与右侧工作区 MUST 同时保持可见，且两侧均使用统一的 `SplitDivider` 调节宽度
- **AND** 核心对话信息流宽度 MUST 始终保持不低于 520px；向内拉宽一侧时仅在核心信息流触及 520px 下限后才平滑压缩相邻可让渡侧至其最小宽度，向外收缩一侧时另一侧宽度保持稳定、释放空间优先归还核心对话信息流，对话输入节点、草稿与滚动位置保持不变

#### Scenario: 视口不足三分屏阈值时平滑退回双栏并保留桌面偏好
- **WHEN** 三分屏展开期间浏览器视口缩窄至不足 1172px（但仍大于 760px 移动断点）
- **THEN** 页面 MUST 自动退回保留核心对话信息流（不低于 520px）与右侧工作区的双栏并排视图，MUST NOT 覆盖桌面已保存的对话列表展开偏好
- **AND** 当视口重新拉宽至 1172px 以上时，页面 MUST 自动恢复三分屏并行展示

### Requirement: Development 专注模式必须提供就近的设置、额度和对话入口

独立 Harness 和 Development 专注模式 MUST 在对话主区以保留最左 52px 唯一侧边导轨的两级左侧导航全屏设置视图展示设置，同时隐藏已展开的左侧对话列表与宽度分隔条（独立 Harness 中已展开的右侧工作区及工作区分隔条也 MUST 同步临时隐藏而不卸载内部状态）而不改写其展开偏好、宽度、筛选及未发送草稿；Development 普通分屏 MUST 继续使用右侧设置抽屉而不遮挡工程工作区。任一单栏覆盖展示对话列表的模式（独立网页窄屏、专注模式窄屏、Development 分屏展开及收起态暂看）MUST 在列表标题栏提供“返回当前对话”入口，仅并排双栏与三分屏并行列表省略该按钮；所有非隐藏对话列表（包括分屏模式）MUST 在工作空间分组标题右侧提供快捷“新建对话”入口并在无筛选条件时保留无历史记录的工作空间。

全屏设置 MUST 采用从左到右的两级左侧导航：最左为一级设置分类（模型、智能体、程序接入、系统提示词），且“模型”分类不显示向右展开箭头；选中“模型”时紧邻向右展开分组供应商二级菜单与右侧详情区，两个导航栏与详情区各自独立滚动；切换到无二级菜单的分类时二级栏自动收起，单栏内容区贴左并在舒适阅读宽度内展示；窄屏视口下折叠为顶部导航且不产生横向溢出。设置入口提示、全屏设置与 Development 普通分屏设置抽屉标题 MUST 统一收口为「设置」，去掉「智能体与模型」旧标题、枚举式副标题及全屏下的「返回对话」文字按钮；全屏设置顶栏展示当前路径与右上角「关闭设置」（`×`）按钮，并支持通过 `Escape` 键或再次点击导轨设置图标返回对话。

独立 Harness、Development 专注模式与 Development 普通分屏（含展开态与收起态）MUST 共用唯一侧边导轨并在设置图标上方提供独立的“供应商额度”入口，原设置齿轮图标统一仅用于打开或关闭设置而 MUST NOT 触发额度摘要。展开态与收起态悬停或键盘聚焦该额度图标 MUST 展示已有的供应商额度摘要；点击该额度图标（包括收起态点击后展开分屏）MUST 打开设置并直达模型的全部供应商“账号与额度”页签，不受前一次设置选项影响；收起态点击“设置”或“展开当前对话”或“新建对话” MUST 同步展开分屏并保持原对话与草稿。全屏设置打开期间，侧边导轨仅设置图标高亮；点击导轨“对话列表” MUST 退出设置并确保展示对话列表而不反向收起列表；点击导轨“当前对话”（Development 专注模式） MUST 退出设置回到当前对话而不收起对话面板。无论是全屏设置还是分屏设置抽屉，通过外部工程指令、提醒浮窗或对话列表切换或新建对话时均 MUST 自动关闭设置视图；打开或关闭设置 MUST NOT 改变对话选择、未发送草稿或已有执行，退出全屏设置后 MUST 原样恢复打开前的对话、对话列表以及已展开的右侧工作区视图。

#### Scenario: 从设置返回原对话
- **WHEN** 用户在独立 Harness 或 Development 专注模式下保留对话列表（及独立 Harness 右侧工作区）展开并输入草稿，点击侧边导轨的“设置”按钮，然后通过右上角「关闭设置」（或按 `Escape` 键、再次点击设置图标）返回对话
- **THEN** 打开设置期间最左 52px 唯一侧边导轨 MUST 保持可见且仅设置图标高亮，左侧对话列表、宽度分隔条及右侧工作区 MUST 隐藏，主区展示标题为「设置」的两级左侧导航全屏设置页
- **AND** 关闭设置后，系统 MUST 还原打开前的对话列表展开状态、右侧工作区展开状态、各栏宽度、原对话以及未发送输入；打开或关闭设置 MUST NOT 发起或停止执行

#### Scenario: 从左到右的两级左侧导航与单栏贴左宽度
- **WHEN** 用户在全屏设置中查看「模型」并切换到「智能体」「程序接入」或「系统提示词」
- **THEN** 「模型」分类不显示右侧箭头图标，选中时自左向右依次呈现一级设置导航、分组供应商二级菜单与右侧详情区并各自独立滚动
- **AND** 切换到「智能体」「程序接入」或「系统提示词」时供应商二级栏收起，单栏内容贴左并在舒适阅读宽度内展示；窄屏视口下导航折叠到顶部且无横向溢出

#### Scenario: 全屏设置期间点击左导轨切回对话或列表
- **WHEN** 用户在全屏设置中点击侧边导轨的“对话列表”或 Development 专注模式中的“当前对话”图标
- **THEN** 点击“对话列表” MUST 退出设置并确保对话列表可见而不反向折叠列表
- **AND** 点击“当前对话” MUST 退出设置回到当前对话而不错误收起整个对话面板

#### Scenario: 从额度入口进入模型账号与额度
- **WHEN** 用户悬停或键盘聚焦设置上方的额度图标
- **THEN** 系统 MUST 展示已有的供应商额度摘要；齿轮不再触发该摘要
- **AND** 点击额度图标 MUST 打开设置中模型的全部供应商“账号与额度”页签，不受前一次设置选项影响

#### Scenario: 分屏模式展开态与收起态使用独立额度入口
- **WHEN** 用户处于 Development 普通分屏展开态或收起态
- **THEN** 唯一导轨设置图标上方 MUST 显示独立的“供应商额度”图标，齿轮图标不再悬停触发额度摘要
- **AND** 展开态与收起态悬停或聚焦独立额度图标 MUST 展示现有供应商额度摘要且不越出视口，点击 MUST 保持或展开分屏并在「设置」抽屉直接打开全部供应商“账号与额度”页签
- **AND** 收起态悬停“展开当前对话” MUST 展示暂看浮层而不自动固定，点击设置或新建对话 MUST 展开分屏，同时保持原有对话、未发送草稿与执行不变

#### Scenario: 在指定工作空间新建对话
- **WHEN** 用户在专注模式或分屏模式打开对话列表，并点击工作空间标题右侧的新增按钮
- **THEN** 系统 MUST 使用该空间打开新对话输入并聚焦，且不创建空对话、不改变该组折叠状态；点击名称仍可折叠或展开

#### Scenario: 单栏列表返回当前对话与设置自动关闭
- **WHEN** 用户在分屏模式等单栏覆盖展示对话列表时查看列表，或打开设置抽屉后从提醒浮窗、对话列表或外部工程页面触发打开/新建对话
- **THEN** 单栏列表标题栏 MUST 显示“返回当前对话”按钮，点击后返回当前对话并保留原草稿
- **AND** 打开或新建对话时设置抽屉 MUST 自动关闭并切换到目标对话或新对话输入
