## Context

现有初始化和同步已维护资源、生成入口并诊断；网页更新已有安装归属与跨实例交接记录，但未覆盖所有登记目录。技能正文会装配空间绑定与组件片段，不能直接让所有空间发现同一个成品。

## Goals / Non-Goals

目标是一次确认得到可用目录及可恢复的更新结果。保留组织资产和来源隔离。不引入智能体发起更新、共享自有技能编辑或真实发布。

## Decisions

1. 采用固定 `~/.buildr/resources/` 共享目录，版本和完整内容摘要只保存在内部元数据。新目录完整校验后在稳定锁下切换；发布失败恢复旧目录，中断重试恢复切换并清理暂存和备份，不逐文件覆盖。通过显式资源引用解析官方来源，空间清单不写个人绝对路径。
2. 官方技能保持全部附件，组织技能留在空间；核心 `AGENTS.md` 与项目初始化文件按所属资产保留，不新增 `templates/` 分类。程序迁移逻辑随程序。
3. 复用现有回执识别未修改官方副本，转换为共享引用；已修改副本保留，未证明所有权不删除。完整替换时清理旧文件、历史资源目录及损坏副本；失败空间保留待完成，恢复后按最新版重建，不保留每个旧资源集。
4. 添加操作先检查目录身份、安全范围和登记版本，串联已有初始化与同步，保留可重试登记。已有目录接续，重复目录不新增身份。
5. 更新沿用现有持久记录、版本钉住和安装归属，一次确认授权自动准备及应用。新版进程接续逐空间结果，每项重新核对身份，失败隔离。重试不重复安装；模拟开发更新继续隔离。
6. 保留配置适配器，标准入口去重。开发来源更新继续模拟；自举开发工作空间的正式激活仍属于唯一执行器，不从普通目录准备入口拆跑或替代，不能把跳过当成功。诊断核对当前安装、资源完整性、采用身份和入口内容。

## Risks / Trade-offs

- 跨机器缺少本机资源 → 安装或准备当前资源再生成入口；逻辑引用可移植。
- 更新后长时间关闭的目录不可访问 → 持久待完成结果，恢复后重试，不声称已就绪。
- 已有对话缓存旧技能 → 提示新对话，不伪造宿主加载证明。
- 用户定制与官方升级冲突 → 保留定制并明确报告，不强行覆盖。
- 程序交接中断 → 新进程按目标版本和记录修订接续，保留此前成功结果。

## Migration Plan

先安装并验证共享资源，再迁移可证明未修改副本与引用，最后生成入口、诊断及记录采用结果。升级的临时备份只用于切换中断恢复，完成后清理；不执行跨工作空间整体回滚。旧布局与未带固定布局标记的采用状态必须重新准备，不能因摘要相同就跳过入口重建。浏览器与命令行验证均使用隔离数据目录。

## Shared Location Discovery

右上角更多菜单和技能目录的“安装信息”共用同一窗口，展示当前程序对应资源集路径；技能详情显示实际来源目录。两处复用路径复制和本机目录打开交互。只读查询不准备资源，打开动作用资源集身份或技能身份解析并执行网页写保护，不接受任意路径。macOS 调用 Finder，Windows 调用文件资源管理器；首轮不新增分类管理或空间总览。入口与标题使用信息图标和简短名称；窗口居中，长路径单行省略，悬停和复制仍使用完整路径。
