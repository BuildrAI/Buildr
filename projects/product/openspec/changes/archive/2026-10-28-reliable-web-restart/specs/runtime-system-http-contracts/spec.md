## ADDED Requirements

### Requirement: 重启状态必须提供受授权的只读契约

网页系统接口 MUST 提供会话授权的只读重启状态，区分未发起、进行中与已确认失败，并在失败时返回有界的原因。健康接口 MUST 提供非秘密的重启进行中标记供本机受认证调用方发现；指定后继的私有退出标识 MUST NOT 出现在任何公开响应、命令行或日志。

#### Scenario: 页面读取失败状态
- **WHEN** 合法页面会话读取已有失败重启状态
- **THEN** 接口 MUST 返回稳定的失败代码和原因且不发起新进程或改变状态

#### Scenario: 无效授权
- **WHEN** 请求缺少合法页面授权或认证退出标识不属于当前受理重启
- **THEN** 接口 MUST 分别拒绝未授权读取或返回退出冲突，MUST NOT 暴露秘密或执行退出
