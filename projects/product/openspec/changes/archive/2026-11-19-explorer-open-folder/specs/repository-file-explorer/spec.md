## ADDED Requirements

### Requirement: 已打开的当前文件支持直接打开所在文件夹

资源管理器（Explorer）与源代码管理完整当前文件视图中已成功读取的当前本地文件 MUST 提供“打开所在文件夹”入口，直接请求本机文件管理器打开该真实文件所在的目录；涵盖可编辑文本、只读文本、图片、大文件分段以及暂不支持阅读的普通文件。不同工作树（Worktree）中的同名文件 MUST 分别打开各自实际检出目录中的对应父目录。

系统 MUST 通过受本机会话（Session）授权的写入型接口校验文件来源、普通文件身份与当前检出目录身份后再打开父目录，MUST NOT 接受历史提交（Commit）、越界路径、越界符号链接（Symbolic Link）或 Git 管理目录请求；历史提交文件 MUST NOT 显示打开所在文件夹入口。

#### Scenario: 打开资源管理器嵌套文件与不同工作树的所在文件夹

- **WHEN** 用户在资源管理器打开嵌套子目录中的当前文件或关联工作树中的同名文件，并触发打开所在文件夹
- **THEN** 系统 MUST 向本机文件管理器请求打开该文件在对应检出目录中的实际父目录，而不是仓库根目录、主目录或文件路径本身
- **AND** 已打开页签、编辑内容与阅读位置 MUST 保持不变，并提示已请求打开目录

#### Scenario: 非编辑视图文件也可打开所在文件夹且历史文件不提供

- **WHEN** 用户在资源管理器查看当前图片、超过5 MiB的大文件分段或不支持阅读的二进制文件，或者查看历史提交文件
- **THEN** 当前文件视图 MUST 允许触发打开所在文件夹并定位其实际父目录，不受只读或分段限制阻拦
- **AND** 历史提交文件视图 MUST NOT 提供该入口，服务端也 MUST 拒绝携带提交标识、越界路径或缺少会话授权的请求
