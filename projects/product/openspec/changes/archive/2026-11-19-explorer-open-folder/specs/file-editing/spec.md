## ADDED Requirements

### Requirement: 文件阅读与编辑面板提供一致的打开所在文件夹入口

共享文件面板（FileEditingPane）在资源管理器（Explorer）和项目资料入口查看当前本地文件时，MUST 在顶部操作区提供统一的“打开所在文件夹”操作，直接在本机文件管理器打开当前文件的实际父目录；项目资料入口的“在资源管理器中打开”操作 MUST 使用可区分图标，与“打开所在文件夹”在视觉与提示上明确区分，且保持阅读/编辑切换布局稳定。

当目录已不存在、文件来源身份变化或本机文件管理器启动失败时，界面 MUST 显示明确错误反馈并保留当前编辑草稿与历史；同一文件的异步请求状态 MUST 随文件身份隔离，切换文件页签时不会错显其他文件的加载状态。

#### Scenario: 在项目资料与资源管理器中使用统一入口打开目录

- **WHEN** 用户在项目资料当前文档或资源管理器文本、Markdown、HTML 面板点击“打开所在文件夹”
- **THEN** 系统 MUST 请求打开该文件实际所在目录并展示成功提示
- **AND** 项目资料头部中“打开所在文件夹”与“在资源管理器中打开”MUST 各自保持清晰图标与文字提示，原有阅读/源码切换和保存状态布局 MUST 保持稳定

#### Scenario: 目录失效或打开失败时保留编辑现场

- **WHEN** 用户触发打开所在文件夹但目录已不存在或系统调用失败
- **THEN** 系统 MUST 显示清晰错误提示，同时保留当前文件页签、未保存输入与撤销历史
