## ADDED Requirements

### Requirement: 精确文件打开不以全量清单为前提

对话文件目标的代码库与工作树可唯一核对时，系统 MUST 先读取该文件并显示正文，MUST NOT 以全量代码库清单成功作为正文的前提。系统 MUST 继续校验文件来源、可读性、路径边界和文件版本，并保持目录加载独立。无法经目标查询确认的文件 MUST 回到既有来源核对语义，MUST NOT 猜测替代文件。

#### Scenario: 完整清单仍在读取

- **WHEN** 用户点击可唯一确认的对话文件，完整代码库清单尚未返回
- **THEN** 系统 MUST 展示正确文件的正文，并在清单返回后保留当前文件与工作树。
