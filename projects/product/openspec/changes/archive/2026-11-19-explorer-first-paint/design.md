## Context

对话打开前已经要求真实工作树身份与文件可读，但完整目录清单不属于目标文件的验证依据。

## Decisions

在现有代码库接口增设可选的目标路径筛选。仅用实际 Git 对象目录与登记来源校对范围；未找到唯一目标则沿用现有解析，不能拿未确认结果替代。正文继续经原文件接口核对，并在短时的一次性交接中传给阅读器。完整清单随后加载，不改写已选工作树或文件。没有观察到长期知识事实变化，不新增知识文档。

## Risks / Trade-offs

不同目录碰巧同名不能用于消歧；已确认目标必须依据当前登记和 Git 身份。保留旧查询和历史定位。浏览器验收分别观察首屏与侧栏，不以目录接口耗时替代。
