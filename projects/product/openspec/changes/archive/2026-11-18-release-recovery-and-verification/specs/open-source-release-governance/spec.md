## ADDED Requirements

### Requirement: 已尝试的主包上传只能只读确认

主包上传意图和受理事实 MUST 保存在绑定准确版本和原包的发布证据中。上传已受理或尝试结果未知时，官方源暂不可见 MUST NOT 授权重新上传；发布器 MUST 能继续只读确认而不重复上传前兼容性检查。确认准确版本、完整性和发布标签前 MUST NOT 写 GitHub Release。

#### Scenario: 官方源延迟可见
- **WHEN** 上传被受理但准确版本或标签暂不可见
- **THEN** 执行 MUST 有界等待并保留待确认事实；同原包恢复只读回查，不重复上传。

#### Scenario: 旧尝试结果缺失
- **WHEN** 已进入恢复但没有可验证的未尝试证据
- **THEN** MUST 只读确认；网络未知或 404 不得解释为写入授权。
