## ADDED Requirements

### Requirement: 具体代码库内逐项选择工作树

资源管理器 MUST 保留代码库多选。工作树（Worktree）选择 MUST 仅在选定一个具体代码库时启用，逐项表示该代码库的实际检出目录，单次选择一个稳定身份；全部或多个代码库时 MUST NOT 用拼接目录组冒充一个工作树（Worktree）。已有任务（Task）多库及历史定位 MUST 保持准确。

#### Scenario: 未选择具体代码库
- **WHEN** 代码库范围为全部或多个代码库
- **THEN** 工作树（Worktree）选择 MUST 禁用并解释需要选择一个代码库，文件树仍允许浏览各代码库的登记目录

#### Scenario: 单库选实际目录
- **WHEN** 用户选择一个代码库并切换工作树（Worktree）
- **THEN** 选项 MUST 逐项展示实际目录名称、分支与路径，文件树只读取所选真实来源，已打开文件保持

### Requirement: 局部读取和刷新避免重复正文

目录 MUST 在展开时读取当前层直接子项，普通完整当前文本 MUST 使用一次正文请求满足阅读和编辑，MUST NOT 为相同新鲜观察立即重复请求正文。文件和目录 MUST 提供范围明确的独立刷新。目录刷新 MUST 仅重读当前范围已展开目录，收起目录再次展开时 MUST 重新观察；MUST NOT 因目录刷新重读当前文件或重新发现全部无关工作树（Worktree）。保存冲突、来源核验与只读边界 MUST 保持。

#### Scenario: 按层展开
- **WHEN** 用户首次展开一个目录
- **THEN** 系统 MUST 只读取该层直接子项，不提前遍历其他代码库根或全部后代

#### Scenario: 普通文本打开
- **WHEN** 用户打开可完整读取的当前普通文本
- **THEN** 右侧阅读与编辑 MUST 共用一次返回的正文与准确编辑身份，图片、历史和大文件保持原有边界

#### Scenario: 刷新范围明确
- **WHEN** 用户刷新目录，另有已收起目录和已打开文件
- **THEN** 系统 MUST 只重新读取当前展开的目录，收起目录下次展开再读，当前正文与输入保持；文件刷新 MUST 独立取得其当前观察
