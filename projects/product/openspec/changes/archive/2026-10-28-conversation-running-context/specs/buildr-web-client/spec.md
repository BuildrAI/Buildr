## MODIFIED Requirements

### Requirement: 对话必须固定当前输入与准确执行名称

只有当前执行状态为 `running` 且属于该次执行最后一段的用户输入及助手名称行 MUST 在阅读其后内容时固定于滚动区域顶部，不覆盖其他历史或造成整页跳动。执行结束、停止、失败、待回应、状态未知或阅读其他历史段时 MUST 恢复自然滚动排版，不保留悬浮边框、阴影或空白占位。名称 MUST 来自该段实际智能体（Agent）与模型（Model），不能被草稿选择或后续执行重标。长用户输入 MUST 默认收起，点击展开后在固定的有界高度内滚动阅读，并可再次收起；图片与完整原文 MUST 保留。正常执行 MUST 只在准确名称后显示呼吸灯与基于真实开始时间的持续时长，刷新不重新起算；失败、待回应、停止中、活动工具及未知状态 MUST 继续明确表达，不能被普通动画冒充。

#### Scenario: 滚动长执行历史
- **WHEN** 用户滚动阅读当前实际运行段之后的长过程
- **THEN** 对应用户输入和准确名称行 MUST 保持在内容顶部，其他历史段 MUST 自然滚动且不固定
- **AND** 加载更早记录及实时追加 MUST 保持原阅读位置

#### Scenario: 长输入展开和收起
- **WHEN** 用户输入超过默认显示高度并点击展开
- **THEN** 完整内容 MUST 可在固定高度内滚动，名称行与对话正文 MUST 仍可见，点击收起 MUST 恢复紧凑显示

#### Scenario: 名称与持续时间
- **WHEN** 同一对话出现不同模型的历史回复，当前执行仍在运行
- **THEN** 各名称行 MUST 保留实际模型，呼吸灯与时间 MUST 紧随准确的当前执行名称，不在输入框上方重复显示运行状态

#### Scenario: 固定区域的可见边界
- **WHEN** 用户阅读滚动到当前实际运行段的固定上下文下方
- **THEN** 固定区域 MUST 具有实体背景与清晰的底边界及轻阴影，正文不得透出；不得用整块外框嵌套用户气泡，名称不得采用默认链接下划线

#### Scenario: 定位当前输入与助手内容
- **WHEN** 用户点击定位用户输入或助手内容的入口
- **THEN** 系统 MUST 定位对应段落，仅移动当前对话的内部滚动区，不切换对话、触发发送或移动外部页面
- **AND** 入口 MUST 提供明确的可访问名称与键盘操作，助手最终答复存在时 MUST 优先定位该答复，只有固定区域实际存在时才预留其高度

#### Scenario: 长处理过程就近收起
- **WHEN** 用户展开已完成的长处理过程并滚动阅读
- **THEN** 该段名称行及展开过程底部 MUST 均提供直接收起入口，收起后 MUST 保留当前段落的可理解阅读位置；已完成段的名称行不得因展开而恢复悬浮

#### Scenario: 运行转为终态
- **WHEN** 当前执行完成、失败或停止
- **THEN** 固定区域 MUST 立即恢复普通聊天排版，用户图文、准确名称、答复及过程摘要 MUST 保留，不留下卡片或固定占位
