## Context

现有 RunView 保存执行控制与上下文占用，但不表达压缩阶段；原生事件可提供准确的开始、完成或状态清除。动机见 proposal.md。

## Goals / Non-Goals

目标是在同一执行身份下呈现压缩等待，且刷新、停止、终态和异常观察不残留错误提示。非目标是主动压缩、展示摘要正文、估计百分比或新增执行主状态。 Qoder 指 SDK 接入；已核对 Qoder CN 1.1.86 的 ACP 转换层未转发内部压缩状态，本轮按用户决定保留现状，不改厂商程序或传输通路。

## Decisions

- 增加可选压缩阶段快照及原生阶段事件；执行主状态不变。旧记录缺字段即无提示，旧客户端忽略字段，无需迁移。
- 快照携带原生压缩身份和开始时间。重复开始保持原时间，结束只清除匹配身份；原生观察明确缺少阶段时可清除，缺省字段不表示已经结束。
- Codex 按 contextCompaction 的条目生命周期；DSH 按匹配当前输入谱系的 compaction/start、end；Qoder 按主会话 system/status 及 compact_boundary。拒绝跨轮次或子智能体事件。
- 对话应用保存阶段，现有 SSE 与快照传输自然带出；只在有效运行状态显示。不确定、停止及终态清除陈旧进行中事实，可靠原生观察可重新确认。
- 失败诊断不等于整轮失败：先清除压缩提示，再沿原执行的真实状态展示诊断。

## Risks / Trade-offs

- 原生版本无事件 → 不根据静默或 Token 数变化推断。
- 断线缺少结束 → 不确定状态隐藏提示，重新观察准确原执行。
- 原生错误可能包含敏感内容 → 使用既有安全诊断，不保存摘要正文。
- 不提供百分比 → 原生没有可靠总量，使用已持续时间。

## Migration Plan

可选字段随服务及前端一起交付；无需数据库模式迁移。回滚忽略新字段，不重放执行。当前知识的智能体集成说明受新增阶段事实影响，建议后续在知识维护授权内校准；本次不扩展长期知识写入。
