## MODIFIED Requirements

### Requirement: 总览保持轻量的派生读取
总览 MUST 由既有登记事实派生，不建立第二关系存储，不要求获取所有代码库的本地状态。首版 MUST 保留简洁组成展示、对象入口和必要滚动，MUST NOT 将复杂图编辑、运行监控或任务统计作为使用前提。

#### Scenario: 多代码库读取
- **WHEN** 用户打开包含多个代码库的总览
- **THEN** 系统 MUST 不等待全量 Git 状态扫描，单个对象状态读取失败 MUST 只影响相关对象

#### Scenario: 窄屏查看完整组成
- **WHEN** 组成区域不足以并排显示三列对象
- **THEN** 系统 MUST 纵向展示去重对象，并通过显式名称呈现真实项目引用服务和服务引用代码库关系
- **AND** 搜索、聚焦、共享标记、部分不可读取提示及对象入口 MUST 保持，不要求横向滚动或悬停才能理解关系
