## Context

动机与范围见 [proposal.md](proposal.md)。现有后端通过模块贡献装配命令行工具（CLI）与 HTTP 入口，同一个应用层可以被两者调用；前端已有统一抽屉（Drawer）、代码编辑器和表格。已确认的离线原型来源为同一工作树中的 `services/buildr-web/src/prototypes/external-environments/`，保全版本见 [prototypes/viewer.html](prototypes/viewer.html)。原型含有的历史协作说明以用户最新收敛范围及本设计为准。

## Goals / Non-Goals

**Goals:** 连接是一项可长期引用的工作空间事实，MySQL 专业执行保留自身语义；配置一次后，本机智能体（Agent）和用户页面均可查询。执行入口明确连接编号、可选当前数据库和查询语句（SQL）。

**Non-Goals:** 不建立独立环境模块、查询结果产物或共享编辑协议，不引入额外对话与自动诊断编排。本轮仅支持普通 MySQL TCP 连接；公司接入时按实际需要扩展隧道或证书配置，不猜测企业网络。

## Decisions

### 一份声明、独立的本机认证

公共连接声明记录稳定编号、名称、类别、具体类型、自由环境标记、类型专用的 `config` 与内部认证引用；数据库地址、端口、用户名和默认数据库仅属于 MySQL 的 `config`，不是所有连接的通用必填字段。首个类型为 `category: data-source`、`type: mysql`。声明保存到工作空间 `connections/manifest.yml`；凭据只保存到本机应用数据目录，以工作空间编号和独立认证编号定位。密码不进入声明、返回值或日志。本机凭据采用认证加密和独立受限权限密钥文件，不把它描述为企业凭据管理服务或系统钥匙串。更新先写新的不可变凭据，再按观察版本原子提交声明；删除连接仅删除登记与本机认证，不操作外部系统。

本机认证绑定提供者类别、具体类型和该提供者定义的认证目标摘要，并将绑定纳入认证加密校验。每次调用前核对当前声明，包含由 Git 或外部编辑改变的声明；目标变化时拒绝发送旧凭据并要求重新配置。MySQL 的认证目标包含主机、端口和用户名，名称、环境、默认库和展示设置不影响绑定。

同一工作空间的代码工作树（Worktree）使用同一连接身份，读取规范来源中的声明；不得因为代码分支而复制出新数据库或退回同名目标。连接增改删校验观察版本，显式报告冲突。

### 一套应用能力、两个入口

新增通用 `connections` 模块，其类型登记表负责查找专业对接器（Connector）。每个类型定义自身配置校验、认证形态、连接测试及可提供的专业操作；首版只注册 MySQL 实现，不建设动态插件平台。新增其他类型只需注册实现与专用表单、工具入口，不修改公共连接模型，也不要求实现数据库查询。Kibana、DMP、XXL-JOB、Nacos 属于后续接入对象，本轮不伪造其可调用能力。

命令行工具（CLI）使用 `buildr connection list|create|update|remove|test|databases|tables|columns|query`；其中连接维护是通用动作，库表发现与查询属于 MySQL 能力，不适用类型明确失败。页面通过 HTTP 调用相同应用能力。机器输出采用结构化 JSON，密码只通过本机输入文件或页面表单提交，不作为命令参数回显。现有命令行扩展结构可满足首版需求，后续按实际消费需要增加模型上下文协议（MCP）薄入口。

HTTP 路径以 `/connections` 为根，创建使用 POST，修改使用 PATCH，删除使用 DELETE；测试使用 `POST /connections/test`；读取库表字段使用连接下的 `databases|tables|columns`；查询使用 `POST /connections/:id/query`。测试与查询均要求现有本机会话校验。公开连接返回 `hasCredentials`，不返回认证编号或认证内容；具体提供者（Provider）决定认证形态及是否必需，通用层允许无需认证的类型。

### MySQL 执行与查询边界

采用 `mysql2` 驱动及 `node-sql-parser` 的 MySQL 语法解析。允许单条 SELECT 及只读公共表表达式（CTE），拒绝修改、多语句、文件/锁/赋值和已知有副作用的函数。使用数据库只读事务（Transaction），生产账号继续由数据库原生只读权限保护；工具语法检查不是数据库权限替代。

无最外层 LIMIT 时添加 100；显式 1—500 保留，超过 500 拒绝并保留原始查询。支持明确 OFFSET，用户或智能体（Agent）自行调整条件或翻页；不自动抓取全部数据。保留提交语句和实际执行语句。查询超时 10 秒，返回数据容量上限 4 MiB，超限或超时报告实际失败，不伪称完整结果。结果采用独立列数组与行数组，保留重名列、空结果表头、小数和大整数精度。

默认数据库只决定未限定表名的上下文，`database.table` 按真实账号权限执行。资源列表勾选只影响用户展示，不限制工具发现与查询权限。

### 简洁的用户页面

工作空间导航增加“连接”，页面只有连接列表和查询两个页签。新增编辑统一抽屉（Drawer），包含标准 MySQL 连接字段与测试按钮。查询页选择连接和当前数据库，左侧为可选展示库的资源列表，右侧为常驻编辑器、运行按钮和结果表格；运行状态、错误、行数与耗时就近显示。首版不保存查询历史或智能体（Agent）查询结果，不增加接手操作。

## Risks / Trade-offs

- 查询语法支持存在解析库边界 → 不支持的语句明确失败，保留用户输入；覆盖常见联表、聚合、JSON 函数、只读公共表表达式（CTE）和限定库名。
- 只读查询仍可能消耗数据库资源 → 限制单次返回行数、容量和执行时间；这些限制不承诺扫描行数等于返回行数。
- 本机认证尚未绑定或机器网络不通 → 仅对应连接调用失败，不阻断代码或其他连接工作。
- 并发修改连接或查询期间切换目标 → 写入校验版本；页面忽略旧目标的异步结果，避免把旧库数据显示为新库数据。
- 新依赖影响主包消费 → 声明随包运行依赖并验证隔离安装后的实际命令入口。

## Migration Plan

此能力为新增，缺少连接清单时读取为空列表且不自动创建文件；首次保存按正常动作创建。既有任务、代码与智能体接入记录保持兼容。回退代码时保留连接声明与本机认证，不自动删除用户配置。测试先使用独占的临时 MySQL 实例与只读账号，公司连接留待后续联调。
