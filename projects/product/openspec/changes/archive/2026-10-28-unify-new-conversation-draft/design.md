## Context
当前文本存储键含工作空间，新建选择器维护独立临时状态，当前页面工作空间参数未用于初始化。指定旧对话的早期标题失败码为 agent_title_output_invalid；其 Codex 执行搭配 swe-2 模型，协议转换不传递结构化输出约束，而提示未说明 JSON 字段。

## Goals / Non-Goals
实现一份可恢复的新草稿及准确归属；保留已有对话隔离、权限和任务身份。不更改真实对话目录，不批量覆盖旧标题，不放宽工具或网络隔离。

## Decisions
- 新草稿存储键仅包含配置域；文本、归属和任务绑定一起保存。明确默认空间用 @default 表达，未选择时才使用当前页面空间。
- 当前页面空间只用于首次初始化，不随浏览页面、查看旧对话覆盖已有草稿。切换空间解除旧任务绑定。新草稿附件和模型选择使用稳定槽位。
- 存储不可用继续使用同页内存，并诚实提示。旧版当前空间草稿在首次读取时接续，其余旧键保留但不自动合并。
- Codex 独立标题请求同时显式提供 JSON 字段及示例，保持严格解析，不接受任意正文冒充标题；给跨协议转换保留文本中的约束。手动名称和当前版本保护沿用原实现。
- 合并并发目录刷新，去除初始化重复读取；保持后续设置更新和聚焦刷新。目录约 12 秒的现场原因须依真实计时判断，不能由截图推定计算耗时。

## Risks / Migration
多份旧草稿不可能无损自动合为一份；只迁移当前空间、保留其他旧键，不选择性覆盖。浏览器队列时长需现场分阶段证据，无法从总时长推断后端慢。

## Verification
纯逻辑测试覆盖稳定存储键、跨空间保留、任务解除、发送迁移和存储失败；标题执行器集成测试覆盖文本格式约束和严格输出解析；类型检查及适用隔离浏览器场景覆盖选择器与导航。
