## ADDED Requirements

### Requirement: 本机 Codex 发现与一次确认

系统 MUST 有界发现本机 Codex 桌面安装、内置程序及已有登记，显示可区分的安装与配置来源，不要求网页用户填写路径、端口或凭证。发现 MUST 不启动模型或创建聊天。确认 MUST 重新校验候选身份及已观察版本，保留旧登记与默认选择，只有明确请求才切换默认。一次确认 MUST 自动准备独立生成来源及受支持的桌面连接组件；两项能力的可用性 MUST 分别报告，局部失败 MUST 保留另一项已成立配置。升级及身份变化 MUST 重新核对，MUST NOT 静默换账号、程序或配置来源。

#### Scenario: 桌面安装没有搜索路径命令
- **WHEN** 本机安装 Codex 桌面且内置程序不在搜索路径（PATH）
- **THEN** 系统 MUST 提供该安装供选择，确认后复用真实入口及适用原生配置，不启动生成模型检查安装

#### Scenario: 确认期间安装变化
- **WHEN** 候选已显示但安装、程序或配置身份变化
- **THEN** 系统 MUST 报告局部冲突，MUST NOT 按旧输入执行其他路径

#### Scenario: 桌面组件准备失败
- **WHEN** 生成登记已成功而桌面组件未启用
- **THEN** 系统 MUST 保留生成登记并明确显示未就绪原因，MUST NOT 把发现成功或安装成功当成原聊天绑定成功

### Requirement: Codex 分层接入与明确退出

接入入口 MUST 先提供智能体（Agent）种类选择，选择 Codex 后才打开独立二级抽屉。一级抽屉 MUST 保持已接入列表的管理职责，二级抽屉 MUST 展示检测、候选及配置来源，并提供明确的确认和取消。取消 MUST 不创建登记或改变默认项。未发现安装时 MUST 显示明确空状态及重新检测，MUST NOT 展示空白抽屉或允许确认。确认成功后 MUST 返回父列表并分别报告生成及桌面准备结果，DSH 既有接入行为 MUST 保持。

#### Scenario: 取消本机接入
- **WHEN** 用户选择 Codex 并查看候选后取消
- **THEN** 系统 MUST 只关闭二级抽屉，父列表、默认值及登记不变

#### Scenario: 没有本机安装
- **WHEN** 用户选择 Codex 而本机未发现可接入安装
- **THEN** 子抽屉 MUST 说明未发现的对象和检测机器，允许重新检测或取消，确认不可用

### Requirement: Codex 新接入与已有连接维护分开

已有任一 Codex 登记时，界面 MUST 禁用 Codex 新接入并标明已接入。新接入请求 MUST 在登记锁内、已观察版本校验后拒绝已有 Codex，MUST NOT 更新登记或重复准备桌面。旧命令行登记更新 MUST 保持兼容。已有连接维护 MUST 由详情显式进入并携带 `existingAgentId`，只允许当前已登记 Codex 与对应同一真实程序及配置来源的候选；MUST 保留登记编号与默认值，MUST NOT 新建其他项、切换候选或接受 `makeDefault:true`。目标丢失、不匹配或维护候选未识别到桌面安装 MUST 局部失败；取消 MUST 无写入，结果不明 MUST 查询而不自动重发。

#### Scenario: 已接入后再次请求新接入
- **WHEN** 当前已有 Codex，而用户或另一入口尝试新接入
- **THEN** 界面 MUST 禁用选择与二级确认，后端 MUST 报告已接入，登记及桌面准备次数不变

#### Scenario: 已有连接明确维护
- **WHEN** 用户从已有 Codex 详情确认重新准备连接
- **THEN** 系统 MUST 只维护匹配的原登记，保留其编号、默认项与其他接入；错误目标 MUST NOT 转为新接入

### Requirement: 接入列表简洁与全部登记可见

一级抽屉 MUST 展示所属本机数据目录中全部已接入智能体（Agent），MUST NOT 按种类或可用性隐藏 DSH 或旧 Codex。条目 MUST 将默认选择与详情、Codex 移除操作分开；详情 MUST 按需显示于与条目对齐且遵守视口边界的紧凑浮窗，只突出生成与桌面状态并折叠低频说明，不在列表下堆叠说明。接入选择 MUST 支持悬停、点击及键盘路径，窄屏 MUST 可操作。操作完成、目标移除或抽屉关闭后 MUST 不保留错误对象的详情浮窗。

#### Scenario: Codex 与 DSH 已登记
- **WHEN** 当前登记同时包含 Codex 和 DSH
- **THEN** 两项 MUST 均显示且保留实际默认选择；查看详情、禁用新接入和取消 MUST NOT 改变登记

### Requirement: Codex 移除接入与自有服务停止

系统 MUST 允许按已观察版本移除指定 Codex 接入，不修改 DSH 或其他接入。存在排队、生成或连接准备时 MUST 保留全部状态并局部报告原因。执行移除时，当前 Buildr 应用实例 MUST 阻止相同范围的新生成、登记、默认选择和连接准备，先确认 Buildr 自有生成实例退出，再以已观察登记版本删除该接入；关闭结果不明或版本漂移 MUST NOT 静默删除登记。移除默认项 MUST 清空默认值，MUST NOT 自动选择另一接入。移除 MUST 停用桌面业务连接，MUST NOT 删除桌面聊天、记忆（Memory）、配置、插件（Plugin）、任务或长期关系，也不结束桌面进程。删除登记后即使桌面断开状态保存失败，系统 MUST 继续禁止旧连接调用并报告局部警告；结果不明 MUST 查询当前登记，MUST NOT 自动重发移除。独立桌面进程在登记删除前接受的请求可完成并保留结果；本能力 MUST NOT 宣称跨进程全局撤销或完全相同内容重新登记的原子保护。

#### Scenario: 空闲 Codex 移除
- **WHEN** 用户确认移除空闲 Codex
- **THEN** 系统 MUST 先确认自有服务停止，再移除本项并停用连接，其他接入和用户工作记录保持

#### Scenario: 有未结束工作
- **WHEN** 指定 Codex 尚有排队、生成或连接准备
- **THEN** 系统 MUST 提示先结束或取消相关工作，登记、默认项和连接不被部分移除

#### Scenario: 退出未确认或登记并发变化
- **WHEN** 关闭自有服务未确认退出，或关闭期间登记版本发生变化
- **THEN** 系统 MUST 保留登记并报告当前局部失败，退出未确认时仍禁止替代启动，MUST NOT 改动其他接入

### Requirement: Codex 临时创建不明与自有清理

独立 Codex 生成 MUST 从创建前覆盖清理与取消。创建请求发出后响应丢失、超时或临时身份不明时，系统 MUST 有界关闭自有生成实例并确认退出，MUST NOT 复用、不等待空闲回收、不重发创建。关闭未确认 MUST 阻止同登记启动替代实例，不影响桌面后台。创建中取消、迟到身份与终结后迟到结果 MUST 不继续执行或覆盖草稿。有效输出与清理结果 MUST 分开表达，回填 MUST 仍通过全部输出与版本检查。系统 MUST 不采用桌面共享服务，MUST 不写原聊天生成轮次。

#### Scenario: 创建已发生但响应丢失
- **WHEN** 服务接受创建但 Buildr 未获得准确临时身份
- **THEN** 系统 MUST 关闭自己拥有的实例，退出未确认时禁止替代启动，MUST NOT 重放创建

#### Scenario: 创建期间取消后迟到
- **WHEN** 用户取消创建中的操作，随后收到创建结果
- **THEN** 系统 MUST 清理本次自有资源，MUST NOT 启动生成或覆盖用户草稿

### Requirement: Codex 配置与桌面连接分别表达

一级列表与详情 MUST 共用当前桌面连接观察并分别展示生成配置与桌面连接状态。登记、程序可用或最近执行配置 MUST NOT 作为桌面已连接或生成成功的证明，只有桌面明确 `ready` 才能显示已连接。读取中、读取失败、无连接记录、等待桌面加载及断开 MUST 明确区别；关闭或隐藏管理抽屉 MUST 停止轮询。确认后的反馈 MUST 分开报告生成配置与桌面准备结果。

#### Scenario: 生成已配置但桌面未就绪
- **WHEN** Codex 登记存在且生成程序可用，桌面连接未就绪
- **THEN** 列表与详情 MUST 显示生成已配置及桌面实际未就绪状态，MUST NOT 显示整体连接成功；查看详情和刷新 MUST 无登记或配置写入

#### Scenario: 桌面状态读取失败
- **WHEN** 桌面状态读取失败而之前观察过已连接
- **THEN** 当前列表和详情 MUST 显示无法确认，而非沿用旧观察宣称已连接

#### Scenario: 详情位置与部分结果明确
- **WHEN** 用户打开某条 Codex 详情或完成桌面尚未就绪的接入
- **THEN** 详情浮窗 MUST 外右边框与对应条目外右边框对齐且在宽窄视口完整可见，支持键盘与点外关闭；部分结果 MUST 明确区分生成配置登记与桌面未连接，MUST NOT 用整体绿色成功掩盖局部未就绪
