## Context

动机见 proposal.md。`agent-operations` 管理生成登记和自有进程，不承载桌面聊天。R2 及本次实现证据已覆盖聊天面板消息、准确聊天打开、同基址片段链接的宿主（Host）复用和实际任务到达。最新修订补齐整体移除以及选择种类后进入二级抽屉的接入交互。桌面 Codex 未开放受支持的临时调用入口，因此继续独立生成，不能推出所有智能体（Agent）都应采用相同执行方式。

## Goals / Non-Goals

一次确认配置两项能力，保全当前提交说明、任务状态及桌面正常使用。本次不实现共享后台、不读取聊天库、不改 DSH、不保证宿主尚未支持的任意历史链接和跨窗口精确选页。

## Decisions

### 接入与正式组件

`agent-operations` 有界发现桌面、内置程序、搜索路径（PATH）与旧登记，候选身份包含真实程序、配置目录、安装版本及文件身份。确认时重读并验证候选及登记版本，不接受网页任意路径执行。独立生成仍按需启动，不通过模型调用检查安装。

新增 `codex-desktop` 模块维护稳定桌面连接，并以显式关联连接现有生成 `agentId`。生成登记与桌面准备分别保存，桌面准备失败不撤销生成。模块通过受支持的插件（Plugin）命令安装 Buildr 自有本机市场，源及启动入口须来自保留安装，候选工作树只在隔离测试中验证，不安装到共享用户运行时。安装、启用和实际桌面握手分别表达；宿主需要重启时提示且保留进度，不自动重启。

连接组件采用标准输入输出（stdio）模型上下文协议（MCP）工具和原生应用面板（MCP App）。面板业务用工具调用；工具服务调用同一 Buildr 应用能力，按已登记工作空间（Workspace）身份解析真实根，不把任意文件路径当授权。动态页面入口从当前实例读取，不把端口固化到插件。生成进程与工具服务分开管理。

### 接入层级与未安装状态

一级抽屉宽度约 640 像素并适应窄屏，只展示全部已接入条目的名称、默认与简短实际状态。详情按明确点击进入与条目对齐的紧凑浮窗，遵守视口宽高边界，不在列表下面展开大段说明；只突出生成配置与桌面连接，低频配置和生命周期说明折叠；Codex“移除接入”直接放在对应条目上。操作和选择区域分开，查看详情或移除不改变默认项。接入菜单支持悬停及点击，并保留键盘和触屏路径；已有任一 Codex 登记时，Codex 选项禁用并标明已接入，登记不可用也不能再当成新接入。

选择未接入的 Codex 才打开二级抽屉，显示检测状态、具体候选及配置来源，底部提供“确认接入”和“取消”。成功后关闭子抽屉，在父列表提供简洁结果提示，不自动展开详情；取消只关闭子抽屉，不登记、不改变默认项。打开后若其他入口接入 Codex，二级抽屉和全局写入状态再次核对当前登记并阻止确认。未发现本机安装时仍显示同一子抽屉中的明确空状态、重新检测与取消，禁用确认。DSH 既有接入提示及执行语义保留；已登记 DSH 与旧多项 Codex 均原样列出，不因本次新接入限制隐藏或合并。

### 新接入与已有连接维护

`POST /api/v1/app/agents/codex/connect` 不带 `existingAgentId` 表示新接入：完成候选复核后，在登记锁内校验已观察版本，存在任一 Codex 即返回 `agent_codex_already_connected`，不写登记、不重新准备桌面。旧命令行登记的更新行为保持兼容，不将界面新接入限制扩展到旧登记更新。

详情“重新检查连接”进入明确的维护二级抽屉，标题“检查 Codex 连接”、确认“重新准备连接”。请求携带 `existingAgentId` 且 `makeDefault:false`；候选只允许该已登记项，并在登记锁内复核目标种类、编号及真实程序和配置目录相同。维护必须识别到可准备的桌面安装，纯命令行候选不能冒充桌面维护成功；新接入的独立生成能力不受此局部条件影响。维护可更新同项安装信息和重新准备桌面，但不能新增登记、换到别的候选或改变默认值；目标不存在或不匹配时局部失败。取消无写入，结果不明只核对当前状态，不自动重发。

日常应用与隔离预览各自读取所属本机数据目录，列表不得因种类或可用性过滤已登记项。预览任务库副本不代表日常接入登记也已复制；本次现场已确认日常有 Codex 和 DSH，预览只有此前在预览确认的 Codex，不将该差异解释为 DSH 删除，也不借验收修改日常登记。

### Codex 移除与断开权威

只为 Codex 条目提供“移除接入”确认，作用于已观察登记版本。存在排队、生成或连接准备时局部拒绝，提示等待或通过现有取消功能结束后重试；不替用户强行中断已有工作。移除执行期间，当前 Buildr 应用实例阻止相同接入范围的新生成、登记、默认选择及连接准备；空闲自有生成实例先关闭并确认退出，退出结果不明保留登记和阻止替代启动。随后以比较并交换（CAS）移除该 Codex 登记；移除默认项时清空默认值，不暗中切到 DSH 或其他 Codex。

这里不提供跨进程全局撤销事务。独立桌面工具进程在登记实际删除前已接受的请求可以完成，结果保留；登记删除后每次业务调用重读登记并禁用。另一个命令行进程以完全相同内容重复登记不会改变内容摘要版本，不能据此识别并保护这一并发意图；正常接入和移除通过同一 Buildr 应用实例串行处理，不将这一边界宣称为跨进程重接入原子性。

生成登记不存在即为桌面业务调用禁用的权威事实，真实桌面模块每次读取该事实。桌面连接同时保存 `disconnected` 状态、使旧准备回执失效，阻止旧组件握手和新绑定、接续、交接；不卸载组件、不修改 Codex 配置、不结束桌面进程。若登记已移除但断开状态保存失败，返回明确局部警告，缺失登记仍阻止调用及复活，不能报整体回滚或让旧连接继续工作。用户聊天、记忆（Memory）、配置、任务及关系全部保留；任务侧既有原聊天链接继续可打开。用户重新明确确认相同安装范围时恢复稳定桌面连接编号，不因默认变化自动重绑。请求结果不明时网页刷新原登记核对，不自动重发移除。

### 具体聊天与独立关系

桌面连接、长期任务关系及有界回执分别持久化在对应本机所有者目录，使用已有原子写入和排他锁。关联建立幂等，解除校验独立关系版本。任务事实由现有任务应用验证；关系不修改任务状态或正文版本。

面板创建 `bindingRequestId`，经 `ui/message` 要求承载聊天直接取得 `CODEX_THREAD_ID` 并提交；工具服务启动环境和共享 `CODEX_SESSION_ID` 均不替代承载身份。面板查询匹配回执后恢复关联列表，重开时重新确认真实身份，不依赖面板缓存自证。单次交接携带稳定编号及准确目标，收到的原聊天回执仅表示接收，不能当任务完成；不明结果查询、不自动重发。

### 固定入口和共用业务视图

地址为 `/workspaces/<workspaceId>/codex#/tasks/<encodedTaskId>`，外层基址在同一工作空间内保持稳定。受限导航适配继续使用原有 React 路由和详情组件，实际片段保存准确目标，首次加载、刷新、返回／前进和外部片段变化统一解析。原路径归一及历史资源状态不得覆盖新片段目标。

当前可控制旧页经安全采用动作切换到固定入口，保留状态与草稿；新 Codex 链接使用固定入口，普通 Web 链接不变。历史任意路径链接仍可正确到达，但可能新增页。宿主默认同基址匹配不等于任意页面发现，多页及跨窗口行为分别验收，不能调用私有宿主接口（Host API）。

### 独立生成清理

保持一次操作一个 `ephemeral:true` 临时会话（Ephemeral Session）以及现有材料、输出与草稿校验。创建发出后结果不明立即关闭自有实例并确认退出，不等待空闲回收、不复用、不重发。创建中取消或迟到结果不继续生成；释放失败转关闭，关闭未确认禁止启动替代实例。有效输出与清理结果分开表达；回填仍须通过所有输出及版本校验。独立生成环境剥离共享服务内部开关，不继承桌面执行管道。

## Risks / Trade-offs

- 同基址复用属于已测版本行为 → 以真实点击的原页身份、页数和任务内容验收，不按地址或工具返回认定完成。
- 插件（Plugin）缓存或宿主刷新要求 → 安装版本与活跃握手分开，未就绪不冒充可交接。
- 同目录不等于相同运行时 → 界面明确基础配置来源与生成限制，持续工作留在桌面原聊天。
- 多入口并发及账号变化 → 保持关系版本，重连／同安装升级保留连接编号，实质账号或配置变化不原地重定向旧编号。

## Migration Plan

旧生成登记无需迁移即可继续使用，桌面信息按确认增量建立。普通 Web、书签和材料旧路径继续有效；只采用当前可控制页面，不扫描或关闭用户其他页。回退代码时保留本机关系和用户成果，不删除聊天。DSH 后续单独探索一个服务进程覆盖所有能力，不在本次实现或规范中预设其方案。

### 详情与真实连接状态

一级抽屉打开时统一读取 Codex 桌面连接状态，列表与详情共用同一观察，关闭或隐藏后停止轮询。生成登记、程序可用性、服务运行状态及最近执行配置均不能证明桌面已连接，也不能证明一次生成已成功；只有桌面连接明确为 `ready` 才显示已连接。读取中和失败分别为等待确认和无法确认，缺失、等待加载、不可用及断开保持可区分。详情浮窗不重复一级条目标题和大段配置页结构，保留显式刷新及必要的连接维护入口；未知或候选环境原因在低频信息中保留，未准备桌面不得误报全部接入完成。DSH 仍按原状态呈现，不套用 Codex 两路能力。

### 浮窗位置和结果提示

详情按用户偏好使用轻量浮窗，浮窗外右边框与触发条目外右边框对齐并保持一致间距；窄屏按实际视口避让，必要时翻转，不裁切内容。分区使用统一内容边缘、稳定行距和细分隔，标题与关闭同行，默认只突出生成和桌面两项状态。键盘可打开和关闭，关闭返回原触发按钮，点击外部、切换条目、移除目标及隐藏页面均正确结束旧详情。接入或维护的部分完成结果使用普通、准确的结果提示，不能把桌面未连接整体染为绿色成功；完整技术原因保留按需查看。
