## ADDED Requirements

### Requirement: 文章页必须发现任务工作树草稿

文章应用 MUST 从已登记且当前身份有效的任务工作树（Worktree）发现任务范围内项目 `docs/publications/` 中新增或修改的有效文章。它 MUST 将这些候选作为草稿并返回来源任务标识与标题；MUST 区分主目录及不同任务的同名文章，且 MUST NOT 因任务已完成而隐藏仍存在的稿件。未变化的主目录文章副本 MUST NOT 重复列入。

#### Scenario: 已完成任务中的新文章
- **WHEN** 已完成任务的有效工作树中有主目录尚不存在的文章
- **THEN** 文章页 MUST 显示该草稿及可打开的来源任务，支持正文和原文预览

#### Scenario: 多个来源有同名文章
- **WHEN** 主目录及两个任务工作树包含同一项目同一文章标识的不同稿件
- **THEN** 列表、深链接、阅读、收藏及资源 MUST 分别绑定对应来源，不能覆盖或混淆

#### Scenario: 未变化的文章副本
- **WHEN** 工作树稿件与当前主目录稿件内容版本相同
- **THEN** 文章页 MUST 保留主目录文章并排除重复候选

#### Scenario: 开发入口与安装包行为一致
- **WHEN** 用户通过开发入口或已安装产品包的普通文章页查看当前工作空间
- **THEN** 两种入口 MUST 都能发现合法任务工作树草稿并读取对应正文、来源任务和图片，不能依赖临时预览模式

### Requirement: 工作树文章预览必须保持来源与读取边界

工作树文章详情、保存与资源 MUST 重新核对任务范围、项目登记及工作树身份，并从同一工作树固定文章目录读取。图片与附件 MUST 保持原有类型、相对路径及符号链接限制；MUST NOT 接受任意目录参数或在来源失效时退回同名主目录文件。预览与编辑 MUST 保持来源，不复制、集成或发布稿件，MUST NOT 将工作树稿件暴露为主目录编辑、上传或删除目标。

#### Scenario: 正文和图片来自工作树
- **WHEN** 工作树稿件引用合法本地图片且主目录中有同名不同图片
- **THEN** 阅读器 MUST 显示工作树正文与图片，并标明来源任务

#### Scenario: 工作树失效或资源越界
- **WHEN** 来源工作树被移除、身份变化，或图片路径越界、为符号链接
- **THEN** 对应读取 MUST 返回准确不可用诊断，其他来源文章仍可查看

#### Scenario: 保持主目录写入行为
- **WHEN** 用户查看工作树草稿或编辑主目录文章
- **THEN** 草稿编辑 MUST 作用于原工作树稿件并保留来源任务入口，主目录文章原有受版本保护的编辑行为 MUST 保持有效

### Requirement: 文章阅读必须保持有界且一致的内容宽度

文章阅读器 MUST 在宽屏及展开阅读时保持居中且具有适宜宽度上限的正文列，配图 MUST 与正文使用相同可用宽度；窄屏 MUST 随容器缩小且不产生页面横向溢出。章节目录 MUST 从真实标题生成并能定位对应章节。

#### Scenario: 宽屏展开及窄屏阅读
- **WHEN** 用户在宽屏展开阅读文章，或在窄屏查看带大图和章节标题的文章
- **THEN** 正文与图像 MUST 对齐并保持宽度约束，章节目录 MUST 可用

### Requirement: 人必须能够校准工作树文章措辞

文章页 MUST 复用现有编辑器支持修改工作树稿件的标题、摘要和正文，保存到相同来源任务的原文件，保留其他元数据及资源。保存 MUST 校验已观察的来源身份和内容版本；来源失效或版本变化 MUST 明确拒绝覆盖并保留用户输入，最新稿件对照 MUST 读取同一来源。编辑行为 MUST NOT 自动执行 Git 提交、集成、发布或改变任务状态。

#### Scenario: 修改措辞后保存和回读
- **WHEN** 用户编辑工作树草稿的标题、摘要或正文并保存
- **THEN** 原工作树文件 MUST 保存新内容，列表和阅读器 MUST 更新，主目录及其他任务同名稿件 MUST 保持不变，图片预览 MUST 仍来自原工作树

#### Scenario: 外部修改或来源变化
- **WHEN** 智能体修改了同一稿件，或用户编辑期间来源根、文件身份或工作树有效性发生变化
- **THEN** 保存 MUST 拒绝使用旧观察覆盖当前内容，保留输入并允许从同一来源对照最新稿件，不回退主目录

#### Scenario: 原文内直接修改
- **WHEN** 用户切换到原文并校准措辞
- **THEN** 原文 MUST 能原位编辑并保存或取消，保留同一来源和冲突保护；身份、状态及发布记录不可经该文字入口静默更改，格式错误保留输入并给出提示

#### Scenario: 工作树阅读入口精简
- **WHEN** 用户阅读工作树草稿
- **THEN** 页面 MUST 提供原文内编辑，MUST NOT 在顶部重复展示“编辑文章”按钮；普通文章管理入口、列表编辑及普通文章已有编辑链接 MUST 保持兼容
