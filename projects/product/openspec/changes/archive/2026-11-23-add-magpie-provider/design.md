## Context

Magpie 公开 `/api/hello`、`/v1/models`、`/v1/responses`；已经与 Buildr 的 Codex 和 Claude Code 真实联调。额外检查确认 `/v1/magpie/quotas` 返回的是上游账号记录，不是网关总额度。

## Goals / Non-Goals

用户能在现有供应商抽屉连接本机网关，也能显式要求准备受管实例。使用同一模型网关、分组和选择状态。不更改现有账号；首版不接入多账号额度显示或远程网关。

## Decisions

- 独立供应商 ID；复用自定义端点存储、模型租约和 Responses 请求实现。Magpie 动态目录与探测单独处理，不把任意 OpenAI 兼容端点认作 Magpie。
- 下载固定官方版本和校验值；仅显式动作启动。优先复用已运行的有效实例；不从普通刷新、断开或重试推理触发安装。
- 额度后续可接到 Magpie 设置页，按上游账号保留原单位、额度窗口、重置时间和观察时间；未知或多路由不挂模型余额。不采用用户字段作为模型身份或额外登录凭据。

## Risks / Trade-offs

端口占用、网关离线和空目录分别处理。不能根据目录确认实际下游账单；保留选定来源并阻止自动降级。旧自定义端点不自动迁移。
