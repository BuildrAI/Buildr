## ADDED Requirements

### Requirement: 控制资源释放后的显式继续

用户已明确要求继续原目标、准确原轮已受理且结果未知、原控制资源释放已经核验、没有待决定及该对话的在途工作、并且原参与者、模型来源、模型、档位和权限保持一致时，系统 MUST 允许用准确原轮身份手动预览并接续一次。系统 MUST 保留原轮未知结果、工具条目和原生执行引用，接续提示 MUST 要求先核对当前成果及未知命令，MUST NOT 重放原指令或工具、推定独立命令退出、宣称旧工作成功或代答问题。预览和发送 MUST 校验同一已观察版本与准确原轮；没有释放证明、存在待决定或选择变化时 MUST 拒绝此例外。普通发送、排队及自动恢复 MUST NOT 获得此例外。

#### Scenario: 已释放但原结果未知时明确继续
- **WHEN** 用户要求恢复原对话，准确资源释放已成立，原轮仍有未知工具结果且没有其他在途工作或待决定
- **THEN** 原组合的显式继续 MUST 被接受一次，原轮和工具结果 MUST 继续保持未知并可查，接续提示 MUST 要求先核对现状

#### Scenario: 没有释放证明或存在待决定
- **WHEN** 释放未确认、原轮身份或版本变化、请求仍待答、原轮中断前有未解决决定、或者选择发生变化
- **THEN** 手动继续 MUST 被拒绝，原记录和输入 MUST 保留

#### Scenario: 禁止隐式恢复未知结果
- **WHEN** 页面刷新、后台重启、自动恢复、普通发送或排队发生
- **THEN** 系统 MUST NOT 据资源释放自动重发或续做未知操作
