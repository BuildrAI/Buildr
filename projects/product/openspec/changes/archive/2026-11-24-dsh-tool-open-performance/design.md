## Context

桌面工具沿用独立 WebView 与一次性票据。多仓库清单已经能分批返回，单仓库仍等待全部检出状态。

## Goals / Non-Goals

缩短点击到反馈、目录树和当前改动可用的时间。沿用 DSH 原生标签、现有工作空间边界和 Git 操作前置条件。

## Decisions

- 插件在验证桌面交接后给 URL fragment 附加工具标识。票据页保留允许的目标字段，生产入口按目标选模块。旧网页仍可走现有导航兼容路径。
- 仓库清单保留发现顺序与请求上限。优先读取选中或默认的工作树，返回其实际状态；其余检出由后台阶段补齐。后台刷新期间保留已显示的结果。
- 工作树快照仅供显示，刷新未确认期间保留现有 Git 写入的版本校验与目标范围。

## Risks / Trade-offs

- 插件、票据页和前端需兼顾滚动升级，使用同源工作空间约束并核对冷启动和已有认证两条路径。
- 早期状态和完整状态都必须使用已验证的检出身份，缺少状态的工作树不能表现为无改动。
