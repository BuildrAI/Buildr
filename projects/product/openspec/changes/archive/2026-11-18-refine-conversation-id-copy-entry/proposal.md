# 变更提案：对话 ID 复制收进顶栏更多菜单并改为列表悬停显现

## 背景与问题
1. 先前为了精简视觉干扰去掉了列表、提醒浮窗与当前对话顶栏的常驻 ID 文本，仅保留裸露的复制图标后，图标失去了文本依附：
   - 在对话列表与提醒浮窗每行右下角常驻显示时，整列形成重复符号噪声，侵占原本留给状态与草稿标签的右侧留白；
   - 在当前对话顶栏标题旁单放一个复制图标时，容易让用户误以为是“复制对话标题”。
2. 用户经权衡确认采用方案二：当前对话顶栏把复制入口收进右上角“更多对话操作”菜单，对话列表与活动提醒浮窗仅在悬停或键盘聚焦该行时显现复制图标。

## 变更目标
1. **对话顶栏复制收进更多菜单**：移除 `.ac-thread-identity` 独立复制图标容器，在“更多对话操作”下拉菜单中提供 `复制对话 ID（<8位短ID>）` 菜单项（未保存草稿对话禁用），点击复制完整对话 ID 并展示自动消失的轻提示。
2. **列表与提醒浮窗改为交互时显现**：保留行右下角复制按钮及无重叠防挤占内边距，默认隐藏（`opacity: 0; pointer-events: none`），仅在鼠标悬停该行、键盘聚焦该行内元素或处于 `已复制` 反馈期间显现（`opacity: 1; pointer-events: auto`）。
3. **同步更新规范与浏览器场景验证**：更新 `agent-conversations` 规范及对应端到端测试断言。

## 非目标
- 不改变关联对话选择器中 8 位短 ID 的展示方式。
- 不改变消息或失败路径原有的 `CopyButton` 行为。
- 不修改后端接口、列表状态判定或排序逻辑。
