## Context

见 proposal.md。源码观察已支持隐藏暂停和跨页签共享，无需改造；对话订阅仍会在隐藏页签占用连接。

## Goals / Non-Goals

释放不可见观察占用，降低轮询，保留准确恢复；不保证所有网络慢问题被消除，不改执行控制，不引入全局业务状态库。

## Decisions

用共享页面可见性 Hook 驱动主/子对话订阅生命周期；隐藏立即 abort 并清理重试，恢复时重读准确对话后再订阅，保留现有身份/代次保护。子对话额外遵守其展开可见性。已有源码观察共享机制保留，不再建跨页签对话副本与选主状态，避免扩大同步复杂度。

普通聊天目录30秒兜底，模型设置5秒，显式操作与恢复可见仍刷新；不使用永久缓存。

上传以 Performance API 的固定名称记录文件读取及每次请求等待耗时，覆盖草稿/普通附件。只留每种阶段最近一次，诊断异常吞掉，不输出文件身份；网络段包括浏览器排队和后端时间，不能冒充服务端处理时间。

## Risks / Trade-offs

- 隐藏期间无逐条前端推送 → 后台执行继续，恢复时重读并以原有订阅快照核对。
- 模型外部变化最多30秒兜底延迟 → 设置、焦点与显式操作保持刷新。
- 上传原因仍可能是网络或服务端 → 不增加自动重试，保留实际错误与耗时。

## Migration Plan

无持久数据迁移，回退代码不改变已有对话或附件。
