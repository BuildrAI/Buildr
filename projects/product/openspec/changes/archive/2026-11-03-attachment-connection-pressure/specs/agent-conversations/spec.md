## ADDED Requirements

### Requirement: 不可见对话观察必须释放连接并可准确恢复

页面隐藏时主对话及子对话实时观察 MUST 释放连接并取消观察重试；折叠的子对话 MUST NOT 保持独立实时连接。恢复可见或重新展开时 MUST 重新核对准确对话并按现有身份及代次规则恢复观察，不得停止后台执行、确认未查看消息、代答或重发输入。普通聊天模型目录 MUST 使用30秒兜底刷新，设置界面 MUST 保持5秒刷新，并保留显式操作、焦点和恢复可见刷新。

#### Scenario: 隐藏页签不挤占上传连接
- **WHEN** 多个页签正在观察活动对话，部分页签转为隐藏
- **THEN** 隐藏页签 MUST 释放主/子对话实时连接，前台页签 MUST 可继续上传附件
- **AND** 恢复可见 MUST 核对准确对话进展，不发送新的工作输入

#### Scenario: 折叠子对话
- **WHEN** 用户折叠正在观察的子对话
- **THEN** 该子对话独立连接 MUST 被释放，重新展开 MUST 先核对当前事实再恢复观察

### Requirement: 附件耗时诊断不得改变上传结果

普通附件及草稿附件 MUST 通过固定名称的本机 Performance API 分别记录最近一次文件读取及请求等待耗时；不得记录文件名、正文、身份或认证信息。诊断失败 MUST NOT 改变上传成功、错误或版本校验语义；网络阶段 MUST NOT 被解释为纯服务端耗时。

#### Scenario: 上传失败仍保留原错误
- **WHEN** 网络请求失败或 Performance API 不可用
- **THEN** 上传 MUST 保留原始结果或错误，不得因诊断失败额外重试或掩盖错误
