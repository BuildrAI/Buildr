## ADDED Requirements

### Requirement: 执行异常必须通过统一事实安全恢复

Agent Service MUST 按执行器结构化故障及准确观察统一恢复协议坏流、观察断连及进程退出，复用原对话、执行选择和持久预算。受理、结束、控制资源释放与工具结果 MUST 独立保留，MUST NOT 重放未知操作或推断成功。

#### Scenario: 准确资源释放后接续
- **WHEN** 任一执行器发生协议坏流，准确控制资源已释放且无待回应问题
- **THEN** 系统 MUST 接续剩余目标并先核对已有成果和未知操作

#### Scenario: 问题和旧轮保护
- **WHEN** 资源释放未确认、存在待回应问题、用户停止或更新输入
- **THEN** 系统 MUST 保留原事实并阻止陈旧自动恢复

#### Scenario: 持续失败
- **WHEN** 恢复重复失败或服务重启
- **THEN** 系统 MUST 共享持久预算并保持去重，不无限恢复
