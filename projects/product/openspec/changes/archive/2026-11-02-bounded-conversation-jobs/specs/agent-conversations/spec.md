## ADDED Requirements

### Requirement: 前台有限命令必须具有真实退出期限

Buildr 隔离 DSH 中的前台 shell 命令 MUST 使用原生执行器的有界超时终止，MUST NOT 因等待到期自动转为无限后台作业。需要长期运行的服务 MUST 显式选择后台启动，系统 MUST 保留其准确作业身份与停止能力。超时结束 MUST 保留超时事实和已有输出，不得显示成功或自动重发。

#### Scenario: 媒体预览命令挂住
- **WHEN** 前台媒体预览命令超过实际执行期限
- **THEN** 原生执行器 MUST 终止该命令并返回超时结果，不遗留自动提升的后台作业

#### Scenario: 显式运行后台服务
- **WHEN** 智能体在授权范围内显式后台启动需要保留的服务
- **THEN** 系统 MUST 保留该服务，不能因模型轮次结束或前台期限到达而终止它

### Requirement: 仅后台作业不得冒充模型执行

系统 MUST 区分模型仍执行、仅后台作业、未读、待决策和未知事实。模型已确认结束且仅有后台作业时，后台作业 MUST NOT 单独使对话进入活跃提醒或模型执行统计；完整历史 MUST 保留可发现的后台状态及准确控制。未读、待决策、其他准确模型执行和未知结果 MUST 继续按真实事实提示，不得把后台作业排除出活动统计等同于进程退出或资源释放。

#### Scenario: 已读答复仅剩后台服务
- **WHEN** 模型已结束、答复已读且没有待决策或其他模型执行，仅有后台作业
- **THEN** 对话 MUST 不因该作业出现在活跃提醒或执行中模型统计，历史 MUST 标明后台作业仍运行

#### Scenario: 后台作业伴随未读答复
- **WHEN** 模型结束但答复仍未读且后台作业仍运行
- **THEN** 系统 MUST 保留未读提醒，并明确后台作业不代表模型仍执行

#### Scenario: 旧摘要保留错误活跃标记
- **WHEN** 旧摘要将仅后台作业的已读对话缓存为活跃
- **THEN** 新读取 MUST 按准确且版本匹配的状态重算，不改写历史工具结果，不要求直接修改数据库
