## Why

前台命令等待超时默认升级为无限后台作业，使已结束模型轮次长期显示活跃。需要真正的进程退出期限，并将后台作业与模型执行区分。

## What Changes

- Buildr 隔离 DSH 的前台 shell 超时后由原生执行器终止，不再自动转后台；显式后台启动保留。
- 仅后台工具活动不再单独触发活跃对话或模型执行统计，历史与作业控制仍保留。
- 兼容旧摘要，保留未读、待决策、真实模型运行和未知状态。
- 无破坏性公开 API 变更；前台命令超时行为有意改变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `agent-conversations`: 有界前台命令以及后台作业与模型活动的分离。

## Impact

DSH 原生配置覆盖、活动派生与只读摘要兼容、执行统计、对话状态展示、回归及 Agent 指引。无共享凭据修改或历史业务重发。
