## ADDED Requirements

### Requirement: 资源移除与永久删除明确分离
项目、服务、代码库和技能的“移除” MUST 只取消允许移除的登记及关联，保留代码、源文件和历史记录；确认 MUST 说明影响。列表操作 MUST 保留固定右侧，使用紧凑列宽及按钮间距，同排低强调显示，窄容器可以横向滚动，不使用醒目的默认危险按钮。彻底删除文件 MUST 属于独立功能，本次不提供。

#### Scenario: 移除后保留目录
- **WHEN** 用户确认移除可移除的资源
- **THEN** 登记从列表消失，源目录及文件保持不变，符合登记条件时可以重新选择

### Requirement: 服务新增直接选择服务目录
新增服务 MUST 列出 projects/*/services/ 下未被服务登记的真实目录；选择已有目录 MUST 只登记并解析其代码位置。不选择已有目录时 MUST 根据用户选择或入口项目在 projects/<项目>/services/<服务标识>/ 新建。系统 MUST 保留唯一代码库引用并自行转换内部相对路径，不要求用户填写模块目录。

#### Scenario: 选择已有服务
- **WHEN** 用户选择已有服务目录并提交
- **THEN** 系统校验目录观察与当前登记版本，保存正确代码位置，不覆盖或补写原文件

#### Scenario: 新建与冲突
- **WHEN** 用户未选已有目录并提交新服务
- **THEN** 系统在明确项目的 services/ 下创建目录并登记；目录已存在、重复或观察过期时拒绝覆盖并保留输入
