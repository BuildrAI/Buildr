## ADDED Requirements

### Requirement: 已有代码库候选登记
代码库新增 MUST 提供工作空间内未登记真实 Git 根目录候选，选择后带入实际目录及可确定的本地配置，保存只增加登记。已有外部绝对路径输入 MUST 保持可用。候选观察过期或重复位置 MUST 拒绝保存。

#### Scenario: 代码库移除再登记
- **WHEN** 用户移除未被服务引用的代码库并重新选择保留目录
- **THEN** 系统重新登记该真实代码位置，Git 状态与文件不被改写

#### Scenario: 代码库仍被服务引用
- **WHEN** 用户请求移除仍被服务引用的代码库
- **THEN** 系统说明引用并拒绝移除，保留全部登记与代码
