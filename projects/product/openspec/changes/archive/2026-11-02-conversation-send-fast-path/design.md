## Context
普通消息串行经过 prepare-send 和 send；prepare 构建来源文件，submit 再构建。超限还调用原模型摘要。

## Goals / Non-Goals
日常发送一次受理，无自动摘要等待。保留原生恢复、增量交接、显式预览、容量权限与幂等校验。不增加后台摘要、不清理历史。

## Decisions
- send 的 previewToken 改为可选；有令牌仍严格校验，无令牌在同一受理动作内准备并校验。沿用请求去重与版本检查。
- Web 普通发送直接调用 send；显式预览、恢复和问题交接沿用专用语义，预览不再生成模型摘要。
- 同参与者 contextRef 存在、无未交付记录且非切换/问题交接时避免历史组织、文件生成；真实增量交接继续用原始来源。
- 删除 prepareHandoff 的模型摘要等待；兼容旧 skipHandoffSummary 字段。通过一次直接提交消除重复准备，不新增跨请求无版本缓存。

## Risks / Trade-offs
直接提交不绕过权限和容量；旧预览仍须失效保护。上下文身份未知由现有恢复逻辑处理，不以同模型代替身份。

## Validation
真实服务测试直接发送、重复输入、过期版本、超限索引无摘要；浏览器断言普通发送不调用准备接口。观察受理/原生接收边界，不把替身计时作为真实账号性能结论。
