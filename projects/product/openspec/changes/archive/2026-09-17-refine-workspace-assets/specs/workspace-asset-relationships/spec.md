## ADDED Requirements

### Requirement: 删除项目和服务登记
系统 MUST 支持按当前清单版本删除项目（Project）或服务（Service）登记；删除项目只解除其引用，删除服务解除全部项目对它的引用。系统 MUST 保留文件、代码库与历史任务，不重写历史身份。

#### Scenario: 删除共享服务
- **WHEN** 用户确认删除多个项目引用的服务
- **THEN** 系统 MUST 原子移除服务登记与相关引用，保留代码和历史记录

#### Scenario: 陈旧删除
- **WHEN** 确认期间清单版本改变
- **THEN** 系统 MUST 拒绝删除并要求重读受影响对象

### Requirement: 独立轻量资源列表
服务与代码库 MUST 提供独立列表接口（API），使用同一声明和关系事实，返回本对象及必要关系摘要。列表与完整关系读取 MUST 不执行全量 Git 状态扫描；单个代码库状态 MUST 可按需读取，失败局部展示且不阻塞列表。

#### Scenario: 大工作空间列表
- **WHEN** 用户打开含多个仓库的服务或代码库列表
- **THEN** 系统 MUST 直接返回声明摘要而不等待 Git 工作区扫描，普通列表不请求全量关系接口
