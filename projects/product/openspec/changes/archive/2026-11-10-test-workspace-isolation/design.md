## Context

系统已有 `createIsolatedWorkspaceState`，以独立目录及 `.buildr-test-state.json` 管理生命周期；标准入口使用它，但直接同进程 CLI 探针没有自行接入。真实登记守卫只拒绝系统临时目录与任务工作树，仓库内 `.buildr/local/inproc-probe` 不在覆盖范围。正常开发预览通过独立实例数据根读取共享登记，这是必须保留的行为。

## Goals / Non-Goals

目标：支持的测试入口默认隔离，登记与管理归属写入不能逃出测试边界；环境漂移和旧运行时不得转写真实用户状态；正常预览保持共享真实工作空间。

非目标：不按目录名扩充黑名单，不复制真实账号或工作空间，不提供抵抗任意同权限恶意脚本的操作系统沙箱，不改变普通用户登记流程。

## Decisions

1. 复用已有测试状态根与生命周期身份文件，不新增平行状态。隔离入口派生 `BUILDR_TEST_STATE_REQUIRED=1`，使新实例在状态根意外缺失时也不能回退；不以通用 `NODE_TEST_CONTEXT` 强加 Buildr 内部约束。写入保护在构造时捕获测试范围，并在操作时同时核对当前范围，防止缓存对象或删除环境变量导致逃逸。
2. 校验实际路径和最近现存祖先，拒绝经符号链接越出范围。测试状态缺失、已结束或目标越界时，在目录创建、锁和管理归属写入之前失败；锁内及实际写入前重新检查。
3. 同进程 CLI 辅助工具接入现有开发测试初始化，并验证有效应用和产品数据根。正常调用可沿用本轮隔离根，显式覆盖只能指向隔离范围内的目录；错误覆盖失败后仍恢复环境与输出。
4. 登记持久化及管理归属分别保护自身写入，不能只保护登记文件而遗漏 workspace-local 管理身份。正常无测试上下文的用户实例不受测试约束；预览共享登记只读复用保持原样，测试预览共享来源仍在隔离环境内。
5. 缺陷回归使用模拟的用户目录与真实文件系统，不尝试写真实开发版。覆盖非临时命名、直接辅助工具、子进程、环境缺失与漂移、缓存实例、符号链接以及既有预览共享和快照用例。

## Risks / Trade-offs

新增保护只拒绝测试环境越界写入，保护真实登记及管理归属不变量。少数此前依赖越界路径的测试需要改为正确隔离夹具，而不是删除断言。读取不附加写入门禁，失败不影响无关只读功能。普通用户没有测试上下文时不增加门禁。

状态根校验是防止开发误用的确定性边界，不是权限沙箱；同权限脚本故意伪造环境或直接写文件不在证明范围。

## Migration Plan

无需用户配置或数据迁移。现有开发版污染登记通过既有移除接口定点处理，保留工作空间目录。候选代码保持任务工作树，未集成前不更新真实开发版。
