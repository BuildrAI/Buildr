## Context

动机见 proposal.md。知识正文已有受控图片读取，项目文档未返回正文摘要，任务材料已有来源和正文摘要但缺少区分实际检出位置的观察身份。任务项目读取已在独立阅读器中核对当前作用域、完整组证据及候选优先级，图片必须复用该选择，不能自行拼接保留根。

## Goals / Non-Goals

目标是保持原阅读界面，同时使图片与正在显示的文件正文、实际来源及材料关联一致。范围限于可读文件正文，不为数据库任务说明猜测图片所在目录，不扩展文章资源、任意附件、Mermaid 或 DSH。

## Decisions

1. **以观察上下文接续，只读不保存。** 可读正文增加可选 `imageContext: {documentDigest, sourceIdentity}`。摘要来自真实字节，来源身份根据作用域、实际选定文件根、目录身份及相对文档路径确定性产生；它不是许可令牌（Token），不保存映射或授权。取图每次重新执行当前正文和来源选择，比较已观察两值并核对图片引用。单独按路径取任意图片无法证明当前阅读关系，因此不采用。
2. **应用拥有来源选择。** 项目取图复用项目登记和来源定位；任务本机材料限制在该任务目录，任务项目材料复用现行任务项目/服务候选选择。用同一内部来源对象同时读取正文、产生上下文和取图，物理根不进入公开正文或清单。已选候选失效、材料同名换源和相同正文换检出位置均拒绝旧观察。
3. **共享受控图片文件技术能力。** 共享实现仅负责当前 Markdown 图片引用提取、本地相对路径规范化、普通文件及祖先无链接检查、类型签名和8 MiB有界读取；领域应用提供身份与来源。只接受正文中真实图片引用，忽略围栏与行内代码中的假引用；允许不越过实际读取根的父相对路径及编码文件名。SVG、远程、绝对、反斜杠、空字节和越界均拒绝。
4. **读取前后核对。** 读取正文与图片使用有界普通文件描述符（File Descriptor），读取前后核对文件身份/大小/修改观察和实际路径；返回图片前再核对正文、来源及当前材料关联。现有路径重检缩小替换窗口，不宣称抵御任意恶意进程同时重命名的原子保护。
5. **三个同源入口。** 项目、任务材料、任务项目文档分别有明确主体的图片 GET，参数仅包含当前路径/实际 href 和已观察两值；拒绝未知或重复参数，复用 `binaryResponse` 的 `no-store`、`nosniff` 与类型。前端显式传入当前 workspaceId，来源/正文变化重建图片URL及阅读DOM；失败只提示该图片不可读取和刷新方法，正文与导航保留。
6. **兼容现有调用。** 公开材料响应闭合模式（Schema）增加可选字段并由现有生成器输出数据传输对象（DTO）；关联清单、写入版本、任务状态和数据库不变。无上下文、缺失或不安全图片保持安全文本/局部提示。现有文章只读资源边界保持原契约。

## Risks / Trade-offs

- 外部修改在读后发生 → 图片仍绑定已观察正文和来源，后续请求重读；不缓存为当前事实。
- 图片被删除或材料换源 → 拒绝当前图片，保持正文可读并提示刷新，不能回读其他候选。
- 编码路径与父相对路径 → 服务端按实际根完整校验，客户端仅提前过滤确定非法输入，不代替授权。
- 重复读取成本 → 每次只读取该有界文档与图片，不扫描项目或全任务；不在列表加载所有图片。
- 老客户端/旧正文 → 可选上下文向后兼容，缺失不生成任意资源URL；无迁移。

## Migration Plan

部署只包含接口和阅读增强，不迁移持久数据。回退程序后原文和关联仍完整，图片回到已有安全文本表现。验收包括正常图片、链接后的项目文档、编码/父相对路径、伪造引用、链接与越界、正文/关联/根身份变化、候选失效及真实生产阅读入口。代码地图（Code Map）与资料阅读说明按最终实现校准。
