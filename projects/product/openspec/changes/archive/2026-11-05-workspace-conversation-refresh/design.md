## Context
任务运行选择由工作树证据决定；清理后集合为空。应用壳的 workspace key 同时重建缓存提供者、偏好提供者和对话 portal。

## Goals / Non-Goals
保留启动权限，补齐只读解释；不自动启动主库，不推断 squash 等价，不检查远端。

## Decisions
复用任务提交读取的来源、尾注归属和有界扫描，逐库用 Git 祖先关系核对当前主库 HEAD；仅在任务目录为空时执行，不引入状态。保留偏好提供者随空间重置，但只包围业务页；缓存与应用框架不再使用空间 key，对话保持框架内稳定挂载。列表左上角显式调用全部空间入口。

## Risks / Trade-offs
历史扫描可能截断或无法证明变基后的等价提交：明确未知，不用任务状态推断。共享缓存已按 workspace 键隔离，移除外层 key 不得引入跨空间读写。无数据迁移；回滚源码即可。
