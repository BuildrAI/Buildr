## ADDED Requirements

### Requirement: 未受理提交必须纳入活动对话并显示准确发送状态

系统 MUST 从已有待发送记录派生等待发送、发送失败两种状态并纳入活动对话总数，不新增持久状态。等待后台、资源或投递中未确认受理 MUST 显示等待发送及具体原因；明确失败 MUST 显示发送失败并保留输入及错误原因。受理或取消确认后 MUST 移除该派生状态，回到真实执行及未查看状态。待发送本身 MUST NOT 增加执行中模型或待决策统计，同一对话已有真实执行及待决策 MUST 保留。取消 MUST 沿用实际可取消性和版本，未知结果不得冒充已取消。

#### Scenario: 等待或投递中
- **WHEN** 已提交指令等待或正在投递但未确认受理
- **THEN** 对话 MUST 留在活动列表显示等待发送及具体原因，MUST NOT 冒充执行中

#### Scenario: 明确失败
- **WHEN** 提交明确失败
- **THEN** 对话 MUST 留在活动列表显示发送失败，输入及原因 MUST 保留

#### Scenario: 取消或受理
- **WHEN** 对应提交确认取消或受理
- **THEN** 下一次读取 MUST 去除该派生状态，不重发指令，原执行或待决策 MUST 保留

## MODIFIED Requirements

### Requirement: 对话入口必须自然展示活动提醒

右侧 MUST 保留“当前对话”气泡图标的悬停临时预览和点击固定展开/收起行为，并新增列表样式“所有对话”入口。活动对话 MUST 收纳于新增入口的悬停浮窗（Popover），不得常驻铺开额外条目；活动数量 MUST 只在新增入口显示。两个临时浮层 MUST 互斥，但 MUST NOT 因查看活动而关闭已固定对话。双入口点击 MUST 打开自己的视图、切换另一视图或在当前视图再次点击时收起；高亮 MUST 只指示实际显示的对应视图。历史固定显示时 MUST NOT 弹出活动浮窗。悬停或键盘聚焦 MUST 默认展示全部已登记空间的活动对话，并按准确工作空间身份分组，不提供空间筛选；组标题 MUST 显示空间名称与条数，组顺序 MUST 按最近真实消息活动时间、组内 MUST 保持同一规则倒序，包括等待发送、发送失败、执行中、等待回应、状态待确认及有未查看新消息；每条 MUST 可直接打开准确对话，并保留所属工作空间（Workspace）。每条 MUST 只显示一个静态主状态，不使用转圈或闪烁，也不重复堆叠执行与未查看标记。打开 MUST NOT 自动发起工作、代答或改变执行事实。浮层为悬停临时预览时 MUST 允许短暂移出后继续停留，不得在指针短暂离开时立即消失。

#### Scenario: 多空间后台执行
- **WHEN** 用户浏览一个空间而另一已登记空间的对话开始执行
- **THEN** 统一入口 MUST 在正常可见页面刷新周期内更新活动数量，悬停浮窗 MUST 展示该对话，用户无需先切换空间
- **AND** 点击 MUST 打开提醒所指空间和对话，保留当前工作页面

#### Scenario: 已结束且已查看不属于活动
- **WHEN** 用户悬停“所有对话”入口且对话没有尚未受理的提交
- **THEN** 浮窗 MUST NOT 混入已结束且已查看的对话
- **AND** 已结束但仍未查看的对话 MUST 留在活动区，查看后移出；执行中或等待回应 MUST NOT 因查看而移出

#### Scenario: 浮窗移动与无鼠标入口
- **WHEN** 用户将鼠标从入口移入浮窗，或使用键盘及窄屏触控访问入口
- **THEN** 浮窗 MUST 可继续操作，键盘可聚焦条目并按 Escape 关闭，窄屏点按 MUST 与桌面点击遵守相同的视图开合规则
- **AND** 多条活动 MUST 在浮窗内有界滚动，桌面点击图标或浮窗顶部独立“查看全部对话”文字按钮 MUST 可进入全部空间历史；MUST NOT 在滚动列表底部重复该入口。空间名称 MUST 仅在分组标题显示，浮窗行辅助信息 MUST 紧凑展示智能体与模型，MUST NOT 重复展示更新时间
- **AND** 浮窗行 MUST 展示对话 ID 并提供与对话标题栏一致的复制入口，复制 MUST NOT 改变当前对话或消息查看状态

#### Scenario: 当前对话原交互保留
- **WHEN** 用户悬停当前对话气泡图标，再点击固定展开并再次点击收起
- **THEN** 临时预览和固定对话 MUST 使用同一内容、草稿和执行事实，临时预览 MUST NOT 自动确认查看
- **AND** 移入新增所有对话图标 MUST 关闭临时预览并展示活动；从活动条目打开 MUST 固定准确对话

#### Scenario: 双入口切换与重复点击
- **WHEN** 面板收起、显示当前对话或显示历史时，用户点击气泡或列表图标
- **THEN** 收起时 MUST 打开目标视图，显示另一视图时 MUST 切换到目标视图，已经显示目标视图时 MUST 收起
- **AND** 显示历史时悬停列表 MUST NOT 弹出活动浮窗；关闭历史后悬停气泡 MUST 预览当前对话而不是历史
