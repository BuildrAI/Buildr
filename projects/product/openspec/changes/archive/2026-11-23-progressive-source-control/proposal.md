## Why

集鲜等多仓库工作空间打开源代码管理时，登记读取被逐库克隆查询拖慢，未核对的仓库还不能主动打开。

## What Changes

- 先显示完整登记清单，不等待 Git 或克隆状态；优先核对已选或新点选的仓库，其他状态逐库补齐。
- 复用经内容版本验证的登记解析，不缓存真实 Git 和克隆状态以替代核对。
- 无破坏性变更，不改变既有 API 或 CLI 参数，也不抓取远程。

## Capabilities

### Modified Capabilities

- `code-source-control`：可点选的轻量清单、逐库进度、当前仓库优先和登记读取去重。

## Impact

Buildr 本机代码状态读取、工作空间登记查询、网页仓库树和状态调度。无数据迁移。
