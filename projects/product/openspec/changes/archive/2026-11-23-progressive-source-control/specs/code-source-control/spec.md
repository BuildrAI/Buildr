## ADDED Requirements

### Requirement: 可操作的登记清单与当前仓库优先

轻量登记清单 MUST 无需逐库检查克隆或 Git 状态即可显示全部已登记仓库。普通查看 MUST 允许在状态未确认时点选仓库，并优先调度尚未开始的目标；有效的已选来源优先于后台待核对来源。只有实际确认工作树身份后才读取该来源的正文或启用依赖该身份的写入。核对完成的仓库 MUST 逐库更新，不以未读冒充干净，不因后台结果抢占选中项。登记解析 MAY 在当前内容版本一致时复用；克隆状态和 Git 身份 MUST 仍按目标核对，登记漂移 MUST 不提交为当前事实。

#### Scenario: 先看到并点选后面的仓库
- **WHEN** 冷打开多仓库工作空间，已返回登记清单但两个后台仓库正在核对，用户点选尚未开始的仓库
- **THEN** 列表 MUST 已显示全部名称，被点选仓库 MUST 在下一个可用读取位置优先安排，无需等待全量完成
- **AND** 项目状态 MUST 按独立结果更新，所选工作树确认前 MUST 不把其他正文或空状态冒充为该来源结果

#### Scenario: 复用登记不掩盖现场变化
- **WHEN** 同一内容版本下连续逐库读取，随后登记变更或某个仓库克隆失败
- **THEN** 同版本 MAY 复用登记解析；登记变化 MUST 重新核对，克隆失败 MUST 仍只显示在受影响仓库。
