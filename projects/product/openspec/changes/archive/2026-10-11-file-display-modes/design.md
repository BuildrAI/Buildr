## Context

动机见 proposal.md。当前共用面板对所有文本提供阅读/编辑切换；历史与片段另走资源浏览器的只读源码分支。项目下级文档已经共用面板与同文件会话，不需改变来源或导航。

## Goals / Non-Goals

目标是统一文本呈现与只读行为，复用现有编辑器、高亮语言包、编辑历史与保存队列。不引入编辑器依赖，不改变后端保存接口（API），不把历史或片段纳入当前文件的保存会话。

## Decisions

- Markdown 才保留显示模式；普通文本始终显示编辑器，不自动聚焦。保留单独的编辑权限判断，不以显示编辑器推断可写。
- 完整当前文本沿用共享会话；只读配置随最新文件政策双向更新，保留正文、选择与撤销历史，并在接收编辑事务时再次拒绝只读正文变更。
- 历史与片段复用同一底层编辑视图，通过专用只读适配提供内容、语言、全局行号、命中与选择，保留原分页和来源提示。替代方案是把它们装入可保存会话，容易混淆历史/当前身份，因此不采用。
- 原有模拟入口继续引用共同源码；相关说明随本次规则校准，并保留历史确认材料。

## Risks / Trade-offs

- 只隐藏“编辑”按钮仍可能让编辑器接收修改 → 编辑器状态与会话事务同时只读，保存边界保持有效。
- 异步高亮加载、只读策略变化可能重置位置或历史 → 通过配置更新保留状态并补回归。
- 替换只读表面可能丢失片段行号、查找命中或选中范围 → 保留原有外层分页/选择语义，验证历史及片段定位。

## Migration Plan

无数据迁移或接口变更。已有 Markdown 会话模式继续有效；普通文本的旧阅读状态不再控制展示。当前源码不预写正式规范，归档时统一收敛。
