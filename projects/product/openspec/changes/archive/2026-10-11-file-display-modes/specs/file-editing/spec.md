## MODIFIED Requirements

### Requirement: 两个入口统一编辑真实文件

系统 MUST 在项目资料 README.md、AGENTS.md、由项目资料内链接逐层打开的项目当前 Markdown 文档，以及资源管理器（Explorer）的当前普通文本文件中提供相同的文件面板与保存行为。编辑 MUST 读取完整原文，按工作空间（Workspace）及真实文件身份共享当前内容和编辑历史；来源选择 MUST 明确区分项目登记来源、代码库及检出目录，不能按同名文件或分支名称替代。文件信息 MUST 紧凑显示相对路径、目录与版本，完整绝对路径可查看。

面板 MUST 按文件类型选择呈现：Markdown 默认渲染阅读并保留“阅读 / 编辑”切换；代码、配置和普通文本 MUST 直接显示编辑器，MUST NOT 显示阅读/编辑切换。普通文本打开时 MUST NOT 自动聚焦正文。当前文件能否修改 MUST 由其真实只读状态决定，不得由编辑器的显示方式推断。仅 Markdown 的编辑状态 MUST 提供可开关的预览（Preview），非 Markdown 文本 MUST NOT 显示预览入口。切换文件、退出编辑或变为只读时 MUST 关闭预览，且 MUST NOT 清空内容或编辑历史。

Markdown 的阅读/编辑切换 MUST 保持控件等宽、位置与文件路径布局稳定；预览（Preview）MUST 作为单独的编辑辅助操作显示，不挤动主切换。当前绑定的权限或只读政策变化 MUST 在正文版本不变时仍更新可编辑状态，并保留输入与编辑历史。

#### Scenario: 同一文件跨入口继续编辑
- **WHEN** 用户在项目资料修改文件后，从资源管理器（Explorer）打开同一实际文件
- **THEN** 两入口 MUST 呈现同一当前内容、保存状态和可继续的编辑历史
- **AND** 不同检出目录的同名文件 MUST 保持独立

#### Scenario: 阅读与编辑的模式保持清晰
- **WHEN** 用户打开 Markdown 或代码、配置、普通文本
- **THEN** Markdown 默认显示渲染正文且可切换编辑；其他文本直接显示编辑器且无阅读切换，不自动聚焦正文
- **AND** 仅 Markdown 编辑时显示预览（Preview）开关，返回阅读再进入编辑时预览默认关闭

#### Scenario: 进入项目资料内的下级文档
- **WHEN** 用户从项目资料的当前文档点击项目内 Markdown 链接，或继续进入下一层文档
- **THEN** 系统 MUST 以该文档的真实项目来源和相对路径打开同一阅读/编辑面板，并沿用自动保存（Auto-save）、快捷键及保存冲突处理
- **AND** 返回上一篇 MUST 恢复对应文件的内容与编辑历史；只读边界和项目来源内的路径限制继续有效

#### Scenario: 刷新后返回项目下级文档
- **WHEN** 用户从项目下级文档打开资源管理器（Explorer），刷新页面后返回项目
- **THEN** 系统 MUST 恢复该项目的资料入口、当前文档路径和返回上一篇的导航历史，再读取真实正文
- **AND** 导航恢复 MUST NOT 保存正文副本、跨项目恢复或绕过相对路径校验

### Requirement: 编辑范围维持明确边界

历史内容、二进制文件、超限或片段阅读 MUST 保持只读。只读代码与普通文本 MUST 复用编辑器显示，对受支持语言保留语法高亮，提供明确只读提示并禁止正文变更；历史或片段 MUST 保留实际来源、版本、全局行号和定位边界，MUST NOT 作为当前完整文件保存。只读 Markdown MUST 保留渲染阅读。图片和二进制 MUST 沿用原展示。Buildr 管理的生成副本 MUST 按来源维护，受管区块（Managed Block）MUST 保持原文不变，完整受管文件允许修改区块外内容；受管标记损坏时 MUST 明确拒绝受影响写入。新增编辑能力 MUST 不自动开放服务、知识、任务或技能其他入口，不自动执行 Git 提交、推送或发布。

#### Scenario: 编辑根规则的用户部分
- **WHEN** 文件含完整受管区块（Managed Block），用户只修改区块外内容
- **THEN** 系统 MUST 允许保存，并验证受管内容仍与已观察原文一致

#### Scenario: 尝试编辑只读内容
- **WHEN** 用户查看历史文件、大文件片段、生成副本或试图修改受管区块（Managed Block）
- **THEN** 系统 MUST 显示对应边界且服务端拒绝不允许的保存

#### Scenario: 只读代码仍便于阅读
- **WHEN** 用户打开只读当前代码、历史代码或大文件源码片段
- **THEN** 系统 MUST 显示带受支持语法高亮的只读编辑器及原因，保留来源、版本和全局行号
- **AND** 输入、粘贴、撤销及重做 MUST NOT 修改只读正文或触发保存；允许选择、复制与查看定位
