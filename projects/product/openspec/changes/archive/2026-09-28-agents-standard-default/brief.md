# 标准默认智能体接入

目标：用户无需等待 Buildr 为每个遵循共同文件约定的产品登记专用实现；传 `codex`、`dsh` 或省略品牌时可以准备标准文件，已有专用接入方式和用户文件仍受保护。

边界：标准入口只承诺文件布局与安全维护，不证明任意宿主已经加载。DSH 默认只发现技能根目录的直接子项，因此标准输出采用技能标识对应的一级目录。规则（Rule）作用域和技能（Skill）语义选择仍由智能体（Agent）承担。

验收：标准默认、已知专用例外、显式选择、非法参数、已有选择保持；通用技能（Skill）不漏装且明确限定不扩大；跨品牌共享文件幂等；旧有效回执/嵌套目录可迁移；用户修改、未知内容、多份不一致回执、符号链接与目标冲突不被覆盖；诊断不冒称安装/激活证明。

当前认知复核：随包适配参考、命令参考、首次使用与运行时维护技能指引，以及 `knowledge/docs/reference/agent-runtime-adapter-contribution.md` 已更新（updated）。9 份维护说明的 29 个本地链接与末尾换行已检查；公开 JSON 升版说明与实际 schemaVersion 一致。知识索引原路径与关联保持一致（aligned）；整体产品定位、代码地图职责与术语体系不受改变（not-applicable），未重建。源码、增量规范、说明分别保持事实边界。

- 完整低成本回归通过：类型、单元、组件、契约、架构、规范质量与严格规范校验。
- 最终聚焦投射/归属/能力测试 60/60 通过，覆盖多品牌旧回执、嵌套目录、用户改动、未知内容、符号链接、失败回滚、观察状态校验与真实并发写入。另以失败反例证明专用品牌显式采用标准目录的绑定冲突不可漏检，修复后通过。
