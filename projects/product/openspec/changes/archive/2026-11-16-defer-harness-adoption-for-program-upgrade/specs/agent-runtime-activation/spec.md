## ADDED Requirements

### Requirement: 受管程序更新期间延迟交接并保持接单

执行后台已经登记候选且受管程序升级仍持有管理权时，系统 MUST 保留候选并提供等待原因。已核验的当前后台仍在接单时，普通指令和可派发的待发送内容 MUST 继续交给它。程序更新释放后，系统 MUST 自动接续已登记候选的交接，遵守原有兼容性、执行保留和派发保护。显式激活 MUST 仅在目标确实就绪时报告成功，等待超时 MUST 保留已登记候选。后继实际启动失败仍沿用既有恢复机制。

#### Scenario: Codex 程序升级等待旧执行释放

- **WHEN** 程序更新仍在等待释放且 Harness 已登记目标运行单元
- **THEN** 健康旧后台继续接单，待程序更新结束后自动切换，无需再次请求激活
