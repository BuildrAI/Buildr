## Context

动机见 `proposal.md`。现场同一组合因旧轮未知而创建新参与者和原生上下文（Native Context），`preview.switching` 却按参与者编号计算，产生虚假交接；`ConversationRetainedWork` 按未知状态常驻展示已释放且无未结工具的旧轮。恢复编排只接受 stopped，无论准确控制资源是否释放，unknown 都退回人工。正式版装配还显式关闭自动接续。

## Goals / Non-Goals

**Goals:** 让系统中断后的原目标在原组合及原权限内自动获得实际执行；准确区分正在运行、结果未知、控制已释放和需要人决定；内部上下文重建不冒充用户交接。

**Non-Goals:** 不判断业务成果是否已经完成，不替用户做决定，不自动更换组合，不重放未知操作，不为正常结束的普通对话反复追加工作，不启动另一套目标或任务登记；当前正在执行的真实“收尾”保持原归属。

## Decisions

### 1. 目标接续与旧操作重试分开

沿用当前对话的用户输入、已有成果索引、`interruption` 和尝试记录。原执行仍运行则只恢复观察；终态明确且已完成则结束恢复；有系统中断来源且准确控制已经释放时，允许新恢复执行先核对当前文件、原工具与未知结果，再继续不依赖待决事实的工作。未知结果保持原样，不能转成完成，也不直接重发原操作。相比单纯放宽 stopped 判断，该分离保留局部副作用保护并解除全目标停摆。

| 责任 | 维护的事实与动作 |
|---|---|
| 现有对话应用 | 原目标、当前版本、一次性恢复身份、实际组合、发送准入和系统中断来源 |
| 现有执行器（Executor） | 准确原生观察与控制资源释放证明，不判断业务目标是否完成 |
| 智能体（Agent） | 读取成果与工具事实，判断哪些已生效、哪些尚待完成，沿原目标继续工作 |
| 页面 | 呈现实际执行与必要决定，内部恢复不增加交接动作或无待办价值的常驻提示 |

### 2. 持久有界恢复及取消

系统恢复沿用原运行派生的唯一请求身份，并关联原运行；复用现有持久自动尝试预算，最多三次连续自动接续，与临时故障重试共用计数，避免一次恢复失败后永久停止，也避免无限链。已登记恢复意图但发送前中断时沿同一身份接续，不重复消耗预算或新增请求。用户停止、必要决定、账号身份或可用性变化、并发新输入及预算耗尽阻止相关自动动作。恢复意图和发送均校验当前版本；新用户目标重新计数。

### 3. 同组合与原生上下文身份解耦

参与者和上下文编号仅决定恢复历史及资源归属，不能单独代表用户换智能体或模型。对外切换按真实连接、模型账号身份、模型、档位、思考强度及权限比较。即使必须重建上下文，仍组织必要原始来源给同一组合，但不追加“交给”事件或要求查看交接包。真正切换组合保留原有交接来源与可查入口。

### 4. 历史保留不等于当前待处理

已释放、无活动及未知工具、无待决定的旧轮继续保存在原历史及恢复引用中，不占输入区常驻折叠栏。仍有活动、未知工具或待决定时继续显示准确风险与控制；原结果不被删除、改写或伪装成功。恢复状态只在恢复确实执行期间显示，不能根据希望显示“继续进行”。

### 5. 装配与知识一致

Buildr 开发版与正式版均启用同一恢复策略，私有服务仍允许宿主明确关闭自动接续。同步已有 `knowledge/docs/architecture/agent-integration.md` 的恢复与交接段落及交付给智能体的对应操作指引，不新增平行文档或规则门禁。

## Risks / Trade-offs

- [把旧副作用执行两遍] → 控制证明、持久恢复身份和版本检查；恢复指令要求先观察成果，保留未知工具引用和原授权；不能重放原提示或工具。
- [后台任务仍在写入] → 没有准确控制释放证明不自动恢复；仍活动只恢复观察；独立未知操作由智能体先核对，不按最终回复或空工具列表推定成功。
- [重复模型开销] → 持久三次预算与既有退避，正常答复、用户停止及新目标不继续旧恢复。
- [页面隐藏真正风险] → 仅无活动、无未知工具、无问题且已释放的旧轮不常驻，真实风险继续显现且历史可追溯。

## Migration Plan

在独立工作树（Worktree）修改现有结构和可选尝试关联，兼容旧记录的缺省字段；不改写既有历史。先以真实进程、存储和浏览器回归证明自动接续及反例；交付后依既有唯一激活入口采用新服务。回退源码不删除对话、原生记录或已形成的业务成果。

### 升级中的恢复策略更新

宿主（Host）重新接入时通过已有认证的 `/host/attach` 携带明确恢复设置；只有与启动时 `legacySourceId` 一致的来源可更新该后台设置。应用读取同一设置，后继后台沿用当前值，避免旧启动参数让正式版升级后仍关闭恢复；未明确提供设置的观察客户端不改变它。独立进程回归覆盖后台不重启、原成果保留和无需人工续发的接续。
