## 共同源码与隔离边界

原轨迹表、详情函数、参数／结果 JsonTree 和 Markdown 显示使用现装 DSH 0.2.0-rc.2 源码复制件，不手画相似详情。新增列直接修改独占复制件的 `colgroup`、`thead`、`td` 和 `colSpan`，没有在真实运行时（Runtime）的页面元素（DOM）上插列。原详情标签保留，内容对象是新增模拟扩展。

正式产品的轨迹扩展公开入口尚未存在；临时工厂导出、`prototypeSource` 与 `prototypeRenderObjects` 都只是原型适配，不是现装接口，生产不得导入其他功能（Feature）内部值或依赖页面元素（DOM）劫持。剪贴板改为内存模拟，不访问真实后端、源文件、身份凭证或运行时配置。

为单文件限额，只保留原高亮器的 JSON／TS／shell 启动语法与原纯文本回退，未演示的懒加载语言目录和 KaTeX 字体样式不内联。原详情及 JsonTree 功能未重画；数学外观、其他语言外观、附件、真实剪贴板、超大历史虚拟化不在验证范围。
