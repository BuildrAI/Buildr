## Why

查看旧记录时反查当前资产不能证明当次来源，且增加读取成本和失败点。用户已经确认把来源识别前置到 DSH 动作发生时保存，之后读取原记录直接取得事实，为 Buildr 参与观察建立可保存、重载和追溯的数据源。

## What Changes

- **BREAKING**：移除页面及原查询后的自动来源反查、旧记录回退和当前关联作为主标记的条件。没有正式来源字段的记录显示“未采集”，不解释为非 Buildr 或按当前文件追认；当前开发功能没有旧记录兼容查看需求，原历史不改写。
- 定义 `dsh.event-sources/v1`。当次生产者（Producer）在原事件 `data.eventSources` 和规则注入 `message.source.eventSources` 保存来源状态及匹配对象；不增加事件顶层字段、原记录类型或模型正文。
- `EventSources.execution?={outcome,exitCode?}` 仅由实际命令解释器（Bash）前台正规化结果同期写入，后台／转后台保持未知，原生失败优先；查看时不解析输出文本推成功，也不以来源确认推定执行成功。
- Buildr 公开 `source inspect` 输入支持 `mode: metadata|content`，默认 `content` 兼容。采集提供者使用 `metadata` 校验实际原始摘要及资产提供证据，不发送普通用户正文，也不返回当前／观察正文；查看主路径不调用该接口。这是当次识别，不是旧记录反查。
- 改造选定 Host 生产者、成功／失败及子调用正规化、原持久化（Persistence）和重载、查询透传与轨迹组装。来源来自实际读取／注入／调用现场，保全实际胜出位置、提供者、对象身份、观察版本、证据及原事件引用，来源失败只影响来源信息。
- 正文以 `contentRefs` 引用原持久事件文本块。保全 `block`、`start`、`end`、`unit: utf16` 及完整性声明 `completeness`，不把片段、行窗口或当前文件当成完整历史正文，不新增正文仓。
- 原来源列、原详情附加区和并列 Buildr 标签共享同一持久事实。标签仅过滤已加载窗口中有确认 Buildr 提供关系的原记录；默认标记只读已发布元数据，不产生来源反查请求，按需正文只读原事件。
- 保持原七类、身份、原序、参数、结果、定义、计时、搜索、折叠、分页及连续阅读。提供者严格为 `providedBy=buildr`，仅管理关系与普通用户资料直接读取排除；资料能力只保留调用及必要目标引用。确认的失败调用仍保留来源和原失败结果，不以 `--json` 或输出文案代替实际入口证据。
- 扩展明确的软件开发工具包（SDK）补丁／构建／组合交付边界，独立条目停用旧生产者后启用新实体产物；旧 SDK、旧安装及相同版本号不证明新 Host 契约生效，不能手改应用归档或配置档。

原配置与设置贡献须恢复：独立根条目标识不自动继承旧设置命名空间，必要客户端（Client）兼容修正限定原 AgentLoop 设置卡，通过公开配置描述定位实际服务；不新增主机端（Host）别名或放宽替换包。

## 本轮阅读与性能调整

首步收口另外补当前真实入口盘点及安装身份、资料单对象必要引用、直接技能文件／程序工具调用（PTC）／资料能力真实样本和当前组合撤回恢复。开发来源查询绑定不代替正常公开安装状态批准的命令入口；已投射并由Buildr提供的技能附属本地命令属于覆盖核对范围。只确认实际入口和版本，未知的裸名称或其它执行世界不按主机端（Host）PATH猜来源。资料集合检查保留任务引用，明确资料写入同时保留确切`--path`，不复制正文或把输入文件冒作业务对象。具体落实见第11节。

四项已确认调整细化同一来源阅读能力：固定 52px 两行列表按可视区域虚拟化（Virtualization），复用记录版本索引；无正文能力零原事件查询，正文按同一观察租约（Observation Lease）有界批读；列表以动作／对象／结果为主，详情去重复并保留实际退出码；通过公共 Markdown 预览／原文切换阅读当次片段，保留片段说明及单滚动。正文缓存最多 32 项、8MiB，不扩大为当前文件或用户资料正文缓存。

使用现有公有 `observeSession`，每批同会话最多 32 个真实事件引用，只复制选中事件并最终释放租约，无逐引用 `readEvent` 兼容回退。共享查询接口及八模块交付图不新增替换；实际 API 可用性和性能由当前 Host 测量证明。旧页面约 597ms／5000 行与原 17MB 历史两引用约 315ms 首次、143ms 重复的基线保留；受控渲染与真实查询分别比较，不以零来源 RPC、测试计数或编译通过替代性能验收。具体义务见第 10 节清单。
