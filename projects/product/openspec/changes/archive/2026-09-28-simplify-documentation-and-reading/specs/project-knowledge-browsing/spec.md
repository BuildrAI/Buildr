## ADDED Requirements

### Requirement: 阅读呈现必须保留原文的内容边界
共享 Markdown 阅读器 MUST 保留围栏代码块、连续命令及文本目录树的换行与缩进，复制代码 MUST 返回该代码块正文，不混入行号、按钮或相邻段落。表格 MUST 在窄阅读区局部滚动，不撑宽页面。章节 MUST 具有稳定且不重复的标识，合法的同页和跨文件章节引用 MUST 定位对应正文。源码与阅读模式 MUST 对应同一文件。

#### Scenario: 阅读并复制多行命令
- **WHEN** 用户从知识主屏或副屏阅读含连续命令和缩进的代码块并复制
- **THEN** 显示和复制内容保留原有换行、空行及缩进，窄屏仍可阅读全部内容

#### Scenario: 阅读表格与章节引用
- **WHEN** 用户在窄屏阅读宽表或跟随章节链接
- **THEN** 表格只在自身容器横向滚动，章节链接定位真实标题，返回保留原正文

#### Scenario: 阅读 Mermaid 源码
- **WHEN** 正文含 Mermaid 围栏而当前阅读器没有渲染能力
- **THEN** 页面明确标注当前显示源码而非图示，保留可读源码、复制能力及原文件位置
- **AND** 不把源码回退报告为图示渲染成功，不引入远程脚本或手写不完整解析器

### Requirement: 文内本地引用必须能按实际链接安全阅读
读取当前已登记成果、来源或已发现普通文档时，系统 MUST 支持正文实际写出的本地相对文本和图片引用，无需为每个合法引用补写成果登记。引用读取 MUST 绑定已可读入口身份，逐步重新读取并验证每个链接确实存在于上一步 Markdown 正文，限制链长与内容大小；每步 MUST 复用所属范围的真实路径、敏感文件、类型和符号链接检查。未登记引用 MUST 保留实际路径、只读阅读及返回能力，不加入普通文档计数或自动写索引。已登记引用继续保留原有身份与阅读方式。

#### Scenario: 合法文件尚未登记阅读关联
- **WHEN** 当前正文引用范围内存在且允许读取的说明或规则文件，但该文件没有成果条目
- **THEN** 用户可在现有阅读区查看实际内容并返回，不被要求先维护索引
- **AND** 内容变化后继续阅读重新核对当前链接与文件，不返回失效链的缓存正文

#### Scenario: 客户端伪造或越界引用
- **WHEN** 链接并不存在于入口正文、超过有界链长、指向敏感位置、符号链接或所属根以外
- **THEN** 接口拒绝该引用，其他正文继续可读，不提供任意本机文件读取

#### Scenario: 阅读正文中的图片
- **WHEN** 当前正文引用本地 PNG、JPEG、GIF 或 WebP 图片
- **THEN** 系统按同一引用边界读取有大小上限且类型匹配的图片，以同源受控响应显示
- **AND** 不执行 HTML 或 SVG 图片脚本，不自动加载远程图片，失败只影响该图片

### Requirement: 阅读搜索和数量必须解释实际覆盖范围
主题阅读 MUST 说明其数量来自已登记说明、图示和代码地图；文档目录 MUST 说明其数量来自已发现普通 Markdown 文件，含补充资料且去重，不包含规范历史、规则、技能、生成副本和文内临时引用。搜索说明 MUST 与现有标题、摘要、路径及祖先主题或章节匹配字段一致，不宣称正文全文检索。副屏 MUST 默认收起重复目录及筛选，仍能展开访问相同完整导航，并保留既有放大阅读入口。

#### Scenario: 读者检索与比较两个数量
- **WHEN** 用户切换主题阅读和文档目录，或输入仅出现在正文的词
- **THEN** 页面能说明当前数量口径和搜索字段，不用无匹配结果暗示正文不存在

#### Scenario: 侧读继续理解来源
- **WHEN** 用户在副屏打开知识引用
- **THEN** 正文优先获得可用宽度，目录可按需展开且条目未被删除，原放大和返回仍可用
