## Context

原审查已读正文并识别引用及程序消费。此前默认入口已收敛为认识、开始、概念三条路径；本轮承接未完成合并、执行依据与阅读器问题。用户明确授权继续实施和删除 guide，同时要求首页无特殊需求不大改。

## Goals / Non-Goals

完成必要信息迁移后删除重复文件，修复已观察到的阅读故障，保留可信安装和恢复依据。不开新文档站、角色分类系统、全文搜索、独立图示引擎或产品设置；不批改历史记录。

## Decisions

1. 事实只维护一处。图示指向原技术正文，文档目录覆盖实际当前资料，主题阅读提供关系导航；知识根 README 留兼容导航。结构化资源清单和包文件列表随删除同步。
2. 删除 guide 命令及包内文件。安装/恢复留在现有 CLI 参考和产品技能，应用负载交付同一份 CLI 参考供离线读取；其他源码链接仍需仓库。资产输入说明进入现有帮助，示例由真实资产接口验证，避免另建字段手册。
3. 阅读器共享一处 Markdown 行为。代码块保留原始文本并逐块复制，宽表自身滚动，标题生成稳定片段。已登记成果维持现有跳转；实际引用但未登记的文本可在现有副屏或原阅读区只读查看、返回，不强迫增加索引。分块阅读共享整篇正文的标题编号，原始安全链接保留 `./` 和编码字符供实际引用核验。
4. 引用读取以当前可读文档为起点，每一步确认 href 确实出现在前一正文，校验范围、真实路径、敏感路径、大小及有限深度。图片仅支持受限栅格类型，不执行本地 HTML/SVG。沿用既有知识读取边界，不提供任意文件读取接口。
5. Mermaid 仅提供忠实源码、复制、明确提示和原文位置。本轮不引入新依赖或自行实现不完整解析器。
6. 校准旧规范与技能叠加片段时，保留上游技能来源，明确本地片段对同一动作的优先约束。已有实施授权继续有效；具体安全冲突只停止受影响动作。

## Risks / Trade-offs

旧命令使用者会得到未知命令，现有帮助和技能给出可用入口；不存在保留无效别名的过渡期。引用链扩大可读资料范围，必须以已可读起点、真实引用和路径校验约束，恶意路径及符号链接需要失败测试。删除前逐一检查入链，历史文本按历史证据保留。

## Migration Plan

先合并内容和更新引用，再删除文件并核对打包；同步现行规范，不改历史目录。源技能交付后由既有同步机制更新工作空间（Workspace）投射，本轮不手改投射副本。失败时保留当前修改与明确检查结果，不修改正常运行的应用实例。

## Validation

定向执行知识登记/文档链接、资产帮助及已安装产物、技能组合及包资源校验；阅读器执行渲染单元、安全读取集成和隔离生产构建浏览器检查。分别报告静态检查和实际视觉/复制结果；智能体审阅不宣称真人首次上手验收。
