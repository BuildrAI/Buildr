## Context

对话与任务之间已有正式关联，也存在能通过原对话中的明确任务 ID 和工作空间核实的历史任务。任务完成、预览用途结束和 Git 成果保全有各自的证据。

## Decisions

- 由 `task-finish` 在同一次收尾中检查相关前序任务。优先读取准确绑定的对话关联；同一对话的既有记录能核实工作空间和任务 ID 时也可纳入。逐项重读正式任务，仅对已完成任务检查遗留资源。
- 从资源归属和当前用途决定清理范围。仍明确保留供试用、被其他任务使用、含未保存内容或交付尚未合入的资源继续保留。预览离线仅证明停止，原用途仍须核对。
- 复用预览的定向清理和 Git 工作树清理。预览依赖该工作树时先处置预览，保留的预览继续保全所依赖的工作树。远端引用仍按原授权与实时前置条件处理。
- 结果逐任务、逐资源回读。历史关联不可读或单项处置失败时继续当前任务和其他安全动作，通过收尾结果交代实际缺口。

## Risks / Trade-offs

在当前对话之外按名称搜索容易把同名任务或他人现场带入删除范围。通过准确关联、正式记录和资源归属限制候选；当前用途无法确认时保留。已有记录和提供者足以承担核验，无需新增状态或迁移。
