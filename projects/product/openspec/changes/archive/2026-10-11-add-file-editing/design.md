## Context

见 proposal.md。项目资料按项目登记来源读取，资源管理器（Explorer）按代码库和所选检出身份读取；两者不能按同名路径猜测映射。现有 Markdown 展示可能加工正文，编辑必须取得完整原文。确认版位于 `prototypes/file-editing.html`，独立阅读器保留于本机临时目录；任务内复用正式原型阅读器。

## Goals / Non-Goals

提供两个入口共享的真实文本编辑和有条件保存。首版不扩展其他资料入口，不提供跨次完整本地历史（Local History）、二进制编辑、自动提交或远端操作。

## Decisions

### 文件定位与保存

在既有代码文件能力中新增 GET `/code/editor-file` 和 POST `/code/save-file`。选择器（Selector）区分项目来源与代码检出目录；只接受登记对象和相对路径，不接受任意绝对路径。项目选择器支持项目真实来源内的当前 Markdown 文档，包含从 README.md、AGENTS.md 内链接逐层打开的文档，不按文档层级切换到另一套阅读或保存能力。响应提供实际绝对路径、源范围、稳定文件身份、来源身份、内容版本、可编辑性及受保护范围；同一实际文件从不同入口打开使用同一文件身份，不将来源范围差异混入编辑状态的键。

保存传入选择器（Selector）、已观察文件身份、来源身份及版本。服务器重新定位、验证普通文件、UTF-8、大小、路径与来源，校验受管内容，返回最新完整正文或明确冲突。写入通过独占临时文件、同步及原子替换缩小不完整写入和覆盖窗口。应用内保存串行；任意外部编辑器没有共同锁，最终检查与替换之间仍存在极短竞争窗口，不声明跨进程原子比较交换（CAS）。

### 共享编辑器与会话

使用 CodeMirror 6 管理编辑内容、输入法、选择、撤销（Undo）和重做（Redo）；相比自行维护文本历史，它提供成熟编辑语义，较完整 VSCode 宿主接入范围更小。编辑状态由工作空间（Workspace）页面上方的共享会话（Session）保存，按工作空间及真实文件身份去重。页面只传文件选择、Markdown 链接和导航上下文，不自行实现保存或冲突逻辑。

默认阅读；编辑后约 700ms 防抖保存，中文输入组合期间不发送中间保存，失焦或切换时刷新必要的待保存内容。每个文件串行保存，保存期间的新输入仍为待保存，旧响应不得把新内容标为已保存。保存、预览和入口切换不重建历史。

### 外部变化与失败

焦点恢复或活跃文件的有界刷新发现外部变化。无本地修改时采纳新内容；有本地修改时保留输入并暂停当前文件保存。409 响应返回最新完整文件供对照，合并结果按新观察版本再次保存；再次变化继续冲突。明确采用磁盘内容前显示替换后果。保存失败提供重试，切换工作空间（Workspace）时按原范围保留未完成草稿和人工合并结果，返回后继续处理；关闭浏览器页面时仅对仍未保存的内容提示，其他文件继续工作。

### 展示与兼容

复用确认的紧凑路径、目录/版本、保存状态、阅读/编辑和冲突面板；没有单独撤销、重做按钮。主状态只保留等宽、固定位置的“阅读 / 编辑”：Markdown 阅读显示渲染正文，其他文本正常显示内容；移除“原文 / 阅读模式”。仅 Markdown 编辑时在第二行固定位置提供预览（Preview），不挤动第一行路径与主切换，退出编辑、切换文件或变为只读后默认关闭。项目资料与资源管理器（Explorer）的文档相对链接共享根内定位约束；返回项目时仅携带当前文档与路径历史，重新读取真实正文，不把页面刷新后的返回降级为根文档。相同正文版本的权限或只读政策变化更新可编辑状态，保留输入和编辑历史。非文本、历史及片段阅读继续复用原有读取显示。前端与服务器共同保护受管区块（Managed Block），服务器拥有最终写入校验。新编辑能力不改变旧读取接口的无写入承诺。

## Risks / Trade-offs

- 文件来源漂移 → 保存重新定位并核对来源与文件身份，保留输入并局部失败。
- 外部编辑器并发 → 最后时刻重读核对并原子替换，明确文件系统保证的实际边界。
- 换行与文件头丢失 → 严格 UTF-8 读取，保留 BOM、换行方式和文件权限，不保存渲染后正文。
- 编辑状态占用内存 → 只为实际打开的文件维护状态，切换工作空间（Workspace）仅缓存未完成的草稿；首版只在页面会话（Session）内保留历史。
- 新依赖与正文体积 → 同源打包、保持 5 MiB 文件上限，只有保存路由扩大请求体上限。

## Migration Plan

保留原读取能力并按入口逐步接入共享面板。没有数据迁移。恢复旧入口可撤销本次代码，但已由用户保存的文件内容继续保留。

## 知识影响

现有 `knowledge/code-map/system-services-assets.md` 及 `knowledge/index.yml` 将代码模块（Code Module）描述为读取职责，需要后续补充本轮有版本条件的保存能力，以及共用文件面板和工作空间（Workspace）编辑状态的关系。本轮完成影响复核并保留这一组校准建议；未修改知识文件，避免把源码实施范围扩展为未获授权的知识维护。
