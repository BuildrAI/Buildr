## Context

参见 proposal.md。已确认原型位于本机 skills-preview/index.html（已在实现前读取），保留现有导航、紧凑列表和 720px 可展开抽屉。清单和本地技能源继续作为事实，不迁移数据库。

## Goals / Non-Goals

**Goals:** 有界读取完整说明与附属文本，保持资料阅读上下文、局部失败和当前工作空间隔离；以可复制指令完成维护交接。

**Non-Goals:** 自动安装与更新、直接启停写入、远端抓取、脚本执行、二进制预览、版本统计与市场。

## Decisions

- 新增 agent-assets skills 列表/详情/文件只读契约，复用当前清单解析，filesystem repository 负责目录安全。列表只读取主说明的有界摘要，不递归扫描全部技能资料；详情才枚举，文件按需读取。
- 技能源仅接受 skills/ 下登记的普通目录；拒绝符号链接，文件最多 512 KiB，枚举最多 500 项并报告截断。未知二进制列出但不执行或预览。
- 详情使用现有 MarkdownHost 的安全渲染，相对链接解析后仍由后端验证；来源信息和是否必需不凭路径名称猜测。
- 维护使用领域内的实时指令预览和固定底部一键复制动作，取消生成/返回修改/取消步骤。详情保持挂载，嵌套二级抽屉覆盖且不推动一级；关闭动画结束后恢复触发按钮焦点。草稿按技能与操作保存在本页，刷新或离开清除。与现有交接方式一致，复制失败真实提示手动复制，不伪造发送成功；不新增虚构后端执行动作。
- 列表与详情请求支持取消，状态按工作空间和技能身份重置；抽屉关闭不清空搜索。

## Risks / Trade-offs

- [外部内容和路径风险] → 只读、有界、拒绝符号链接和越界；Markdown 不注入原始 HTML。
- [清单启用与运行时加载混淆] → 显示清单事实，同步未检查则明确未知。
- [第一版维护不直接执行] → 按真实交接标注按钮及反馈，保留刷新入口，不模拟成功。

## Migration Plan

增加兼容只读接口与页面，无数据迁移；回退前端和新增接口即可，不改变技能源。
