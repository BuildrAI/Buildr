## ADDED Requirements

### Requirement: 浏览器标签页共享后台状态读取

自动观察 SHALL 通过显式共享读取选项复用同一工作空间（Workspace）、任务范围与代码库（Repository）的在途读取及短期有效观察结果，保留原观察时间；不同范围 MUST 隔离。共享结果 MUST 有容量和有效期上限，并在已知文件变化、来源登记变化或相关 Git 写入后立即失效。读取期间的新变化 MUST 使随后请求再次核对，旧读取不得恢复已失效结果。单个客户端断开 MUST NOT 取消其他客户端正在等待的共享工作；工作空间观察释放或应用关闭 MUST 取消所属工作。默认即时读取与手动刷新 MUST 不复用已经完成的共享结果。

#### Scenario: 多个标签页打开相同来源
- **WHEN** 多个标签页并发或在共享有效期内读取相同来源的自动观察
- **THEN** 后端共享一次实际状态检查，返回同一观察时间；关闭其中一个标签页不影响其余读取。

#### Scenario: 变化与显式刷新
- **WHEN** 观察发现来源变化、登记变更、Git 写入或用户显式刷新
- **THEN** 相关后续读取重新核对，不将旧结果报告为新观察；其他来源不被全量失效。
