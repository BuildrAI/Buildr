## ADDED Requirements

### Requirement: 供应商接入与模型目录独立管理

系统 MUST 默认展示自定义供应商表单，ChatGPT API 与 DeepSeek API 预设只收集 API Key。系统 MUST 阻止重复新增相同的内置接入或相同端点与协议的自定义接入，保留已有账号和历史绑定。自定义模型发现 MUST 保留候选选择，模型页 MUST 支持手动添加、移除和启停。

#### Scenario: 读取候选后维护目录
- **WHEN** 用户在自定义供应商的模型页读取模型列表
- **THEN** 只有用户选择加入的候选才进入目录，已有模型和偏好保留
- **AND** 用户可以移除目录中不再需要的模型

#### Scenario: 升级后刷新旧账号
- **WHEN** 旧自定义账号使用相同端点、协议与凭据重新读取
- **THEN** 账号身份和历史会话模型绑定保持有效
