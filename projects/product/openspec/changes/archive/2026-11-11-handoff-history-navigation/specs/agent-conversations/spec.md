## ADDED Requirements

### Requirement: 交接必须提供无需整读内部索引的轻量导航
系统 MUST 为接续 Agent 提供直接可用的按来源分页历史读取方式，MUST NOT 要求先整文件读取内部来源索引。超过内联容量时 MUST 提供有界轮次目录与完整来源读取方式；目录省略旧轮次时 MUST 明确其覆盖不完整并保留访问全部来源的入口。轮次导航 MUST 保留准确轮次身份和范围，不把内部索引称为本轮正文，不以摘要替代授权和原始消息。

#### Scenario: 索引超过文件读取上限
- **WHEN** 交接索引大于 256 KB 且历史超过内联接收容量
- **THEN** Agent 能从交接中的轻量目录和分页参数开始读取，无需先整读索引；所有来源仍可按准确修订查询

#### Scenario: 目录只覆盖最近轮次
- **WHEN** 历史轮次超出目录预算
- **THEN** 交接明确目录省略部分，并提供不限制轮次的全来源分页入口，不将最近目录冒充全部历史

### Requirement: 交接历史必须支持兼容的消息优先视图
绑定历史查询 MUST 支持可选 `view: messages`，按原顺序返回非工具的可见消息及通知，保留用户输入、追加、纠正、回答、助手说明及最终答复。省略视图或指定 `all` MUST 保持既有消息和工具元数据查询行为。游标 MUST 对应所选视图内的固定来源及轮次集合，续页 MUST 保持相同视图；错误视图 MUST 被拒绝。消息截断、不可读修订、详情和绑定范围 MUST 保持既有明确边界，MUST NOT 因过滤读取原生工具正文。

#### Scenario: 工具密集轮次消息跨页
- **WHEN** Agent 在包含大量工具、用户纠正和通知的轮次使用 messages 视图并逐页读取
- **THEN** 每页按过滤后的消息计数，连续游标覆盖全部消息且不重复、不遗漏，工具详情不被访问

#### Scenario: 旧调用与错误参数
- **WHEN** 调用方省略 view 或传入不支持的 view
- **THEN** 省略时保留原消息及工具元数据结果，不支持的值明确失败
