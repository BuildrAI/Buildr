## 请求场景人工审阅

| 请求或现场 | 预期行为及当前指引结论 |

| 方案已确认，继续完成实现 | 完成规划后接续已授权实现，不再索取同一授权 |
| 按已确认决定修订这组材料 | 连续修订授权范围，不逐文件确认 |
| 实现出现范围内可逆错误 | 自行修复及复查；命令阻塞须先解决原因 |

| 提案检查有效且直接进入实现 | 复用；相关规范或其他变更变化后刷新冲突检查 |
