## MODIFIED Requirements

### Requirement: Development 专注模式必须提供就近的设置、额度和对话入口

独立 Harness 和 Development 专注模式 MUST 在对话主区显示智能体与模型设置，并保留已显示且可并排的对话列表；Development 普通分屏 MUST 继续使用原设置抽屉。独立 Harness、Development 专注模式与 Development 普通分屏（含展开态与收起态导轨）MUST 均在设置图标上方提供独立的“供应商额度”入口，原设置齿轮图标统一仅用于打开设置而 MUST NOT 触发额度摘要。展开态悬停或键盘聚焦该额度图标 MUST 展示已有的供应商额度摘要；点击该额度图标（包括收起态点击后展开分屏）MUST 打开设置并直达模型的全部供应商“账号与额度”页签，不受前一次设置选项影响。打开或关闭设置 MUST NOT 改变对话选择、未发送草稿或已有执行；专注模式返回对话 MUST 还原原有视图。

#### Scenario: 从设置返回原对话
- **WHEN** 用户在专注模式打开设置，然后选择返回对话
- **THEN** 系统 MUST 保留打开前的对话和未发送输入；打开或关闭设置 MUST NOT 发起或停止执行

#### Scenario: 从额度入口进入模型账号与额度
- **WHEN** 用户悬停或键盘聚焦设置上方的额度图标
- **THEN** 系统 MUST 展示已有的供应商额度摘要；齿轮不再触发该摘要
- **AND** 点击额度图标 MUST 打开模型的全部供应商“账号与额度”页签，不受前一次设置选项影响

#### Scenario: 分屏模式展开态与收起态使用独立额度入口
- **WHEN** 用户处于 Development 普通分屏展开态或收起态导轨
- **THEN** 导轨设置图标上方 MUST 显示独立的“供应商额度”图标，齿轮图标不再悬停触发额度摘要
- **AND** 展开态悬停或聚焦独立额度图标 MUST 展示现有供应商额度摘要且不越出视口，点击 MUST 在设置抽屉直接打开全部供应商“账号与额度”页签
- **AND** 收起态点击独立额度图标 MUST 展开分屏并在设置抽屉直接打开全部供应商“账号与额度”页签，同时保持原有对话、未发送草稿与执行不变

#### Scenario: 在指定工作空间新建对话
- **WHEN** 用户点击专注模式对话列表中工作空间标题右侧的新增按钮
- **THEN** 系统 MUST 使用该空间打开新对话输入并聚焦，且不创建空对话、不改变该组折叠状态；点击名称仍可折叠或展开
