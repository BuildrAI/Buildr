## Context

动机见 proposal.md。现有 CodeMirror 编辑器、查询页面与只读 `tables` 接口已具备。用户确认版保全于 `prototype/confirmed.html` 与 `prototype/confirmed-source/confirmed-review.html.txt`，临时预览仍用于对照。

## Goals / Non-Goals

目标：兑现确认的连续键盘交互，以局部职责封装支持后续快捷操作。非目标：完整数据库客户端、字段自动推导、通用插件平台、自动执行查询或改变账号权限。

## Decisions

- `editor/shortcut-actions.ts` 维护操作注册表（Registry）和编辑计划（Edit Plan）。操作定义包含身份、触发词、标题、可用条件和计划；不拥有键盘或网络。
- `editor/sql-context.ts` 使用 MySQL 语法树（Syntax Tree）与词法节点识别当前语句和表引用，处理引号、注释、字符串、中段替换、限定库名和别名。语法识别局限只关闭不确定位置的补全，普通编辑与运行始终可用。
- 无分号完整查询后，空行隔开且当前行仅有一个未引用的操作词时，补全通过共享分析器验证前段已完整结束，允许注册表（Registry）匹配新快捷操作；不要求未展开的操作词本身能解析为查询。普通换行别名、显式 `AS`、未闭合括号及注释引号不获得此资格。这里只判断编辑起点，不改变执行边界；展开后的范围和运行仍共用原定位。
- `editor/database-catalog.ts` 是每个页面范围的目录对象，消费既有查询客户端（Client）；按库复用读取、保存成功或失败状态，显式刷新和范围变化时取消并清理。页面装配连接身份、观察版本及启用数据库；不跨实例共享目录。
- `editor/sql-completion.ts` 适配 CodeMirror 原生候选，统一筛选、状态反馈、按键优先级、编辑事务（Transaction）及后续候选。确认操作形成独立撤销边界。纯状态项不参与确认；失败项有明确重试动作。
- 精确触发词的 Enter / Tab 确认不依赖异步候选弹层已就绪：没有候选时，按同一位置上下文和操作注册表确认并应用原编辑计划。部分输入、禁用状态及普通编辑位置不走此分支。候选打开或更新中时，确认按当前输入调用同一候选来源，保留仍有效的已选项目，否则使用当前筛选首项；不接受旧过滤结果或误插入换行，纯提示仍保留普通编辑。
- `MySqlQuery` 通过局部属性向编辑器注入目录及当前上下文。`SqlQueryEditor` 以可重配扩展承接上下文变化，不为变化重建文档或清空撤销历史。页面停用、运行忙碌或选择变化时清除候选资格。
- 新增直接前端依赖 `@codemirror/autocomplete`、`@codemirror/lang-sql`，复用项目已有 CodeMirror 版本体系。替代方案是复用原型正则，但不能可靠区分字符串、注释或中段位置；自写候选弹层则重复实现焦点与可访问性，均不采用。
- 模板展开与现有查询执行分离。智能体（Agent）继续直接使用现有结构读取与查询工具，无需学习界面按键；不改变既有技能（Skill）指引。
- `sql-execution-target.ts` 是执行文本与范围的唯一定位来源，返回 `sql`、`from`、`to` 和选择模式；光标模式只移除范围两端的空白，选区模式保持原选段。`editor/sql-statement-highlight.ts` 通过 CodeMirror 装饰（Decoration）展示同一范围，无有效目标时不显示；不重复分割 SQL 或请求数据库。
- `MySqlQuery` 开始查询时保存该定位结果及文档快照，编辑器在执行期间只标记此范围；成功、失败、取消或连接范围变化时解除固定。文档与快照不符时隐藏旧框，不能把旧偏移应用于新文本。选区跨多条或引号、块注释未闭合时不展示可执行提示，已有错误反馈继续有效。

- `sql-statement-analysis.ts` 负责统一语句分析：先识别字符串、注释、括号及显式分号，再对无分号的顶层语句起始候选用完整 MySQL 解析确认前段已完整结束。完整可解析的单条查询优先保留整体，`UNION`、子查询及 `WITH` 主查询不按关键字直接拆分。歧义片段不自动执行，手动选区仍精确保留原文交后端校验。
- 本地分析使用与后端相同的 `node-sql-parser@5.4.0` 的 MySQL 精简构建；只判定语法及边界，不重写 SQL、不取代后端权限与只读校验。最近文档的分析结果只作有界派生缓存，光标移动及运行复用同一文档结果，不请求数据库。候选解析量超出有界预算时明确要求选区或分号，避免阻塞输入。

跨行范围使用一个连续的整体外轮廓：测量同一执行范围的可见文本片段，连接行间距并随每行末端转折，以 CodeMirror 图层（Layer）绘制单个闭合矢量路径。文本片段不各自绘制边框，语句内部没有分隔横线；滚动、折行和尺寸变化时随编辑器重新测量，图层不拦截鼠标。

## Risks / Trade-offs

- 不完整 SQL 语句可能解析含糊 → 结合节点边界及局部语句标记进行保守识别，用代表性复杂语句测试，不能在字符串或注释内启用补全。
- 异步结果与目标切换竞争 → 每个目录拥有取消信号与代次；旧请求结果不更新新状态，视图卸载释放监听及请求。
- 已有单库 1000 表上限 → 原样显示真实容量错误与重试，不截断伪称完整；按名称查询属于后续独立目标。
- 当前知识涉及前端职责定位 → 核对既有连接代码地图；本次只补必要来源与扩展边界，不扩大无关知识维护。

## Migration Plan

光标紧跟结束分号及该行尾随空格时归属刚结束的语句；下一条语句的内容开始位置（存在分隔空格时）归属下一条。该规则只在 `sqlExecutionTarget` 定义，展示与执行同时消费，避免修复显示后仍运行错误语句。

无数据迁移。随前端构建打包新增依赖与扩展；回退前端改动即可恢复原有编辑方式。正式查询约束、后端接口和本机偏好均保持原语义。
