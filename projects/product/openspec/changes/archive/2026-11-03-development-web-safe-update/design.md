## Context

问题见 proposal。现有构建器返回产物根路径，开发准备及验证器共享调用；安装器以 no-stop-instance 推迟进程退出，自举唯一执行器持有身份、锁和恢复信息。首轮沿用这些职责和公开 schema，不新建调度器。

## Goals / Non-Goals

目标是让耗时编译发生在在线目录之外，失败不破坏旧网页，并以真实 HTTP 交付判断恢复。不是零停机承诺，不回退 checkout、依赖或数据库，不把 HTTP 验收冒充浏览器渲染验收。源码发生变化后，仅保留旧启动器无法证明旧后端可重新启动；该情形必须诚实报告恢复失败及保留恢复信息。

## Decisions

### 构建器拥有隔离构建和最短发布

使用现有 owned artifact staging 在目标相同文件系统创建独立候选目录；先解析 npm 与本地工具链，再执行构建。验证完整普通文件树、index、引用的关键脚本/样式，拒绝缺失和越界。保留 string 返回值以兼容开发准备、发行和验证器。

发布前将旧树转入本次 owned backup，再把完整候选转入目标；第二步失败则恢复旧树，恢复也失败时保留 backup 并报告路径。两个 rename 不是单次原子替换，仍可能有毫秒级目录空窗，必须准确说明。备选的常驻代理、版本路由或双实例复杂度超过本机首轮收益，暂不采用。进程退出仍只在现有自举最后切换，不在构建前退出。

上一代内容寻址 assets 按文件保留且不覆盖新产物，避免旧浏览器在切换后加载分块失败；使用可重建的相对资源清单区分本代与保留资源，避免无限积累。清单不是恢复或任务状态。旧树不含新清单时仅以实际合法文件作为迁移输入，拒绝 symlink 和目录穿越。

### 页面验收不改变身份 authority

连续性探测继续按认证 health 保持旧 status 和所有权判断，另附页面结果。首页检查应用挂载节点与模块入口；同源脚本、stylesheet、modulepreload 检查成功状态及媒体类型，拒绝 HTML fallback。不把实例 secret 发给静态资源，不保存 HTML/session token。

复用和新启动均须通过页面交付才返回 passed；恢复中 preserved 分支同样核对页面，失败保留恢复信息。页面检查使用总预算且不把资源数量乘成无限等待。

### 计时与进度复用现有结果和日志

阶段、操作与执行结果附加 startedAt、finishedAt、durationMs，耗时采用单调时钟。阶段/操作开始和结束以固定字段 JSONL 写现有 worker stderr 日志，不输出参数、环境或完整原始子进程流。输出捕获避免默认 maxBuffer 造成成功被误判失败；保持解析完整输出、摘要有界。

连续性提供退出、启动、页面验收和总耗时。认证退出前至网页验收完成的时长为中断保守上界；原页面此前不可用、未观察到中断、失败仍在中断分别标注，不填伪造的零或精确值。

## Risks / Trade-offs

- 短目录空窗和旧页面/新后端协议兼容 → 明示并保留最后进程切换边界，不承诺零中断或跨版本无条件兼容。
- 发布恢复失败 → 保存唯一可恢复旧树，诊断指明具体路径，不用 finally 误删。
- 进程在目录替换之间被 SIGKILL → 首轮不新建跨进程事务日志；保留旧备份，既有 pending 恢复报告未完成，不冒充自动恢复保证。
- HTTP 检查不能执行 JS → 测试证明交付边界，真实浏览器验收按需要另做。
- 旧版本后端无法从当前 checkout 重启 → 不自动 git reset 或回退用户数据，保留失败事实。

## Migration Plan

先在独立任务工作树完成规范及回归，所有真实进程场景只在产品隔离 runner 中执行。保留既有函数和 schema，新增字段可被旧消费者忽略。未获收尾授权前不提交、集成或正式激活；验证不得安装、重启或改写当前 4458 的真实 profile。首轮连续性旧替身曾只读查询默认端口，归属保护阻止终止；替身现通过 releasePort 注入消除该查询，后续检查使用隔离状态。

## Knowledge Impact

本轮有界核对了 `knowledge/code-map/task-system.md` 的自举说明及 `knowledge/code-map/system-services-assets.md` 的工程职责。唯一执行器、构建/托管归属和身份 authority 未改变，现有地图入口继续有效；不在缺少知识维护授权时扩改地图或 Archify 成果。

建议后续校准任务地图自举段：在进程健康之外明确首页及同源脚本/样式验收通过才清除待恢复信息，说明阶段进度和中断保守上界；若维护关联自举图，同步细化恢复验收节点，不新增第二套执行责任。本变更与源 Skill 已记录实际边界，知识建议不阻止本轮实现验证。
