## Purpose

定义 Buildr 开发网页在自举更新期间的产物保全、真实页面交付验证和阶段耗时观察，避免把长时间构建变成同样长的页面中断，且不以进程存活冒充网页恢复。

## ADDED Requirements

### Requirement: 构建失败不得破坏正在使用的网页产物
开发网页更新 MUST 在独立位置构建并校验候选产物，准备失败 MUST 保留旧产物与已认证的运行实例；只有候选入口和关键资源完整时才能发布。发布失败 MUST 尝试恢复旧产物，恢复失败 MUST 保留可诊断的备份，不宣称成功。系统 MUST NOT 自动回退用户源码或业务数据。

#### Scenario: 编译或工具链准备失败
- **WHEN** 已有可用网页且新构建的工具链、编译或产物校验失败
- **THEN** 原入口和资源 MUST 保持原内容，旧实例 MUST 不因该失败被退出

#### Scenario: 发布写入失败
- **WHEN** 候选构建成功但发布失败
- **THEN** 更新 MUST 恢复原产物或报告恢复失败及保留位置，MUST NOT 删除唯一可恢复副本

#### Scenario: 旧页面仍引用内容寻址资源
- **WHEN** 发布后旧页面请求仍被保留的上一代哈希资源
- **THEN** 更新 MUST 不因清空产物目录而破坏该资源，MUST NOT 将旧资源覆盖到新版本同名资源之上

### Requirement: 连续性成功必须验证页面及关键资源
自举 MUST 分别表达经认证的实例身份与页面可用性。实例复用、新启动和失败恢复宣称网页可用前 MUST 验证首页为应用 HTML，且关键同源脚本和样式响应成功且媒体类型正确。HTTP 200 的 HTML 回退 MUST NOT 被视为脚本成功。检查 MUST 不将实例秘密发送至静态资源，不输出会话令牌；HTTP 交付通过 MUST NOT 被表述为浏览器渲染通过。

#### Scenario: 健康接口正常但页面损坏
- **WHEN** 实例身份验证通过而首页或关键资源缺失
- **THEN** 系统 MUST 保留实例所有权事实并报告页面失败，MUST NOT 返回网页已恢复成功

#### Scenario: 页面资源响应被回退替代
- **WHEN** 模块脚本路径返回状态 200 的 HTML
- **THEN** 页面验收 MUST 失败，不得仅凭状态码通过

### Requirement: 更新进度与中断观察必须真实且可接续
自举 MUST 在现有结果结构中记录阶段、操作及总执行的开始、结束和单调耗时，并在现有独立执行日志中提前输出正在执行的阶段。日志 MUST 不包含命令秘密或完整环境。输出展示截断 MUST 不导致成功子进程被误判失败。切换计时 MUST 与构建耗时分开，MUST 标明保守上界、原页面已不可用、未知或仍在中断，不伪报精确中断或零中断。

#### Scenario: 构建尚未完成
- **WHEN** 独立执行仍在运行长命令
- **THEN** 已有日志 MUST 能定位当前阶段及开始时间，而无需等待最终结果

#### Scenario: 正常或失败切换
- **WHEN** 已发起认证退出并尝试恢复网页
- **THEN** 结果 MUST 区分完成后的切换耗时上界与尚未恢复的中断，原页面此前不可用时 MUST 明示该事实

#### Scenario: 子进程输出超出展示容量
- **WHEN** 子进程真实成功且输出大于默认缓冲展示容量
- **THEN** 执行 MUST 保留真实退出事实，摘要截断不得转成执行失败
