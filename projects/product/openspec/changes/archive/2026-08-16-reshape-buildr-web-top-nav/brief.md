# 将 Buildr Web 壳层改为上下结构

一句话摘要：按已确认静态稿把 Buildr Web 主导航放到顶栏，内容通栏在下方；进入工作空间直接打开任务列表。

## 背景与问题

柔和产品感换肤后，壳层仍是 248px 左侧栏。导航、工作空间和次级入口挤在窄栏，内容被横向压缩；窄屏侧栏滑出且无入口。用户确认上下结构静态稿后需要实施。

## 目标 / 非目标

**目标：** 顶栏承载品牌、任务/项目/服务/文章、工作空间、设置、交给 Agent；进入 Workspace 直接打开任务列表；服务/文章整页列表或详情；任务页与项目页宽屏左列表右详情，项目编辑在详情右上角；筛选一行；窄屏导航可用；保留路由、API、session、CSP 与 `data-nav`。

**非目标：** 不改 API/URL；不换组件库；不恢复杂志衬线；不把服务/文章改成并排分栏；不以 Vite HMR 冒充完成。

## 受影响用户或角色

在本机浏览器使用 Buildr Web 查看任务与资源的用户；编写 browser smoke 的维护者。

## 核心流程

进入 Workspace → 直接打开该空间任务列表。顶栏切换任务/项目/服务/文章。任务页与项目页宽屏左侧浏览列表、右侧看详情；服务/文章仍整页切换。品牌或工作空间切换也回到当前空间任务列表。Release Awareness 横幅不阻断导航。

## 关键变化

- 左侧栏移除；顶栏水平导航。
- 「开始」退出主导航，且不再作为 Workspace 落地页。
- 工作空间切换器上移到顶栏。
- 任务筛选改为一行。
- 任务页宽屏改为左列表右详情（2026-08-16 用户确认）。
- 进入 Workspace 直接打开任务列表（2026-08-16 用户确认）。
- 项目页宽屏改为左列表右详情，编辑按钮放在详情右上角（2026-08-16 用户确认）。

## 审美闸门

| 项 | 内容 |

| 可接受样本 | 柔和产品感 + Ant Design 5 + 雾青绿；静态稿顶栏通栏 |

## 影响 / 风险 / 兼容性

窄屏项多时收入明确菜单，避免无入口。每个 `data-nav` 保持唯一。无 API 破坏。

## 验收摘要

生产托管 dist 上：顶栏导航可点、进入 Workspace 落到任务列表、`data-nav` active、交给 Agent/退出仍在、任务与项目宽屏并排、项目编辑在详情右上角、筛选非竖排卡。
