# 已确认的第四版原型

`body.html` 与 `viewer.html.accepted` 保留用户确认时的原字节，来自本次讨论独占临时目录。后者是原 `viewer.html` 的阅读器外壳快照，采用快照扩展名避免任务阅读器再次嵌套一层外壳、重复列出页面；任务展示统一使用 `body.html`。讨论期间的原临时阅读入口仍保留用于对照。两张 `preview-v4-*.png` 是当时实际查看的截图；`verification-v4.md` 只说明模拟交互验证，不能作为正式实现验证。

`source/` 保存确认版的模拟状态和局部组件，导入已改为构建别名，以当前检出目录解析正式公共组件及主题。`build.mjs` 使用当前产品锁定依赖，从本目录可重新生成自包含 HTML；默认输出到 `rebuilt/`，禁止覆盖确认文件。重建可能包含公共组件后续变化，不冒充原确认字节。

在产品 Node 及已准备的前端依赖下执行 `node build.mjs <isolated-output-directory>`。任务方案设计使用本目录的原确认文件，正式界面测试使用任务工作树中的产品构建。
