## ADDED Requirements

### Requirement: 页面完整编辑代码库声明
代码库列表和详情的编辑入口 MUST 可修改名称、说明、Git 地址、远端名称、集成分支和目录，MUST 保持稳定身份及服务引用。保存 MUST 只更新声明，不执行远端改写、切换分支、克隆或搬迁；所有写入 MUST 核对当前版本，冲突保留输入。

#### Scenario: 本地仓库修改集成分支
- **WHEN** 用户给未声明远端的本地仓库设置集成分支
- **THEN** 系统 MUST 保存并展示该分支，后续读取使用新声明，不修改当前工作分支

#### Scenario: 修改远端地址
- **WHEN** 用户保存与当前实际远端不同的有效地址
- **THEN** 系统 MUST 保存声明，并在状态检查中显示待对齐与实际远端，不隐式执行 Git 写入

#### Scenario: 编辑时发生冲突
- **WHEN** 声明版本在抽屉打开后改变
- **THEN** 系统 MUST 拒绝陈旧保存，保留输入并提示重新核对

### Requirement: 声明与实际对齐状态独立
系统 MUST 按需检查单个代码库实际根目录、远端和被引用模块；声明保存不等于实际对齐。有效仓库当前分支不同于集成分支 MUST 只展示差异，不单独认定为身份错误。界面 MUST 提供检查与后续对齐指引。

#### Scenario: 修改仓库位置
- **WHEN** 用户改为已有目录
- **THEN** 系统 MUST 核对真实 Git 根和模块路径边界，拒绝子目录、重复登记与模块越界；模块缺失显示待对齐

#### Scenario: 新目录尚未准备
- **WHEN** 用户将目录声明改到尚不存在的位置
- **THEN** 系统 MUST 保存并显示待准备事项，保留旧目录及其内容，不将保存标为搬迁完成

### Requirement: 管理界面读取本地 Git 配置
代码库详情和编辑 MUST 按需读取对应本地仓库的远端名称、实际地址和当前分支，不以清单缺失字段断言本地未配置。读取 MUST 不修改 Git 或清单，不推断集成分支。编辑 MUST 保留声明目标，缺失目标时补入可确定的实际配置，异步结果 MUST 不覆盖用户已输入内容。

#### Scenario: 根仓库只有目录声明
- **WHEN** 本地存在 origin 地址而声明中只有目录和集成分支
- **THEN** 详情 MUST 展示实际地址，编辑 MUST 自动补入实际地址与远端名称，保留已声明集成分支，保存前清单不变

#### Scenario: 多远端或声明待对齐
- **WHEN** 本地远端存在歧义或声明与实际不一致
- **THEN** 系统 MUST 展示实际可选配置及差异，不丢弃已保存目标，不把当前任务分支当成集成分支

#### Scenario: 本地读取失败
- **WHEN** 目录缺失、非真实根目录或读取配置失败
- **THEN** 系统 MUST 显示具体状态并保留已有声明，不将失败解释为没有远端

### Requirement: 服务编辑可就地新增代码库
服务编辑的代码库选择器 MUST 按过滤、新增、已有选项的顺序展示，无匹配时 MUST 保留新增入口。新增 MUST 在当前服务抽屉内编辑草稿，不打开第二层抽屉。保存 MUST 在同一版本保护事务内登记新代码库并更新服务引用；取消、冲突或校验失败 MUST 不留下部分登记。

#### Scenario: 编辑服务并新增代码库
- **WHEN** 用户在服务编辑中选择新增代码库并保存
- **THEN** 新代码库与服务引用 MUST 一并保存，服务身份和其他项目引用不变

#### Scenario: 取消或保存失败
- **WHEN** 用户取消新增、关闭编辑或保存时版本冲突
- **THEN** 系统 MUST 不产生新代码库登记；取消新增或保存失败时 MUST 保留外层名称说明输入，关闭编辑可取消整体草稿

### Requirement: 新增代码库从地址提供默认值
新增代码库 MUST 从有效 Git 地址末段去除末尾斜杠和 `.git` 后自动填写标识，并默认使用 `repositories/<末段>` 作为目录。系统 MUST 支持 HTTP、SSH 与 SCP 风格地址。标识和目录被手动修改后 MUST 分别保留用户输入；已有代码库编辑 MUST 不因地址变化自动改标识或目录。

#### Scenario: 自动填写与手动覆盖
- **WHEN** 用户输入或修改 Git 地址
- **THEN** 未被手动修改的标识和目录 MUST 跟随有效末段更新，手动值不变；无有效末段时 MUST 不猜测主机名为仓库标识
