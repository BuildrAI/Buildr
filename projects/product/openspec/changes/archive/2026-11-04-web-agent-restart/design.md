## Context
Web shutdown 先释放资源再等待 server.close，活动请求及长连接可永久拖延关闭。独立Agent已有准确代次、忙闲和停止确认能力，当前Web重启只断开宿主。

## Goals / Non-Goals
保障正常Web交接有界排空连接；提供单独Agent重启。不强杀模型任务、不重发请求、不改变对话历史。

## Decisions
- 保持资源释放期间返回stopping；资源释放后停止Web监听，给予响应短暂排空时间再关闭残余HTTP连接，已调度写任务继续由执行器排空。关闭连接不冒充业务失败或成功。
- Agent重启请求携带已观察generation。对准确配置下所有活跃代次先核对空闲，再逐个请求if-idle停止并等待准确确认；死进程未知记录保留，不冒称确认停止。退出后释放旧宿主连接并重新连接，确认新代次就绪。
- Web与Agent分别重启，避免现有Web更新隐式中断任务。菜单明确区分，忙碌时返回409且保留当前页面。
- 不采用增大超时或强杀兜底；超时报告当前阶段并保留数据，重新读取后再操作。

## Risks / Trade-offs
长连接断开 → 页面重新连接，不重放写入。忙闲检查后出现新工作 → 服务端if-idle再次核对。部分代次退出失败 → 保留已发生事实、返回失败并允许重读。

## Migration Plan
无数据库迁移，构建与隔离测试后由正常交付激活流程采用。未获Git交付授权前保留候选工作树。
