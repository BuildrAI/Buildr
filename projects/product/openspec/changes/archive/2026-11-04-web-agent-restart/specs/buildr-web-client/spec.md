## ADDED Requirements

### Requirement: 独立执行服务可以显式安全重启
Buildr Web MUST 提供独立的Agent执行服务重启入口，说明与Web重启的范围差异。请求 MUST 绑定已观察generation，按准确配置核对全部活跃后台；存在正在执行的工作或待处理事项 MUST 拒绝重启并显示具体提示。空闲时 MUST 请求正常退出并核对准确确认后启动及连接新后台，只有新代次就绪才报告完成。对话、账号及未知操作结果 MUST 保留，MUST NOT 重放历史指令或工具。过期身份、连接超时与部分退出 MUST 如实报告，不冒称成功。

#### Scenario: 空闲后台重启
- **WHEN** 用户确认重启已观察的空闲执行服务
- **THEN** 系统确认旧后台退出并连接新代次，保留对话与账号

#### Scenario: 执行期间拒绝重启
- **WHEN** 任一活跃后台仍有工作或待处理事项
- **THEN** 系统拒绝重启并保留当前执行，提示处理后重试

#### Scenario: 过期观察或退出失败
- **WHEN** 已观察代次改变或准确退出尚未确认
- **THEN** 系统报告具体失败并保留记录，不重放未知操作

### Requirement: Web重启必须排空持续连接后完成交接
Web重启 MUST 停止接收新请求并有界排空已有HTTP连接，持续事件流和长轮询 MUST NOT 永久阻止旧实例退出。已调度写入 MUST 继续完成并保留真实结果，MUST NOT 因客户端断开重放。新实例 MUST 在旧实例准确释放后接管同一地址。

#### Scenario: 存在持续连接
- **WHEN** 用户重启Web且仍存在事件流或未结束的HTTP连接
- **THEN** 系统在有界排空后断开残余连接、完成资源退出并让后继接管地址
