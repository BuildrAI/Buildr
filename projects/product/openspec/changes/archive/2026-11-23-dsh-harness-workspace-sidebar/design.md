## Context

DSH rc.5 的公开右栏只挂载到屏幕上的原生 Session，且保存 Session 级布局。独立 Harness Web 拥有对话、工作空间与文件/Git 操作的权威。

## Decisions

- 使用会话界面席位承载 Harness 视图，保留框架和原生右栏；目录未绑定或承载正在切换时使用不挂载旧右栏的独立面板。宿主按工作空间记住目录一致的现有 DSH 会话；清单就绪后依次复用已记住、当前同目录、最近活动的同目录会话，无需手动绑定，排除归档、子智能体、待迁移、其他工作空间已绑定的会话。不得创建空会话或写原生执行。返回时恢复原生界面。
- 在 DSH 右栏注册两个命名类型，开始页直接使用原生卡片和主题，仅提供名称与线条图标。多个分栏或浮窗打开的实例按当前承载的实时清单收敛；没有正确承载的标签不挂载工具内容。两个模块继续请求 Harness 的准确工作空间和版本，不调用 DSH 文件或 Git 写入接口。无原生承载时保留 Harness 自己的工作区。
- 授权交接仍只使用环回页面短期票据、隔离 guest 和明确本机绑定。桌面桥只接受当前可信 Harness 页的有限导航与工作空间观察，不共享凭据，不转发任意弹窗。按点击时的宿主偏好决定目标，并暴露明确的外部打开选择。

## Risks / Trade-offs

- 右栏仍限制于已绑定、目录一致的真实 DSH Session。目录不一致或会话消失时 fail closed，保留 Harness 内容。
- 嵌入浏览器登录状态独立，站点可能拒绝某些操作；使用已有显式外部操作，不自动重放失败导航。
- 老宿主不猜测兼容，不改包或私有存储；停用插件恢复原生呈现。

## 原生外壳与中栏

由 DSH 插槽提供中栏定位与标题栏安全区；保活网页视图随中栏几何改变。原生会话选择退出 Harness，插件内部的工作空间会话对齐保留 Harness。原生右栏入口复用对话标题内的工作区按钮；返回使用对话更多菜单。未连接时直接保留自有工作区，不展示原生会话选择或编号。
