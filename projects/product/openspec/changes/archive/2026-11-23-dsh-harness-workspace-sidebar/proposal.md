## Why

Harness 的全窗口面板遮住了 DSH 原生浏览器和终端，普通网页链接也无法遵循宿主偏好。用户需要在不离开 Harness 对话的情况下使用同一工作空间的原生工具和 Buildr 文件、Git 工具。

## What Changes

- 在 DSH 会话界面并排展示 Harness 和原生右栏。默认自动连接可用的同目录会话，记住所选实例；首次有多条时优先当前同目录会话，再看同目录内最近活动。用户无需选择原生会话。
- 增加独立的资源管理器和源代码管理标签，按工作空间各一个；开始页复用原生按钮样式并提供图标，不替换原生浏览器、终端和工作区文件。
- 用户点击的普通网页和账单链接使用 DSH 现有链接偏好；无法使用原生侧栏时给出明确的外部打开选择。
- 未绑定时仍可使用 Harness，不创建或写入 DSH 会话。不更改公开协议、独立网页默认行为或日常 DSH 配置。

## Capabilities

### Modified Capabilities

- `harness-dsh-desktop-plugin`：支持工作空间级右栏组合及宿主链接偏好。

## Impact

影响开发插件、Harness Web 的桌面呈现与隔离验收；不改变后台对话或 Git 写入权威。

## 桌面布局调整

Harness 仅占据中栏；保留左右 DSH 原生开合和完整左栏导航，取消临时顶栏。布局调整不新增原生会话或定时任务能力。
