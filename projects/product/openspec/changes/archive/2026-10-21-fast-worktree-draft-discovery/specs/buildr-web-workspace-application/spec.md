## MODIFIED Requirements

### Requirement: 文章页必须发现任务工作树草稿

文章应用 MUST 依据已登记的任务工作树证据发现任务范围内项目 `docs/publications/` 中新增或修改的有效文章。发现 MUST 读取证据登记的检出位置，并以文件系统观察核对：检出目录存在且路径不经过符号链接、其 `.git` 登记指向证据记录的来源仓库 Git 公共目录、当前分支与登记一致；文件系统核对不一致或检出位置缺失的来源 MUST 不列出其草稿，并作为局部诊断上报。它 MUST 将这些候选作为草稿并返回来源任务标识与标题；MUST 区分主目录及不同任务的同名文章，且 MUST NOT 因任务已完成而隐藏仍存在的稿件。未变化的主目录文章副本 MUST NOT 重复列入。草稿的正文、原文、图片读取与保存 MUST 在访问时重新核对任务范围、项目登记及工作树身份，列表发现本身不替代该核对。

#### Scenario: 已完成任务中的新文章

- **WHEN** 已完成任务的有效工作树中有主目录尚不存在的文章
- **THEN** 文章页 MUST 显示该草稿及可打开的来源任务，支持正文和原文预览

#### Scenario: 多个来源有同名文章

- **WHEN** 主目录及两个任务工作树包含同一项目同一文章标识的不同稿件
- **THEN** 列表、深链接、阅读、收藏及资源 MUST 分别绑定对应来源，不能覆盖或混淆

#### Scenario: 未变化的文章副本

- **WHEN** 工作树稿件与当前主目录稿件内容版本相同
- **THEN** 文章页 MUST 保留主目录文章并排除重复候选

#### Scenario: 登记来源已漂移

- **WHEN** 工作树证据存在，但登记的检出位置被移除、为符号链接、其 Git 登记不指向证据来源或当前分支与登记分支不一致
- **THEN** 列表 MUST 跳过该来源的草稿并给出局部诊断，MUST NOT 退回同名主目录稿件或以未核对目录顶替

#### Scenario: 开发入口与安装包行为一致

- **WHEN** 用户通过开发入口或已安装产品包的普通文章页查看当前工作空间
- **THEN** 两种入口 MUST 都能发现合法任务工作树草稿并读取对应正文、来源任务和图片，不能依赖临时预览模式
