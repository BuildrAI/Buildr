## ADDED Requirements

### Requirement: 模型目录由后台核对维护并静默读取
系统 MUST 在本机服务启动后立即后台核对已接入账号及模型，并以30秒间隔继续核对；同一服务 MUST 共享当前本机结果，外部核对 MUST 不重叠，关闭后 MUST 停止调度。普通账号和模型目录读取 MUST 只读取当前本机结果，不等待或触发外部核对；显式手动核对 MUST 保持可用。本机账号退出、来源失效与模型启停 MUST 立即反映，MUST NOT 由旧结果绕过执行校验。

#### Scenario: 外部核对耗时较长
- **WHEN** 一次后台核对仍未完成，多个页面读取目录
- **THEN** 系统 MUST 立即返回已有本机结果，不重复核对，不等待外部完成

#### Scenario: 后台调度与退出
- **WHEN** 服务启动、达到后续30秒触发点，或服务关闭
- **THEN** 启动 MUST 发起后台核对，后续无进行中核对时 MUST 再次发起，关闭 MUST 停止后续调度

### Requirement: 正常模型刷新不打扰用户
系统 MUST 在初次无结果时静默保留空列表，在正常获取、刷新成功和恢复时 MUST NOT 新增状态或成功提示。失败 MUST 保留已有模型列表并提示实际异常及影响；恢复后 MUST 撤掉对应异常，不弹恢复成功。初次读取尚未完成 MUST NOT 冒充账号或模型已失效。

#### Scenario: 初次无结果或正常刷新
- **WHEN** 本机尚无模型结果或后台正常刷新
- **THEN** 页面 MUST 不显示获取中、刷新中或成功提示，有结果后自然更新

#### Scenario: 刷新失败后恢复
- **WHEN** 外部核对失败且后来恢复成功
- **THEN** 页面 MUST 在失败时保留已有列表并说明异常，成功后只更新结果及撤掉异常
