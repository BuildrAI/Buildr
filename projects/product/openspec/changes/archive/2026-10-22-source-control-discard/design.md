## Context

复用 code 应用的来源解析、完整内容快照（Snapshot）、同源会话（Session）授权及公共目录操作互斥。现有 commit-context 提供内容摘要版本和完整去重路径数量。

## Goals / Non-Goals

恢复到 HEAD 并清除所选路径全部比较层；单文件重命名同时恢复关联旧路径。全部仅指当前工作树（Worktree）。不做跨库批量删除、历史重写、忽略文件清理或冲突解决。

## Decisions

确认前读取独立 discard-context，返回实际来源、文件清单和版本。执行请求必须携带该版本；客户端不能仅凭列表状态写入。相对于按比较层丢弃，统一恢复至 HEAD 避免同一文件两层入口语义不一致，确认文案明确说明。

索引（Index）采用独占原索引锁和临时索引（Index），复核后逐路径恢复；新增路径仅逐文件删除，不递归清理。路径按字面解释，拒绝父级符号链接、特殊目录和子模块（Submodule），保留无关与忽略内容。应用内写入复用公共目录互斥；失败保留已发生事实，绝不自动重试或回写旧内容。

页面按路径合并全部暂存、未暂存和未跟踪项；条目身份固定为 working 与文件路径，不随外部暂存操作变化。新增只读 working 比较，基线为固定 HEAD、内容为当前磁盘；无 HEAD 或新增文件从空内容比较。已暂存新增后删除等净变化为零的路径仍可核对索引（Index）残留，但差异不得伪造。恢复单个文本块仍只修改当前文件，不隐式清除索引（Index）。灰色图标用于日常入口，确认框继续用危险按钮表达实际删除。

## Risks / Trade-offs

破坏性删除不可撤销 → 明确文件范围及确认，执行前内容摘要校验。外部工具无法与应用锁共享原子事务（Transaction） → 写入前复核来源和内容，尽量同步执行，不承诺任意外部编辑器原子保护。逐项失败 → 返回实际已完成路径和部分失败说明，强制重新读取。完整快照（Snapshot）有现有大小上限 → 超限明确不可用，不接受截断观察。

## Migration Plan

新增独立接口（API）和可选界面回调，已有模拟入口与调用方保持可用。无需数据迁移。
