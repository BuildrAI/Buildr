## ADDED Requirements

### Requirement: 资源管理器默认以工作空间目录为根

默认资源管理器 MUST 从当前获准工作空间目录按真实文件层级浏览，不把仓库或工作树平铺到根。普通目录列举 MUST NOT 依赖 Git 发现、Git 子进程或状态结果；仅按需列出所请求层级，并保留原文件访问范围。用户 MUST 可显式切换到已核对的工作树并返回工作空间目录；源代码管理打开显式检出下的文件时 MUST 保留该来源。

#### Scenario: 多仓工作空间首次打开资源管理器

- **WHEN** 工作空间在 `repositories` 下有多个仓库，而用户没有选择工作树
- **THEN** 首屏在实际层级显示 `repositories`，展开后在其下显示子目录，不等待工作树或状态核对

#### Scenario: 显式查看另一工作树

- **WHEN** 用户显式选择一个已核对的工作树或从其差异定位文件
- **THEN** 浏览该工作树，不能因其失效而把同名文件改用工作空间根读取
