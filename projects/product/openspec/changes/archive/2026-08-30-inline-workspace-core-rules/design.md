## Context

当前随包核心规则与入口分离；同步器硬编码旧引用，诊断只检查引用存在，包清单将核心规则登记为必需内置项。已有安装回执可证明上次交付字节，不必引入新迁移状态。

## Goals / Non-Goals

目标：入口正文单一来源；用户正文原样保留；安全处理旧文件；通用专业规则不退化。

不做：跨仓启动继承、新适配器、全局门禁、额外规则权威、版本发布、规范工作空间受管副本手工更新。

## Decisions

1. 随包 `resources/workspace/AGENTS.md` 的现有标记区块是唯一规则正文源。生成和诊断均读取该区块；不在代码常量或第二个规则文件复制正文。
2. 保持现有标记，以便原位替换旧引用区块。缺失时追加区块；多块或破损标记只修复可识别受管片段，区块外字节不变。诊断比较完整区块，发现旧引用和正文漂移。
3. 核心规则迁移复用内置回执与同步事务。只处理固定旧身份和路径；相符的普通文件按摘要删除。修改、无回执或符号链接保留并提示；明确受管的旧登记停用，未知登记不改。
4. 六条原则按产品、架构、性能组织；既有重叠责任和失败边界合并，不新增原则。规则仍只表达边界；专业流程留给技能。
5. 现有渲染消费者继续读取入口，不扩展适配器。静态验证、测试与当前产品说明改为新契约；历史归档不改写。

## Risks / Trade-offs

- 误删用户改动 → 文件、路径、受管登记及回执一致才删；未知保留。
- 区块外内容丢失 → 对正常、缺失、破损与重复标记测试字节保留及幂等。
- 旧必读登记造成双权威 → 对确定受管项停用；对未知归属提示用户决定，不自动读取为产品核心规则。
- 遗留规范包含已局部化的末尾格式要求 → 明确移除随包要求，保留产品项目自身约束。

## Migration Plan

随下一次已授权的产品更新或同步生效；本任务只在隔离环境验证新建和升级场景。受管旧文件删除可从安装版本或版本控制恢复；保留文件不覆盖。降级产品不承诺恢复旧布局。

无；用户已确认目标与边界。
