# 近期存储优化实施记录

## 当前成果

用户已授权实施。本任务独立工作树为 `.worktrees/agent-storage-optimization`，分支 `task/agent-storage-optimization`。长期冷热任务独立使用 `.worktrees/agent-conversation-tiering`，保持待办且源码干净。此前方案材料中的“仅规划”描述属于历史阶段，本记录补充当前实施事实，不改写历史。

- 私有对话格式升级到 v5：主表只保存头和计数；同一对话、同一修订的完整正文只存一份，main/inherited 位置引用正文。有界预览不重复短正文。
- 大于 16 KiB、最多 64 MiB 的已完成或失败工具记录尝试 zstd 无损压缩，仅变小时采用。读取校验长度、摘要与 UTF-8，损坏明确报错，不冒充空历史。
- 分页、详情、搜索、继承及交接使用统一正文。可见消息保持 raw，搜索仍只匹配标题和可见用户／助手消息，不引入工具日志搜索或 FTS。
- 迁移使用准确 owner/storage 边界，存在其他活跃后台时拒绝；迁移前建立一致性 SQLite 备份、校验内容指纹，事务内转换并逐条往返验证。v5 触发器拒绝旧格式写入。旧库只读不迁移；已有新输入时不能用旧备份覆盖。
- 连接级复用 Node 编译缓存；HOME/TMP 仍隔离。只把明确可重建的编译缓存纳入既有安全维护，不删原生会话、账号、必要日志、附件或已发交接来源。
- 随包 Agent 使用指引已补充备份、不可混写、回滚与原生会话边界。
