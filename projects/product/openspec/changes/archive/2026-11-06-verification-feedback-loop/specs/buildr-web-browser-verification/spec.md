## ADDED Requirements

### Requirement: 独立浏览器场景必须可选择并隔离失败
已声明独立的浏览器场景 MUST 具有稳定身份、独立初始化和清理。选择完整组 MUST 发现全部成员；选择不存在的身份 MUST 明确失败。一个场景失败 MUST 不阻止无依赖场景执行；清理或服务状态污染 MUST 明确报告并停止受污染现场的继续使用，不能将未执行成员算通过。结果 MUST 保留各场景身份、结果和耗时。

#### Scenario: 两个独立场景失败
- **WHEN** 完整组含两个独立失败和一个成功场景
- **THEN** 同轮 MUST 报告两个失败及成功，各场景 MUST 从独立浏览器及夹具状态开始

#### Scenario: 准确身份定点执行
- **WHEN** 调用方选择一个已知场景身份
- **THEN** MUST 只运行该场景及其初始化，未知身份 MUST 失败且不能回退为全部或空成功
