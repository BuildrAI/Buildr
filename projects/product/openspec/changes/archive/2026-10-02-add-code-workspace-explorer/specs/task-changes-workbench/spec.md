## ADDED Requirements

### Requirement: 从差异定位完整文件并返回审阅
任务差异面 MUST 提供“查看完整文件”入口，绑定所选文件的代码库、实际工作目录或明确提交（Commit）版本及相对路径，进入代码区域资源管理器并定位文件；任务服务引用可以提供可调整的代码库范围预设，文件树 MUST 展示这些代码库的完整文件，不按任务差异文件裁剪。任务当前阶段、所选提交/文件和阅读位置 MUST 保留；完整文件缺失、已删除或来源不能确认时 MUST 显示对应来源诊断，MUST NOT 改读其他目录或版本。

#### Scenario: 查看未提交文件的完整实现
- **WHEN** 用户在当前任务的未提交文件差异点击“查看完整文件”
- **THEN** 系统 MUST 在资源管理器打开该实际工作目录的完整文件并定位适用行
- **AND** 返回任务 MUST 保留原文件差异选择

#### Scenario: 查看提交中的完整文件
- **WHEN** 用户在明确提交中的文件差异点击“查看完整文件”
- **THEN** 系统 MUST 使用该提交的完整标识读取文件及适用目录，明确历史版本
- **AND** 用户选择查看当前文件时 MUST 明确打开当前目录版本，不能把历史标签替换为当前内容
