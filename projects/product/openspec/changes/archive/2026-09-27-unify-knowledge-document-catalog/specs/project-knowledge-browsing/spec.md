## MODIFIED Requirements

### Requirement: 主题目录与全部资料必须共享唯一成果登记
主题目录 MUST 从当前范围索引的主题及父子关系呈现，主题资料（旧称“全部资料”）MUST 从同一索引的成果登记检索；两种入口 MUST 读取同一正文，MUST NOT 各维护一套文件或资料清单。主题资料与文档目录入口 MUST 在主题目录附近清晰可达，默认阅读仍由已登记默认主题决定。说明文档分类 MUST 包含普通说明与术语资料。

#### Scenario: 一份资料关联多个主题
- **WHEN** 同一已登记成果关联多个主题或暂未关联主题
- **THEN** 全部资料仍只列出该成果一次；关联主题中的入口指向同一份正文，未关联资料仍可检索

#### Scenario: 术语资料参与统一检索
- **WHEN** 当前范围登记了术语资料
- **THEN** 用户可在全部资料的说明文档分类检索和打开该成果，无需额外复制为普通说明

## ADDED Requirements

### Requirement: 知识入口必须提供由实际文件形成的文档目录
项目与服务知识 MUST 在现有主题阅读之外提供文档目录，按真实目录组织普通 Markdown 文件，显示标题、相对路径、数量并支持检索。目录 MUST 独立于知识成果登记，复用同一文件正文，不写回索引或另建正文；无知识索引时仍可发现允许位置的文档。范围 MUST 明确包括当前登记范围、项目关联服务的真实文档位置以及工作空间的根级阅读入口和 docs 说明；重复真实文件 MUST 去重，工作空间公共说明 MUST 与项目或服务内容分组。目录扫描 MUST 有界，达到上限或部分读取失败时 MUST 明确说明，不能把已发现数量当作完整总数。

#### Scenario: 未登记手册与已有主题并存
- **WHEN** 项目包含未登记的使用指南和已登记知识主题
- **THEN** 用户可从同一知识入口的目录找到指南，同时继续按原主题、图和地图阅读
- **AND** 目录的标题或路径搜索与文件数量基于实际可发现文件，不把每份指南创建为新主题

#### Scenario: 当前文件发生变化
- **WHEN** 文件被新增、改名、合并或删除后刷新目录
- **THEN** 目录按当前文件重新发现，叶子不因旧登记而虚构存在；已删除内容打开时明确不可读
- **AND** 返回目录保留适用的关键词与定位

#### Scenario: 无索引与大型目录
- **WHEN** 当前范围没有知识索引，或文档扫描达到上限
- **THEN** 前者仍能查阅已有普通文档；后者明确范围不完整且允许继续读取已列文件

### Requirement: 自动文档发现必须限制扫描和读取范围
文档目录 MUST 排除隐藏路径、凭证与敏感内容、依赖和构建产物、规范与历史变更、技能与规则、随包资源副本及测试样本。目录与正文 MUST 使用同一允许位置和安全校验，拒绝符号链接、绝对路径、路径穿越、禁止位置、二进制与超过读取上限的文件；查询 MUST 不执行命令、不跟随外部链接、不改变任何文件或 Git 状态。关联服务 MUST 依据实际登记解析，不能任意浏览工作空间外文件。

#### Scenario: 任意文档标识尝试越界
- **WHEN** 调用方篡改标识指向隐藏、敏感、未关联服务或范围外文件
- **THEN** 接口拒绝且不返回正文，合法目录仍可读取

#### Scenario: 普通文档内继续阅读
- **WHEN** 文内链接能匹配允许目录中的另一份文档或已登记成果
- **THEN** 用户可在现有阅读界面继续打开同一正文，已登记成果保留图与来源能力
- **AND** 不可读取的引用有明确提示，不通过放宽路径边界或复制正文实现跳转
