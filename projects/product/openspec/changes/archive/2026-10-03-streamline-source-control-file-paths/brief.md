# 源码文件单行阅读与实际路径

[任务说明](@task/source-control-file-paths)

本变更让源代码管理文件行优先显示名称，仅在同名时补充最短可区分目录提示，通过快速提示确认实际绝对路径；差异（Diff）头直接显示可选择复制的完整路径并减少重复说明。具体来源、实际比较版本、任务（Task）入口及错误提示保持。位置详情保留，复制图标移至目录、分支或固定提交各自行末；差异（Diff）代码区隐藏机器头，保留行号、增删与不连续区块的省略提示。

仅调整本入口的展示，共享任务和资源管理器默认行为不变；绝对路径不成为读取输入。验收关注主、子来源及同名跨库文件的真实路径、历史和重命名前后关系、行末复制，以及正常和窄分屏的操作与布局；补丁（Patch）精简须保持代码、行号、增删和多个区块的非连续语义。

方案见 [proposal.md](proposal.md)，组件边界见 [design.md](design.md)，直接实施与验证见 [tasks.md](tasks.md)。
