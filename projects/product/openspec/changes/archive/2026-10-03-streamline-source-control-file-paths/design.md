## Context

见 [proposal.md](proposal.md)。源码管理复用 `ChangedFileList` 和 `TaskDiffReader`；当前文件行用局部样式排成两行，路径由原生 `title` 表达，差异（Diff）头重复列出相对目录和仓库说明。具体来源目录及固定版本已由上层核对。

## Goals / Non-Goals

在本入口释放文件列表及差异（Diff）头空间，同时使完整实际路径可见。只增加共享组件可选展示参数，不更换文件身份、读取边界、任务默认页面或资源管理器搜索布局。

## Decisions

- 文件行在窄栏优先显示名称及既有状态、可得统计，不为普通文件常驻相对目录。同一文件分组有同名文件时，只补充最短可区分的目录提示；源码管理通过 `ChangedFileList` 可选 `pathHint` 参数提供此显示策略，任务和资源管理器默认仍表达原相对目录。重命名保留可见原名或移动关系，不依赖完整目录常驻。可选路径提示约100ms开启、非交互且不接收鼠标事件，避免挡住上下选择；不使用原生路径提示承担快速响应，也不新增交互浮窗。
- 路径提示由源码管理提供已确认工作树（Worktree）目录及相对变化路径，重命名前后均保留。新增 `data-file-path` 表达相对文件路径，浏览器场景按此稳定身份定位；文件键及接口（API）输入仍使用相对路径，不用显示文字识别来源。
- `TaskDiffReader` 的简洁头只由源码管理启用：文件名、简明比较层和操作同组，完整绝对路径独立可选；展示和复制共用此路径。取消本入口重复仓库说明和独立比较带，顶端具体来源、固定版本和任务（Task）入口保持，完整历史比较标识可按需查看。其他调用方默认保持原头部和路径复制行为。
- 长绝对路径允许断行并选择完整文本，正常和300px阅读宽度下不覆盖操作。位置详情继续按需展开，复制图标置于目录及分支／固定提交各自的值行末，保留可访问名称和同一复制值，取消独立重复按钮行。
- 原始补丁（Patch）继续完整解析；只在源码管理的可选紧凑呈现中去掉文件机器头与首个区块头，后续不连续区块用简明省略提示分隔。行号、增删、真实代码及必要语义提示保持，左右对比三列使用同一行序列；共享任务默认呈现不变。
- 读取失败、截断、缺侧及其他局部状态仍显示，不把简化说明解释为读取完整。

## Risks / Trade-offs

- 不同工作树（Worktree）的同名文件容易显示错误目录 → 从当前真实来源传入路径，切换来源时同时更新提示、头部及复制目标，读取身份不变。
- 删除或历史文件的绝对路径可能在当前磁盘不存在 → 路径只表达所选来源与相对文件身份，内容依旧按真实比较层和完整提交（Commit）标识读取，必要版本提示保留。
- 共享组件的样式影响任务入口 → 新参数默认关闭，样式按源码管理及可选模式限定，沿用已有任务阅读验证。
- 直接删原始文本导致行号漂移或不连续区块看似连续 → 先完整解析再做可选呈现，按解析后的机器头／区块类型处理，保持代码行和省略边界，不按代码文字前缀删除。

## Migration Plan

不迁移数据、接口或依赖。正式前端构建更新共享组件及源码管理调用点；旧入口保持默认，可通过回退本次呈现恢复原布局。
