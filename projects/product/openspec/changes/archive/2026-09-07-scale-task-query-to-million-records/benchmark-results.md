# 百万级 Task 查询验收结果

## 运行边界

- 显式命令：`npm run benchmark:task-query-million`
- 数据量：1,000,000 条四态 Task，包含稀疏 Project、Service、Child、复盘与关键词数据
- 环境：Node v24.15.0，macOS arm64，10 CPU，16 GiB 内存
- 临时数据：约 802 MB，运行结束后自动删除
- 准备耗时：85.28 秒，不计入查询延迟
- 进程常驻内存（RSS）读数：约 212 MB
- 采样：每个查询记录首次冷态读数，并预热后执行9次记录P50/P95；观察目标仅约束暖态P95

## 最终结果

| 查询 | 冷态 | P50 | P95 | 观察目标 |
|---|---:|---:|---:|---:|
| 默认首批 | 871.028 ms | 38.853 ms | 58.499 ms | 200 ms |
| 游标下一批 | 17.654 ms | 14.942 ms | 28.248 ms | 200 ms |
| 单状态首批 | 402.969 ms | 55.371 ms | 72.792 ms | 200 ms |
| Project + Service | 39.275 ms | 51.527 ms | 83.735 ms | 200 ms |
| 有直接 Child | 48.039 ms | 37.506 ms | 58.818 ms | 200 ms |
| 无直接 Child | 47.687 ms | 68.185 ms | 92.029 ms | 200 ms |
| 复盘状态 | 40.084 ms | 40.560 ms | 65.695 ms | 200 ms |
| 关键词 | 41.579 ms | 33.454 ms | 51.949 ms | 500 ms |
| 约 90% 位置深游标 | 272.340 ms | 33.777 ms | 37.920 ms | 200 ms |

全部暖态查询满足本次观察目标。默认与单状态路径直接使用覆盖索引；稀疏结构过滤由关系/复盘索引反向驱动后只排序匹配子集；关键词由FTS5虚拟表取得identity后回表组装；跨状态深游标按当前及后续状态执行最多4个有界查询并合并。

## 日常测试边界

百万级数据命令没有登记到验证注册表（verification registry）、changed/core/candidate/release/Browser或默认npm测试脚本链。日常验证只保留小数据行为、迁移同步和查询计划断言。
