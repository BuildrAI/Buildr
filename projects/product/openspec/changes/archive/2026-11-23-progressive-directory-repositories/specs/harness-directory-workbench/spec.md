## ADDED Requirements

### Requirement: 工作台先展示仓库清单再分批核对

目录工作台 MUST 优先显示获准工作空间根内的登记仓库；普通目录 MUST 先做有界浅层发现。待核对仓库 MUST 可点选并优先读取，状态逐库更新；写入仍 MUST 按已核对 Git 身份授权。更深扫描 MUST 显式继续，并区分待继续、读失败与确认没有仓库，MUST NOT 把正常待继续显示为读取失败。

#### Scenario: 已登记的第二层仓库
- **WHEN** 已登记工作空间有多个第二层仓库
- **THEN** MUST 不依赖深扫先显示这些仓库，并在有界并发下逐库核对。

#### Scenario: 普通目录继续发现
- **WHEN** 用户在普通目录浅层发现后要求继续
- **THEN** MUST 从原有有界扫描进度继续，保留已显示来源；过期或跨作用域的游标 MUST NOT 用于访问其他目录。
