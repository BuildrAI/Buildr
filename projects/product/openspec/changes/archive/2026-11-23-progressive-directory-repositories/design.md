## Context

现有完整目录接口负责扫描、校验工作树与状态，不能在完成前显示行。

## Goals / Non-Goals

登记清单不启动深扫，普通目录快速浅层可用。保留既有写入检查，不以任何提示扩展权限。

## Decisions

- 以经范围核对的工作空间登记文件作为路径提示；新接口只返回路径和名称。逐库读取时使用现有 Git 身份，失败保留原行。
- 普通目录先浅层发现；后续由作用域与目录版本绑定的短时游标继续有界队列，不用用户提供任意锚点，不因继续发现取消既有结果。
- 页面统一逐库发布，读取优先权跟随明确点选，不增大后台并发。未扫描不报失败，确有失败时单独表达。

## Risks / Trade-offs

独立目录无需登记；范围外提示、链接穿越和替换均不授权。超时游标明确要求重新开始，原有可读成果不因续读失败被清空。
