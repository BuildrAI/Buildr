## Context

原生会话约652 MiB，Buildr仍有约114 MiB工具正文副本。Codex 的模型记录与展示命令不完全同形，原生模型输出可能已截断。当前清理器绑定参与者最近上下文，并提前跳过小记录；预算耗尽也未与无法匹配区分。

## Goals / Non-Goals

按准确历史执行定位；移除一切已证明重复且有净收益的正文片段；完整还原保存时的条目；按原生执行器、原因、实际存储字节验收。活动、未知和缺乏身份/完整性证据的内容继续保留。不重放、不修改原生文件、不做原生归档或第三组交接去重。

## Decisions

- 以 attempt 的原生上下文、绑定与已提交参与上下文为依据；只有相互一致的证据才能选择旧上下文。没有证据时不猜用当前上下文。
- 老版本未保存上下文或展示工具 ID 不同，允许在准确配置域内通过原生工具 ID、原轮 ID 或完整命令字节定位唯一原生记录；重复命令无法消歧则保留。引用定位字节保存位置，不更改或证明原执行归属和结果。
- Codex 的权限绑定摘要不同于模型网关配置；只在记录的档位候选重新计算后与完整摘要一致时还原网关配置，不能将摘要直接用于目录计算。DSH 独立图片对象须由已接受原生事件中的内容摘要指向，逐字节一致后才替换；归一化后的不同字节不替代原图。
- 原生值引用支持有界 JSON 内层读取与确定的命令展示变换。按保存时截断前缀寻找真实片段，整条原始摘要不一致就拒绝转换。
- 原生缺少的片段保存在有界本地残片中，输入与正文重复部分复用一次；引用清单可压缩。比较实际编码与有界预览开销，再预留128字节的每条结构开销；剩余净收益为正才采用。原生没有任何可复用片段则保留原表示。
- 私有格式升级，兼容读取旧引用；旧后台仍可写时延迟采用。控制保存继续使用惰性正文与原修订，不能把片段重新复制成完整正文。
- 单批预算、上下文数量和内存保持有界；预算耗尽停在当前未处理项之前，下一批继续。扫描汇总每个结果的条目及实际字节，不能把未扫描或预算延迟称为不支持。

## Risks / Trade-offs

原生模型记录并不等于完整工具输出，因此覆盖率不能预设100%。混合片段增加读取表达能力和版本迁移成本，但避免保留完整重复正文。原生缺失时仍明确局部失败；本地残片不是完整兜底副本。真实数据回填只能在已交付保留版本中执行，最终同时观察物理文件与正文净减少。

## Migration Plan

隔离验证新旧引用、旧上下文、编码、部分原生输出、CAS、预算和恢复保全；交付后由唯一自举所有者采用。迁移先保全备份、排除旧写入器，不批量去副本；后续维护单独逐项转换。最终枚举未转换原因并回读已转换条目，不以启动成功替代覆盖率证明。
