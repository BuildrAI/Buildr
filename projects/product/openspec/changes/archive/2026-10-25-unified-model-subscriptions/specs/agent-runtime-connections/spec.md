## MODIFIED Requirements

### Requirement: 每家使用独立且按应用配置域隔离的配置

第一版每个应用配置域（Profile）内每家 MUST 使用一套 Buildr 独立配置，通过用户已有的厂家账号登录。正式版、开发版及预览环境 MUST 使用各自已解析的本机数据根，不共享或自动复制外部桌面配置、凭据和历史。连接身份 MUST 绑定提供者、程序来源、准确配置目录及配置来源身份；普通模型选择 MUST NOT 被当作账号来源改变。接入 MUST 不要求新建厂家账号；统一套餐能力允许本配置域内显式接入的模型来源被三家消费，各家默认桌面配置仍不得自动共享或接管。

#### Scenario: 同一接入用于不同工作空间
- **WHEN** 用户在同一应用配置域（Profile）中切换已登记工作空间（Workspace）
- **THEN** 已建立的厂家连接 MUST 可以继续使用，每段对话仍保存自己的归属及执行位置
- **AND** MUST NOT 为每次页面切换重新登录或复制凭据

#### Scenario: 开发预览验证接入
- **WHEN** 隔离预览环境建立新的厂家连接
- **THEN** 登录、配置、历史及接入记录 MUST 只进入该预览的私有数据根
- **AND** MUST NOT 修改正式版、开发版日常实例或外部桌面应用的配置

#### Scenario: 配置目录被替换
- **WHEN** 保存的配置来源与当前实际来源不匹配
- **THEN** 相关恢复或发送 MUST 返回明确诊断并保留原绑定
- **AND** MUST NOT 把旧原生编号转交其他目录或自动创建替代上下文

## ADDED Requirements

### Requirement: 网关模型必须与原厂账号检查解耦

统一模型网关模式 MUST 按程序、所选模型来源及必要原生平台认证分别检查；MUST NOT 仅凭原厂模型账号为空拒绝其他套餐。原生模式 MUST 保留原有账号路径。

#### Scenario: Codex 使用自定义模型
- **WHEN** Codex 原生程序可用且所选网关来源可调用，自定义提供者不要求 OpenAI 登录
- **THEN** 系统 MUST 允许继续并投射真实模型能力，不将空原厂账号标为全部接入失败
