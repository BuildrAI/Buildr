## 本版阅读方式

进入路径：项目主页 → 项目知识 → 《知识建设与维护》。解释文档先说明目的、职责分工、实现位置和变化后的维护方式，在相应段落直接展示技术图（Technical Diagram）与代码地图（Code Map），保留独立查看入口，两种展示共用同一内容。读者可以查看关联技能（Skill）、规范与真实文件，再返回原文。精简指减少无关栏目，不是删除解释。

代码地图（Code Map）仅覆盖本能力，按“工作方法与开发交接、现有读取与页面基础、成果位置”组织。每个区域包含范围说明、带职责注释的真实目录和关键文件，以及必要协作说明。文件可点击只读查看，已有代码与拟新增能力分开。项目级全景代码地图（Code Map）暂缓，不用相关资料列表冒充地图。

项目技术图（Technical Diagram）列表收录任务基线 `knowledge/archify/` 下的 3 张已有展示图，另列本次职责关系草图；不收录视觉校验输出，也不宣称已重新核对全部图义。已有图以隔离框架阅读，移除外部字体依赖，保持原图内容。

原型沿用 Buildr Web 现有导航与视觉框架。26 份来源快照来自任务基线 `6fab9694` 及本次规划材料；技能（Skill）工作方法与运行代码分别解释。拟新增的 `code-map`、知识读取模块与正式页面明确标注。
