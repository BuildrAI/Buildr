## ADDED Requirements

### Requirement: 共享阅读器保留常见文档语法结构与安全边界

共享阅读器 MUST 支持常见 Markdown 标题、段落、引用、嵌套有序与无序列表、强调、行内代码、参考式链接、反引号及波浪线围栏、缩进代码，以及 GFM 表格、任务列表和删除线。代码内容 MUST 保留换行与相对缩进。相对文件、任务和图片访问 MUST 沿用原来源与授权约束；原始 HTML MUST 作为文字显示，危险链接 MUST NOT 成为可执行目的地。本能力不承诺任意扩展语法或原始 HTML 执行。

#### Scenario: 文档混合常见表达
- **WHEN** 作者使用引用内列表、嵌套强调、参考式链接、删除线、对齐表格或缩进代码
- **THEN** 阅读器 MUST 展示对应结构，不把代码合并为段落，不让转义的表格分隔符产生额外列

#### Scenario: 文档包含架构文本
- **WHEN** 架构文本位于任一种合法围栏中
- **THEN** 阅读器 MUST 保留换行、空行、树状连线和相对缩进，并允许复制代码内容

#### Scenario: 保持宿主链接与锚点行为
- **WHEN** 读取含参考式相对链接、带空格目的地、重复标题与代码内部伪标题的文档
- **THEN** 阅读器 MUST 将安全相对目的地交给原宿主处理，并按真实显示标题保持稳定锚点与重复序号

#### Scenario: 作者内容不扩大执行权限
- **WHEN** 文档包含原始 HTML、编码或普通危险链接、未经允许的图片或未闭合 Mermaid
- **THEN** 阅读器 MUST 保持安全文本或既有失败提示，不执行 HTML、不启用危险链接、不绕过图片来源检查、不绘制未闭合图示
