## Context

共享阅读器已拥有安全链接判断、受控图片、代码复制、Mermaid 状态和标题计数；现有解析器不能可靠处理引用、参考式链接及复杂嵌套。动机见 proposal.md。

## Goals / Non-Goals

目标是统一语法解析与安全显示，并保持公开渲染选项和阅读入口兼容。不承诺完整通过所有 CommonMark/GFM 一致性用例；不新增数学公式、语法高亮、可执行网页或远程图片加载策略。

## Decisions

- 用 `marked` 的词法结果构建安全的文档对象模型（DOM），不直接插入解析库生成的网页字符串。相较继续补正则，成熟解析器能统一块级和行内语法；相较直接显示 HTML，显式节点装配更容易保留权限边界。
- 使用 `entities` 解码标准实体字符，再作为文本写入，不以浏览器网页解析执行作者内容。
- 保留现有代码块生成和链接/图片策略。相对链接继续携带原目的地供宿主打开；参考式链接只改变语法解析，不增加访问权限。
- 对 `marked` 16 不识别结束围栏尾部制表符的边界，使用局部词法适配并复用库的代码处理；扫描仅限当前代码块，不为每个围栏拆分剩余全文。
- 标题显示与标题计数基于同一语法树，忽略代码和链接定义，维持重复标题序号。未闭合 Mermaid 保留源码且不触发绘图。
- 样式仅增加引用和任务列表等局部规则，不改页面布局或外围导航。

## Risks / Trade-offs

- [标准解析改变过去的字面量显示] → 增加常见语法与现有链接、锚点、安全行为回归；保留查看原文入口。
- [解析库默认不负责安全] → 不使用其网页输出；危险目的地保持文字，原始 HTML 只写文本节点。
- [依赖增加] → 显式声明并锁定版本，生产构建打包，禁止远程资源。
- [未闭合图示被误触发] → 根据代码令牌的原围栏判断闭合，不把流式半成品交给绘图器。

## Migration Plan

没有存储迁移。先在任务隔离位置完成实现、回归、类型和构建检查；交付与保留应用更新仍等待本轮收尾授权。回退可恢复原渲染器与直接依赖，不改作者文件。
