## ADDED Requirements

### Requirement: 工作台分屏与提交阅读保持统一
Buildr Web MUST 将菜单头部和页面标签栏置于同一顶部层，下方内容分屏使用一致细竖线、短抓手和可拖动操作区；固定清单 MUST 只呈现一个分隔。文件与提交目录 MUST 有明确标题和对齐的仓库、分支、数量信息。用户 MUST 能在正文阅读、选择并复制完整提交说明与完整哈希；同一路径在工作区及各个提交中的差异 MUST 按所选来源分别呈现。

#### Scenario: 折叠菜单并固定清单
- **WHEN** 用户折叠菜单、查看改动与提交并固定实施清单
- **THEN** 顶部栏 MUST 同层对齐，下方分隔样式一致且清单边界没有重复竖线

#### Scenario: 阅读完整提交和同路径差异
- **WHEN** 用户选择提交及其中一个在其他来源同名的文件
- **THEN** 正文 MUST 完整显示可选可复制的提交内容，并读取所选提交内该文件的差异

### Requirement: 左右与上下差异对比准确呈现
差异阅读 MUST 提供左右对比和上下对比，两种模式均保留删除、新增及上下文，并 MUST 在选中文件时按真实来源读取包含文件首尾未修改行的完整差异。完整内容 MUST 按所选文件请求，MUST NOT 在目录扫描时一次读取所有文件全文；读取失败和超过边界时 MUST 明确提示，不冒充完整内容。上下对比 MUST 按顺序显示删除和新增行及对应行号，不替换为新版本正文。左右对比的旧代码、中间行号、新代码 MUST 在补丁头、空白占位和滚动后逐行对齐。窄屏无法容纳左右对比时 MUST 显示并选中上下对比。顶部屏界短竖线 MUST 与下方分屏线对齐。

#### Scenario: 切换左右与上下对比
- **WHEN** 用户读取修改文件并切换左右和上下对比
- **THEN** 两种模式 MUST 保留增删差异，选中状态 MUST 对应实际呈现模式

#### Scenario: 阅读文件前后上下文
- **WHEN** 用户选择工作区或当前任务提交中的文本文件
- **THEN** 两种对比 MUST 包含该来源的首尾未修改内容，并保留完整增删语义
- **AND** 主动刷新 MUST 等待所选完整差异的当前读取，快速切换 MUST NOT 被旧响应覆盖

#### Scenario: 左右对比包含空白行并滚动
- **WHEN** 用户阅读带补丁头、不等长增删和空白占位的左右对比并滚动
- **THEN** 两边代码与中间行号 MUST 保持相同行高和纵向位置

#### Scenario: 调整全局分屏宽度
- **WHEN** 用户拖动菜单或列表详情的分屏边界
- **THEN** 顶部短线 MUST 与下方同一边界对齐

### Requirement: 刷新与禁用状态稳定
任务列表等待刷新结果时 MUST 保留当前已读数量和列表，刷新按钮 MUST 保持尺寸及位置；成功后 MUST 按新响应更新列表和统计；首次读取仍 MUST 明确显示加载状态。宽度不足的左右对比 MUST 固定显示为禁用灰色，悬停 MUST 仅展示原因，MUST NOT 再改变文字和背景颜色。

#### Scenario: 主动刷新列表与悬停禁用项
- **WHEN** 用户刷新已有任务列表或悬停宽度不足的左右对比
- **THEN** 等待结果时已有数量、列表和按钮位置 MUST 保持稳定，禁用项外观 MUST 不变化且显示原因

#### Scenario: 相同条件刷新得到更多任务
- **WHEN** 同样查询条件的刷新响应包含新增匹配任务
- **THEN** 列表和统计 MUST 更新为新结果，MUST NOT 为保持视觉稳定冻结统计

#### Scenario: 完整差异正常显示
- **WHEN** 所选文件完整差异已读取且无错误或截断
- **THEN** 正文上方 MUST NOT 额外显示“完整文件差异”说明行

## MODIFIED Requirements

### Requirement: 任务阅读优先加载所需内容
任务详情 MUST优先呈现任务主体和当前阅读节点；未打开节点的审查、验证、协调以及改动与提交扫描 MUST NOT成为当前正文显示的前置条件。按需读取 MUST保持读取中、错误和重试可见，快速切换任务 MUST NOT显示上一任务的响应。相同任务和材料引用的重复详情读取 MUST复用已加载材料；返回已读任务 MUST可立即复用本次会话材料并重新核对。主动刷新 MUST等待取得已打开内容的当前事实，MUST NOT因缓存而省略正文刷新。

#### Scenario: 打开普通任务需求
- **WHEN** 用户打开普通任务并查看任务需求
- **THEN** 页面 MUST读取需求材料，MUST NOT主动请求尚未查看的审查、验证、组合协调信息或改动与提交扫描
- **AND** 材料未返回时 MUST显示加载状态，不提前显示缺失说明的空态

#### Scenario: 阅读报告并快速切换任务
- **WHEN** 用户打开开发实现后切换另一任务
- **THEN** 所需报告 MUST按需读取，旧任务响应 MUST NOT覆盖新任务；已读节点返回时 MUST复用当前任务内容

#### Scenario: 返回已读说明并主动刷新
- **WHEN** 用户返回已读任务，随后点击刷新任务
- **THEN** 页面 MUST可立即展示该任务的已读说明并重核，刷新完成时 MUST呈现最新正文
- **AND** 切换、取消和失败 MUST不将其他任务或失败响应缓存为成功正文
