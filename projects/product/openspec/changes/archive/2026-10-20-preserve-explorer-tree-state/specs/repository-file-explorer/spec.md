## REMOVED Requirements

### Requirement: 普通入口默认折叠且显式定位局部展开

**Reason**: 旧要求中的普通重新进入即全部折叠已被用户本次明确要求取消，与较新的跨入口保留现场要求冲突。

**Migration**: 采用“首次折叠且往返保留目录现场与显式定位”要求；首次折叠和显式定位继续保留，普通往返接续用户目录现场，无数据迁移。

## ADDED Requirements

### Requirement: 首次折叠且往返保留目录现场与显式定位

首次普通打开资源管理器（Explorer） MUST 默认折叠全部代码库（Repository）根和文件夹。用户在同一工作空间（Workspace）的保留页面中离开后普通返回，MUST 保留仍适用的目录展开、折叠与滚动状态，包括尚未打开文件的情况；普通导航 MUST NOT 主动清空或重新展开目录。目录内容重新读取 MUST 保持用户目录现场，MUST NOT 自动展开全部来源。此要求不承诺浏览器（Browser）整页刷新后的持久恢复。

明确文件定位 MUST 只自动展开该文件的真实代码库（Repository）根及必要父目录，MUST NOT 展开无关根或文件夹。对当前同一文件再次发起明确定位时 MUST 仍能展开其必要路径。目录折叠与定位 MUST 保持已打开文件、实际来源、固定历史版本、筛选与搜索的现有语义。

#### Scenario: 首次折叠且普通返回保留目录现场
- **WHEN** 用户首次普通打开资源管理器（Explorer），展开任意根和多层文件夹后切换到源代码管理（Source Control），再普通返回
- **THEN** 首次进入时全部根 MUST 折叠；返回时 MUST 保留离开前仍适用的展开与滚动，已打开的有效文件正文和来源 MUST 保持
- **AND** 同一页面内用户手动展开的根 MUST NOT 因目录数据更新而被自动折叠或全展开

#### Scenario: 未打开文件与手动折叠同样保留
- **WHEN** 用户只手动展开或折叠目录，未打开任何文件，然后离开并普通返回
- **THEN** 系统 MUST 保留这些展开和折叠，MUST NOT 以没有活动文件为由重置文件树

#### Scenario: 定位一个文件及重复定位
- **WHEN** 用户从任务（Task）、源代码管理（Source Control）或搜索中明确打开嵌套目录内的文件，随后折叠其目录并再次明确定位同一文件
- **THEN** 每次定位 MUST 展开其真实来源根及必要父目录，其他来源和无关文件夹 MUST NOT 因该动作展开
- **AND** 文件身份、来源筛选、固定版本与返回现场 MUST 保持准确

### Requirement: 工作树组选项紧凑且保留真实范围

工作树（Worktree）组选项的主名称 MUST 以单行省略表达真实名称集合，辅助信息 MUST 保留角色与适用目录数量，完整名称及来源路径 MUST 仍可核对。多库名称过长 MUST NOT 通过无限换行占满下拉列表，MUST NOT 以首个目录冒称整组或改变筛选身份。

来源选择的下拉面板 MUST 有可辨识的完整边框、独立表面和适度阴影。仅已核对的真实 Git 主工作树（Main Worktree）MUST 标注“主工作库”；其他目录 MUST NOT 显示“浏览起点”“关联任务”等角色标签。主目录身份 MUST 依据 Git 当前目录列表，与工作空间登记位置、预览运行位置及任务关联分开核对；多库组选项 MUST 仅在所有成员均已确认是主目录时标注，未知身份 MUST NOT 猜测。来源身份、名称与选择范围 MUST 保持。 标注为“主工作库”的选项 MUST 固定排在其他目录之前，同类选项 MUST 保持原顺序；排序 MUST NOT 自动改变当前选择。

#### Scenario: 多库长名称在窄面板内可选
- **WHEN** 用户在窄资源管理器（Explorer）面板打开包含多个不同目录名称的工作树（Worktree）组选项
- **THEN** 主名称 MUST 保持单行并在超宽时显示省略，辅助数量与角色 MUST 可见，完整真实名称及路径 MUST 可查看，选择仍使用原分组身份

#### Scenario: 面板边界与辅助关系清楚
- **WHEN** 用户打开来源下拉面板查看默认目录、任务关联目录和其他工作树（Worktree）
- **THEN** 面板 MUST 与背后文件树清楚分隔；辅助信息 MUST 只为真实主目录显示“主工作库”，其他目录 MUST 无角色标签，搜索与选择仍可使用

#### Scenario: 预览登记在关联目录时仍识别真实主目录
- **WHEN** 工作空间登记或预览运行位置是关联工作树（Linked Worktree）
- **THEN** 该位置 MUST NOT 被标为“主工作库”，真实 Git 主目录 MUST 仍按已核对身份标注，目录名、路径及筛选语义 MUST 保持

### Requirement: 目录展开及时反馈且不重复扫描无关来源

资源管理器（Explorer）对已读取且仍适用的目录 MUST 直接复用条目，不因收展动画或重复读取延迟展示、阻止连续展开。首次读取 MUST 显示真实等待或失败，不预造目录内容。未指定任务且明确检出身份匹配登记默认目录的只读操作 MUST 直接核对该来源，MUST NOT 因枚举无关工作树（Worktree）或任务关联推迟读取；路径包含关系、忽略规则及读取结束时的身份校验 MUST 保持。其他检出、明确任务与固定历史的读取语义 MUST 保持，MUST NOT 以跨请求陈旧身份替代当前核对。

#### Scenario: 已读取目录立即再次展开
- **WHEN** 用户折叠并重新展开已有条目的目录，或快速连续展开已读取的多层目录
- **THEN** 页面 MUST 直接显示已有内容，不重新请求同一有效目录，也不等待收展动画结束才能处理下一次展开

#### Scenario: 默认目录读取只依赖自身真实身份
- **WHEN** 只读请求未指定任务且其明确检出身份与当前登记默认目录匹配
- **THEN** 系统 MUST 在核对来源与路径后读取，并复核结束时身份，MUST NOT 扫描无关任务关联；目录被替换、越界或身份不匹配时 MUST 仍拒绝错误来源
