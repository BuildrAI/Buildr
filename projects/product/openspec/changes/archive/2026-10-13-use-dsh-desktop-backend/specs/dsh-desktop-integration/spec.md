## ADDED Requirements

### Requirement: 现有插件提供受限桌面连接

现有 Buildr 插件（Plugin）MUST 在真实桌面后台提供版本化回环连接，私有发现文件和随机凭证认证，精确标识配置范围、渠道及实例。协议 MUST 单一权威契约，限制消息及请求大小，不向网页暴露秘密、不开放任意命令，不改其他插件。退出 MUST 只清理自有监听、发现文件与请求，不关闭 DSH 或 Buildr。

#### Scenario: 取消所有权
- **WHEN** 其他连接请求取消不属于它的请求
- **THEN** 插件 MUST 拒绝，原请求保持

#### Scenario: 旧发现或认证不符
- **WHEN** 范围、协议、实例或凭证不匹配
- **THEN** Buildr MUST 拒绝，不按进程编号猜测或回退

### Requirement: 当前桌面配置与独立请求

插件 MUST 每次读取桌面当前选择，经原生准备调用确认模型（Model）、提供者（Provider）及推理级别（Reasoning Effort）。生成 MUST 无会话编号、工具或自动上下文，仅执行一次；每项请求独立中断控制器。取消、断连及退出 MUST 只中断其拥有的请求，结束释放记录，迟到结果不冒充成功。

#### Scenario: 配置变化
- **WHEN** 两次生成之间桌面选择变化
- **THEN** 每次 MUST 使用各自准备时确认的配置，不能改全局或重标旧结果

#### Scenario: 断连
- **WHEN** 生成连接断开
- **THEN** 插件 MUST 中断其请求，其他连接和聊天保持

### Requirement: 准确客户端导航与回执

插件 MUST 区分桌面客户端（Client），按明确目标查询当前聊天、打开原生聊天及 Buildr 任务。多客户端无唯一目标 MUST 报告歧义，不能广播。打开原生聊天 MUST 调用受支持接口并观察准确目标选中才确认。任务导航 MUST 校验本渠道和准确任务地址，复用自有侧栏页面；重复打开不刷新或丢失草稿。

#### Scenario: 打开聊天
- **WHEN** 按准确关系打开原生会话（Session）
- **THEN** 插件 MUST 让明确客户端选中目标并以实际观察编号确认

#### Scenario: 歧义
- **WHEN** 多客户端可用且无唯一目标
- **THEN** 插件 MUST 报告歧义，不操作其他窗口

#### Scenario: 打开任务
- **WHEN** 当前聊天请求打开关联任务
- **THEN** 插件 MUST 打开准确任务地址并复用已有页面，不先跳首页或刷新同页
