## ADDED Requirements

### Requirement: 独立查询消费新连接实例

独立 MySQL 查询工具 SHALL 支持明确选择的新内置 MySQL 实例与当前观察版本，并继续保留旧查询入口。查询与结构发现 MUST 在获取认证前核验实例绑定、启用状态、认证目标、完整认证来源及版本；版本过期、来源不兼容或个人组失效 MUST 明确失败，不回退其他实例或认证。页面与命令行接口（CLI） SHALL 使用同一查询应用与既有单条只读、精度、时间和容量限制。

#### Scenario: 新实例直接查询
- **WHEN** 用户或智能体（Agent）选择有效的新 MySQL 实例及当前版本提交单条查询
- **THEN** 查询返回该次实际数据库、执行语句及结果，页面继续使用现有右屏工作面和结果布局

#### Scenario: 观察后实例变化
- **WHEN** 查询提交前连接配置或个人认证已被其他入口改变
- **THEN** 本次操作明确冲突，不把旧观察交给新目标，不影响旧连接查询

### Requirement: 新实例查询偏好独立保存

新实例的启用数据库及当前数据库 SHALL 保存在本机，按工作空间（Workspace）及实例的明确身份与旧连接区分，并使用独立偏好版本保护并发。保存偏好 MUST 不改变连接配置、团队文件、认证版本或其他实例偏好。切换目标时页面 MUST 取消旧请求的展示资格。

#### Scenario: 同名新旧实例
- **WHEN** 新旧路径中有同名 MySQL 实例且分别保存偏好
- **THEN** 两者身份和偏好保持独立，不按名称合并，其他入口保存后的陈旧版本明确冲突
