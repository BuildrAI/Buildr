## Context

当前设置界面承载「模型」「智能体」「程序接入」「系统提示词」四个模块，但全屏专注模式（独立 Harness 与 Development 专注模式）沿用了早期为抽屉设计的顶部横向 Tab 布局，外部又嵌套了一层「← 返回对话 + 智能体与模型」页头，且桌面并排模式下左侧对话列表在进入设置时保持显示。这种叠加导致视口被分割成四列嵌套区域，单栏页面在宽屏下缺少舒适阅读宽度控制。

经交互原型对齐并结合用户最终确认（保留最左 52px 图标导轨、去掉「模型」分类右侧箭头、两级左侧导航从左到右展开），需在不破坏 Development 普通分屏右侧设置抽屉的前提下完成统一改造。

## Goals / Non-Goals

**Goals:**
- 独立 Harness 与 Development 专注模式下的设置视图升级为保留最左 52px 图标导轨的两级左侧导航全屏布局，进入设置时隐藏左侧对话列表与分隔条并在退出时无损恢复。
- 一级导航左置且极简（「设置」标题 + 4 个分类项，无额外箭头）；选中「模型」时紧邻展开分组供应商二级菜单与右侧详情区；无子菜单分类时二级栏自动收起，单栏正文贴左限宽阅读。
- 将所有设置入口无障碍标签、全屏页与分屏抽屉标题统一收口为「设置」，移除过时的「智能体与模型」和枚举式副标题及全屏下的「返回对话」文字按钮，支持顶栏 `×`（关闭设置）与 `Esc` 快捷键退出。
- 修正全屏设置打开期间点击左导轨「当前对话」「对话列表」按钮的状态转换，避免误收起面板或反向折叠列表。

**Non-Goals:**
- 不改变「模型」「智能体」「程序接入」「系统提示词」内部的后端 API、数据存储结构、账号/租约/额度逻辑。
- Development 普通分屏模式不改为全屏设置，仍使用右侧设置抽屉（同步改名为「设置」并去掉副标题），以免遮挡左侧工程工作区。
- 不改变对话列表自身的展开偏好持久化、排序、搜索与草稿存储机制。

## Decisions

1. **全屏与分屏双形态共源：`AgentModelSetup` 支持 `hideModeTabs` 参数**
   - *选择*：在 `AgentModelSetup` 增加 `hideModeTabs?: boolean`，由 `AgentConnectionSettings` 在全屏模式传 `true`（一级导航交由全屏外框左侧栏承担）、在分屏抽屉传 `false`（保留抽屉内紧凑横向 Tabs）。
   - *备选*：拆成两套设置业务组件。拒绝原因：容易造成「模型 / 智能体 / 程序接入 / 系统提示词」接线和错误提示逻辑分叉。

2. **保留最左 52px 图标导轨与极简退出路径**
   - *选择*：保留左导轨，取消冗余「返回对话」文字按钮；在全屏主区顶部提供极简路径面包屑与右上角 `×`（关闭设置）按钮，并监听 `Escape`（仅在无 Modal / Drawer / Select / Popover 弹层打开时触发）。
   - *权衡*：用户无需寻找返回按钮即可在导轨间随时切换；窄屏（`<760px`）导轨隐藏时仍可通过右上角 `×` 或 `Esc` 顺利返回对话。

3. **一级导航项不加右侧展开箭头**
   - *选择*：遵循用户反馈，四个一级导航项保持统一纯图标+文案样式，不单独为「模型」增加 `>` 箭头，靠表面层次（`#f2f5f4 -> #f8faf9 -> #ffffff`）与右侧实时展开的供应商列表自然表达两级从左到右的信息动向。

4. **保留对话列表与草稿状态而不重写偏好**
   - *选择*：全屏设置打开时对 `.ac-focus-history-pane` 和窄屏列表传入 `hidden={showFocusSettings}`（配套 `.ac-focus-history-pane[hidden]{display:none!important}`），并隐藏 `<SplitDivider/>`，而不调用 `context.setView('conversation')`。
   - *收益*：用户的列表展开偏好、拖拽宽度、筛选条件和滚动状态天然保留，关闭设置立即复原。

5. **设置期间左导轨交互护栏**
   - *选择*：在专注模式打开设置期间，点击导轨「对话列表」退出设置并保证进入列表展开态（而非当原 `view==='history'` 时将其切回折叠）；点击「当前对话」退出设置回到当前对话（而不触发 `collapse` 收起整个对话面板）；并且设置打开期间仅设置齿轮保持高亮状态。

6. **样式严格复用主题字体/图标角色变量**
   - *选择*：`focus-settings.css` 全部字号与图标尺寸使用 `typography.ts` 导出的 `--font-size-*` 与 `--icon-size-*` CSS 变量，确保通过既有 `typography.test.mjs` 静态门禁。

## Risks / Trade-offs

- **旧测试对标题和返回按钮的硬编码匹配**：现有 `standalone.test.ts`、`harness-frame.ts` 及 `buildr-web` 多份浏览器测试依赖「智能体与模型」「智能体与模型设置」「关闭智能体与模型设置」「返回对话」等旧无障碍名称。→ 同步检索并更新所有源码提示与测试断言，确保无遗漏引用。
- **弹层与全局 `Escape` 快捷键冲突**：全屏设置内的 `ProviderConnectionDrawer`、`Modal`、模型系列 `Select`、操作 `Dropdown` 都响应 `Escape`。→ `AgentConnectionSettings` 在捕获或冒泡退出前检查是否存在未受控 `providerEditing` 或可见 AntD 弹层，避免一次 `Esc` 同时关掉整页设置。
- **分屏与全屏共享 CSS 作用域污染**：`.amm-source-list` 与 `.amm-main` 在全屏两级导航与分屏抽屉下宽度与高度行为不同。→ 所有全屏两级布局样式严格限定在 `.ac-focus-settings` 后代选择器下，不改变抽屉模式既有表现。
