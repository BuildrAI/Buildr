## ADDED Requirements

### Requirement: 独立 Harness 网页静态包按引用自动回收

服务 MUST 将独立 Harness 网页静态包目录（`harness-web/bundles/<64hex>` 及遗留 `.stage-*` 暂存目录）纳入既有后台存储维护计划与条件回收。静态包仍被任何未过期页面会话、未过期登录票据、在线监听身份，或当前、待采用、存活运行版本的网页构建产物摘要引用，仍被系统进程占用，未超过 24 小时稳定窗口（`.stage-*` 目录为 15 分钟），或内容身份与 `bundle.json` 校验异常时，MUST 保留并报告原因；页面状态或运行实例记录不可读或损坏时 MUST 保守保留全部静态包。所有引用解除、超过稳定窗口且前后观察复核通过后，后续维护周期 MUST 能自动回收旧包而不要求人工清理。

#### Scenario: 旧静态包已无任何会话或运行时引用
- **WHEN** 某静态包不在任何未过期会话、未过期票据、在线监听与当前、待采用、存活运行版本的摘要引用中，内容完整且超过 24 小时稳定窗口、无进程占用
- **THEN** 自动维护计划列为可回收对象并在复核引用与占用后删除该静态包；仍被引用的静态包保持不变

#### Scenario: 活跃页面会话或状态文件损坏
- **WHEN** 某静态包仍被有效会话或在线监听引用，或者 `session-state.json` 不可读、损坏
- **THEN** 维护保留该静态包（状态损坏时保留全部静态包）并报告原因，不中断线上页面服务

#### Scenario: 遗留临时构建阶段目录
- **WHEN** `.stage-*` 暂存目录超过 15 分钟稳定窗口且无系统进程占用
- **THEN** 自动维护可安全回收该遗留暂存目录

## MODIFIED Requirements

### Requirement: 引用结束后保留运行内容

运行环境和不可变安装依赖 MUST 在仍有运行视图或必要恢复引用时持续保留；无视图引用的内容对象 MUST 自最后硬链接引用变化起至少保留24 小时，且通过完整性和占用复查才回收。针对无引用工具链内容对象的盘点与回收 MUST 支持有界批量处理、定点复核与批次共用系统占用观察：盘点可按单轮数量或字节预算限定校验规模并在后续周期公平接续，执行前后的定点复核仅校验本次计划目标而非重扫全部对象，分批执行在同一存储锁内共用前/后系统占用观察与引用检查而保持逐项完整哈希、单链接及不可写状态核验。任一对象在复核期间新增引用、被进程打开或内容身份变化 MUST 恢复并只保留该对象，不得扩大删除。

#### Scenario: 旧对象刚失去最后视图
- **WHEN** 对象内容很旧但最后运行视图刚释放
- **THEN** 保留对象24 小时，不能按文件原始mtime立即删除

#### Scenario: 缓存重新使用
- **WHEN** 缓存获得新的执行使用观察或维护发现消费者/恢复引用
- **THEN** 重新计算保留窗口，删除前再次核对观察，缺少可靠观察时保守保留

#### Scenario: 大量无引用工具链对象堆积
- **WHEN** `toolchains/objects` 中同时存在上千个超过 24 小时保护期的无引用内容对象
- **THEN** 后台维护按有界单轮预算分批盘点并在同一批次内共用系统占用观察完成删除，不因反复全量哈希与逐项占用扫描触发长退避或停滞；每个对象删除前仍通过完整摘要与链接数核验

### Requirement: 过期瞬时验证证据目录按受管标记自动清理

自动维护 MUST 将连接隔离 `tmp/` 及受管宿主临时目录中带有受管瞬时生命周期标记（`timing.json` 符合 `buildr.verification-timing/v1`、`evidenceRetention` 为 `transient`、`cleanupStatus` 为 `retained` 且 `cleanupReference` 与 `summaryPath` 严格指向自身目录）的验证证据目录（覆盖如 `buildr-e2e-evidence-*`、`buildr-unit-evidence-*` 等含小写字母、数字或连字符的类型名）纳入 `test-artifact` 条件清理；无有效标记、仍在稳定窗口内或仍被进程占用的目录 MUST 保留。

#### Scenario: 过期的瞬时验证证据目录自动回收
- **WHEN** `tmp/buildr-<kind>-evidence-*`（含 `buildr-e2e-evidence-*` 等含数字验证类型）存在本用户所有的合法 `timing.json` 瞬时生命周期标记，超过稳定窗口且无进程占用
- **THEN** 自动维护将该目录列为可清理 `test-artifact` 并在复核标记与占用后安全删除；未过期或无标记的相邻目录保留

### Requirement: 原生会话只能由显式操作在完整引用证明后回收

自动维护 MUST 继续保留原生会话正文，MUST NOT 因日志过期、进程退出、体积或年龄删除或计划删除原生会话；周期性维护计划 MUST NOT 包含原生会话候选。服务 MAY 提供显式运维操作，仅在完整证明无引用后回收单个原生会话对象。

显式操作 MUST 默认只读，并逐项报告对象、大小、观察身份、提供者、绑定、会话身份及保留理由；只有调用方显式确认后才 MUST 实际删除。回收范围 MUST 仅限受管模型绑定内的 Codex rollout 会话文件、DSH 会话目录、Claude Code 独立会话文件（无同身份伴生子目录的 `<uuid>.jsonl`）与 Antigravity 原生会话对象（`antigravity-sessions/<uuid>.jsonl`、`home/.gemini/antigravity-cli/brain/<uuid>`、`home/.gemini/antigravity-cli/conversations/<uuid>.db` 及其 `-wal`/`-shm` 伴生文件、`home/.gemini/antigravity-cli/annotations/<uuid>.pbtxt` 与 `home/.gemini/antigravity/transcripts/<uuid>.jsonl`），以及已完整证明无引用的旧租约绑定 home；MUST NOT 包含账号目录、凭据、配置、共享状态库、插件、附件或其他提供者数据。

死租约绑定 home（`native-home`）的目录根及其所有祖先路径 MUST 严格禁止符号链接；若其目录树内部包含当前用户拥有的临时符号链接（例如原生运行环境创建的工具软链），不得仅因存在内部符号链接而永久阻塞整目录安全回收，但校验与删除过程 MUST NOT 跟随任何符号链接目标，且须严格保持外部目标内容完好无损。

删除前 MUST 汇总全部持久引用来源：全部对话头（当前与历史参与者、全部尝试）、全部原生工具内容记录（含旧编码的来源路径）与全部交接来源索引，并解析到准确的提供者与会话身份；记录同时带有可解析模型绑定时应核对绑定一致。任一来源不可读、记录无法解码、绑定证据互相冲突或引用缺少准确的提供者与会话身份时，MUST 仅保留受影响提供者或绑定并报告原因，MUST NOT 推断为无引用。仅记录账号根但带有准确会话身份的引用，受影响范围 MUST 收敛到该会话，MUST NOT 扩大为整个提供者。

执行 MUST 沿用既有条件回收：稳定窗口、系统占用观察（含打开文件与工作目录）、删除前后身份与引用复核、租约锁与分批预算。变化、占用、观察失败或身份不符 MUST 恢复原对象并只保留该项。针对同一原生上下文的一组会话文件（如 Antigravity 会话 SQLite 库与其 `-wal`/`-shm` 伴生文件），若任一成员被占用则整组保留。

#### Scenario: 无引用且稳定的会话
- **WHEN** 原生会话（包括 Codex、DSH、无伴生目录的 Claude Code 独立会话与 Antigravity 原生会话对象）不在任何对话头、原生工具记录或交接索引中，绑定可解析，引用清单完整，超过稳定窗口且无系统占用
- **THEN** dry-run 报告该项为可回收并给出大小与身份；显式确认后删除该会话对象，账号、配置与其他会话不变

#### Scenario: 任一会话仍被引用
- **WHEN** 对话头、工具记录或交接索引引用该提供者与会话身份
- **THEN** 该项保留并报告引用理由；其他已证明无引用的会话仍可在同次操作中处理

#### Scenario: 引用观察不完整或身份无法确认
- **WHEN** 对话库或交接索引不可读、工具记录无法解码、绑定证据互相冲突或引用缺少准确的提供者与会话身份
- **THEN** 受影响提供者或绑定的全部会话保留并报告原因，不执行部分推断删除；仅记录账号根但带有准确会话身份的引用只保留该会话

#### Scenario: 自动维护或未确认调用
- **WHEN** 周期性维护运行，或调用方未显式确认原生会话删除
- **THEN** 计划不包含原生会话候选，或执行逐项保留并报告需要显式确认

#### Scenario: 删除前出现活动或内容变化
- **WHEN** 预览后会话文件被进程打开、出现新的引用或目录身份变化
- **THEN** 该项恢复并保留，报告实际原因，不中断其他独立对象

#### Scenario: 无引用的 Claude Code 死租约绑定目录
- **WHEN** `connections/claude-code/model-bindings/<64hex>` 内含的会话均无对话头、工具记录或交接索引引用，绑定目录本身也无引用且超过稳定窗口、无进程占用
- **THEN** dry-run 将该目录报告为可回收 `native-home` 候选，显式确认后整目录安全回收，其他仍被引用的绑定目录保留

#### Scenario: 死租约绑定目录内部存在当前用户拥有的符号链接
- **WHEN** 无引用的旧租约绑定目录 `model-bindings/<64hex>` 自身及其祖先均非符号链接，内部存在指向外部目标的当前用户符号链接且其余安全、稳定、无引用与无占用条件全部满足
- **THEN** 显式确认后安全回收该死租约目录（仅移除链接条目本身），外部符号链接目标文件保持完整未修改；若目录自身或祖先为符号链接则仍拒绝回收

#### Scenario: Antigravity 会话目录与 SQLite 伴生文件
- **WHEN** Antigravity 无引用上下文包含多文件 `brain/<uuid>` 目录或 `conversations/<uuid>.db` 及其 `-wal`/`-shm` 伴生文件
- **THEN** 显式确认回收完整删除无引用目录与伴生文件组；若 `.db` 任一伴生文件被进程占用或该上下文仍被引用，则保留该上下文全部会话文件
