## ADDED Requirements

### Requirement: 发布报告保留可比较的成本证据

发布报告 MUST 区分各段本机执行、测试排队、复用和已观察的外部等待；对实际包记录压缩与解包字节、组件大小及可核实的依赖声明。报告 MUST 保留可用的逐检查耗时与资源观测，区分压缩、解包、实际随包依赖与内联统计。数据 MUST 标注范围和来源，缺失保持未知。

#### Scenario: 从本机候选准备到发布接续
- **WHEN** 候选产生新观测或用同一原包接续
- **THEN** MUST 保存原执行与候选来源，不将复用耗时写作实际执行，不用过去候选的包数据冒充当前候选。

#### Scenario: 使用报告复盘优化
- **WHEN** 发布任务记录优化成效
- **THEN** MUST 引用本次报告与可比基线，区分实测差值、未验证的收益及后续建议；MUST NOT 为填补记录而重跑或改变发布结论。
