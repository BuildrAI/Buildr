## MODIFIED Requirements

### Requirement: 右下角入口悬停查看全部已启用来源额度

系统 MUST 在右下角账号设置图标悬停或键盘聚焦时显示全部已启用来源中已登录账号的额度概览，保留账号身份、平台报告的每个周、日、小时或其他额度窗口、余额币种与观察时间；不得只展示当前模型账号或只展示周窗口。未知、失败和旧观察 MUST 明确表达。点击 MUST 保留打开原设置的行为。来源级停用 MUST 按来源停用规则隐藏其账号；模型级停用 MUST NOT 隐藏已登录账号。

#### Scenario: 多账号混合额度
- **WHEN** 已启用来源中的已登录账号分别提供周窗口、日或小时窗口、账户余额或未知额度
- **THEN** 悬停概览逐账号显示对应事实及时间，无百分比的余额不产生进度条，模型级停用不隐藏已登录账号

#### Scenario: 读取失败及入口可用
- **WHEN** 概览读取失败或没有已登录账号
- **THEN** 显示读取失败或空状态，点击按钮仍能打开原设置，未登录与断开账号不伪装为已登录

## ADDED Requirements

### Requirement: 账号来源停用必须默认隐藏且保留账号事实

系统 MUST 以独立于登录、断开和账号可用状态的持久化来源状态表达来源停用，MUST NOT 复用“断开”语义。停用 MUST 保留凭证、登录尝试、账号身份、历史对话、已有租约与模型偏好，MUST NOT 更换身份、释放已有租约或使凭证失效。

停用来源 MUST 从默认账号来源列表、模型目录、模型选择器和额度概览中隐藏，MUST NOT 参与新对话或新执行的模型租约。系统 MUST 继续支持按准确账号身份读取停用来源及历史记录；已有执行 MUST 继续到终态，不因来源停用被中断。账号管理 MUST 提供明确的“显示已停用来源”和“重新启用”入口；重新启用 MUST 恢复同一账号及其既有凭证和偏好，不要求重新登录。

#### Scenario: 停用来源后隐藏且可恢复
- **WHEN** 用户停用一个已登录的模型来源并刷新页面
- **THEN** 该来源不再出现在默认账号来源列表和模型选择器中，也不能创建新租约
- **AND** 管理界面通过“显示已停用来源”仍能读取该账号，重新启用后恢复原账号、模型偏好与登录状态

#### Scenario: 停用不破坏历史与运行中工作
- **WHEN** 来源停用前已有历史对话或正在执行的租约
- **THEN** 历史对话和运行记录仍按原来源可读，运行中的租约不被中断
- **AND** 新执行 MUST 明确拒绝该来源，而不是伪装为模型不存在或账号未登录

#### Scenario: 模型级停用与来源级停用分离
- **WHEN** 用户只停用某来源下的一个模型
- **THEN** 该来源仍出现在账号来源列表和额度概览中，仅该模型退出新选择
- **AND** 来源级停用才隐藏整个来源，两种状态互不覆盖
