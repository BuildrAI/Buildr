## MODIFIED Requirements

### Requirement: 对话模型选择必须按智能体记忆且权限独立保存

Buildr MUST 在应用配置域内跨工作空间记住对话输入区上次明确使用的智能体（Agent）和权限（Permission）选择，MUST 将其应用于后续新对话。模型选择 MUST 按智能体连接身份分别保存，MUST 独立记录该连接上次明确使用的模型、模型来源、服务档位和思考深度；同一智能体再次被选中时 MUST 恢复自己的记忆，不得使用其他智能体的模型或全局单一模型偏好替代。智能体与权限属于对话模块偏好，模型选择器偏好 MUST 与生成提交说明使用的执行模型选择器偏好保持独立。

自动初始选择 MUST 只用于新对话草稿；用户在已有对话中主动切换模型或智能体时，可以恢复该模型的推理强度。偏好 MUST NOT 追溯改写已有对话的实际运行记录、历史或本轮权限。旧版全局模型偏好 MUST 只迁移一次到其准确连接身份；已有按智能体记忆 MUST NOT 被旧值覆盖。

恢复偏好前 MUST 核对当前接入、模型来源、能力与权限可用性。模型来源或模型已停用、连接身份变化或能力不支持时，MUST 明确提示并保持模型未选择，MUST NOT 把自动选择写回原记忆。权限 MUST 按工作空间保留明确选择；没有已保存选择的新草稿 MUST 初始选择完全访问。初始策略 MUST NOT 改写已有对话或旧轮次。浏览器存储不可用时 MUST 保持当前页面选择可用，MUST NOT 阻止对话发送。

#### Scenario: 新对话沿用上次智能体与模型
- **WHEN** 用户在一个工作空间明确选择智能体和模型后新建对话
- **THEN** 新对话 MUST 恢复同一智能体，并在来源、模型、档位和思考深度仍可用时恢复该智能体自己的同一选择
- **AND** 新建动作 MUST NOT 创建执行、发送输入或改写已有对话

#### Scenario: 切换智能体恢复各自记忆
- **WHEN** 用户为智能体 A 选择模型 A1，切换到智能体 B 选择 B1，再切回 A
- **THEN** 切回 A MUST 恢复 A1，切到 B MUST 恢复 B1
- **AND** 任一智能体的选择 MUST NOT 覆盖另一个智能体的记忆，也不得回落到官方默认模型

#### Scenario: 跨工作空间保留选择
- **WHEN** 用户在另一个工作空间新建对话或切换同一智能体
- **THEN** 该智能体的模型记忆 MUST 继续适用
- **AND** 系统 MUST 重新核对模型来源与当前智能体的兼容性，不能直接沿用失效绑定

#### Scenario: 记忆失效不静默覆盖
- **WHEN** 上次模型的来源被停用、模型被停用或连接身份已变化
- **THEN** 输入区 MUST 明确提示原选择不可用并使用当前重新选择入口
- **AND** 原记忆 MUST 保留到用户明确改选，不因本次回退被覆盖

#### Scenario: 旧全局偏好迁移
- **WHEN** 浏览器中只有旧版全局模型偏好，尚无按智能体记忆
- **THEN** 偏好 MUST 迁移到其准确连接身份一次，并在该连接仍可用时恢复
- **AND** 迁移 MUST NOT 覆盖已有其他智能体记忆，之后旧值 MUST NOT 继续回写

#### Scenario: 初始权限与空间记忆
- **WHEN** 用户创建没有已保存权限选择的新草稿
- **THEN** 输入区 MUST 初始选择完全访问，并在发送预览和实际请求中携带同一模式
- **AND** 用户在空间 A 选择默认权限后，A 的新草稿和刷新 MUST 恢复默认权限；B 的明确选择 MUST 保持，未设置的 B 使用初始策略

#### Scenario: 完全访问权限不跨工作空间扩张
- **WHEN** 用户在空间 B 已明确选择默认权限，随后在 A 选择完全访问再返回 B
- **THEN** B MUST 恢复自己已保存的默认权限，不继承 A 的选择
- **AND** A 的明确选择 MUST 保留，已有对话的实际权限 MUST 不被新草稿策略修改

#### Scenario: 已有对话不被新偏好改写
- **WHEN** 用户更改软件级偏好后打开一段已有对话
- **THEN** 该对话 MUST 继续使用自己的运行记录或本对话明确选择
- **AND** 新的软件级偏好 MUST NOT 改变其历史参与者、模型、权限或已发送内容

#### Scenario: 对话选择与执行模型记忆分离
- **WHEN** 用户更改对话输入区的模型、服务档位或思考深度
- **THEN** 生成提交说明所用的执行模型偏好 MUST 保持不变
- **AND** 更改执行模型偏好 MUST NOT 改写新对话的模型选择器记忆
