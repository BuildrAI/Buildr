## 取舍

- **来源停用独立于账号断开。** `enabled=false` 已经表示断开：会更换身份、释放租约并使凭证失效，不能复用来表达“暂时不想看到”。新增持久化来源状态，停用只影响新选择、目录与租约，不触碰登录、凭证、历史对话和已有租约；这样用户重新启用后仍是同一个账号。
- **默认隐藏，管理面显式读取。** 普通账号列表、模型目录和选择器只返回启用来源；管理页通过显式 `includeDisabled` 查询读取停用项，避免把“隐藏”实现成不可恢复的删除。`read(accountId)` 保留读取能力，供历史对话和诊断核对真实来源。
- **停用来源不参与新租约，但已有租约不被中断。** 与模型级停用语义一致：新执行拒绝并说明来源已停用，正在运行的工作继续到终态，避免一次设置变更造成任务半途失败。历史运行记录继续按原账号与模型回读。
- **记忆键选择 `connectionId` 而非展示名。** 智能体展示名可改，连接身份稳定；同一智能体在不同工作空间也恢复同一模型。偏好存储从单值迁移为按连接映射，旧全局值只作为一次迁移来源，不覆盖已有按连接记忆。
- **有效记忆优先于官方默认。** 切换智能体时先查该连接的上次选择，再校验来源启用、模型存在且启用、执行方兼容；没有有效记忆时保持未选择并提示选择。绝不因为“官方来源有默认模型”而丢弃有效记忆。
- **本地链接只开放已登记来源。** `file://` 不作为通用本机文件浏览器；解析后必须落在当前对话所属工作空间或已登记代码库的既有读取边界内。越界、缺失或来源不可验证时保留路径和原因，允许复制，不自动尝试父目录或同名文件。

## 兼容与风险

- `Stored` 增加来源状态字段，旧 `accounts.json` 缺少该字段时按启用读取，不要求重建账号；写入继续沿用现有锁、临时文件、重命名和摘要冲突检查。
- `ModelAccountView` 增加只读字段，旧客户端忽略即可；默认列表语义从“全部账号”变为“启用来源”，但管理查询显式带回停用项，避免管理入口丢失。
- 按连接记忆替换全局键时保留旧键一次迁移；旧值只在对应连接仍有效时写入，之后不再回写，避免多智能体互相覆盖。
- 本地链接解析复用现有文件 API 与来源校验，不新增任意路径读取接口；`file://` 的 host 部分、Windows 盘符和编码需要分别测试。
