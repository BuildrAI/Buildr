## Context

动机与行为范围见 `proposal.md` 和 `specs/code-source-control/spec.md`。现有代码模块已提供登记实例、任务工作树及固定完整提交的来源校验；任务改动应用按路径合并为HEAD到工作目录，任务提交读取也限定任务尾注，不能直接替代全局分层变更和全历史。

候选原型已有共享分屏、悬浮信息、代码来源和完整文件组件。正式源代码管理仍位于资源管理器页面中的占位导出；页面容器已保留访问过的代码页面，任务原有查看有独立应用和阅读组件。

## Goals / Non-Goals

**Goals:** 用同一代码应用和登记权威提供准确的只读观察，展示已登记代码库的全部Git工作树及各自变更，按需读差异和历史文件；分组可折叠、模式选中可辨，保持原型与正式入口的共同界面及任务原有查看。

**Non-Goals:** 不添加Git写入、远端网络同步、任意目录选择、全局状态库、自动任务创建或发布；不重定义任务当前变更的合并语义。选择已枚举工作树只是确定读取来源，不切换分支或修改Git登记。

## Decisions

1. 在既有代码模块新增源代码管理读取，首先校验登记代码库，再以Git真实工作树清单发现主目录和关联检出位置；逐项验证Git公共目录相同并复用资源管理器已交付的共享检出身份。源代码管理的工作树标识与资源管理器的 `checkoutId` 指向同一不透明身份，进入当前文件时显式传递，避免两套来源标识落到默认目录。清单不依赖Buildr任务工作树证据，已存在的Git事实不能因未登记为任务而不可见。命令行、网页和隔离读取执行器共享应用；接收标识后重新枚举核对，拒绝任意路径、伪造或已移除来源。保留登记实例身份，不按Git远端归并。
2. 每个工作树独立读取轻量状态元信息，不预读所有差异；历史按所选来源与本机引用有界读取，提交文件、差异和全文按需读取。每条选择及缓存键包含登记实例、工作树、路径、层和完整版本；当前文件跳转至资源管理器同样保留工作树身份，不能回退到登记默认目录。计数先按工作树内路径去重，库级汇总不把不同工作树的同名路径合并。领先／落后不可得时保持空值。
3. 暂存差异读HEAD→index，未暂存差异读index→工作目录；暂存全文固定已观察索引对象，当前文件和历史文件继续接续现有文件读取边界。根和合并提交明确比较基线，读取不修改索引、引用或工作文件。
4. 正式页面只装配读取钩子、共享界面及受控导航。共享组件接受外部读取状态与回调，删除固定任务编号、模拟刷新和本地假恢复；原型适配器提供模拟数据及内存操作，不能导入真实请求。沿用已有页面挂载保留，不新增共享业务存储。
5. 任务页原有`TaskDetailPage→TaskChangesPane→TaskDiffReader`保持原交互；全局关联仅消费真实有效尾注及可读取任务。先形成确定性读取、正确来源和简单可用首版，之后再由实践扩充。
6. 上方存储库清单按代码库与工作树两层组织，下方变更按代码库、工作树和比较层组织；展开状态与内容选择分别保存。折叠不关闭已打开文件、不变更来源，刷新不重置仍有效的折叠状态。两种查看模式使用已有主题中的明确选中背景与文字，不另造一套导航样式。
7. 工作树名称作为跨库过滤条件，可以同时选择各库的同名来源；库筛选与名称筛选取交集，清除后恢复全部已知来源。读取和缓存仍使用每个代码库及工作树的独立标识，名称不是任务权威。任务打开源代码管理时通过已确认任务范围与工作树证据预选真实来源，清单不删掉其他来源；返回导航携带原任务内容与选择，提交回任务仍只接受明确有效关联。任务详情不复制全局源代码管理，也不将原标签改成全局跳转。

## Risks / Trade-offs

- 索引和工作目录持续变化 → 返回实际观察版本，续读核对对应内容；刷新失败保留旧内容并标明失败，不能拼接不同版本。
- 特殊文件名、重命名、空仓及合并提交 → 使用NUL分隔及明确比较基线，并覆盖相应读取测试。
- 多库与大历史成本 → 状态、提交文件及正文按需有界读取，显示覆盖与截断；不承诺完整远端历史。
- 工作树增加、移除或路径重用 → 读取前核对真实清单、Git公共目录和工作树身份，逐项说明缺失；限制明确区分代码库、工作树与单来源路径，不静默遗漏整个来源。
- 文件和Git环境越界 → 继续使用现有来源、路径和Git安全调用，并测试无写入及拒绝越界。
- 共享组件改变可能影响任务阅读 → 保留任务装配和数据语义，回归原任务路径及上下/左右分屏、悬停和完整文件返回。

## Migration Plan

无用户数据迁移。实现先在任务工作树形成候选，重建前端并重启Buildr预览供用户实际查看。用户审看修正版后明确要求收尾，交付时保留最新开发主线的资源管理器来源和过滤能力，验证组合后的行为，再完成规范同步与归档、常规Git交付及适用自举激活；不发布。撤回未交付候选时正式保留分支和原任务数据均不受影响。
