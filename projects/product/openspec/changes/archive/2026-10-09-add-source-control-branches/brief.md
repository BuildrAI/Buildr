# 明确工作分支切换与历史筛选边界

本次变更（Change）把明确的分支（Branch）切换作为窄写入能力补入源代码管理，同时保留历史、文件和差异（Diff）读取的只读保证。整体任务目标与验收依据见[任务说明](@task/source-control-branches)。

采用第七版原型（Prototype），只实现紧凑管理入口、就地切换和组合历史筛选、固定重置。实际写入重新核对来源身份、已观察版本、目标引用（Ref）、占用和现有改动，不引入其他 Git 操作。已有本地跟踪项使用其自身成果；远程独有项一步建立跟踪并切换。

历史对完整本地与远程引用（Ref）及作者（Author）邮箱进行服务端过滤和分页，默认范围与指定范围分离。原有命令行接口（CLI）只读承诺、任务（Task）来源与固定版本阅读保持。

技术方案见[design.md](design.md)，实施清单见[tasks.md](tasks.md)，已采用原型（Prototype）见[prototypes/source-control-branches.html](prototypes/source-control-branches.html)。

实现已在任务工作树（Worktree）完成，真实接口（API）与界面接入均已验证。后端覆盖真实位置、跟踪复用、覆盖与忽略文件保护、漂移、外部转换局部拒绝及失败效果；前端覆盖紧凑入口、相邻单动作、组合筛选、固定重置和失活页面关闭浮层（Popover）。既有任务（Task）及固定提交（Commit）阅读保持。

验证使用当前 macOS 的隔离 Git 现场与生产托管浏览器。必要浏览器证明由仍适用的既有通过结果和修复后的局部检查组合，不宣称完整 code 选择器一次全部通过；原生 Windows／Linux、安装与发布未在本次验收范围内。当前是可验收候选，尚未集成主应用。

作者筛选验收补充已实现：“我的提交（me）”使用具体工作位置有效已配置的 Git 作者（Author）邮箱；姓名／邮箱输入定位候选，选择后仍按精确邮箱过滤。作者（Author）入口采用就地浮层（Popover），不因输入框获得焦点而收起；身份不可确认或刷新失败时只禁用快捷项，普通候选仍可选择。配置优先级、独立工作树（Worktree）身份及无环境猜测的真实 Git 检查通过；姓名／邮箱输入、同名选择、me 组合条件、重置、无身份回退及读取无写入的新增浏览器用例通过。原同名组合与离页成功子旅程仍适用，未把含失败子旅程的整条命令计为通过。

知识影响已核对：现有 `knowledge/code-map/system-services-assets.md` 将 code 模块概括为已登记来源的只读查看；本次新增明确、独立的切换写入后，该概括需要限定到读取能力，并补充分支（Branch）应用的职责入口。建议后续授权校准这两处地图说明；本次保留知识文件，不将未执行维护表述为已同步。
