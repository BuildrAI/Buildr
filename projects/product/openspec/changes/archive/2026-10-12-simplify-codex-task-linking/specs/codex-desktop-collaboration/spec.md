## MODIFIED Requirements

### Requirement: 具体原聊天绑定与恢复

系统 MUST 接受用户在具体 Codex 聊天中明确要求关联指定任务，由该聊天直接提供具体原生身份；此直接关联 MUST NOT 以网页创建请求或面板二次确认为前提。系统 MUST NOT 使用共享根身份、子执行身份、工具服务环境或匿名页面编号代替当前聊天身份。已明确接入且配置范围有效时，直接关联 MUST 不依赖面板是否加载；接入已移除或配置范围变化时 MUST 拒绝新关联并保留现有关系。既有面板继续通过有界请求确认实际承载聊天，绑定结果 MUST 可查询并校验请求及接入范围。重开或承载聊天变化 MUST 重新核对身份，句柄过期 MUST 不删除长期关系。结果不明 MUST 先查询，不自动重发工作指令。

#### Scenario: 聊天直接关联任务
- **WHEN** 用户在具体 Codex 聊天中给出工作空间内的任务编号并明确要求关联，聊天直接提交准确身份
- **THEN** 系统 MUST 幂等保存该任务与该聊天的关系并返回双向链接，无需先创建待确认请求

#### Scenario: 分叉聊天绑定
- **WHEN** 原聊天及分叉共享根编号但具体身份不同
- **THEN** 系统 MUST 绑定实际承载聊天，不绑定共享根或代执行子聊天

#### Scenario: 面板重开
- **WHEN** 用户重开已绑定面板
- **THEN** 面板 MUST 核对承载身份后恢复关联任务，MUST NOT 只因缓存存在就认定当前聊天相同

#### Scenario: 旧请求兼容
- **WHEN** 直接关联成功后旧请求仍待确认或晚到
- **THEN** 系统 MUST 保留兼容并去重关系，已绑定旧回执重放 MUST NOT 恢复已解除关系

#### Scenario: 接入范围无法唯一确定
- **WHEN** 没有有效 Codex 接入，或存在多个有效接入而未指定目标
- **THEN** 系统 MUST 明确返回未关联原因，不猜测接入，不自动接入或修改默认智能体

## ADDED Requirements

### Requirement: Codex 聊天新建任务默认关联

任务管理技能（Skill）在 Codex 原聊天中新建任务成功后 MUST 默认使用本聊天直接采集的具体身份显式建立关联，用户明确不关联时 MUST 尊重其选择。任务记录命令 MUST NOT 从工具服务或继承进程环境隐式猜测聊天身份。没有准确身份或有效 Codex 接入时 MUST 保留新任务并明确说明尚未关联，不把关联失败当作创建失败，不影响 DSH 或无聊天的任务创建。

#### Scenario: 从 Codex 聊天创建任务
- **WHEN** Codex 原聊天创建任务成功，已取得准确聊天身份且存在明确有效接入
- **THEN** 任务管理技能 MUST 默认调用显式关联动作，并核对返回的任务与聊天身份

#### Scenario: 创建成功但不能关联
- **WHEN** 新任务已创建但聊天身份或有效 Codex 接入不可用
- **THEN** 系统 MUST 保留任务并说明尚未关联，不创建替代聊天或阻止其他任务操作

#### Scenario: 无聊天来源或明确不关联
- **WHEN** 任务来自 DSH、无聊天的命令入口，或用户明确要求不关联
- **THEN** 系统 MUST 不自动建立 Codex 关系

### Requirement: 任务关联入口清楚展示当前事实

任务未关联聊天时 MUST 简洁显示“尚未关联聊天”，MUST NOT 默认展示待确认流程、大块空状态或不可操作的确认入口。用户展开关联帮助时 MUST 得到包含明确任务编号与工作空间定位的可复制聊天指令，不跳转无法确认身份的全局总览。已关联任务 MUST 展示准确聊天的打开与解除操作；保存的关系及聊天链接 MUST 不因面板未加载而隐藏或禁用。旧待确认请求 MUST NOT 阻塞或覆盖长期关系的当前展示。

#### Scenario: 空状态
- **WHEN** 任务没有任何聊天关系
- **THEN** 任务页 MUST 简洁显示尚未关联，并允许复制具体关联指令到目标聊天

#### Scenario: 已有关联无需面板
- **WHEN** 任务已有准确聊天关系但桌面面板尚未加载
- **THEN** 任务页 MUST 继续提供准确聊天链接，不要求先去总览确认
