## ADDED Requirements

### Requirement: Development 以统一顶栏切换工作台与工作空间

Development MUST 在同一顶栏左侧保留当前空间选择与原菜单，居中提供「工作台 / 工作空间」，右侧保留既有产品操作及适用条件。界面 MUST NOT 另设全宽的 Development 开合行或第二个模式入口。工作台以原对话为主，工作空间以原工程导航及页面为主并保留侧边对话。未保存布局偏好的对话首页 MUST 默认进入工作台；既有工程深链接 MUST 打开对应工程现场。模式变化 MUST 保留同一对话、未提交草稿、阅读位置与原工程现场，不触发执行。

#### Scenario: 从工作台进入工作空间再返回
- **WHEN** 用户在当前对话写有草稿时通过顶栏切换两种模式
- **THEN** 顶栏位置保持不变，原对话与草稿保持，工程页与对话从顶栏下方同一高度开始

#### Scenario: 从工作台查看文件或 Git
- **WHEN** 用户通过对话标题栏打开右侧工作区并选择资源管理器或源代码管理
- **THEN** MUST 使用现有工程范围和工具结果，工具切换不改变对话执行范围；回到工作台恢复仍有效的工具现场
- **AND** 对话 MUST NOT 因布局重组新增自动变更文件清单
