## Context
Magpie `/v1/magpie/quotas?kept=1` 返回已记录的各上游账号额度。账户额度和请求选路并非一对一。

## Decisions
- 用独立的源绑定只读操作，校验来源修订和 Magpie 地址；仅返回有界展示字段。失败不改目录状态或额度闸门。
- Magpie 详情按上游标识分组，账号标识遮罩。余额保持原单位，窗口保留原时间；缺失表示未知。重新读取观察不主动请求上游进行配额查询。
- 页面上的已读结果仅对当前源修订生效，不持久化到账户库或外发。保留现有选择器和全局额度概览。

## Risks / Trade-offs
路由组或多账号轮换无法从静态额度推知实际消费。只展示观察，不猜测归属；上游未返回的 API Key 余额保持未知。
