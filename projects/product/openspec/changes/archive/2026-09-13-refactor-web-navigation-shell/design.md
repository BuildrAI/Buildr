## Context

当前路由与客户端均已存在，AppLayout 承载顶栏和抽屉，ProjectsSection 重复编排列表详情。目标直接使用当前 dev 检出；开始时工作目录干净。本次不提交或发布。

## Goals / Non-Goals

只改变共同范围、区域导航、项目展开与菜单；保持详情内容、任务流程、文章阅读、版本冲突和 HTTP 写入边界。技能页只读现有集合，不设计完整资产管理；不实现引导、知识聚合或智能体配置。

## Decisions

- AppLayout 负责顶部区域和窄屏导航抽屉；独立 AppNavigation 完整承载菜单与项目读取，复用既有客户端。
- 路由决定当前区域与展开项目；服务只按当前展开项目读取，切换环境/项目取消旧请求，避免全量服务请求及串数据。
- 工作台复用 TasksSection，文章仍可访问；工作空间复用现有详情，ProjectsSection 简化为目录或 Outlet，避免双重项目列表。
- SkillsPage 消费 agentAssetsApi.inventory，仅显示 skills。沿用本地组件状态，不引入全局状态库。
- 顶栏默认入口保持 tasks。项目与服务旧 URL 保留；浏览器返回恢复展开对象。菜单中文覆盖本轮区域与对象标签。
- 使用 Ant Design 原有主题和图标；手机以明确菜单按钮打开侧栏，保持内容可用。

## Risks / Trade-offs

- 导航读取失败：保持其他区域和直接 URL 可用，提供重试，不以缺少目录数据阻止详情。
- 旧浏览器断言依赖平级顶栏和项目列表宿主：更新对应检查，保留仍适用的稳定元素身份。
- 较窄屏幕重复侧栏：壳层在窄屏折叠，不改变任务列表现有响应规则。
- 快速切换区域时任务自动选择可能晚到：仅在浏览器仍位于任务列表 URL 时跳转，并在卸载时取消待执行选择。

## Migration Plan

无需数据迁移、接口升级或新依赖。按现有构建生成隔离 web-dist 验证；安装运行入口的更新不属于本轮默认动作。若回退，只回退壳层、技能页及配套样式。
