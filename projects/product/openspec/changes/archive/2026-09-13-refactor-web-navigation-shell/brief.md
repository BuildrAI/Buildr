# 顶部与左侧导航框架

用户确认工作台为默认高频入口，工作空间承载环境管理。当前平级顶部菜单调整为共同环境范围之下的两个区域及对应左侧菜单。

本轮完成导航和技能只读入口，保留全部现有详情内容和操作；不实现此前原型的资料聚合、接入引导、执行管理或同步。项目旁加号复用既有创建指令，选择项目只展开其所属服务。

验收关注旧 URL、顶部顺序、中文菜单、单项目展开、服务深链与浏览器返回、异步切换和窄屏。原型参考为本次对话已交付 HTML，最新用户确认优先，不把示例数据写入生产。
