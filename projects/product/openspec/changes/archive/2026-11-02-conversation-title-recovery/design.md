## Context
标题已有原生事件、原生历史读取、启动摘要、完成兜底、显式重生成。失败记录按参与者分早期和完成两个阶段持久保存。现场原生日志只有 source.kind=fallback 的首句截取标题，没有 provider 标题，因此不能把它采用为智能摘要。

## Goals / Non-Goals
打通普通 DSH 隔离摘要，提供有限临时重试，消除历史未知造成的错误活跃。不向工作上下文追加消息、不无限重试、不伪造未知操作成功、不直接 SQL 修改本机业务记录。

## Decisions
1. 可信原生标题优先，缺失才独立生成；删除 DSH 普通对话的拒绝条件，仍仅访问已绑定模型通道。
2. DSH 无工具 HTTP 请求对网络失败、429、5xx 最多额外两次短退避，共用原调用 AbortSignal 和外层时间上限。权限、协议、输出、取消不重试；Codex/Qoder 的原生辅助请求清理约束不放宽。
3. 将历史执行的活跃判断提为同一函数：已释放且无明确 active 或 running 工具的历史未知结果不算活跃，当前未知仍可发现。未读、有效问题仍独立保留提醒。
4. 列表查询按当前轻量头部重新解释可能过期的历史活跃摘要，不修改权威执行结果，也不新增数据库格式版本；后续保存/已读通过统一函数自然刷新摘要。兼容旧后台写入。

## Risks / Trade-offs
单次标题最多三次 HTTP 请求，但总预算不增加；只重试无工具辅助请求。历史未知证据不删除，因此退出活跃不代表任务或操作完成。旧摘要的只读兼容计算必须使用带工具状态的轻量头部，不能因摘要省略工具而漏掉真实在途工作。

## Validation
执行器普通/分叉标题、临时错误/取消/非重试错误；应用原生优先及完成兜底；真实 SQLite 旧摘要、已读更新和重新打开；保护真实活动历史工具。知识影响仅在现有代码地图定位职责不变，无需新增长期知识文档。
