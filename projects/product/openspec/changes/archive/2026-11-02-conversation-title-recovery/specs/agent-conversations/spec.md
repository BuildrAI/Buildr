## ADDED Requirements
### Requirement: 普通 DSH 标题缺失必须具有可用隔离兜底
普通 DSH 对话没有可信原生摘要标题时，系统 MUST 允许通过已绑定模型的隔离无工具通道生成标题，不得仅因不是分叉对话而拒绝。已有手动命名和参与者阶段预算 MUST 保留。HTTP 独立标题的明确网络失败、429 或 5xx MUST 在同一总预算内最多额外重试两次，取消、权限或无效输出 MUST NOT 盲目重试。

#### Scenario: 原生只有截取回退
- **WHEN** 普通对话仅得到 fallback 标题且模型隔离通道可用
- **THEN** 系统 MUST 忽略截取并通过所选模型独立生成，不追加工作指令

#### Scenario: 临时 HTTP 错误
- **WHEN** 无工具标题请求遇到临时服务失败
- **THEN** 系统 MUST 有界退避重试，取消立即结束且总请求不超过三次

### Requirement: 历史已释放未知不得单独保持对话活跃
系统 MUST 在摘要、已读和历史列表查询中一致解释历史执行。当前执行已结束且历史未知执行控制资源已释放、没有明确 active 状态或 running 工具时，历史未知本身 MUST NOT 保持对话活跃。未知执行和工具证据 MUST 保留，真实活动工作、未读和有效问题 MUST 继续可发现。旧派生摘要 MUST 按相同规则解释，不要求用户发送新消息。

#### Scenario: 旧摘要仍标活跃
- **WHEN** 历史未知已释放但旧摘要仍为 active，当前已完成且所有消息已读
- **THEN** 列表 MUST 按普通历史对话处理，重开和标记已读不恢复错误活跃，原未知结果保持不变

#### Scenario: 历史存在真实在途工具
- **WHEN** 历史执行存在明确运行中工具或 active 执行状态
- **THEN** 系统 MUST 保留活跃，不以释放标记掩盖真实在途工作
