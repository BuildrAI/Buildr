# 测试价值审查与删除记录

本轮先完成全部现有测试分类并删除 C 类；执行依赖调整和结果失效粒度暂不混入。分类不等于发布时全部重跑：A 保留必要证明，B 按相关改动选择，C 从日常开发与候选检查中删除。

## 范围与方法

- 已清点三个服务的 455 个常规测试文件，另有 55 个独立检查/浏览器脚本、14 个含检查的辅助文件，共 524 个文件；另外核对 83 个已登记执行入口。服务目录外没有遗漏的常规测试文件。
- 对所有文件进行语法解析，定位 3506 个测试声明和 24477 个断言节点，逐项审查场景与断言目标；对判 C 的源段复读后才删除。这里的声明包含子场景、容器和动态模板，不是实际执行的测试数量。
- 这是全量清点、场景与断言目标审查；没有把它称为逐行人工通读全部源码，也没有把未执行的测试写成通过。随包上游组件的实现由现有组件、完整性与真实安装场景覆盖，本轮不改第三方源。
- 源快照为 `24f3771cb8679f7e55966c60b7d72d5dbb0b5302` 上本任务已有改动；每个原文件的摘要、原行号、每项分类、删除理由和执行入口都在 [完整清单](test-value-review.json)。此清单只记录本次审查，不参与测试选择或发布判定。
