## Context
见 proposal.md。执行统计组件由活动浮窗与对话列表共用，一处改动两处同时生效。对话列表当前按“活动中的对话 / 其他对话”两段平铺全部空间的对话；复制入口分散在二十余处，其中少数已各自实现图标切换，多数仍只有一次性文字提示。

## Goals / Non-Goals
保留活动区独立置顶、跨空间汇总、模型分布筛选、执行总数与不可用反馈；补齐列表分组、组顺序偏好、分组展开与统一复制反馈。不调整统计来源、计数口径、模型名称解析、对话排序规则本身与后端接口。

## Decisions
- 统计只渲染模型分组，网格改为单列；原有“至少完整容纳两排后滚动”的测量继续按模型按钮实际换行计算。
- 执行总数继续使用服务端逐对话统计（智能体分组汇总与模型分组汇总等价），不为展示改动统计接口与计数口径。
- 活动区保持独立置顶，不并入空间分组：跨空间的活动对话需要在同一处可见。统计卡片与活动区标题之间的外边距压缩，作为同一领域信息连续阅读。
- 其他对话按所属工作空间分组；组内沿用现有活动倒序。组顺序保存在本机浏览器偏好，只记录用户显式调整过的空间；“默认”空间组固定置于最后，不参与拖动。
- 拖动使用原生 HTML5 拖动事件，仅作用于非默认组的标题区域；键盘可在拖动把手上用 Alt+上下方向键整组移动，避免仅有指针入口。
- 每组默认展示 5 条，展开状态只在当前视图内有效，不进入偏好，避免下次打开自动铺开全部历史。
- 复制统一为共享复制按钮组件：成功后图标切换为勾选并禁用 3 秒，失败保留复制图标并提示手动复制；带文字入口保留原文字，不再重复弹成功提示。
- 排序只跟随用户输入：交互库新增 `user_at` 列，保存时取用户消息与问题答复的最新时间，单调不回退；升级时按现有活动时间回填，避免升级后顺序跳变。分页游标同步使用该列。
- 列表行只展示智能体与模型，不重复展示更新时间：时间对判断当前工作没有增量，且容易让“顺序为何变化”产生误解。
- 浮层悬停移出等待从 0.2 秒延长到 0.5 秒，仅在指针停留期间保持，不改变点击固定视图的规则。
- 对话列表与活动浮窗条目补充对话 ID 与复制入口；行本身仍需整体可点击，因此复制按钮放在行按钮之外，避免嵌套按钮。

## Risks / Trade-offs
- 失去按智能体筛选入口：当前执行的智能体仍可从对话身份与回复标注获知，用户已明确只需要模型分布。
- 分组后跨空间比较依赖组内排序：默认空间固定最后是用户明确要求，不提供“按最近活动跨组排序”。
- 展开状态不持久化：重新打开列表回到 5 条，减少长列表噪声，代价是需要再次展开。
- 排序不再响应智能体输出：正在执行的对话可能排在较旧的用户输入之后，这是用户明确要求的口径；活动提醒与执行统计仍独立体现新输出。
- 原生拖动不支持触控：触控入口仍可通过键盘与组内搜索抵达目标对话，不引入第三方拖动依赖。

## Migration Plan
无数据迁移。组顺序偏好为新键，旧偏好不受影响；首次读取没有偏好时按列表出现顺序展示。规范同步更新统计维度、活动浮窗条目、列表排序与复制反馈，渲染测试与浏览器检查按新布局调整。
