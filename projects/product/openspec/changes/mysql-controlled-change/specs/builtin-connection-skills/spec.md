## MODIFIED Requirements

### Requirement: MySQL 接入与查询职责独立

MySQL 连接技能（Connection Skill） SHALL 维护目标、完整认证、连接测试、数据库发现及受控变更。查询工具 MUST 保持独立内置能力（Builtin），不得将查询编辑、结果或本机偏好变成团队连接配置。MySQL 专业接入程序 SHALL 随 Buildr 安装，无需用户猜测开发检出路径或额外安装数据库客户端。

#### Scenario: 配置后查询

- **WHEN** 用户保存新 MySQL 实例并打开查询工具
- **THEN** 工具使用明确实例与当前版本访问，测试和查询分别核验，密码不进入页面、参数或普通输出

#### Scenario: 变更不改变查询入口

- **WHEN** 用户通过连接技能执行一次受控变更
- **THEN** 查询工具仍只执行单条只读查询，不得因该次变更获得写入能力

## ADDED Requirements

### Requirement: MySQL 受控变更动作

MySQL 接入程序 SHALL 提供 `apply` 动作，只经已明确选定连接的通用启动入口执行。该动作 SHALL 在连接被显式标记为生产环境时拒绝执行；未声明环境时按非生产处理，并在结果中明确标注，并按语句类别分流：

- 数据修改类（`INSERT`、`UPDATE`、`DELETE`、`REPLACE`）MUST 在事务内执行，并提供受影响的生效行数上限；超过上限 MUST 回滚且不保留部分修改。
- 结构变更类（`CREATE TABLE`、`ALTER TABLE`、`CREATE INDEX`、`DROP INDEX` 及经允许的 `DROP TABLE`、`TRUNCATE`）MUST 明确报告已执行且不可回滚，不得表述为可回滚或原子完成。

`apply` MUST 在执行前核对目标环境与实际结构状态，并在执行后回读实际结果。结果未知时 MUST 报告未知并指引重新读取真实状态，不得自动重试。

#### Scenario: 数据修改成功

- **WHEN** 用户在非生产连接上执行一条受影响行数在上限内的 `UPDATE`
- **THEN** 事务提交，返回受影响行数与回读结果，并说明本次修改已完成

#### Scenario: 修改超过上限

- **WHEN** 一条 `UPDATE` 的实际受影响行数超过本次上限
- **THEN** 事务回滚，数据保持修改前状态，返回明确失败

#### Scenario: 结构变更不可回滚

- **WHEN** 在非生产连接上执行一条已允许的 `ALTER TABLE`
- **THEN** 结果明确说明已执行且不可回滚，并给出回读到的实际结构

#### Scenario: 变更结果未知

- **WHEN** `apply` 在网络中断或超时后未取得明确结果
- **THEN** 返回未知状态与重新读取指引，不自动重发语句

### Requirement: MySQL 变更环境与破坏性语句边界

`apply` MUST 拒绝被显式标记为生产环境的连接；连接未声明环境时 MUST 按非生产执行，并在结果中明确标注未声明。破坏性结构语句（`DROP TABLE`、`TRUNCATE`）MUST 默认拒绝，仅当连接配置显式开启允许破坏性语句且目标环境非生产时执行。权限与账号、服务器全局状态、存储过程与触发器、文件导入导出类语句 MUST 始终拒绝，不受该配置影响。

#### Scenario: 生产环境拒绝写入

- **WHEN** 目标连接声明的环境为生产并提交任一变更语句
- **THEN** 语句未发送到数据库，返回环境拒绝

#### Scenario: 环境未声明

- **WHEN** 连接未声明目标环境
- **THEN** 变更按非生产执行，结果明确标注环境未声明；同一连接的只读测试、发现与查询继续可用

#### Scenario: 默认拒绝删除表

- **WHEN** 连接未开启允许破坏性语句并提交 `DROP TABLE`
- **THEN** 语句未执行，返回破坏性语句被拒绝

#### Scenario: 越权语句不受开关影响

- **WHEN** 连接已开启允许破坏性语句并提交权限或服务器全局状态修改
- **THEN** 语句仍被拒绝，开关不放行该类语句
