## MODIFIED Requirements

### Requirement: 智能体服务必须独立维护并随现有宿主交付

智能体服务（Agent Service）MUST 以 `services/buildr-agent/` 为独立源码、依赖、构建及验证单元，拥有接入、统一对话、参与关系、执行协调、私有交互存储和语义事件。系统 MUST 以私有包（Private Package）随现有 Buildr 发行包交付执行核心、通用客户端（Client）、公共契约（Contract）及本机独立进程承载；用户 MUST 不必另装常驻服务、手动启动额外端口或配置另一套本机认证。厂家原生进程继续由各适配器（Adapter）按其实际方式管理。

Buildr 接入主程序 MUST 保留应用配置域（Profile）解析、工作空间（Workspace）及任务（Task）权威查询、浏览器身份认证和既有超文本传输接口（HTTP）与服务端事件流（SSE）入口。`buildr-agent` MUST 通过执行操作、宿主能力和运行管理三组版本化契约使用必要接入能力，不导入宿主业务模块内部实现、不直接改写任务或工作资产，也不依赖浏览器请求／响应对象。公共声明、客户端和进程承载 MUST 能由其他符合约定的宿主复用，不要求 Buildr 业务模块或启动命令。前端仍归属 `buildr-web`，MUST 通过受认证接口使用安全的公开约定，不能直接依赖服务私有存储或厂家软件开发工具包（SDK）。

#### Scenario: 在没有源码相邻目录的正式安装中运行
- **WHEN** 用户从正式 Buildr 发行包安装并打开新对话能力
- **THEN** 所需 `buildr-agent` 构建产物、独立进程入口及运行依赖 MUST 已包含在该发行包的可解析路径中，后台由产品按需发现或启动
- **AND** MUST NOT 依赖开发工作树、相邻源码目录、实验脚本或未交付的本机依赖
- **AND** 浏览器认证及传输 MUST 使用当前 Buildr 接入，后台本机连接按公开契约自动建立，用户无需手动启动或配置

#### Scenario: 单独验证智能体服务的核心行为
- **WHEN** 维护者验证统一对话、交付或停止状态
- **THEN** `buildr-agent` MUST 能以替身执行者（Executor）和显式宿主能力验证自身行为，不要求启动 Buildr Web 或调用真实模型
- **AND** 实际安装验证 MUST 另行覆盖宿主装配、运行依赖及三家真实接入，不能由核心单元验证代替

#### Scenario: 独立产品接入边界验证
- **WHEN** 非 Buildr 最小宿主使用相同交付运行单元与公共客户端
- **THEN** 系统 MUST 能完成对话、交接、回应及停止，不导入 Buildr 的任务、工作空间或网页模块
- **AND** 该验收 MUST 不要求另建面向用户的独立产品、单独发行包或自研执行者

### Requirement: 原生进程必须按拥有关系和真实存活状态管理

系统 MUST 只管理本接入创建且身份可证明的原生进程与连接。浏览器关闭 MUST 不等于执行后台退出；Buildr 主程序普通退出或重启 MUST 仅断开接入连接，已受理执行及其模型转接、待回应和结果保存 MUST 继续由独立后台持有。断开具体原生接入 MUST 停止其新请求并释放本连接资源，但不能被解释为账号退出、历史删除或活动命令已经停止。

执行后台自身退出 MUST 有界处理中断与自有资源释放，保留未确认执行的状态，不承诺后台自身退出期间活动工作持续运行。旧后台或相关原生执行的持有状态未确认时 MUST 不启动会造成同一执行重复运行的替代者。兼容后台更新 MUST 按对话执行归属和共享配置唯一维护责任并行承接，新版不得恢复仍由旧后台持有的活动执行；不兼容升级仍遵循真实空闲和有界交接。主程序重连 MUST 不触发新的执行恢复代次。

#### Scenario: 前端关闭后重新打开
- **WHEN** 对话页面关闭而执行后台及原生执行仍在运行
- **THEN** 重新打开 MUST 能观察原执行及其待回应事项，不因页面关闭创建第二次执行

#### Scenario: 断开存在活动执行的接入
- **WHEN** 用户断开正在执行或等待回应的原生接入
- **THEN** 系统 MUST 保留对话与已有成果，并准确表达中断、仍有活动工具或状态未知的观察
- **AND** MUST NOT 显示未经确认的“已停止”，也不能关闭外部桌面应用或其他连接的工作

#### Scenario: 后端重启发现未确认执行
- **WHEN** 执行后台自身恢复后发现上次执行未有确认终态
- **THEN** 系统 MUST 先恢复准确配置并观察原生状态与历史，再按既有配置域策略判断是否可安全接续
- **AND** MUST NOT 仅凭原进程号不存在或传输连接断开自动重发上一条指令

#### Scenario: Buildr 主程序重启而后台仍存活
- **WHEN** Buildr 主程序重启并发现原独立执行后台
- **THEN** 系统 MUST 重新连接并观察原执行，保留原生身份、后台代次和准确待回应
- **AND** MUST NOT 调用后台退出或以新启动为由自动发送续做
