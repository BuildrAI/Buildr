## Context

见 proposal.md。已有 `resourcesReleased` 表示控制资源释放，不证明旧命令结果。已有手动继续使用 `continueRunId`、稳定请求身份和原配置；提交新轮时已经保留旧轮结果、工具条目及准确执行引用。

## Goals / Non-Goals

**Goals:** 只为用户明确要求的原目标接续开放窄入口，继续前先核对未知结果。

**Non-Goals:** 不开放普通发送、自动恢复、模型切换、待决定交接或任意强制解锁；不替代进行中的完整遗留执行控制改造。

## Decisions

- 复用手动继续而非重写状态。只有已受理未知原轮、资源释放准确成立、没有待决定或本机在途工作、原选择保持一致时放行；旧轮仍保存未知。
- 预览与真实发送共用同一判断，并保留准确版本校验；独立后台发送门禁也消费该判断，避免只放开预览。
- 使用新恢复提示先核对现状，不重发原文、不逐条重放工具。普通发送与队列保持保守，自动恢复仍不接续未知结果。

## Risks / Trade-offs

- [独立命令可能仍运行] → 保留其未知状态、准确来源及原轮引用，恢复提示必须先核对该命令，不能重做操作或扩大权限。
- [释放证明后发生新工作] → 要求当前代次、当前版本和无在途工作；原生写入冲突仍由原接入拒绝。
- [其他活跃变更也调整继续逻辑] → 本变更只增加显式继续条件，不实施其普通新指令及保留执行界面；集成时核对差异，不覆盖其他任务。

## Migration Plan

无需迁移旧数据。旧记录缺少资源释放证明时继续拒绝。最小更新后先通过准确观察确认当前代次，再为用户指定原轮预览和发送一次。
