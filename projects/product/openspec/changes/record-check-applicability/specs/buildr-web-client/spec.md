## ADDED Requirements

### Requirement: 任务详情必须区分检查未执行与不适用

任务详情的方案审查、实现审查与开发验证目录项 MUST 按当前事实区分三种呈现：已有专业结果时展示结果摘要；无结果且工作摘要检查结论为 `not-applicable` 时展示不适用及其理由；无结果且无结论时展示未执行，MUST NOT 把不适用与未执行合并为同一占位。理由 MUST 能在对应内容区直接阅读。

#### Scenario: 不适用理由可见
- **WHEN** 任务详情读取到某检查的工作摘要结论为 `not-applicable` 且无真实结果
- **THEN** 对应目录项 MUST 标注不适用并在内容区展示登记的理由
- **AND** MUST NOT 把该理由渲染为已通过或待执行的占位
