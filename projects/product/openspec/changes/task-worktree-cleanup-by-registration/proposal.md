# 工作树清理不扫描已登记检出

## Why

清理任务工作树时，提供者会递归扫描检出目录，确认没有“未登记的嵌套 Git 仓库”。在单仓工作空间里，检出目录包含 `node_modules`、`build` 等内容，扫描超过 1 万个目录或 5 秒上限后拒绝清理——即使证据完整、目标工作树干净且已交付。

## What Changes

- 有存储证据时，清理只按登记对象逐项执行，不再扫描检出目录内容。
- 无历史恢复仍做有界扫描：只在登记对象范围内查找嵌套仓库，并跳过依赖与构建目录。
- 每个目标仍逐项核验 Git 登记、公共目录、分支、干净状态、保留引用与占用。

## Impact

- 能力：`git-worktree-provider`（任务工作树检查与清理）。
- 不改变创建、证据结构与交付核验。
