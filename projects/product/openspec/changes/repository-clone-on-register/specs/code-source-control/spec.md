## ADDED Requirements

### Requirement: 缺失代码目录的显式克隆入口

源代码管理 MUST 为已登记但本地目录缺失的 git 代码库实例提供「克隆到本地」入口；该动作 MUST 使用登记来源的远程地址、远程名与集成分支执行真实 `git clone`，由后台执行器异步进行，执行结果通过同一来源清单反映。克隆入口 MUST NOT 对已存在真实目录的实例重复克隆。

克隆期间系统 MUST 展示该实例正在克隆的状态并防止对同一实例并发发起；克隆建立 `.git` 后可被正常读取，前端及读取方不再标记为缺失。克隆失败后系统 MUST 保留实例条目、返回可理解的失败原因，并继续提供同一克隆入口重试；失败 MUST NOT 改变登记数据或其他实例状态。

#### Scenario: 登记库目录缺失时发起克隆
- **WHEN** 已登记 git 代码库的本地目录不存在，用户点击克隆到本地
- **THEN** 系统 MUST 以登记来源后台克隆，清单中该实例展示克隆中状态，完成后作为可读取来源呈现

#### Scenario: 克隆进行中重复触发
- **WHEN** 某实例正在后台克隆，用户再次点击克隆到本地
- **THEN** 系统 MUST 拒绝重复发起并提示仍在进行，不产生第二个克隆进程

#### Scenario: 克隆失败后的重试
- **WHEN** 后台克隆失败（网络、认证或目录冲突）
- **THEN** 系统 MUST 展示失败原因并保留克隆到本地入口，再次触发执行一次新的克隆

#### Scenario: 克隆收敛为已有目录
- **WHEN** 后台克隆启动前或执行中目标目录已由外部建立
- **THEN** 系统 MUST 结束克隆并把实例表达为可读取目录，不得删除或覆盖既有内容
