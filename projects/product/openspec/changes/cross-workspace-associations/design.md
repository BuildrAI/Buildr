## Context

现有关系保存在对话记录的 `taskIds`，旧记录只有 `taskId`，两者隐含对话所属空间。任务侧按空间和任务编码反查对话；当前选择任务整行会切换关系，已关联导航另行常驻。宿主校验已登记空间与真实任务，独立对话服务不拥有任务记录。

## Goals / Non-Goals

- 关系在两端一致，按准确身份发现与导航；保留原对话空间、目录和执行。
- 不新增通用关系平台、不复制任务数据库关系、不创建任务或自动发送消息。
- 沿用现有 React、Ant Design、宿主和对话版本事务，不引入依赖或先做临时原型。

## Decisions

1. **唯一关系来源**：新增 `taskLinks: {workspaceId, taskId}[]`；缺失时将旧 `taskIds/taskId` 解释为本空间引用。旧字段只投影本空间部分，旧写入更新本空间部分并保留跨空间引用；显式新字段维护完整集合，混用输入拒绝。新增逐项宿主校验，解除失效引用不要求对象仍存在。保存仍以当前对话版本为条件。
2. **同一来源跨空间**：关联目标必须是当前宿主可验证的工作对象；不得跨接入来源混用内部范围标识。默认工作空间的对话也能关联已登记空间的任务，但默认空间本身没有任务。
3. **任务反查**：任务筛选按目标空间和编码匹配完整引用，跨对话所属空间分页返回，保留旧数据回退；宿主传入可访问空间集合。不在任务库重复写关系。
4. **精确发现**：任务使用现有有界列表按空间逐页读取后匹配完整名称或编码；对话使用全空间摘要列表逐页匹配完整标题或标识。请求可取消，输入变化使旧结果失效，局部失败明确提示而非报告无匹配。不先加载全部原始消息，不自动选择唯一匹配。
5. **共同交互**：共用关联浮层外壳，导航与解除使用不同控件；主入口不显示名称或编码。悬停可移入，短暂移出不立刻关闭；点击/键盘可固定，Esc 和点击外部关闭。新增和解除不收起浮层，长列表有界滚动。
6. **草稿兼容**：未创建对话仍可选择任务，跨空间引用随首次实际发送保存；不因建立引用提前创建空对话，不把异空间任务编码当成本空间任务传入发送。
7. **智能体入口**：`link-task` 可选任务空间，默认当前空间；追加完整引用而不丢失异空间关联；读回准确引用集。工作上下文携带完整引用。

## Risks / Trade-offs

- 同名同码 → 始终展示空间和准确标识，复合键去重，不自动消歧。
- 跨空间或对象不可读 → 保留引用并显示不可确认，可明确解除；不显示虚假零。
- 精确发现遍历多页有成本 → 仅搜索时执行、分页有界、可取消；后续有实际规模证据再引入专用索引，不先造查询平台。
- 后台更新导致版本冲突 → 本次关系不写入，保留用户输入并刷新当前事实，禁止覆盖或自动重放未知结果。
- 老后台兼容 → 新字段属于运行输入，开发/交付按现有公开包准备与后台升级机制采用；不手写安装产物。

## Migration Plan

读取兼容旧记录，正常关系写入时物化完整引用；不批量重写历史。旧客户端写入不会移除异空间引用。候选中验证真实协议与旧字段兼容，再按独立收尾授权集成。
