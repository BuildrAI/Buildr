## MODIFIED Requirements

### Requirement: 对话入口必须可以查看并维护所属任务引用

每段内部对话（Conversation）MUST 提供关联任务（Task）的入口，允许选择可访问的已登记工作空间（Workspace）内已有任务建立或解除关联。引用 MUST 包含准确工作空间及任务身份，允许对话和任务属于不同空间。新增前 MUST 由宿主核对真实任务，解除 MUST 只移除指定引用，不删除任务或对话，不改变所属空间、目录、执行、任务状态或发送消息。系统 MUST 不在关联入口创建任务或建立通用关系管理器；未关联任务时对话 MUST 继续可用。任务侧 MUST 反查同一份权威关系，不独立保存副本。既有同空间引用 MUST 保留，旧字段更新 MUST NOT 丢弃其他空间引用，版本冲突 MUST NOT 覆盖当前集合。

#### Scenario: 从对话关联已有任务
- **WHEN** 用户在对话关联入口明确选择已核对的任务
- **THEN** 系统 MUST 保存准确空间与任务引用并更新数量
- **AND** 对话历史、执行状态与任务记录本身 MUST 不受影响

#### Scenario: 解除或更换任务关联
- **WHEN** 用户使用独立解除动作移除一个引用或新增另一引用
- **THEN** 系统 MUST 只修改指定关系并保留原任务、对话与其他引用
- **AND** 任务侧反查 MUST 反映最新关系

#### Scenario: 多任务双向导航
- **WHEN** 一段对话关联两个不同工作空间中编码相同的任务并刷新
- **THEN** 两个引用 MUST 分别保留，两端 MUST 能打开准确空间的对应对象
- **AND** 两个任务的关联对话 MUST 都包含该对话

#### Scenario: 逐项解除关联
- **WHEN** 用户移除一个引用并提交过期对话版本
- **THEN** 系统 MUST 报告冲突并保留当前完整集合，不自动重放

#### Scenario: 旧客户端不覆盖跨空间引用
- **WHEN** 已有跨空间引用的对话收到旧同空间任务字段更新
- **THEN** 系统 MUST 只替换同空间部分，其他空间引用保持不变
- **AND** 旧记录只包含任务编码时 MUST 按原对话空间解释

### Requirement: 内部对话必须具有独立稳定身份和准确工作范围

Buildr MUST 为每段内部对话（Conversation）保存稳定身份、标题、所属工作空间（Workspace）、准确起始目录（CWD）及观察版本。标题、可见历史和入口 MUST 不随执行方切换而改变归属。普通对话 MUST 不要求关联任务（Task）；每段对话 MUST 可以保存零到多个包含准确工作空间身份的任务引用，允许跨已登记工作空间关联，与任务构成多对多关系，旧单任务引用 MUST 无损兼容读取，创建后 MUST 可以按当前观察版本设置、更换或解除，任务身份 MUST 由宿主权威校验且 MUST 不复制任务状态。工作目录 MUST 在首次发送前明确可见并固定到该原生执行范围，查看其他页面 MUST 不自动改写它或注入页面内容。

#### Scenario: 普通咨询无需任务
- **WHEN** 用户从全局入口创建普通对话
- **THEN** 系统 MUST 创建独立对话并显示当前保存的工作空间（Workspace）与执行位置，不强制创建任务（Task）
- **AND** 创建或打开动作 MUST 不自动发送模型指令

#### Scenario: 创建后维护任务引用
- **WHEN** 用户对准确对话明确设置、更换或解除任务引用并提供当前观察版本
- **THEN** 系统 MUST 校验任务身份后原子保存新引用，隐藏、标题等其他字段 MUST 不被该动作改写
- **AND** 任务不可用、版本冲突或工作空间不受支持时 MUST 拒绝并保留原引用与全部历史

#### Scenario: 浏览另一工作对象
- **WHEN** 用户在保留当前对话时打开另一任务或项目页面
- **THEN** 当前对话的身份、草稿、归属和执行位置 MUST 保持
- **AND** 新页面内容 MUST 只有在用户明确加入时才成为交付输入

### Requirement: 任务入口必须只维护内部对话引用

一个任务（Task）MUST 可以具有多段内部对话（Conversation），任务入口 MUST 对零、一、多条实际关系统一展示关联数量浮层，支持关联已有对话并选择准确对话。创建前 MUST 核对已登记工作空间（Workspace）及任务身份，保存任务引用而非复制任务状态。内部关系 MUST 不混入旧外部原生会话（Session）关系数量，也不因新增参与者而重复关联。关联 MUST 不授权跨任务执行或建立通用关系管理器。

#### Scenario: 任务尚无内部对话
- **WHEN** 用户在无关联的任务浮层中明确选择新对话
- **THEN** Buildr MUST 展示关联该准确任务的新草稿输入界面，不因展开关联浮层自动创建对话
- **AND** MUST NOT 自动寻找或打开外部桌面会话

#### Scenario: 任务存在多个内部对话
- **WHEN** 一个任务有多段内部对话
- **THEN** 系统 MUST 允许用户按对话标题、时间及状态选择准确目标
- **AND** MUST NOT 仅根据最近活动或当前 Agent 品牌猜测目标

#### Scenario: 点击必须展示准确对话
- **WHEN** 用户点击关联对话或从多条清单选择一条
- **THEN** 系统 MUST 展开对话面板并读取该准确身份，失败时 MUST 展示错误，不发送消息

### Requirement: 智能体执行任务必须维护当前对话关联
在准确绑定的 Buildr 内部对话中，智能体 MUST 在成功创建、激活或明确接续本轮实际执行任务后维护该任务与当前对话的关联，不要求用户手动补关联。系统 MUST 提供接受准确任务身份、在同次调用内读取当前集合并按已观察对话版本条件写入的追加关联动作；调用方 MUST 也能提供明确观察版本进行校验，引用包含任务空间，未指定时使用当前对话空间，复用宿主准确对象校验及版本化写入，MUST 保留其他关联；重复关联 MUST 不创建重复关系或修改任务状态。仅提及、只读查询、浏览页面 MUST NOT 自动建立关系。缺少准确对话绑定时 MUST NOT 按最近对话、进程或目录猜测。任务登记成功与对话关联成功 MUST 分别核对，关联失败 MUST 保留已成立任务和其他关系，不冒充已关联或回滚任务。

#### Scenario: 智能体创建任务后自动关联
- **WHEN** 智能体在已绑定内部对话中创建本轮实际执行任务成功
- **THEN** 智能体 MUST 使用当前对话观察版本追加该任务并核对保存结果，用户无需点击关联

#### Scenario: 接续多个任务
- **WHEN** 智能体明确接续本轮第二个实际执行任务且当前对话已有第一个关联
- **THEN** 新关联 MUST 保留第一个任务，重复追加 MUST 不改变集合或发送模型指令

#### Scenario: 版本变化或任务不可用
- **WHEN** 追加关联使用陈旧版本或无法核对的任务空间或任务
- **THEN** 系统 MUST 拒绝相关写入，保留任务记录、当前关联及对话历史，智能体 MUST 重读判断而非覆盖集合

#### Scenario: 普通查询不建立关联
- **WHEN** 智能体仅查询其他任务或用户只浏览另一任务页面
- **THEN** 当前对话的关联集合 MUST 保持不变

## ADDED Requirements

### Requirement: 任务与对话关联入口必须采用一致的数量浮层

对话入口 MUST 只显示图标、关联任务和数量，任务详情 MUST 只显示图标、关联对话和数量，不常驻对象名称或编码。无关联 MUST 显示 0；读取未确认 MUST NOT 显示为零。浮层 MUST 默认向上展示并在空间不足时调整，MUST NOT 撑开页面或改变信息流滚动位置。浮层 MUST 支持悬停移入、点击固定、触屏、键盘进入和 Esc 退出；短暂移出 MUST NOT 立即关闭。浮层 MUST 展示已关联项与新增关联搜索，已关联项点击 MUST 只打开详情，解除 MUST 使用独立控件；新增和解除后 MUST 保持浮层打开并同步数量。对象行 MUST 显示名称、准确标识和所属空间，长列表 MUST 有界滚动。

#### Scenario: 零、一和多项使用同一入口
- **WHEN** 任务分别有零、一、多段关联对话
- **THEN** 入口 MUST 均先展开同一浮层，不因只有一项而直接跳转，不因零项自动创建对话

#### Scenario: 连续维护与导航
- **WHEN** 用户新增第二个关联后解除第一个，再点击剩余已关联项
- **THEN** 维护期间浮层 MUST 保持打开并同步数量，点击对象 MUST 打开准确详情而不解除关系

#### Scenario: 悬停与输入不丢失
- **WHEN** 用户从入口移入向上浮层并聚焦搜索框输入
- **THEN** 浮层 MUST 保持可操作，Esc MUST 可关闭，正文滚动位置 MUST 保持

### Requirement: 关联搜索必须精确发现完整对象

关联搜索 MUST 支持任务完整名称或完整编码，以及对话完整标题或完整标识；MUST 覆盖可访问已登记空间的必要分页，不限于首批已加载项。搜索 MUST 只展示全匹配候选，多项同名同码 MUST 分别展示空间，不自动选择或关联。已关联候选 MUST 标明且不重复添加。输入或目标变化后旧结果 MUST NOT 覆盖新状态。局部读取失败 MUST 明确提示，不得把部分结果或读取失败表述为完整无匹配。

#### Scenario: 跨空间同名同码及深分页匹配
- **WHEN** 两个空间有同码任务，且其中一项不在第一页，用户输入完整编码
- **THEN** 搜索 MUST 展示两个准确空间的候选，只有明确点击的对象建立引用

#### Scenario: 完整标题与非全匹配
- **WHEN** 用户输入某对话标题的一部分，随后输入完整标题
- **THEN** 前者 MUST 不作为精确匹配展示，后者 MUST 列出全部精确匹配并允许显式添加

#### Scenario: 迟到及局部失败
- **WHEN** 搜索 A 尚在进行时用户改为 B，或一个空间无法读取
- **THEN** A 的迟到结果 MUST 不覆盖 B；无法读取的空间 MUST 有局部原因，已读取匹配仍可使用
