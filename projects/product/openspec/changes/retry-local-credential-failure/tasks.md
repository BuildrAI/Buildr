# 1. 规格

- [x] 1.1 `agent-conversations` 增补有界重试要求：本机网关租约凭据失效时重新准备并接续恰好一次，身份变化或账号不可用时不接续。
- [x] 1.2 `shared-native-model-accounts` 增补续期期间执行要求：状态短暂降级不中止在途请求、不撤销其正在使用的租约；身份变化或断开仍立即失效。

# 2. 模型访问层

- [x] 2.1 账号状态降级撤销租约时跳过仍有在途请求的租约，其余租约立即撤销；这些租约随所属执行来源释放。
- [x] 2.2 补充模型访问层单元测试：有在途请求的租约在账号降级后不再被判定失效，无在途请求的租约立即失效。

# 3. 对话应用层

- [x] 3.1 新增「本机网关凭据失效」判定，只匹配 Buildr 自己的失败文本与错误码，不并入临时故障允许清单。
- [x] 3.2 该失败在准确执行结束、工具全部结束、无待定请求、账号身份未变化且账号可用时，先撤销该参与者的执行来源与旧租约，再自动接续一次；撤销失败则不接续并保留真实原因。
- [x] 3.3 该接续单独计数并单调结束：第二次同因失败保留真实原因、不再自动重试，且不占用三次临时故障名额。
- [x] 3.4 补充判定与接续边界的测试：判定只命中本机凭据文本，接续恰好一次，同因再次失败即停止；待定请求、未结束与仍在运行的工具仍然不接续；接续时账号已不可用或身份已变化由正常发送路径重新核验，失败的接续如实记录且不再接续。
- [x] 3.5 接续前核对账号可用性：账号已断开或停用时不接续；账号仍启用但状态不可用时按原生账号重新核对一次，核对后仍不可用则不接续，核对可用才撤销来源并接续。
