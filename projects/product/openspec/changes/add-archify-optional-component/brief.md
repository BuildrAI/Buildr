# Archify 可选组件接入

让需要绘图的用户通过 Buildr 安装固定版本 Archify，并统一管理更新和卸载。

当前 Archify 来自用户级目录。本次提供 2.16.0 正式发行包作为可选组件（Component），默认不安装，选用后交付完整技能（Skill）和程序。图示源文件与 HTML 留在项目目录，卸载不删除这些成果。

本次不改变上游绘图行为，不新增开发前置条件，不接管现有用户级同名目录。主要风险是发行体积与同名安装冲突，分别通过固定完整发行包和现有所有权检查处理。

验收包括默认不启用、完整安装后可渲染、重复同步稳定、用户改动受保护、卸载保留图文件与打包完整性。具体边界见 [方案](proposal.md)、[设计](design.md)、[规范](specs/archify-component/spec.md) 和 [任务](tasks.md)。
