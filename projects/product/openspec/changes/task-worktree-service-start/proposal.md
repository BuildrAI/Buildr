# 任务按自己的工作树启动服务

## Why

任务的工作树已经归属该任务，但任务范围声明按项目登记，公共服务未必出现在每个项目里。任务本地验证按范围过滤，导致工作树里实际存在的服务无法启动。

工作树是任务现场的真实事实：任务里能看到哪些目录，就应该能启动哪些服务，与项目范围无关。

## What Changes

- 任务本地验证的服务集合只由本任务工作树决定，不再按任务范围声明过滤。
- 工作树归属以提供者证据与当前 Git 观察为准：同一仓库公共目录、同一检出目录、同一分支才算。
- 任务记录与范围声明不变；同一任务的所有服务仍共用一个泳道。

## Impact

- 能力：`service-runtime`（任务本地运行）。
- 不新增命令、配置字段或登记；不改变运行定义、泳道与前端连接语义。
