## MODIFIED Requirements

### Requirement: 原型路径接入真实工作现场
页面 MUST 延续已确认原型的柔和视觉、原工作区左侧的一级区域图标及其可悬停查看或固定展开的二级导航、四区概览、完整任务列表、详情优先呈现目标/进展/下一步/成果以及并排资料阅读。项目入口 MUST 到达同一真实对象并保留可返回路径。窄屏 MUST 可用且无横向页面溢出。工作台任务列表 MUST 按任务状态选择每条任务展示的摘要来源。

#### Scenario: 接续工作与阅读
- **WHEN** 用户从概览打开任务、阅读关联资料并返回
- **THEN** 界面 MUST 显示真实内容并恢复原有列表范围和筛选，不跳到第一条任务。

#### Scenario: 专业动作仍可达
- **WHEN** 用户需要原型、审查、验证或父子任务维护
- **THEN** 页面 MUST 保留对应已有能力和安全约束，不以新布局删除专业结果。

#### Scenario: 任务行摘要按任务状态选择
- **WHEN** 工作台任务列表展示一条任务
- **THEN** 进行中任务 MUST 显示工作摘要的最近进展
- **AND** 终态任务 MUST 显示任务结果摘要
- **AND** 进行中任务在工作摘要缺失时 MUST 回退到任务结果摘要
- **AND** 终态任务在结果摘要缺失时 MUST 回退到任务目标，MUST NOT 以工作摘要的最近进展充当结论
- **AND** 摘要来源 MUST NOT 因工作摘要的更新时间早于任务结果写入时间而改变
- **AND** 任务详情页 MUST NOT 受该选择影响，交付结果仍按任务结果摘要呈现
