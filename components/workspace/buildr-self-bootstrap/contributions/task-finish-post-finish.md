### Buildr 自举工作空间激活

本节只适用于 Buildr 自举工作空间。已交付的真实 Git 变化命中自举输入时，交给 `buildr-self-bootstrap-sync`，由它唯一执行同步、精确提交推送、开发应用更新、入口检查与最终诊断。

新收尾使用明确基线、交付提交、分支、远端和宿主作为待核验输入；任务编号可选，不要求任务记录存在或已完成；不要求旧收尾运行、候选、交接或对账。脚本自行复核当前事实，激活失败只形成独立遗留事项，不撤销交付或重复推送业务内容。环境清理由原资源所有者独立处理。

未安装自举组件的普通工作空间或未命中自举范围的改动不触发；协作者更新同样按实际变化判断，只有诊断漂移而没有明确变化范围时先核对来源。旧执行入口已退役，历史记录和资源按实际归属保留。
