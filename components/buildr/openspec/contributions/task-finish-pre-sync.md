在任何 canonical spec sync 前，从 Buildr workspace root 和 Project registry 解析 `<workspace>`、`<project>` 与 `<change>`。当 Change 有 delta specs 时，先调用 Task Finish 的 archive rehearsal helper 在隔离 planning copy 中使用当前 OpenSpec CLI 预演 archive；记录 OpenSpec version、Change、owner、结果与 cleanup status，失败或 cleanup retained 时停止。没有 delta specs 时记录 not-applicable。随后运行 `buildr openspec check <change> --stage pre-sync --project <project> --target <workspace> --json`；active change 的 apply 阶段不得预写 canonical specs，只有结果为 `ok: true` 后才可执行 agent-driven canonical sync。结果不是 `ok: true` 时，停止尚未执行的 canonical sync、final assurance、archive、commit、rebase、merge、push 或 cleanup。Rehearsal 不替代 pre-sync/post-sync，也不得修改真实 planning root。
