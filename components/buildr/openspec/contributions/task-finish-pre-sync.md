在任何 canonical spec sync 前，从 Buildr workspace root 和 Project registry 解析 `<workspace>`、`<project>` 与 `<change>`，并运行 `buildr openspec check <change> --stage pre-sync --project <project> --target <workspace> --json`。active change 的 apply 阶段不得预写 canonical specs；只有结果为 `ok: true` 后才可执行 agent-driven canonical sync。结果不是 `ok: true` 时，停止尚未执行的 sync、archive、commit、rebase、merge、push 或 cleanup。
