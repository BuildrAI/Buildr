# 任务验证

本技能（Skill）是 `buildr.task-verification/v4` 的默认提供者。项目拥有测试代码、替身（fixture/mock）、构建脚本和环境；智能体（Agent）选择并调用 Maven、Gradle、npm、Playwright、Browser、HTTP 等真实工具。Buildr 只维护项目测试地图和开发完成后的任务验证报告，不生成计划或统一运行测试。

## 按本次目标进入

| 目标 | 读取与动作 |
|---|---|
| 选择已有检查 | 核对任务目标、真实改动和相关项目测试地图，按下节选择与执行；遇到服务绑定、外部代码库或位置诊断时读[路径根与声明字段](references/project-verification-v4.md) |
| 维护测试地图 | 读[地图写入步骤](references/maintain-map.md)，依据实际构建、测试、脚本、持续集成（CI）和团队边界维护少量稳定测试体系；不在地图中逐项登记测试文件 |
| 查看或登记已有报告 | 读[报告登记步骤](references/record-report.md)；查看只执行 `inspect`，登记先核对已有结果适用性，不因登记重新调查测试体系或运行检查 |

项目测试地图位于 `projects/<project>/verification.yml`，使用 `buildr.project-verification/v4`。只选择检查或登记报告时不加载地图写入步骤；缺少测试时交给 `project-testing` 在实际改动范围内补齐，不在本技能中生成框架或测试。

## 选择与执行已有检查

从改动追踪到用户实际使用的交付物（Artifact），核对受影响的公共行为、构建与资源依赖、安装或部署后入口及平台差异。先判断已有检查的内容、环境、目标和覆盖范围是否仍适用；复用有效结果，只补充新改动、失败或明确未解决风险所需的检查。保留原执行事实并说明复用依据，无法确认适用性的历史结果不作为当前成功证据。

需要执行时，智能体（Agent）直接调用项目工具。执行地图入口前重新读取当前地图的 `locations` 及根目录适用规则，在对应 `ready` 位置按声明的 `argv` 与解析后的 `cwd` 调用，保留项目拥有的包装命令（wrapper），不得简化为系统 `PATH` 上的裸 `node` 或 `npm`；`kind: agent` 按真实根和指引选择工具。路径根、服务范围和位置诊断的解释见[声明字段](references/project-verification-v4.md)。`unavailable` 只表示该族当前目录不可用，说明局部缺口并继续其他可执行检查，不使有效地图或已有真实结果失效。

优先运行相关检查。扩大到完整回归应有改动影响、项目必需要求或明确未解决风险作为依据；环境冒烟仅在目标适用、环境可用且已获授权时执行。必要的构建、安装后功能和平台检查应在开发完成前执行，不能仅因被归类为发布检查而推迟；优先复用真实入口和隔离环境，外部副作用仍遵守原有授权。

自动选择结果、测试名称、位置可用和命令成功都不能替代覆盖判断。完整入口必须覆盖测试族声明的范围；发现缺少测试、入口失配或漏选时，在授权范围内调整声明，或交给 `project-testing` 补齐并验证。失败时修复并只重跑受影响检查；无法完成的部分如实说明。

开发中的临时反馈不写任务验证报告（Task Verification Report），不创建 Buildr 计划（Plan）、执行（Run）、执行记录（Execution Record）或流程状态。

## 前端检查与工具选择

前端验证按[前端协作与证据](references/frontend-verification.md)区分项目自动化依赖、智能体（Agent）现场工具、交互观察和视觉审查（Visual Review）。只有任务涉及前端时读取；不要求统一浏览器提供者（Provider）。

## 形成完成结论

开发完成后逐项交代受影响边界对应的有效检查或未覆盖项，区分缺少测试、未执行、环境不匹配和执行失败。仍有必要边界未验证时报告验证不完整，不能将部分通过表述为全部验证。开发阶段的结果经适用性核对后直接纳入报告，不因阶段转换重复验证。

明确结论与未覆盖项后，按[报告登记步骤](references/record-report.md)选择合法写入入口和已观察版本。登记保存实际验证事实，不触发重新执行检查或新增流程状态。

## 报告边界

报告只说明实际验证情况，不等于业务验收、任务完成、提交、推送、部署或发布。`not-passed`和`incomplete`如实保留；下一步由智能体依据用户目标和当前事实判断，不生成统一`proceed|blocked`。
