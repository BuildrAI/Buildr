# 任务资产观察与审查

## Purpose

在非简单 Workspace 任务期间持续维护轻量资产 observation，在任务结束时完成资格审查、人工决定和独立维护任务交接。

## Consumer Obligations

consumer 必须提供 canonical Workspace root、稳定来源 task identity、task owner 和当前可观察任务事实；Task Development consumer 只在正式 handoff 前触发 finalize 并等待结果，不得自行汇总信号、执行资格门禁或判断最终沉淀内容。Task Finish 不得读取 observation 或触发 finalize。consumer 处理 accepted observation 时必须提供独立目标 task identity，并在完成时按 outcome 提供类型化去向证据。

## Minimum Guarantees

provider 必须把 observation 保存到 canonical Workspace 的 `.buildr/asset-review/inbox/`，保证该目录由根 `.gitignore` 排除，并让主 checkout、linked task worktree 与嵌套执行路径解析到同一 inbox；不同物理 Workspace checkout 不得通过用户级状态合并。provider 必须以独立 observation id 隔离并发任务，以 owner 校验和原子替换保护单文件，并安全迁移 identity 匹配且无内容冲突的 v2 用户级 observation。

provider 只保存精炼事实和证据引用，不保存隐藏推理或完整任务轨迹；候选必须限制为 Rule、Skill、capability Contract 或 product follow-up，并核验现有资产覆盖。没有合格且未解决的候选时必须确定性返回 `discarded`；存在候选时才进入人工 accept/reject。accept 只建立独立新任务 handoff，不授权在原任务修改长期资产。

## Effects and Authorization

provider 可以创建、更新、迁移和精确删除当前 owner 的 Workspace-local untracked observation。迁移冲突、identity 损坏或 owner 不匹配时必须保留来源与目标并 fail closed。finalize 可以返回 `discarded` 或请求人工 accept/reject；Rule、Skill 或 capability Contract 的 tracked 维护记录必须与独立新任务中的实际资产修改一起提交，product follow-up 只向 OpenSpec 交接。

## Result Evidence

provider 返回 observation identity、canonical Workspace root、owner、lifecycle status、覆盖结论、已审查证据摘要、候选类型、人工决定、独立任务 handoff 和可验证去向。finalize 结果必须明确为 `no-observation`、`discarded` 或 `awaiting-human`。

`asset-integrated` 必须包含 tracked maintenance record、commit、target branch 和 remote ref；`product-absorbed` 必须包含 change identity 和实际 proposal/design artifact；`no-change` 必须包含独立任务 identity、核验结论和稳定证据引用。完成后必须说明 observation 已删除；任一证据不足时必须保留。

## Decision Points

canonical Workspace 无法解析、`.gitignore` authority 缺失、owner 或 Workspace identity 不匹配、legacy/target 内容冲突、候选与权威资产冲突、人工决定缺失、handoff 未进入独立任务、tracked 资产变更尚未集成、product follow-up 尚未吸收来源事实或 no-change 缺少正式核验时，provider 必须停止删除或沉淀。provider 不可用或本地状态不可写时，consumer 必须报告降级，不得伪造 observation 结果。

## Allowed Variations

provider 可以采用组织自定义评分和证据选择方法，但必须保持 Workspace-local untracked authority、linked worktree 共享、单任务所有权、候选类型、无候选 discard、人工决定、独立新任务 handoff、类型化删除条件和无完整轨迹边界。实现可以替换内部 helper，但不得要求公共 CLI、daemon、watcher、数据库、全局索引、CAS 或复杂锁。
